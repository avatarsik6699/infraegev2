## Главная мысль в одном абзаце

`infraegev2` — наблюдаемый продукт и владелец своей инфраструктуры. Он создаёт полезные сигналы и
управляет VPS, контейнерами, сетью, резервными копиями и восстановлением. `sre-kit` — универсальная
система наблюдения: получает сигналы от разных продуктов, приводит их к общему виду, хранит,
показывает и на их основании создаёт оповещения. Недоступность `sre-kit` не должна останавливать
`infraegev2`, а `sre-kit` не должен разворачивать или изменять инфраструктуру продукта.

## Снимок текущей интеграции

На момент последней сквозной проверки 23 августа 2026 года always-on Project `infraegev2`
содержал семь включённых Source, и все они имели статус `ok`. Это исторический снимок успешной
проверки, а не обещание текущего состояния. Актуальное состояние показывают
`make sre-management ACTION=status`, Dashboard и Source detail; локальный `sre-kit-local` является
выключенным по умолчанию ручным fallback и не является production authority.
