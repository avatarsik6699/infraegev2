## Goal

Перед запуском kodumka.ru с оплатой (общий релиз 192–197) проверить все учебные материалы: курс
Python (30 уроков), курс Excel (15 уроков) и 25 тем ЕГЭ (1–19, 22–27, 203 подтемы с «Практикой и
итогом»). Найти и исправить фактические ошибки, неверные ответы, пробелы в объяснении,
нарушения шаблона и опечатки, не меняя авторскую последовательность.

Решение архитектора 2026-10-19: промежуточного звена в виде стенда больше нет — правки вносятся
прямо в код уроков на сайте (`apps/web/src/entities/{lesson,course}/content/`), и сайт
становится единственным источником учебного текста. Стенд (`content/lesson-design/`)
замораживается как архив; выгрузка из него отключается, чтобы не затереть правки сайта. Проверки,
которые сейчас сверяют сайт со стендом, переводятся на проверку самого сайта. Аудит идёт одной
единицей за раз, в одной сессии, без параллельных агентов; каждый список находок утверждает
архитектор.

### Порядок работы (решение архитектора 2026-10-19)

1. Архитектор вручную проходит уроки по порядку (курс Python → курс Excel → темы по порядку
   экзамена) и присылает замечания.
2. Каждое замечание добавляется в Backlog отдельным пунктом (`T12`, `T13`, … в группе своей
   единицы) и исправляется в коде урока на сайте: текст — в модуле урока, схема — строкой вызова
   построителя в манифесте и `site_media.py`, запускаемая программа — в манифесте, задача — в банке.
3. Во время правок проверки не запускаются. После всех исправлений — один полный прогон и ретест
   всех уроков (`T1`), затем итоговая сверка (`T10`).
