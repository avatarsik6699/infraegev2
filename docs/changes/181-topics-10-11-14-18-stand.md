## Goal

Перестроить на демо-стенде четыре темы ЕГЭ по [пайплайну](../runbooks/lesson-pipeline.md) и
[порядку волны](../runbooks/lesson-wave.md), этапы 1–8 (SPEC §9, пункт 1): № 10 «IP-адреса и маски»
(`docs/artifacts/lessons/10.md`, «Решу ЕГЭ» — тема 348), № 11 «Объём информации: пароли и записи»
(`11.md`, тема 350), № 14 «Системы счисления: операции и неизвестные цифры» (`14.md`, темы 220,
239, 274), № 18 «Робот-сборщик монет» (`18.md`, тема 412). Исходники архитектора уже в git под
нужными именами; нумерация заданий совпадает с каталогом «Решу ЕГЭ».

Агент на тему (Opus 5.5, effort high): фаза А — частоты и карта, контрольная точка, фаза Б —
тексты, задачи, схемы и проход глазами ученика. Оркестратор — общие файлы, гейт, браузер, свой
проход, публикация. Пересечения с готовыми темами: 14 — с темами 5 и 8 (запись чисел, перевод),
11 — с темой 7 (объём, бит и байт); общие термины и схемы переиспользуются, а не дублируются.

Решения архитектора (2026-10-12):
- **Тема 10 решается на Python модулем `ipaddress`** (`ip_network`, `ip_address`, `hosts()` и другие
  средства модуля): ручное двоичное рассуждение объясняет, что считает модуль, и остаётся
  проверкой, а рабочий способ задач — программа. Модуль объясняет сама тема: курс Python отнёс его
  к инструментам одной темы (`course-python/constructs.py`); термины — только для основ Python.
- **Тема 18 решается только в Excel, Python в уроках нет.** Мини-лист и строка формул курса Excel,
  термины `{{xl-…}}`, книги `.xlsx` на задачу; от исходника остаются Excel и ручной разбор, его
  разделы с Python не переносятся. `checks.py` по-прежнему пересчитывает ответы вторым способом
  (это проверка, а не материал урока), а `verify_sheets.py` — формулы мини-листов. Стены поля в
  книгах экзамена — толстые границы ячеек; мини-лист стенда границ пока не рисует — оркестратор
  добавляет их (T2).

Код сайта не меняется.

## Implementation Notes

- Стены (T2) рисуются тенью внутри ячейки (`box-shadow`, `data-w`), а не толщиной границы: сетка не сдвигается. Стена между двумя клетками ставится на одной из них. `block_data` отдаёт `walls` только у листов со стенами — данные курса Excel для сайта не изменились; блоку `SheetBlock` сайта стены и «Поле из файла» понадобятся при переносе темы 18.
- `course-python/constructs.py`: исходник `10.md` числился темой 13 (старая нумерация) — исправлено на 10, `needs.md` пересобран.

- `tracer.py` (по отчёту агента темы 10): условие с вызовом метода (`bits.count('1') == 9`) объяснялось как «даёт `None` — блок пропускается»: `_pure` не считал методы чистыми. Теперь методы, которые только читают объект (`count`, `startswith`, `bit_length` и др.), вычисляются, а если условие нельзя вычислить повторно, ветвь берётся по следующей выполненной строке. Объекты `ipaddress` в панели переменных — «сеть 172.20.76.0/22», «адрес …» вместо `IPv4Network('…')`. Выгрузки курсов для сайта не изменились (`export_course --check`, stale 0).
