# Движок рисования иллюстраций для уроков

Программа рисует иллюстрации и ролики «от руки», без ручной работы: сцена описывается кодом, числа считаются кодом, кадры собираются в WebM, MP4 и WebP. Манера описана в [STYLE.md](STYLE.md), правила публикации — в [SPEC §2.3](../../SPEC.md) и [FRONTEND.md](../../FRONTEND.md).

Принципы:

- **Ясность важнее краткости.** Длины роликов нет ограничения, но одна идея на ролик.
- **Воспроизводимость.** Одна сцена с тем же seed даёт те же кадры. Правка кода видна как правка сцены, а не как новый рисунок.
- **Числа из кода.** Значения, порядок вызовов и повторы считает сцена и сверяет через `assert` с текстом урока.
- **Ошибка раньше, чем в кадре.** Движок падает на символе без глифа и предупреждает об обрезанных и мелких подписях.

## Устройство

| Файл | Роль |
| --- | --- |
| `handdrawn.py` | Ядро: примитивы, `Ink`, `Text`, `Scene` |
| `build.py` | Находит сцены, рендерит, кодирует, пишет `manifest.json` |
| `brand.py` | Знак бренда в углу сцены: разбор SVG знака сайта, плитка «логотип и адрес», проверка пересечений |
| `blocks_tree.py` | Блок «дерево вызовов»: построение рекурсией, раскладка в любой области, рамка вокруг поддерева |
| `rekursiya_chain.py` | Блок роликов про цепочку значений: ряд кругов, дуги вопросов и ответов |
| `rekursiya_*.py`, `specimen.py` | Сцены (видео и статичные рисунки) |
| `fonts/` | Шрифт Neucha и лицензия OFL |
| `reference/specimen.png` | Лист образцов всех примитивов |
| `manifest.json` | Размеры, длительность, подписи и предупреждения собранных сцен (справочно) |

Тесты: `scripts/tests/lesson_media_engine_test.py` (команда в [README](README.md)).

### Холст и координаты

Координаты в пикселях итогового кадра (ширина сцены обычно 1600), начало слева вверху, ось Y вниз. Рисуется в двойном разрешении (`SS = 2`) и уменьшается фильтром LANCZOS: линии получаются гладкими. Внутри примитивов координаты умножаются на `SS`, снаружи о нём знать не нужно.

Кадр в приложении сжимается до ширины колонки (около 640 px на компьютере и 350 px на телефоне). Поэтому подписи не мельче 48 px на холсте 1600 (лучше 56–74), см. STYLE.

### Время

- Каждый элемент появляется с `t0` за `dur` секунд: линия прорисовывается по длине, буквы печатаются по одной. `dur = 0` — появление сразу.
- `accent_at` перекрашивает элемент в акцентный цвет за 0,25 с (главная мысль кадра).
- `vanish_at` растворяет элемент за `VANISH` (0,5 с). Так делают «чистый лист» между фазами или заменяют «= ?» значением.
- `Scene(width, height, fade_start, duration)`: с `fade_start` весь кадр плавно белеет до `duration` (бесшовная петля). `poster_time` — итоговый кадр (когда всё появилось), он же постер и статичная версия.
- Кадры после `settled_at` до `fade_start` одинаковы, сборка рендерит их один раз.

### Примитивы

| Функция | Рисует | Когда брать |
| --- | --- | --- |
| `line`, `arrow` | неровный отрезок, стрелка | связь, направление |
| `curve` | стрелка-дуга | переход между соседями, «вопрос вниз, ответ вверх» |
| `circle` | окружность одним движением | вершина, значение |
| `dashed_ellipse` | штриховая рамка | группа, повтор, «это одно и то же» |
| `box` | скруглённая рамка | таблица, карточка, блок кода |
| `polyline`, `axes` | ломаная, оси со стрелками | график, зависимость |
| `number_line` | числовая ось со стрелкой и засечками | значения n, порядок обхода |
| `cross_out`, `check_mark` | зачёркивание, галочка | неверно и верно |
| `underline` | подчёркивание | заголовок фазы |
| `Text` | рукописные заглавные | любые подписи |

Сцены короче пишутся через помощники `Scene`: `scene.shape(box, x0, y0, x1, y1, key="b1", color=ACCENT)` строит фигуру и добавляет её (сид берётся из `key`), `scene.label("F(4)", (x, y), 72, key="t1")` добавляет подпись. Для расстановки соседних надписей есть `text_width(text, size)`, для проверки строки перед рисованием — `glyph_support(text)`.

Все они возвращают штрихи (списки точек); `Ink(strokes, t0, dur, rng, color=..., width=...)` превращает их в анимируемый элемент. `Text(text, center, size, t0, dur, rng, color=..., anchor="c"|"l", font_path=...)` рисует подпись, `\n` переносит строку.

### Случайность

Общий `random.Random(seed)` даёт «почерк», но зависит от порядка элементов: добавление элемента меняет все следующие. Новые сцены берут `scene.rng(key)`: независимый поток на каждый ключ (`scene.rng(f"node:{n}")`), правка одного элемента не меняет остальные. Существующие сцены остаются на общем потоке, чтобы их одобренные кадры не менялись.

### Неровность и знак

`WOBBLE` в `handdrawn.py` (сейчас 0,65) масштабирует неровность линий, рамок, окружностей и штриховых рамок разом: чтобы изменить общую интенсивность, меняют одну константу и пересобирают сцены. `Scene(..., brand=True)` рисует в правом нижнем углу знак бренда (`brand.py`): 40 px высотой, половинной прозрачности, с адресом `infraege.ru`; `brand=False` отключает его. Знак не входит в `elements`, поэтому не влияет на время сцены.

### Проверки

`Scene.warnings()` возвращает: элементы за холстом, надписи мельче `MIN_TEXT_SIZE`, содержимое, подошедшее к знаку бренда ближе 14 px. Сборка печатает их и пишет в `manifest.json`. `Text` бросает `ValueError`, если в шрифте нет глифа. В Neucha нет `−`, `→`, `←`, `×`, `≠` и степеней: пишем `-`, `·`, слова, стрелки рисуем `arrow`. Знаки `≥` и `≤` движок собирает сам из `>`/`<` и черты под ними.

## Шаблон сцены

```python
"""Ролик «…»: одна идея, откуда числа."""
import random
from handdrawn import Scene, Ink, Text, circle, arrow

NAME = "rekursiya-example"   # имя файлов
LESSON = "rekursiya"         # папка в apps/web/public/lesson-media/ (None — эталонная сцена)
KIND = "video"               # "video" или "still" (один WebP, без видео)

def build():
    scene = Scene(1600, 740, fade_start=9, duration=9.5, seed=7)
    ring = scene.add(Ink(circle((400, 300), 64, scene.rng("ring")), 0, 0.4, scene.rng("ring-ink")))
    scene.add(Text("F(3)", (400, 304), 74, 0.2, 0.2, scene.rng("label")))
    ...
    return scene, {"alt": "краткое имя для скринридера"}
```

Затем: `uv run --no-project --with pillow python docs/artifacts/lesson-media/build.py --only rekursiya-example`, просмотр постера, `LessonVideo` в уроке, `pnpm validate:content`.

## Сборка

`build.py` находит все модули с `NAME` и `build()`, поэтому список сцен нигде не ведётся. `--list` показывает найденные, `--only A,B` собирает перечисленные (имена через запятую), `--out DIR` меняет каталог. Пересобирайте только нужные сцены: байты WebM меняются при каждой сборке.

- **Видео:** кадры PNG → WebM VP9 (CRF 40) и MP4 H.264 (CRF 30), постер WebP. Ширина видео до 1200 px (в колонке ролик занимает около 640 px, постер остаётся в полном размере). Ключевой кадр раз в 5 с: ключевой кадр стоит целого рисунка (около 50 КБ), поэтому при частых файлы разрастаются (раз в 0,5 с — в пять раз, раз в 2 с ролик о двух функциях весил 1,4 МБ), а при редких перемотка запаздывает.
- **Статика (`KIND = "still"`):** один WebP для уроков (ориентир до 80 КБ, жёсткий предел в тесте 200 КБ) или PNG для эталонных сцен. Итоговый кадр берёт `Scene.render_still()`.
- MP4 и постеры воспроизводимы побайтно, WebM нет (многопоточность libvpx), поэтому байты WebM не сравнивают.
- Вес: ориентир 300 КБ на формат, мягкий. Превышение печатается предупреждением.

## Подключение к уроку

Видео — компонентом `LessonVideo` (`src`, `poster`, `width`, `height`, `alt`, `caption`), статичный рисунок — `LessonFigure` (`src`, `width`, `height`, `alt`, `caption`). Оба стоят после абзаца, который иллюстрируют; подпись одна; между рисунком и роликом не меньше двух блоков. `pnpm validate:content` проверяет, что файлы существуют, что оба формата и постер на месте и что в папке нет лишних. Nginx отдаёт папку с Range (206) из образа, Node-сервер так не умеет.

## Как расширять под более сложные схемы

1. **Составные сцены.** Общие детали выносятся в модуль-блок по образцу `rekursiya_chain.py` (функции получают сцену и добавляют элементы). Второй потребитель — повод сделать блок общим; до этого держать в файле урока.
2. **Геометрию считать.** Позиции задаются формулами (`x_of`, `ring_around`), а не подбираются вручную; так схема переживает смену чисел.
3. **Одна идея на ролик.** Если сцене нужна вторая идея, это второй ролик (пример: «С базой» и «Без базы»). Внутри ролика фазы разделяют `vanish_at`.
4. **Стабильный почерк.** Для новых сцен использовать `scene.rng(key)`.
5. **Таблицы и графики.** `box`, `line`, `polyline`, `axes` и `Text` покрывают простые случаи (см. лист образцов).
6. **Чего пока нет.** Фигурных скобок, выносок с изломом, маркерного выделения, штриховки, группового смещения, камеры (масштаб, панорама), моноширинного рукописного текста для кода. Добавлять по мере первой реальной схемы, вместе с образцом на `specimen` и тестом.
7. **Статичные иллюстрации.** `KIND = "still"` плюс компонент `LessonFigure`. Для плотных схем выбирайте ширину холста 1300–1600 и подписи 54 и крупнее: на телефоне рисунок сжимается до 350 px. Ширину и высоту передайте компоненту из размера сцены.
8. **Производительность.** Кадр рисуется 0,3–0,5 с, ролик в 25 секунд собирается около 2 минут. Если сцены станут заметно тяжелее, кэшировать неизменные слои.

## Ограничения

Только Pillow (без альфа-каналов и векторной графики), один шрифт, одна «кисть», линейное время с плавным входом. Обо всех подводных камнях (глифы, Range, GOP, недетерминизм WebM) — в [KNOWN_GOTCHAS](../../KNOWN_GOTCHAS.md).
