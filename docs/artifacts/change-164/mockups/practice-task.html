Алгоритм вычисления функции F(n) задан соотношениями:

F(n) = 1 при n ≤ 2
F(n) = F(n − 1) + F(n − 2) при n > 2

Чему равно значение F(7)?

Запишите целое число в десятичной системе счисления.
Подсказка
Постройте значения по порядку: сначала F(1) и F(2), затем каждое следующее как сумму двух предыдущих.
Решение
1, 1, 2, 3, 5, 8, 13. Ответ: 13.
