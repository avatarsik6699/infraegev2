Зачем нужны база и шаг

В первом примере мы использовали две части определения. Первая — начальное значение, от которого можно начать вычисления. Его называют базовым случаем: F(1) = 1 просто дано, вычислять его не нужно.

Вторая часть — правило перехода: F(n) = 2·F(n − 1) + 1 при n > 1, которое показывает, как получить следующее значение из предыдущего.

Как это выглядит на схеме

Разобранный пример

Найдите F(5), если F(1) = 1 и F(n) = 2·F(n − 1) + 1

Начнём с того, что дано, и будем подниматься вверх.

  1. F(1) = 1
  2. F(2) = 2·1 + 1 = 3
  3. F(3) = 2·3 + 1 = 7
  4. F(4) = 2·7 + 1 = 15
  5. F(5) = 2·15 + 1 = 31

Частая ошибка

НеверноВычислять F(5) через F(4), не зная F(4), и надеяться, что значение «само найдётся».
Как правильноНачать с базового значения F(1) и подниматься вверх до нужного номера.
Идея

База отвечает на вопрос «с чего начать?», шаг на вопрос «как получить следующее?».

Обратите внимание

Без базового случая вычисление не имеет, с чего начаться, и не заканчивается.

Та же цепочка в Python

Python
1def F(n):
2    if n == 1:
3        return 1
4    return 2 * F(n - 1) + 1
5
6print(F(5))  # 31

Что произойдёт, если убрать базовый случай?
Вызовы не остановятся, пока не закончится допустимая глубина, и программа завершится ошибкой.
Чему равно F(3) при F(1) = 1 и F(n) = 2·F(n − 1) + 1?
