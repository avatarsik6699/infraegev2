**Любую такую задачу сначала полезно разделить на четыре действия.** Это позволит понимать назначение каждой части программы.

1. **Получить числа, среди которых будем искать.** Например, все числа от 100 до 200 или только числа, кратные 23.
2. **Проверить условие для очередного числа.** Например, найти его делители и посчитать их.
3. **Вычислить величину, которую требует условие.** Это может быть само число, сумма делителей, наибольший делитель или частное от деления.
4. **Вывести результаты в нужном порядке.**

Число, которое мы сейчас рассматриваем, будем называть **кандидатом**: оно потенциально подходит, но ещё должно пройти проверку.

Например, задача:

> Найти числа от 10 до 30, имеющие ровно четыре натуральных делителя.

Рассуждение:

- кандидаты — числа 10, 11, 12, …, 30;
- для каждого кандидата находим все делители;
- считаем их;
- если получилось ровно четыре, число подходит.

Пока здесь не требуется никакой сложной математики. Но если проверять каждое число неудачным способом, программа может работать слишком долго. Поэтому дальше мы отдельно разберём правильность и скорость поиска.

**Основа задания — деление с остатком.** Начнём с того, что именно оно означает.

Если разделить 17 на 5, то пять помещается в семнадцати три раза, и ещё две единицы остаются:

17=5·3+2.

<figure class="plate-figure">
%%remainder(17, 5)%%
<figcaption>17 клеток, разложенных рядами по 5. Полных рядов три — это частное 17 // 5. Две клетки на полный ряд не хватило — это остаток 17 % 5.</figcaption>
</figure>

Здесь:

- 17 — число, которое делим;
- 5 — число, на которое делим;
- 3 — целая часть частного;
- 2 — остаток.

Для неотрицательного целого n и положительного целого d всегда можно записать:

n=dq+r, 0≤ r<d.

Остаток меньше делителя: если бы остаток был хотя бы d, из него можно было бы выделить ещё одну полную порцию по d.

В Python есть две отдельные операции:

```python
17 // 5
```

Результат — `3`, целая часть частного.

```python
17 % 5
```

Результат — `2`, остаток.

Сравним несколько примеров:

| Выражение | Результат | Объяснение |
|---|---:|---|
| `17 // 5` | 3 | Три полные пятёрки |
| `17 % 5` | 2 | Осталось две единицы |
| `20 // 5` | 4 | Четыре полные пятёрки |
| `20 % 5` | 0 | Ничего не осталось |
| `3 // 7` | 0 | Ни одной полной семёрки |
| `3 % 7` | 3 | Всё число осталось в остатке |

**Число делится на другое без остатка тогда и только тогда, когда остаток равен нулю.**

Поэтому:

```python
n % d == 0
```

означает:

> Проверить, делится ли `n` на `d` без остатка.

Например:

```python
18 % 3 == 0
```

даёт `True` — «истина», условие выполнено.

```python
18 % 5 == 0
```

даёт `False` — «ложь», условие не выполнено.

Обрати внимание на различие:

```python
n = 18
```

— присваиваем переменной `n` значение 18.

```python
n == 18
```

— проверяем, равно ли значение `n` числу 18.

В дальнейшем мы в основном работаем с положительными целыми числами. Для отрицательных чисел у `//` есть особенность: результат округляется вниз, а не просто получается удалением дробной части. В рассматриваемых алгоритмах для натуральных чисел эта особенность нам не мешает.

Обычное деление `/` здесь чаще всего не требуется:

```python
18 / 3     # 6.0
18 // 3    # 6
```

Если заранее проверено, что число делится без остатка, `//` даёт нужное целое частное.

Ещё одна необходимая операция — возведение в степень:

```python
10 ** 9
```

Это 10⁹.

**В Python степень записывается через `**`, а не через `^`.**

**Условия задачи необходимо переводить в код буквально.** Несколько похожих русских формулировок могут означать разные проверки.

| Формулировка | Проверка |
|---|---|
| Число кратно 7 | `n % 7 == 0` |
| Число не кратно 7 | `n % 7 != 0` |
| Число чётное | `n % 2 == 0` |
| Число нечётное | `n % 2 != 0` |
| Число больше 100 | `n > 100` |
| Число не меньше 100 | `n >= 100` |
| Число меньше 100 | `n < 100` |
| Число не превышает 100 | `n <= 100` |
| Число принадлежит отрезку [100;200] | `100 <= n <= 200` |

Знак `!=` означает «не равно».

Если должны одновременно выполняться два условия, используем `and` — «и»:

```python
n % 3 == 0 and n % 5 == 0
```

Число должно делиться и на 3, и на 5.

Если достаточно хотя бы одного условия, используем `or` — «или»:

```python
n % 3 == 0 or n % 5 == 0
```

Такое условие допускает три ситуации:

- число делится только на 3;
- только на 5;
- одновременно на 3 и на 5.

То есть `or` не означает «строго одно из двух».

**Для перебора чисел в заданном диапазоне нам понадобится цикл.** Цикл — это повторение одних и тех же действий для разных значений.

```python
for n in range(10, 15):
    print(n)
```

Программа выведет:

```text
10
11
12
13
14
```

Разберём запись:

- `range(10, 15)` задаёт последовательность целых чисел от 10 до 14;
- `for n in ...` последовательно присваивает переменной `n` каждое из этих значений;
- `print(n)` выводит текущее значение.

**Правая граница `range` не включается.**

Поэтому для отрезка [L;R], где обе границы включены, нужно:

```python
for n in range(L, R + 1):
    print(n)
```

Например:

```python
for n in range(10, 30 + 1):
    print(n)
```

Здесь будет обработано и число 30.

Отступы в Python показывают, какие команды относятся к циклу или условию:

```python
for n in range(10, 31):
    if n % 3 == 0:
        print(n)
```

Смысл:

1. Берём очередное число от 10 до 30.
2. Проверяем делимость на 3.
3. Если проверка успешна, выводим число.

Команда `if` означает «если».

**Для работы с масками нужно различать число и строку.** Строка — последовательность символов, записанная в кавычках.

```python
1234
```

— число.

```python
"1234"
```

— строка из четырёх символов.

С числом выполняем арифметические действия:

```python
12 + 34
```

получаем:

```text
46
```

Строки при сложении соединяются:

```python
"12" + "34"
```

получаем:

```text
1234
```

Переход от числа к строке:

```python
str(1234)
```

Переход от строки с записью целого числа к числу:

```python
int("1234")
```

Поэтому можно сначала собрать запись из частей:

```python
s = "12" + "7" + "34"
```

Получится строка:

```text
12734
```

А затем превратить её в число:

```python
n = int(s)
```

Количество символов в строке:

```python
len(str(n))
```

Для натурального числа это количество цифр его обычной десятичной записи.

Например:

```python
len(str(1234))   # 4
```

**Операции с цифрами позволяют проверять дополнительные требования к числу.** Некоторые условия удобнее проверять арифметически, другие — через строку.

Возьмём:

n=50721.

| Выражение | Результат | Смысл |
|---|---:|---|
| `n % 10` | 1 | Последняя цифра |
| `n // 10` | 5072 | Удалили последнюю цифру |
| `n % 100` | 21 | Значение последних двух цифр |
| `n // 100` | 507 | Удалили последние две цифры |
| `(n // 100) % 10` | 7 | Цифра сотен |

Почему остаток от деления на 10 даёт последнюю цифру?

Любое неотрицательное целое число можно представить так:

n=10q+r, 0≤ r<10.

Часть 10q соответствует всем полным десяткам. Остаток r — единицы, то есть последняя цифра.

Аналогично:

n=100q+r, 0≤ r<100.

Остаток соответствует последним двум разрядам.

Поэтому:

```python
n % 100 == 37
```

проверяет окончание на 37.

Если окончание начинается с нулей, нужно учитывать длину записи. Например, остаток 7 при делении на 100 сам по себе ещё не различает число 7 и число, оканчивающееся на `07`.

Через строку такое окончание проверяется явно:

```python
str(n).endswith("07")
```

`endswith` означает «заканчивается на».

Сумму цифр можно посчитать понятным циклом:

```python
digit_sum = 0

for ch in str(n):
    digit_sum += int(ch)
```

Здесь:

- `str(n)` даёт запись числа;
- `ch` последовательно принимает значения отдельных символов;
- `int(ch)` превращает символ цифры в число;
- цифры складываются.

Для 50721 получится:

5+0+7+2+1=15.

Если нужно проверить отсутствие повторяющихся цифр:

```python
s = str(n)

if len(set(s)) == len(s):
    print("Все цифры различны")
```

Почему это работает?

- `len(s)` — общее количество цифр;
- `set(s)` оставляет только различные символы;
- если количество не уменьшилось, повторов не было.

**Проверить, встречается ли в записи числа цифра или группа цифр, можно через `in`.**

В задачах последних лет часто встречаются условия вроде «в записи числа есть цифра 1 и цифра 6» или «запись содержит последовательность цифр 53». Это проверки **строки**, а не арифметики.

```python
s = str(1677016)

print("1" in s and "6" in s)
print(s.count("16"))
```

Программа выведет:

```text
True
2
```

Здесь:

- `"1" in s` — истина, если символ `1` встречается в строке хотя бы один раз;
- `s.count("16")` — сколько раз группа символов `16` встречается в строке.

Поэтому:

| Формулировка | Проверка |
|---|---|
| Запись содержит цифру 7 | `"7" in str(n)` |
| Запись не содержит цифру 0 | `"0" not in str(n)` |
| Есть и цифра 1, и цифра 6 | `"1" in s and "6" in s` |
| Есть цифра 2 или цифра 3 | `"2" in s or "3" in s` |
| Последовательность «53» встречается ровно один раз | `s.count("53") == 1` |

**«Встречается ровно один раз» и `count` совпадают не всегда.** `count` считает непересекающиеся вхождения: найдя группу, продолжает поиск после неё.

```python
s = "7777"
print(s.count("77"))
```

Программа выведет:

```text
2
```

Но если считать все места, где начинается `77`, их три: позиции 0, 1 и 2. Сравни на схеме:

<figure class="plate-figure">
%%overlap("7777", "77")%%
<figcaption>Жирные отрезки — то, что находит <code>count</code>: после вхождения с позиции 0 поиск продолжается с позиции 2. Вхождение с позиции 1 перекрывается с уже найденным и пропускается.</figcaption>
</figure>

Для групп вроде `53` или `567` перекрытие невозможно — у них начало не совпадает с концом, и `count` даёт верный ответ. Для групп вроде `77` или `121` нужно уточнить, что считает условие.

**Иногда числа нужно перебирать по убыванию.** Например, когда спрашивают о наибольших подходящих числах.

У `range` третий аргумент — шаг. Отрицательный шаг означает движение вниз:

```python
for n in range(10, 4, -2):
    print(n)
```

Программа выведет:

```text
10
8
6
```

Правая граница по-прежнему не включается: до 4 цикл не дойдёт.

Найдём три наибольших числа меньше 1000, которые делятся на 7 и оканчиваются цифрой 3:

```python
found = []

for n in range(999, 0, -1):
    if n % 7 == 0 and n % 10 == 3:
        found.append(n)
        if len(found) == 3:
            break

print(found)
```

Программа выведет:

```text
[973, 903, 833]
```

`break` немедленно завершает цикл. Здесь он срабатывает, когда найдено третье число.

**Нижняя граница в таком поиске обязательна.** Если искать те же три числа меньше 200 циклом `while`, который просто уменьшает `n`, найдутся 133 и 63, а третьим окажется −7: подходящих положительных чисел всего два, и цикл ушёл в отрицательные числа. `range(199, 0, -1)` остановится на 1 и честно вернёт только два числа.

**Коротко.** Решение любой задачи этой темы собирается из одних и тех же частей:

1. перебрать нужные числа — `range(L, R + 1)`, по убыванию или с шагом;
2. перевести каждую часть условия в проверку — `%`, сравнения, `and`, `or`, проверки строки;
3. вывести то, что просит условие, в нужном порядке.

Делители, простые числа и маски в следующих подтемах — это новые проверки, которые встраиваются в ту же схему.
