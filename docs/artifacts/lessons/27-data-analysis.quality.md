## Проверка фактов и ограничения

- Для 1,0; 2,5; 4,0 при `R = 2` соседние разности равны 1,5, но полный размах равен 3,0. Это контрпример к неверному сравнению только соседних значений.
- У 1,0; 1,5; 2,0 суммы модулей разностей равны 1,5; 1,0; 1,5. Медианная частица — единственный центр. Для 1, 2, 3, 4 два средних кандидата дают одинаковый минимум. Нечётный размер сам по себе тоже не гарантирует единственную **частицу**: у энергий 1, 1, 2 суммы разностей равны 1, 1, 2, поэтому две разные частицы делят минимум. В задачах на единственный центр такие случаи исключены условием.
- Учебный полный пример из 12 оригинальных частиц даёт центры с энергиями 1,5; 5,5; 10,5; 15,5. Наибольший квадрат расстояния между разрешёнными парами II внутри одной группы равен 17; `int(sqrt(17) * 10000) = 41231`, `int(15.5 * 10000) = 155000`.
- Для 100 отобранных точек прямой просмотр проверяет 4 950 пар, для 10 000 — 49 995 000. Фильтрация и один квадратный корень в конце сокращают работу, но не число пар. Урок не обещает, что квадратичный перебор подходит для любого допустимого файла; при большом числе отобранных точек потребуется отдельный геометрический алгоритм.
- Python `float` хранит десятичные значения приближённо. В авторских данных границы и усечение не зависят от этой погрешности. Условия с действительно близкими к порогу десятичными значениями потребуют точного способа счёта.
- Независимые оракулы в `apps/api/tests/test_task_27_bank.py` проверяют ответы задач 01–07, файлы, ссылки на разделы, границы групп и программные решения. Канонические ответы: `3`, `1 1`, `3`, `10`, `10`, `4 4`, `36055 135000`. Условия, код, данные и миниатюра написаны заново; текст внешних задач не переносился.

Теория, задачи и файлы подготовлены как `published` для локальной проверки архитектором до `/ship`. Автоматические проверки и агентский аудит не подменяют ручную проверку содержания и страницы. Результаты финального Critical Gate и браузерного осмотра относятся к отчёту `/work` Change 153.
