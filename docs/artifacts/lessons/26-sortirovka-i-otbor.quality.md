## Независимые ответы

Ответ каждой задачи печатает её решающая программа, запущенная рядом с приложенным файлом; `topic-26/bank.py` сверяет его с ответом в тексте подтемы. `apps/api/tests/test_task_26_bank.py` пересчитывает все 67 ответов другим способом, чем урок:

| Что проверяется | Независимый способ |
| --- | --- |
| Задачи на маленьких данных | Полный перебор наборов, цепочек, паросочетаний, порядков и расписаний |
| Рейтинги | Устойчивые сортировки от младшего критерия |
| Наибольшее количество и наибольший элемент | Префиксные суммы и `bisect` |
| Цепочки коробок, расписания, маршрут альпиниста | Динамическое программирование |
| Простои и нагрузка | Массив загрузки по секундам |
| Места, серии, изолированные точки | Проверки по множеству |
| Камера хранения | Куча освобождений |
| Наименьшее число блоков | Наибольшее паросочетание (алгоритм Куна) |

Тест также проверяет: checker принимает ответ и отвергает соседний; задачи подтем 7–8 вне mastery; у задач итоговой страницы нет ссылок на теорию; программы не длиннее 64 символов в строке; задачи прежнего урока архивированы и вне уроков.
