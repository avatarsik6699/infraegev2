# Задание 16 ЕГЭ: рекурсивные алгоритмы с полного нуля

По актуальным материалам ФИПИ, задание 16 проверяет умение вычислять рекуррентные выражения — то есть последовательности, в которых новое значение определяется через предыдущие. [Навигатор ФИПИ ЕГЭ-2026](https://doc.fipi.ru/navigator-podgotovki/navigator-ege/2026/Inf_3_algoritm.pdf)

Главная мысль задания очень проста:

> Нам дают несколько начальных значений, а затем правило, позволяющее получать следующие значения.

Например:

[
F(1)=1,
]

[
F(n)=2F(n-1)+1,\quad n>1.
]

Это означает:

* первое значение уже известно: (F(1)=1);
* чтобы получить (F(2)), нужно воспользоваться (F(1));
* чтобы получить (F(3)), нужно воспользоваться (F(2));
* чтобы получить (F(4)), нужно воспользоваться (F(3));
* и так далее.

Разберём всё постепенно.

---

## 1. Что вообще означает запись (F(n))

Функция — это правило, которое получает аргумент и возвращает результат.

Например:

[
F(n)=n^2.
]

Тогда:

[
F(2)=2^2=4,
]

[
F(5)=5^2=25.
]

Здесь значение можно вычислить сразу: подставили (n) в формулу и получили ответ.

Но в задании 16 функция часто определяется иначе:

[
F(n)=2F(n-1)+1.
]

Теперь значение (F(n)) зависит от другого значения этой же функции — (F(n-1)).

Например, для вычисления (F(5)) нужно знать (F(4)):

[
F(5)=2F(4)+1.
]

Но для (F(4)) нужно знать (F(3)):

[
F(4)=2F(3)+1.
]

Получается цепочка зависимостей:

[
F(5)\rightarrow F(4)\rightarrow F(3)\rightarrow F(2)\rightarrow F(1).
]

Такая зависимость функции от самой себя называется рекурсией.

---

# 2. Две обязательные части рекурсии

Любое корректное рекурсивное определение содержит две части.

## Часть 1. Начальное значение

Например:

[
F(1)=1.
]

Его также называют:

* базовым случаем;
* условием завершения;
* базой рекурсии.

Это значение ни через что вычислять не нужно — оно уже дано.

## Часть 2. Правило перехода

Например:

[
F(n)=2F(n-1)+1,\quad n>1.
]

Это инструкция, показывающая, как получить следующее значение через предыдущее.

Можно представить последовательность костяшек домино:

* (F(1)) — первая костяшка, которую толкнули вручную;
* формула — правило, по которому каждая костяшка толкает следующую.

Без начального значения вычисления никогда не закончатся:

[
F(5)\rightarrow F(4)\rightarrow F(3)\rightarrow\dots
]

---

# 3. Почему такое определение действительно задаёт функцию

Рассмотрим:

[
F(1)=1,
]

[
F(n)=2F(n-1)+1,\quad n>1.
]

Мы знаем (F(1)). Поэтому можем однозначно найти (F(2)):

[
F(2)=2F(1)+1.
]

После этого знаем (F(2)), значит можем найти (F(3)):

[
F(3)=2F(2)+1.
]

После этого можем найти (F(4)), и так далее.

То есть из одного известного значения последовательно определяются все остальные:

[
F(1)\Rightarrow F(2)\Rightarrow F(3)\Rightarrow F(4)\Rightarrow\dots
]

Это тесно связано с математической индукцией: если определено первое значение и из каждого значения можно получить следующее, то определена вся последовательность.

# 4. Первый тип: одно предыдущее значение

Рассмотрим классический пример:

[
F(1)=1,
]

[
F(n)=2F(n-1)+1,\quad n>1.
]

Найдём (F(5)).

## Шаг 1. Записываем начальное значение

[
F(1)=1.
]

## Шаг 2. Вычисляем (F(2))

В формуле

[
F(n)=2F(n-1)+1
]

подставляем (n=2):

[
F(2)=2F(2-1)+1=2F(1)+1.
]

Значение (F(1)) известно:

[
F(2)=2\cdot1+1=3.
]

## Шаг 3. Вычисляем (F(3))

Теперь (n=3):

[
F(3)=2F(3-1)+1=2F(2)+1.
]

Мы уже нашли (F(2)=3):

[
F(3)=2\cdot3+1=7.
]

## Шаг 4. Вычисляем (F(4))

[
F(4)=2F(3)+1=2\cdot7+1=15.
]

## Шаг 5. Вычисляем (F(5))

[
F(5)=2F(4)+1=2\cdot15+1=31.
]

Ответ:

[
\boxed{31}.
]

Удобно оформлять вычисления таблицей:

| (n) | (F(n)) |
| --: | -----: |
|   1 |      1 |
|   2 |      3 |
|   3 |      7 |
|   4 |     15 |
|   5 |     31 |

Именно такое последовательное вычисление приводит официальный разбор аналогичной задачи. [Пример задания 16](https://inf-ege.sdamgia.ru/test?theme=209)

# 5. Как работает рекурсивная программа

Эту функцию можно записать на Python:

```python
def F(n):
    if n == 1:
        return 1
    return 2 * F(n - 1) + 1

print(F(5))
```

Разберём каждую строку.

```python
def F(n):
```

Создаётся функция с именем `F`, принимающая число `n`.

```python
if n == 1:
    return 1
```

Если дошли до базового случая, функция возвращает 1.

```python
return 2 * F(n - 1) + 1
```

Если (n>1), функция вызывает саму себя для меньшего аргумента.

## Что происходит при вызове `F(5)`

Сначала Python не знает (F(5)), поэтому раскрывает формулу:

```text
F(5) = 2 · F(4) + 1
```

Но значение (F(4)) тоже неизвестно:

```text
F(4) = 2 · F(3) + 1
```

Продолжаем:

```text
F(3) = 2 · F(2) + 1
F(2) = 2 · F(1) + 1
F(1) = 1
```

После достижения базы начинается возвращение результатов:

```text
F(1) = 1
F(2) = 2 · 1 + 1  = 3
F(3) = 2 · 3 + 1  = 7
F(4) = 2 · 7 + 1  = 15
F(5) = 2 · 15 + 1 = 31
```

Таким образом, есть две стадии:

1. Спуск к базовому случаю:

[
F(5)\rightarrow F(4)\rightarrow F(3)\rightarrow F(2)\rightarrow F(1).
]

2. Возвращение результатов:

[
1\rightarrow3\rightarrow7\rightarrow15\rightarrow31.
]

# 6. Что делает `return`

Это особенно важно для категории «рекурсивные функции с возвращаемыми значениями».

Команда:

```python
return значение
```

делает две вещи:

1. завершает текущий вызов функции;
2. передаёт вычисленное значение туда, откуда функция была вызвана.

Например:

```python
return 2 * F(n - 1) + 1
```

При (n=3) превращается в:

```python
return 2 * F(2) + 1
```

Вызов `F(2)` возвращает число 3. Поэтому выражение становится:

```python
return 2 * 3 + 1
```

Функция `F(3)` возвращает 7.

Важно:

> `F(n - 1)` — это не текст и не номер предыдущей функции. Это конкретное число, которое вернёт вызов функции.

# 7. Рекурсия и рекуррентная формула — не совсем одно и то же

Нужно различать два понятия.

## Рекуррентная формула

Математическое определение:

[
F(n)=2F(n-1)+1.
]

## Рекурсивная программа

Программная реализация, в которой функция вызывает себя:

```python
def F(n):
    if n == 1:
        return 1
    return 2 * F(n - 1) + 1
```

Но рекуррентную формулу необязательно вычислять рекурсивной программой. Её часто удобнее вычислять циклом:

```python
f = 1

for n in range(2, 6):
    f = 2 * f + 1

print(f)
```

Здесь переменная `f` хранит последнее вычисленное значение.

Ход цикла:

| `n` | старое `f` | новое `f = 2*f + 1` |
| --: | ---------: | ------------------: |
|   2 |          1 |                   3 |
|   3 |          3 |                   7 |
|   4 |          7 |                  15 |
|   5 |         15 |                  31 |

Для больших аргументов цикл обычно надёжнее рекурсии.

# 8. Универсальный шаблон для одного предыдущего значения

Если дано:

[
F(k)=a,
]

[
F(n)=\text{выражение с }F(n-1),\quad n>k,
]

то программа имеет вид:

```python
f = a

for n in range(k + 1, target + 1):
    f = выражение_с_f

print(f)
```

Например:

[
F(3)=5,
]

[
F(n)=3F(n-1)-2n,\quad n>3.
]

Найти (F(10)):

```python
f = 5

for n in range(4, 11):
    f = 3 * f - 2 * n

print(f)
```

Обратите внимание:

```python
range(4, 11)
```

перебирает числа:

```text
4, 5, 6, 7, 8, 9, 10
```

Правая граница `range` не включается.

# 9. Второй тип: несколько предыдущих значений

Рассмотрим:

[
F(1)=2,
]

[
F(2)=3,
]

[
F(n)=F(n-1)+F(n-2),\quad n>2.
]

Теперь для следующего значения нужны два предыдущих.

Найдём (F(6)).

## Начальные значения

[
F(1)=2,\qquad F(2)=3.
]

## Вычисляем (F(3))

[
F(3)=F(2)+F(1)=3+2=5.
]

## Вычисляем (F(4))

[
F(4)=F(3)+F(2)=5+3=8.
]

## Вычисляем (F(5))

[
F(5)=F(4)+F(3)=8+5=13.
]

## Вычисляем (F(6))

[
F(6)=F(5)+F(4)=13+8=21.
]

Получаем:

| (n) | (F(n)) |
| --: | -----: |
|   1 |      2 |
|   2 |      3 |
|   3 |      5 |
|   4 |      8 |
|   5 |     13 |
|   6 |     21 |

Ответ:

[
\boxed{21}.
]

# 10. Почему при двух предыдущих значениях нужны две базы

Если дано только:

[
F(n)=F(n-1)+F(n-2),
]

то для вычисления (F(3)) нужны сразу:

[
F(2)\quad\text{и}\quad F(1).
]

Поэтому условие должно сообщить оба значения.

Общее правило:

* если формула использует только (F(n-1)), обычно достаточно одного начального значения;
* если используются (F(n-1)) и (F(n-2)), нужны два начальных значения;
* если используются значения вплоть до (F(n-3)), обычно нужны три начальных значения.

# 11. Рекурсивное решение для двух предыдущих значений

```python
def F(n):
    if n == 1:
        return 2
    if n == 2:
        return 3
    return F(n - 1) + F(n - 2)

print(F(6))
```

Но здесь появляется новая проблема.

Для вычисления `F(6)` программа вызывает:

```text
F(5) и F(4)
```

Для `F(5)` вызываются:

```text
F(4) и F(3)
```

Получается, `F(4)` вычисляется несколько раз.

При больших (n) количество вызовов очень быстро растёт. Поэтому на практике применяют:

* цикл;
* список значений;
* мемоизацию.

---

# 12. Решение через список

Это самый понятный и универсальный способ:

```python
target = 6

F = [0] * (target + 1)

F[1] = 2
F[2] = 3

for n in range(3, target + 1):
    F[n] = F[n - 1] + F[n - 2]

print(F[target])
```

Почему список имеет длину `target + 1`?

Потому что индексы начинаются с нуля:

```text
F[0], F[1], F[2], ..., F[target]
```

Элемент `F[0]` мы просто не используем. Зато математическое (F(6)) находится в программном `F[6]`, что уменьшает путаницу.

Список после вычисления:

```text
[0, 2, 3, 5, 8, 13, 21]
```

# 13. Решение двумя переменными

Хранить весь список необязательно. Для следующего значения нужны только два последних:

```python
f_prev2 = 2  # F(1)
f_prev1 = 3  # F(2)

for n in range(3, 7):
    f_current = f_prev1 + f_prev2
    f_prev2 = f_prev1
    f_prev1 = f_current

print(f_prev1)
```

После каждой итерации происходит сдвиг:

| Переменная | Что хранит до шага | Что хранит после шага |
| ---------- | ------------------ | --------------------- |
| `f_prev2`  | (F(n-2))           | (F(n-1))              |
| `f_prev1`  | (F(n-1))           | (F(n))                |

На Python это можно записать короче:

```python
f_prev2, f_prev1 = 2, 3

for n in range(3, 7):
    f_prev2, f_prev1 = f_prev1, f_prev1 + f_prev2

print(f_prev1)
```

Правая часть вычисляется по старым значениям, и только после этого обе переменные обновляются.

# 15. Мемоизация: как не вычислять одно значение много раз

Мемоизация означает:

> Если функция уже вычисляла (F(n)), результат сохраняется и при повторном обращении берётся из памяти.

На Python:

```python
from functools import cache

@cache
def F(n):
    if n == 1:
        return 2
    if n == 2:
        return 3
    return F(n - 1) + F(n - 2)

print(F(100))
```

Без `@cache` значения вроде `F(50)` вычислялись бы огромное количество раз.

С `@cache` каждое значение вычисляется только один раз:

```text
F(1), F(2), F(3), ..., F(100)
```

Однако для обычного задания 16 чаще всего проще использовать цикл.

# 16. Третий тип: выражения из больших значений функции

Рассмотрим важный тип:

[
F(1)=1,
]

[
F(n)=nF(n-1),\quad n>1.
]

Нужно найти:

[
\frac{F(2024)-F(2023)}{F(2022)}.
]

Пытаться вычислить все значения до (F(2024)) можно, но это неудобно. Здесь нужно раскрыть только несколько последних шагов.

## Шаг 1. Выражаем (F(2023))

[
F(2023)=2023F(2022).
]

## Шаг 2. Выражаем (F(2024))

[
F(2024)=2024F(2023).
]

Но:

[
F(2023)=2023F(2022).
]

Поэтому:

[
F(2024)=2024\cdot2023F(2022).
]

## Шаг 3. Подставляем в исходное выражение

[
\frac{2024\cdot2023F(2022)-2023F(2022)}{F(2022)}.
]

## Шаг 4. Выносим общий множитель

В числителе общий множитель:

[
2023F(2022).
]

Получаем:

[
\frac{2023F(2022)(2024-1)}{F(2022)}.
]

## Шаг 5. Сокращаем

[
\frac{2023F(2022)\cdot2023}{F(2022)}
=2023^2.
]

[
2023^2=4,092,529.
]

Ответ:

[
\boxed{4092529}.
]

Главный принцип:

> Если в условии огромные аргументы, но требуется дробь или разность соседних значений, сначала попробуйте выразить всё через самое маленькое значение функции и сократить.

# 17. Когда считать таблицей, а когда упрощать формулу

## Используйте таблицу или цикл, если:

* нужно найти просто (F(10)), (F(20)), (F(100));
* числа не растут слишком быстро;
* формула содержит условия по чётности или делимости;
* требуется гарантированно получить точное значение.

## Используйте алгебраическое преобразование, если:

* аргументы очень большие: (2024), (10,000);
* функция быстро растёт;
* требуется выражение вроде:

[
\frac{F(2024)}{F(2022)},
]

[
F(2024)-2024F(2023),
]

[
\frac{F(2025)-F(2024)}{F(2023)};
]

* соседние значения имеют общие множители.

# 18. Формулы с несколькими условиями

Например:

[
F(1)=1,
]

[
F(n)=
\begin{cases}
F(n-1)+n, & n\text{ чётное},\
2F(n-1), & n\text{ нечётное}.
\end{cases}
]

Найдём (F(5)).

## (F(2))

Число 2 чётное:

[
F(2)=F(1)+2=1+2=3.
]

## (F(3))

Число 3 нечётное:

[
F(3)=2F(2)=2\cdot3=6.
]

## (F(4))

Число 4 чётное:

[
F(4)=F(3)+4=6+4=10.
]

## (F(5))

Число 5 нечётное:

[
F(5)=2F(4)=2\cdot10=20.
]

Программа:

```python
f = 1

for n in range(2, 6):
    if n % 2 == 0:
        f = f + n
    else:
        f = 2 * f

print(f)
```

Здесь:

```python
n % 2 == 0
```

означает, что остаток от деления (n) на 2 равен нулю, то есть число чётное.

# 19. Несколько взаимосвязанных функций

Иногда определяются две функции:

[
F(1)=1,\qquad G(1)=2,
]

[
F(n)=F(n-1)+G(n-1),
]

[
G(n)=2F(n-1)+G(n-1).
]

Здесь очень важно вычислять новые значения через старые.

Например:

[
F(2)=F(1)+G(1)=1+2=3,
]

[
G(2)=2F(1)+G(1)=2\cdot1+2=4.
]

При вычислении (G(2)) нельзя подставлять уже найденное (F(2)=3), потому что в формуле написано (F(n-1)), то есть при (n=2) требуется именно (F(1)).

Правильная программа:

```python
f = 1
g = 2

for n in range(2, 6):
    new_f = f + g
    new_g = 2 * f + g

    f = new_f
    g = new_g

print(f, g)
```

Или:

```python
f, g = 1, 2

for n in range(2, 6):
    f, g = f + g, 2 * f + g
```

Правая часть сначала полностью вычисляется по старым значениям.

# 20. Универсальный алгоритм решения задания 16

## Шаг 1. Определите область аргументов

Внимательно прочитайте:

* (n) — натуральное число;
* (n) — целое неотрицательное число;
* функция определена при (n\geqslant1);
* функция определена при (n\geqslant0).

Если дано (F(0)), начинать нужно с нуля.

## Шаг 2. Найдите базовые значения

Например:

[
F(1)=2,\qquad F(2)=5.
]

Их не нужно вычислять — они заданы.

## Шаг 3. Определите зависимости

Посмотрите, что встречается в формуле:

* только (F(n-1));
* (F(n-1)) и (F(n-2));
* (F(n-2)) и (F(n-3));
* разные формулы для чётных и нечётных (n);
* две взаимосвязанные функции (F) и (G).

## Шаг 4. Проверьте, приближается ли аргумент к базе

Например:

[
F(n)\rightarrow F(n-1)\rightarrow F(n-2)\rightarrow\dots\rightarrow F(1).
]

Если аргумент уменьшается, рекурсия должна дойти до базы.

## Шаг 5. Выберите способ

* маленький аргумент — таблица вручную;
* обычное последовательное вычисление — цикл;
* несколько предыдущих значений — список;
* рекурсивное дерево с повторениями — мемоизация;
* огромное (n) и дробь из соседних значений — алгебраическое сокращение.

## Шаг 6. Вычисляйте снизу вверх

Обычно безопаснее идти так:

[
F(1)\rightarrow F(2)\rightarrow F(3)\rightarrow\dots
]

а не пытаться держать в голове огромное раскрытие:

[
F(100)\rightarrow F(99)\rightarrow F(98)\rightarrow\dots
]

## Шаг 7. Проверьте границы цикла

Чтобы вычислить значения от (F(2)) до (F(10)):

```python
for n in range(2, 11):
```

а не:

```python
for n in range(2, 10):
```

Потому что последняя граница `range` не включается.

# 21. Основные ошибки

## Ошибка 1. Путать (F(n-1)) и (F(n)-1)

Это совершенно разные выражения:

[
F(n-1)
]

означает значение функции для аргумента (n-1).

А:

[
F(n)-1
]

означает значение (F(n)), уменьшенное на единицу.

---

## Ошибка 2. Подставлять неправильное (n)

Если:

[
F(n)=3F(n-1)+2n,
]

то для (F(4)):

[
F(4)=3F(3)+2\cdot4.
]

Число 4 подставляется во все места, где стоит (n).

---

## Ошибка 3. Не учитывать условия

Если написано:

[
F(n)=F(n-1)+n,\quad n>3,
]

нельзя применять эту формулу для (F(2)) или (F(3)).

---

## Ошибка 4. Перепутать порядок предыдущих значений

В формуле:

[
F(n)=3F(n-1)-2F(n-2)
]

коэффициент 3 относится к ближайшему предыдущему значению, а коэффициент (-2) — к значению через одно.

---

## Ошибка 5. Обновлять переменные слишком рано

Неправильно:

```python
f_prev2 = f_prev1
f_prev1 = f_prev1 + f_prev2
```

Во второй строке `f_prev2` уже изменилось.

Правильно:

```python
f_current = f_prev1 + f_prev2
f_prev2 = f_prev1
f_prev1 = f_current
```

---

## Ошибка 6. Использовать простую рекурсию для большого (n)

Код:

```python
def F(n):
    if n == 1:
        return 1
    return n * F(n - 1)

print(F(2024))
```

может упереться в ограничение глубины рекурсии Python.

Цикл надёжнее:

```python
f = 1

for n in range(2, 2025):
    f *= n
```

А если требуется отношение соседних значений, лучше сначала попробовать сократить выражение.

# 22. Три универсальных программных шаблона

## Одно предыдущее значение

```python
f = начальное_значение

for n in range(первое_n, последнее_n + 1):
    f = формула_через_f

print(f)
```

## Несколько предыдущих значений

```python
target = нужный_аргумент
F = [0] * (target + 1)

F[1] = первое_начальное_значение
F[2] = второе_начальное_значение

for n in range(3, target + 1):
    F[n] = формула_через_F[n - 1]_и_F[n - 2]

print(F[target])
```

## Рекурсия с мемоизацией

```python
from functools import cache

@cache
def F(n):
    if базовое_условие:
        return базовое_значение

    return рекурсивная_формула

print(F(нужный_аргумент))
```

# Главное, что нужно понять

Рекурсивная запись может выглядеть необычно, потому что функция определяется через саму себя. Но логического круга здесь нет:

1. одно или несколько первых значений уже известны;
2. каждое следующее значение выражается через ранее найденные;
3. поэтому значения вычисляются по порядку;
4. `return` передаёт вычисленное значение предыдущему вызову;
5. для маленьких аргументов строим таблицу;
6. для больших — используем цикл, мемоизацию или алгебраическое сокращение.

Если свести всё задание 16 к одной фразе, получится:

> Начни с известных базовых значений и шаг за шагом двигайся к требуемому аргументу, каждый раз строго подставляя текущий (n) в данную формулу.
