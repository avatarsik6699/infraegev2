## Замысел

Задание 23 новое: оно появилось в демоверсии 2027 года, в подборке «Решу ЕГЭ» по нему одна задача. Поэтому уровни выбраны по демоверсии, а не по частоте (решение архитектора 2026-10-09, `topic-23/map.md`):

- **основной уровень**, подтемы 1–5: всё, что нужно для задачи демоверсии, — граф и путь, лучший остаток пути f(v), чтение файла, рекурсия с `@cache`, — и вероятные изменения условия: обязательная и запрещённая вершина, «пути нет»;
- **дополнительный уровень**, подтемы 6–7: повторные проходы по рёбрам (Беллман — Форд), топологический порядок, Дейкстра, количество путей, самый длинный путь, ровно k рёбер. Их задачи не входят в «освоено».

Исходник архитектора — `docs/artifacts/lessons/23_graphs.md`. Компактная подача как у темы 25: текст одним потоком, вывод под кодом, основы Python — подсказки у терминов, перечисления — переключатели, на итоговой странице — шпаргалка. После аудита понятности для новичка (стенд, итерация 2) добавлены песочница «собери путь», расчёт f от цели по шагам, схема списка смежности, дерево вызовов без запоминания и с ним, топологическая сортировка по шагам.

## Независимые ответы

Ответ каждой задачи печатает её решающая программа, запущенная рядом с её файлом (`topic-23/bank.py` сверяет его с ответом в тексте подтемы). `apps/api/tests/test_task_23_bank.py` пересчитывает все 25 ответов другим способом, чем урок (рекурсия с запоминанием):

| Что проверяется | Независимый способ |
| --- | --- |
| Кратчайший путь в файле, через вершину, без вершины | Алгоритм Дейкстры с кучей, путь по участкам |
| Небольшие графы подтем | Перебор всех путей |
| Количество путей и самый длинный путь | Динамика по топологическому порядку (Кан) |
| Восстановленный путь | Предшественники по расстояниям Дейкстры |
| Порядок Дейкстры, топологический порядок, число проходов | Отдельные реализации, не код урока |

Тест также проверяет:
- целая часть ответов по файлам не зависит от `float` и `Decimal`: дробная часть не ближе 0,02 к целому;
- checker принимает ответ (десятичный — и с запятой) и отвергает соседний;
- публичная выдача не содержит ответов и отдаёт файлы как вложения;
- задачи подтем 6–7 помечены `counts_toward_mastery: false`;
- файлы — ациклические графы не больше чем из 200 рёбер.
