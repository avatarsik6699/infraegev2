## Замысел

Черепаха выполняет команды буквально: положение, направление и хвост. Рисунок строится программой `turtle` в масштабе с сеткой целых точек; точки внутри, на границе и снаружи считают по рядам; несколько фигур — пересечение и объединение; наклонные стороны — по столбцам с проверкой спорных точек. Программы `turtle` ничего не печатают, поэтому их рисунок показан схемой построителя; подсчёт по координатам — программы с выводом.

## Банк задач

Задача банка — вопрос подтемы дословно; ответ рисунка даёт исполнитель стенда (`turtle_figures`: след без Tk и класс каждой целой точки); алгоритм и начальное направление читаются из условия. Задачи подтемы 7, где ученик пишет программу подсчёта, показывают решающую программу. Программа исполнителя («Повтори 3 [ … ]») в уроке и в банке — блок кода `algo` с подписью «Алгоритм для исполнителя». Ответ сверяется с ответом в тексте подтемы.

## Независимые ответы

`apps/api/tests/test_task_6_bank.py` пересчитывает все ответы другим способом. Алгоритм читается из условия задачи банка и выполняется отдельным исполнителем на комплексных числах; точка внутри, если контур обходит её (число оборотов), на линии — если лежит на нарисованном отрезке; прямоугольники по границам — формулами, посещения — шагами по единице. Программы подтемы 7 запускаются и печатают тот же ответ. Тест также проверяет: checker принимает ответ и отвергает соседний; задачи дополнительных подтем вне mastery; у задач итоговой страницы нет ссылок на теорию.
