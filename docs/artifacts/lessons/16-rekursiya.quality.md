# Тема 16 — запись качества урока «Рекурсивные алгоритмы»

Дата: 2026-09-29. Change 157. Это запись проверки авторского материала, а не экзаменационный норматив. Основание — [аудит](16-rekursiya.audit.md).

## Источники и границы

- Методические рекомендации ФИПИ-2026 (стр. 4, 11): сначала упростить выражение, затем считать; следить за числом рекурсивных вызовов и условием завершения.
- Авторские статьи Яндекс Образования ([281](https://education.yandex.ru/ege/inf/article/281-16-kodom-optimizatsiia-rekursii), [282](https://education.yandex.ru/ege/inf/article/282-16-funktsii-rekursiia)) и подборки «Решу ЕГЭ» использованы как ориентир приёмов. Тексты, числа и код статей не переносились: все примеры и 9 новых задач написаны заново с собственными числами.
- Документация Python (`functools.lru_cache`, `maxsize=128` по умолчанию, `@cache` = `lru_cache(maxsize=None)`) сверена через Context7.
- Демоверсия ФИПИ 2027 сверена (задание 16 — `(F(n) + 5·F(n−1)) / F(n−2)` при `F(n)=n·F(n−1)`; приём добавлен в урок). Не проверялись: исследования с учениками, ручная проверка архитектором.
