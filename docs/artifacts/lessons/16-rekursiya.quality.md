# Проверка качества: «Рекурсивные алгоритмы»

Статус урока остаётся `review`. Этот файл фиксирует проверку пяти практических заданий перед
отдельным решением о публикации.

## Покрытие и порядок

| Порядок | Задание | Сложность | Самостоятельно проверяемая идея |
|---------|---------|-----------|---------------------------------|
| 1 | `rekursiya-base-sequence` | 1 | Последовательный расчёт от базового случая |
| 2 | `rekursiya-call-stack-trace` | 2 | Два базовых случая и трассировка рекурсивных вызовов |
| 3 | `rekursiya-two-values` | 2 | Хранение двух предыдущих значений |
| 4 | `rekursiya-repeated-calls` | 3 | Размер дерева повторяющихся вызовов и мотивация мемоизации |
| 5 | `rekursiya-large-ratio` | 3 | Алгебраическое сокращение при больших аргументах |

## Проверено агентом

- [x] Все задания требуют самостоятельного ввода ответа (`production`).
- [x] Сложность не убывает: `1 → 2 → 2 → 3 → 3`.
- [x] Каждая ссылка ведёт на существующий `ConceptBlock.id` текущего урока.
- [x] У каждого задания есть отдельные подсказка и развёрнутое структурированное решение.
- [x] Решения объясняют ход рассуждения; новые задания также содержат уместные фрагменты Python.
- [x] Принятые ответы пересчитаны: `32`, `16`, `29`, `25`, `9900`.
- [x] Заведомо неверное значение отклоняется checker-ом для каждого задания.
- [x] Формулировки и решения написаны специально для этого урока, без копирования источников.
- [x] `answer_variants` не входят в публичную проекцию урока.

## Перед публикацией проверяет архитектор

- [ ] Вручную подтвердить арифметику, формулировки и отсутствие неоднозначных трактовок.
- [ ] Оценить рост сложности и объём пяти задач в браузере на desktop/mobile.
- [ ] Подтвердить оригинальность формулировок и достаточность объяснений.
- [ ] Отдельно одобрить перевод урока из `review`/`draft` в `published`.
