## Независимые ответы

Ответ каждой задачи печатает её решающая программа; `topic-16/bank.py` сверяет его с ответом в тексте подтемы. `apps/api/tests/test_task_16_bank.py` пересчитывает все 57 ответов другим способом, чем урок (рекурсия с `@cache`):

| Что проверяется | Независимый способ |
| --- | --- |
| Значения функций, связанные функции, рекурсия вверх | Таблица, заполненная циклом от баз |
| Число вызовов | Замкнутые формулы (2·F(n) − 1 для Фибоначчи, 2ⁿ − 1 для двух одинаковых вызовов) |
| Деления и отношения | Точные дроби `Fraction`, факториалы и произведения целиком |
| Функции цифр | Перебор по строке записи числа |
| Подсчёт по цифрам до 10¹² и 2⁴⁰ | Многочлен суммы цифр и подсчёт состояний по цифрам границы слева |

Тест также проверяет: checker принимает ответ и отвергает соседний; задачи подтем 6–7 вне mastery; у задач итоговой страницы нет ссылок на теорию; программы не длиннее 64 символов в строке.
