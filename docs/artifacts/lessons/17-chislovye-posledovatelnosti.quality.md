## Независимые ответы

Ответ каждой задачи печатает её решающая программа рядом с файлами данных; `topic-17/bank.py` сверяет его с ответом в тексте подтемы. `apps/api/tests/test_task_17_bank.py` пересчитывает все 49 ответов другим способом, чем урок (цикл по индексам и арифметика остатков):

| Что проверяется | Независимый способ |
| --- | --- |
| Соседние пары, тройки, четвёрки | Окна `zip` по сдвинутым спискам |
| Цифры, окончания, количество цифр | Строка десятичной записи модуля |
| Сравнение со средним | Точная дробь `Fraction` |
| Треугольники | Все три неравенства без сортировки, прямой угол — перебором перестановок |
| Пары любых позиций | `combinations`; разности — подсчёт по остаткам |

Тест также проверяет: checker принимает ответ и отвергает соседний; задачи подтем 7–8 вне mastery; у задач итоговой страницы нет ссылок на теорию; программы не длиннее 64 символов в строке; задачи прежнего урока архивированы и вне уроков.
