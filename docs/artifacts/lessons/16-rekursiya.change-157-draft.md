## Goal

Довести урок `rekursiya` до покрытия приёмов, которые реально встречаются в задании 16 (ветвление по чётности и порогу, шаги не на 1,
рекурсия вверх, две функции, «сколько n», дерево вызовов, разность/отношение при огромных аргументах), с упором на рекурсию + кеш
(`@lru_cache`, `sys.setrecursionlimit`) и с циклом как вторым инструментом. Основание — [аудит](./16-rekursiya.audit.md).

## Принципы

- Смысл важнее заучивания: каждый приём вводится как «проблема → наблюдение → идея → приём → проверка»; к каждому — «почему работает» и «когда не сработает»; сверка вторым способом (кеш ↔ упрощение, вверх ↔ вниз).
- Порядок решения (ФИПИ + авторские статьи): упростить → выбрать инструмент (кеш `@lru_cache(None)`, прогрев кеша, `setrecursionlimit`, цикл) → проверить условие завершения.
- Пререквизиты — ссылками на уроки курса Python `funktsii` и `rekursiya`, без дублирования.
- Идеи авторских статей Яндекс Образования используются с переформулировкой; тексты и задачи не переносятся.
