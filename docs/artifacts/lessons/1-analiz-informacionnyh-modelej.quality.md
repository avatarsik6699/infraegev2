## Замысел

Одна система дорог записана рисунком с буквами и таблицей с номерами. Соответствие находят от заметных пунктов — единственной степени, профиля соседей — к их соседям; похожие пункты различают треугольники, общие соседи и проверка предположения; при симметрии ответ проверяют во всех допустимых вариантах. Python в уроке нет: тема решается рассуждением.

## Банк задач

Задача банка — вопрос подтемы дословно; ответ ищет `topic-1/bank.py`: схема и таблица читаются из условия самой задачи (вызов `gm_graph`, перечень дорог в тексте, таблица Markdown), перебираются все соответствия букв и номеров, ответ должен быть одинаков во всех допустимых. Условие задачи в банке — целиком: таблица — блок `table`, схема — картинка PNG того же построителя (19 картинок). Ответ сверяется с ответом в тексте подтемы.

## Независимые ответы

`apps/api/tests/test_task_1_bank.py` пересчитывает все ответы другим способом. Соответствие собирается поиском с возвратом: буквы по одной, начиная с пунктов с большим числом дорог, частичное соответствие отбрасывается при первой нарушенной дороге или её отсутствии. Таблица берётся из блока `table` задачи банка, схема — из вызова `gm_graph` той же задачи на стенде. Тест также проверяет: checker принимает ответ и отвергает соседний; задачи дополнительных подтем вне mastery; у задач итоговой страницы нет ссылок на теорию.
