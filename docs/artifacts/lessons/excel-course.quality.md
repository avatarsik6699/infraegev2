# Мини-курс Excel — проверка качества уроков и практики

Курс перенесён на сайт в Change 177 с одобренного демо-стенда `content/lesson-design/course-excel/` (Change 176) по [пайплайну](../../runbooks/lesson-pipeline.md), раздел «Мини-курс Excel». Это второй опубликованный курс: 15 уроков в 6 модулях, 14 основных и 1 дополнительный (оформление, сводные таблицы, диаграммы). Темы ЕГЭ 3, 9, 18 и 22 на сайте пока устаревшие и на курс не ссылаются; реестр уроков для их терминов — `terms.EXCEL_TERMS`.

## Замысел

Курс учит механизмам электронной таблицы, которые нужны заданиям 3, 9, 18 и 22: адреса и диапазоны, формулы и их копирование со знаком $, функции по диапазону, условия и признаки, условный подсчёт и частоты, текст и даты, фильтр, поиск по ключу, расчёт по вычисленным соседям. Разборы самих заданий остаются темам. Главный наглядный инструмент — живой мини-лист: строка формул, цветные рамки ячеек, которые читает формула, правка исходных чисел с пересчётом в браузере. Процессы показаны пошаговыми схемами (вычисление формулы по шагам, ВПР, СУММЕСЛИ, Ctrl+стрелка), правило копирования — песочницей. Сквозной пример — таблица покупок (тетради, ручки, папки, карандаши).

## Независимые ответы

Ответ каждой задачи банка записан в `course-excel/tasks.json` так, как его вводит ученик. `bank.py` проверяет, что каждое значение ответа есть в ответе урока (небольшие числа урок может назвать словом), а `checks.py` пересчитывает ответы уроков вторым способом. `apps/api/tests/test_course_excel_bank.py` пересчитывает ответы всех 56 задач на чистом Python так, как их посчитал бы Excel, без вычислителя курса, проверяет порядок задач в уроках, урок вне mastery и вложение задачника: один файл по контрольной сумме, MIME `.xlsx`, листы «Задачи» и «Ответы».

## Вычислитель листа

Значения листов сайт считает сам: `apps/web/src/shared/lib/sheet-eval` — порт вычислителя стенда. Опорная семантика — `scripts/lesson_design/sheet_eval.py`; эталонный набор `apps/web/tests/fixtures/sheet-cases.json` (все листы курса как есть и со случайными правками, 210 случаев, 4520 ячеек) генерирует `verify_sheets.py --cases`, а Vitest требует совпадения каждой ячейки. Задачник собирается воспроизводимо (`workbook.py`: одинаковые данные — одинаковые байты) и пересчитывается независимой библиотекой `formulas`.
