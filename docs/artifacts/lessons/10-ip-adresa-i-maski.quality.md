## Замысел

Любая задача задания сводится к одной границе — длине префикса p. Октеты переводят в 32 бита, маску строят слева; адрес сети и последний адрес находят побитово и через размер блока, количество адресов и номер узла — по свободным битам, маску по адресу сети — неравенством L ≤ p ≤ C, два узла — по совпадающим битам, адреса с условием на двоичную запись — по фиксированным и свободным битам. Маска по условию и сочетания позиций единиц — дополнительный уровень.
