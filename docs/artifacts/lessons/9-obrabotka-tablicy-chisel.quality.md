## Независимые ответы

Ответ каждой задачи печатает её решающая программа, запущенная рядом с её файлом; `topic-9/bank.py` сверяет его с ответом в тексте подтемы. `apps/api/tests/test_task_9_bank.py` пересчитывает все 43 ответа другим способом, чем урок (`Counter`, множества, сортированная копия):

| Что проверяется | Независимый способ |
| --- | --- |
| Структура повторов | Длины серий равных значений отсортированной строки (`groupby`) |
| Группы повторяющихся и одиночных | Частоты, собранные словарём вручную |
| Средние | Деление вместо сравнения произведений |
| Порядок и прогрессия | Попарные сравнения соседей, множество разностей |
| Треугольники и грани | Сравнения без сортировки, все тройки из четырёх |
| Соседи ячейки | Список восьми смещений с проверкой границ |

Тест также проверяет: книга `.xlsx` и файл `.txt` задачи содержат одну таблицу; checker принимает ответ и отвергает соседний; задачи подтем 7–8 помечены `counts_toward_mastery: false`; у задач итоговой страницы нет ссылок на теорию.
