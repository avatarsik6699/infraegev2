# Мини-курс Python — проверка качества уроков и практики

Курс перенесён на сайт в Change 175 с одобренного демо-стенда `content/lesson-design/course-python/` (Change 174) по [пайплайну](../../runbooks/lesson-pipeline.md), раздел «Мини-курс Python». Он заменяет прежние 28 уроков: 30 уроков в 8 модулях, 27 основных и 3 дополнительных. Снятые уроки (список дел, «Ошибки», «Составные условия», «Счётчики и накопители», «Цифры числа», «Таблицы», «Полный перебор», «Отбор результата») удалены без редиректов. 140 задач прежних уроков архивированы. Ссылки устаревших тем на снятые уроки ведут на урок, который теперь объясняет тот же приём.

## Замысел

Курс строится снизу вверх: каждый урок начинается с главной идеи и опоры на прошлые уроки, сквозная задача — сумма и наибольшее из 5, −2, 10, 7 — решается всё короче, модули заканчиваются шагом-сборкой. Понятия показаны схемами из того же примера (П21). Процессы, где важен порядок строк, показаны запускаемыми примерами: шаги записаны реальным запуском при экспорте (П20). Тексты прошли аудит Change 174 (T31–T37). Дополнительные уроки решаются и сохраняются, но не входят в «освоено» курса (SPEC §1.4).

## Независимые ответы

Ответ каждой задачи банка записан в `course-python/tasks.json` так, как его вводит ученик. `bank.py` проверяет, что он совпадает с ответом в тексте урока, а `checks.py` пересчитывает ответы уроков вторым способом (каждый урок с задачами проверяется). `apps/api/tests/test_course_python_bank.py` пересчитывает ещё раз ответы 54 задач из всех уроков другим способом: формулами вместо циклов (сумма арифметической прогрессии, сочетания, `math.lcm`, `pow(…, 10)`), полным перебором вместо формулы, регулярными выражениями вместо `fnmatch`. Тест проверяет порядок задач в каждом уроке, что задачи дополнительных уроков вне mastery, что задачи прежнего курса архивированы и что сервер принимает ответ и с `−`.
