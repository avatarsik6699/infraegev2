# ЕГЭ № 24 — проверка качества урока и практики

Статус: локальная реализация Change 150. Урок и задачи имеют статус `published`, чтобы локальная страница выглядела как публичная; архитектор проверил страницу перед локальным `/ship`. Формулировки, пояснения и наборы символов созданы для этого урока. Демоверсия ФИПИ 2027 года использовалась только как ориентир для типа задания и состава символов; текст задания и файл данных не копировались.

## Переход от понятия к задаче

| Раздел теории              | Что вводится и проверяется                                      | Задача               |
| -------------------------- | --------------------------------------------------------------- | -------------------- |
| `file-and-string`          | Чтение строки из файла и сохранение внутренних символов         | Подготовка к № 01–08 |
| `positions-and-fragments`  | Индексы, непрерывность, невключаемая правая граница среза       | Подготовка к № 01–08 |
| `adjacent-and-overlapping` | Соседняя пара и перекрывающиеся вхождения                       | № 01                 |
| `longest-valid-run`        | Текущая и лучшая длина, сброс после запретного символа          | № 02–03              |
| `occurrence-limit`         | Окно с ограниченным числом перекрывающихся вхождений            | № 04                 |
| `expression-grammar`       | Допустимое число, одиночный ноль, ведущий ноль и бинарные знаки | № 05–07              |
| `linear-expression-scan`   | Длина законченного выражения при одном проходе                  | № 08                 |
| `independent-verification` | Сверка с полным перебором на коротких данных и проверка границ  | Контроль № 01–08     |

Теория сначала объясняет смысл нового слова на короткой строке, затем показывает правило и запускаемый код, разбирает результат, предлагает самостоятельное продолжение и типичную ошибку. Ссылки ведут только на опубликованные уроки мини-курса Python: файлы, строки и срезы, циклы, счётчики, арифметические выражения и выбор результата. Прохождение мини-курса не требуется для открытия этой темы.

## Ответы и независимая проверка

| ID           | Основная проверка                                  | Ответ | Ошибочный контроль | Сложность |
| ------------ | -------------------------------------------------- | ----: | -----------------: | --------: |
| `task-24-01` | Все начала `ABA`, включая пересечения              |     4 |                  3 |         1 |
| `task-24-02` | Самый длинный непрерывный участок из `A`, `B`, `C` |     5 |                  4 |         1 |
| `task-24-03` | Самый длинный участок без соседней пары `XY`       |     7 |                  6 |         2 |
| `task-24-04` | Участок с не более чем двумя вхождениями `ABA`     |     9 |                  8 |         2 |
| `task-24-05` | Число целых допустимых строк без нуля              |     4 |                  3 |         2 |
| `task-24-06` | Число целых допустимых строк с одиночным нулём     |     6 |                  5 |         3 |
| `task-24-07` | Длина выражения с вычитанием и проверкой границ    |     8 |                  7 |         3 |
| `task-24-08` | Длина выражения в большом исходном файле           |    81 |                 80 |         3 |

Задачи принадлежат только уроку `string-processing` в позициях 0–7, скрыты из общего каталога практики и связаны с согласованными разделами теории. Семь текстовых файлов хранятся под SHA-256; задачи 01 и 04 используют один файл для разных условий. Файл № 07 содержит 8 544 байта и 1 025 разных фрагментов, проверяющих ведущие нули, начальный и бинарный минус, двойные и конечные операторы. Единственный корректный максимум длины 8 — `9-68-7*0`; такой набор уже нельзя надёжно перебрать глазами. Файл № 08 содержит 133 247 байт исходных данных, а не готовый ответ. Он создан из непериодических блоков с фиксированным seed и единственным целевым выражением длины 81; такой объём требует программной обработки.

Проверка `apps/api/tests/test_task_24_bank.py` заново вычисляет каждый ответ по содержимому файла способом, отличным от опубликованного решения, выполняет все восемь фрагментов кода из объяснений, проверяет принятие верного и отклонение неверного ответа, размер и хеш каждого файла, порядок, связи и публичную проекцию без checker и приватного источника. Для № 07 тест проверяет объём, разнообразие фрагментов и единственность максимума. Для полного выражения отдельный короткий парсер служит независимым эталоном: тест сравнивает с ним линейный код для коротких строк и граничных случаев (`7-0`, `07`, `6--7`, конечный оператор). Проверка прошла: **3 passed**.

## Редакторская и браузерная проверка

Полные примеры Python из теории запущены тестом и выдают обещанные результаты. Поиск выражения дополнительно проверен на коротких случаях с отдельным и ведущим нулём, двойным и конечным оператором. Проверка готового HTML не нашла склеенных русских слов у встроенного кода и ссылок. Проверено, что ссылки ведут только на опубликованные уроки мини-курса.

В локальном окружении страница открылась с восемью задачами и прогрессом `0 / 8`. Playwriter проверил текст, ссылки на файлы и отсутствие ошибок консоли и горизонтальной прокрутки на ширине 390 px; снимок мобильной страницы и карточки каталога сделан через Chrome DevTools после таймаута снимка в расширении. Живой API отдал исходные файлы задач 01, 07 и 08 с HTTP 200 и ожидаемыми размерами 12, 8 544 и 133 247 байт. Браузерные сценарии темы 24 прошли с JavaScript и без него (**2 passed**), включая проверки навигации, контраста кода, доступности и увеличенного текста. Сценарии каталога подтвердили геометрию на ширинах 1305, 820, 390 и 360 px.

Затронутый Critical Gate прошёл: формат, web lint/typecheck, Ruff/Pyright, content validation и asset tests; сфокусированный набор Vitest дал **66 passed**, тест банка — **3 passed**.

## Финальный аудит перед локальным ship

Независимые ревью теории, банка и кода нашли неточное описание незавершённого `7-`, неполное объяснение подстроки `8*9` внутри ошибочного `08*9`, расплывчатое описание `strip()` и англоязычные комментарии в учебном примере. Формулировки уточнены. Эталонный тест задачи № 05 теперь запрещает ноль в любой позиции числа, как требует её условие, и содержит проверку для `60`. Общий фокусируемый блок кода получил видимый внутренний контур; ссылка на урок Python вынесена в общий для тем 17 и 24 компонент. Сигналы Fallow проверены по diff: публикационные экспорты только дополнены новой темой, прежние сигнатуры сохранены.

После исправлений прошли `pnpm format:check`, web lint/typecheck, Ruff/Pyright, `pnpm test:content-assets`, `pnpm validate:content`, **66** сфокусированных Vitest, **3** теста банка и четыре браузерных сценария тем 17 и 24 с JavaScript и без него. Первый повтор браузерного запуска не получил задачи из-за отсутствия read-only URL локальной БД у host runner; повтор с документированным окружением дошёл до проверки и выявил, что тест фокуса прокручивал страницу до проверки геометрии. Проверку фокуса перенесли после геометрии; итоговый запуск — **4 passed**. Playwriter подтвердил фокус на блоке и вычисленный внутренний контур на локальной странице.
