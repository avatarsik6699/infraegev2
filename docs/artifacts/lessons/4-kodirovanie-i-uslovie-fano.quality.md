## Замысел

Условие Фано проверяют в обе стороны; коды — пути в двоичном дереве, буквы — в листьях. По свободным ветвям находят кратчайший код, место для всех букв алфавита и наименьшую сумму длин, затем наименьшую длину слова с учётом частот и сравнивают формы дерева, когда короткий код частой букве невыгоден. Подсчёт кодов, код по записи слова, неравенство Крафта и метод Хаффмана — дополнительный уровень.

Схемы — 12 диаграмм и 5 пошаговых схем (чтение по дереву, место для букв, метод Хаффмана), 5 переключателей вариантов.

## Независимые ответы

Программы банка — функции урока `fano`, `decode`, поиск кода перебором длин и, для наименьших длин, перебор форм свободных ветвей (каждая ветвь пустая, с одной буквой или разделена — как в подтеме 5). `apps/api/tests/test_task_4_bank.py` считает иначе: наименьшую сумму длин — динамикой по вершинам дерева (сколько стоит разместить набор весов в поддереве вершины), коды и счётчики — перебором явных наборов кодовых слов без префиксов, декодирование и коды по записи — перебором всех разрезов битов, метод Хаффмана — кучей.

Тест также проверяет: checker принимает ответ и отвергает соседний; задачи подтем 6–7 вне mastery; у задач итоговой страницы нет ссылок на теорию; программы не длиннее 64 символов в строке.
