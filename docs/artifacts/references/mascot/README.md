# Маскот infraege

Утверждён архитектором 2026-10-04 (Change 170). Источник истины для всех иллюстраций с
маскотом; на сайт позы переносятся в рамках F6 Change 170.

## Персонаж

Живая стопка из трёх камней логотипа ([infraege-mark.svg](../infraege-mark.svg)):

- нижний камень — тело и лицо: глаза-точки, короткий штрих рта, у части эмоций брови;
- средний камень лежит сверху с небольшим зазором;
- верхний камень обведён оранжевым `#ff6a00` — единственный цветной элемент;
- тонкие руки с кружками на концах, короткие ноги с плоскими ступнями;
- только обводка, без заливки, теней и штриховки; линия неровная, «от руки».

Камни и конечности — трассировка сгенерированного листа
[`mascote_list.png`](../for_new_design/mascote_list.png). Глаза, рот и брови заново прорисованы
пером: штрих с нажимом и тонкими концами, точки — капли туши.

## Позы

Файлы в [`poses/`](poses/), по 7–9 КБ, `viewBox` в пикселях исходного листа.

| Группа | Файлы |
|---|---|
| Ракурсы | `front`, `side`, `back` |
| Позы | `stand`, `wave`, `point`, `jump`, `lotus` |
| Эмоции | `happy`, `think`, `sad`, `surprised`, `calm` |

Структура каждого SVG:

- `path.mascot-ink` — чёрные линии тела;
- `path.mascot-accent` — оранжевый верхний камень, отдельным слоем (его можно сдвинуть,
  например «уронить» в сцене ошибки);
- `g.mascot-face` — линии лица с фильтром `#mascot-face-<поза>` (мелкая неровность края).
  Id фильтров уникальны, поэтому несколько поз можно встраивать на одну страницу.

## Правила использования

- Маскот — в hero главной, на входе, 404, ошибке, пустом поиске и в шапках каталогов. Темы и
  курсы остаются предметными иллюстрациями без маскота.
- Предметы вокруг маскота рисуются той же толщиной и характером линии.
- Анимация только CSS-трансформациями слоёв и выключается при `prefers-reduced-motion`.
- Позы не перерисовываются вручную: изменения вносятся через конвейер
  [`change-170/mascot/pipeline`](../../change-170/mascot/README.md).
