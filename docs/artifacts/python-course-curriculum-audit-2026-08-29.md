# Аудит программы Python — 29 августа 2026

## Зачем пересматриваем курс

Текущая 19-шаговая программа последовательно знакомит новичка с базовыми конструкциями, но
уроки 4–19 почти одинаковы по объёму и композиции. Одинаковый ритм «определение → трассировка →
ошибка → процедура» делает разные по сложности темы искусственно равными. В нескольких уроках
один и тот же checkpoint повторяется внутри теории и в общем блоке. Финальный урок применяет
только линейное вычисление и граничную проверку, поэтому не подтверждает заявленное умение собрать
самостоятельную программу из знаний курса.

Официальный навигатор ФИПИ для ЕГЭ-2026 отдельно называет типы и выражения, целочисленные операции,
выделение цифр позиционной записи, массивы, сортировку и поиск. Текущий курс использует часть этих
приёмов в примерах, но не создаёт для них надёжного учебного шага. Включения, итераторы и генераторы
не являются центральным требованием ЕГЭ; они добавляются как компактное продолжение уже освоенных
коллекций, циклов и функций, чтобы курс давал не только набор экзаменационных шаблонов.

## Проверка существующей практики

Все 90 задач первоначальной траектории сохраняют стабильные id, принадлежат ровно одному уроку,
не раскрывают принятые ответы клиенту и проходят реальные варианты ответа через серверный checker.
Последовательности «трассировка → исправление → перенос → локальный запуск» не требуют скрытого
знания. Конкретный разрыв найден только в четырёх локальных этапах: они повторяли простую операцию,
но не закрепляли новые мосты к проекту. Задачи со стабильными id `python-strings-local-run`,
`python-lists-local-run`, `python-dictionaries-local-run` и `python-files-local-run` теперь
проверяют соответственно разбор команды, удаление из списка, изменение записи и запись файла.

## Новые учебные шаги

1. **Числа, типы и выражения** — `int`, `float`, преобразования, приоритет, `/`, `//`, `%`, `**`.
2. **Цифры числа** — выделение последней цифры и укорочение числа через `% 10` и `// 10`.
3. **Сортировка и поиск** — линейный поиск, `sorted`, `list.sort`, `key`, сохранение исходного списка.
4. **Включения** — списковые, множественные и словарные включения; один цикл и одно условие без
   вложенной головоломки.
5. **Итераторы и генераторы** — iterable → iterator → исчерпание → ленивый generator; `yield` и
   generator expression без `send`, корутин и асинхронности.
6. **Ожидаемые ошибки** — узкий `try/except` для конкретных `ValueError` и файловых ошибок без
   безусловного `except`.

## Сквозной проект «Менеджер задач»

Проект не начинается со спецификации или набора абстрактных моделей. В первом уроке появляется
минимально полезный работающий список. Каждый следующий запрос пользователя обнаруживает новую
потребность и естественно приводит к знакомой конструкции Python.

1. Добавить дело и показать список в цикле команд.
2. Отметить дело выполненным, изменить текст и удалить запись; повторяющиеся действия выделить в
   функции.
3. Сохранить список в JSON и восстановить его после запуска.
4. Пережить пустой список, неверную команду, неизвестный номер и повреждённый файл; пройти полный
   сценарий и привести имена и функции в понятный вид.

Каждый урок показывает исходное состояние, несколько небольших изменений и полный конечный снимок.
Одна из пяти практических задач просит выполнить локальный этап и ввести наблюдаемый результат.
Подсказка направляет к нужной части, решение содержит рабочий код, а следующий урок всегда начинает
с канонического завершённого снимка.
