# Assessment B — браузерные измерения

Независимая оценка /root/content_evidence_b, текущая локальная версия Change 156.
Playwriter использован для DOM/CSS, загрузки шрифтов, console/network и измерений
на 1440, 768, 390 и 320px. Полные численные результаты: metrics.json.

Три семейства шрифтов и веса 400/500/600 подтверждены. Размеры включают 12/13/14/16/18px,
24px mobile и 28px desktop для заголовков теории, а также производные размеры Notation.
Основная проза 16/26.88px; шаги примера 14/22.4px; итоговый h3 18/24.3px без линии.
Основной теоретический текст ограничен 640px; максимальная ширина всех измеренных p,
включая практику и итог, достигает 725–730px. Эти числа относятся к разным выборкам.

Range-измерение охватывает 41 p, включая текст в закрытых деталях практики:
desktop/tablet медиана46, p90 63, максимум66 символов на строку; mobile390 —29/35/36;
320 —23/28/30. Это измерение символов, не эксперимент скорости чтения.
В обычном состоянии page overflow не обнаружен. Код и полоса пяти табов практики
имеют собственную горизонтальную прокрутку, отдельно от страницы.

Пользовательские интервалы .12em letter / .16em word / 1.5 line-height / 2em после p
на390px не скрыли содержание. CSS zoom:2 дал document379/396px и article189/198px;
это диагностическая эмуляция, не проверка настоящего browser-menu zoom200% и не
подтверждённое нарушение WCAG. Требуется отдельное воспроизведение перед исправлением.

Контраст основного текста: белый17.93:1; danger/success поверхности14.17/14.55:1.

Синтаксические цвета кода исключены из подсчёта цветов прозы.
