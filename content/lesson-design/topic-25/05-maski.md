Главная идея подтемы: **маска описывает запись числа, а не его арифметические свойства, поэтому кандидатов можно либо проверять по маске, либо сразу строить по ней**. Маски с делимостью стабильно встречаются на экзамене с 2022 года: это больше трети задач задания 25.

Работу со строками — `str`, `int`, `len` — мы разобрали в подтеме 1. Функция `get_divisors` из подтемы 2 понадобится в конце.

---

**Теперь перейдём к маскам: они описывают не арифметические свойства числа, а его запись цифрами.**

Маска — образец, с которым сравнивается десятичная запись числа. В стандартных условиях задания обычная цифра должна стоять на указанном месте, `?` заменяет ровно одну произвольную цифру, а `*` — последовательность цифр любой длины, в том числе нулевой.

Так, маске `12?4` соответствуют 1204, 1214, 1224, …, 1294. А маске `12*4` — например, 124, 1204, 1234, 12004 и 1234564: звёздочка в них обозначает пустую строку, `0`, `3`, `00` и `3456`.

**Пустая строка и цифра 0 — разные вещи.** Подставив вместо `*` в маске `12*4` ничего, получим 124, подставив `0` — 1204, а `00` — 12004. Если забыть пустой вариант, часть подходящих чисел будет потеряна.

Рассмотрим маску посложнее — `12*3?`. В ней фиксировано начало `12`, затем идёт произвольная вставка, затем цифра `3` и ровно одна любая цифра. Разложим несколько чисел по её частям: каждая цифра числа становится под ту часть маски, которой она соответствует.

<figure class="plate-figure">
%%mask_align("12*3?", ["1234", "120034", "12934", "12304", "123"])%%
<figcaption>Числа, разложенные по частям маски 12*3?. Звёздочка может забрать любое количество цифр, в том числе ни одной. Серые клетки — числа, которые разложить по маске нельзя: у 12304 перед последней цифрой стоит 0, а требуется 3, а у 123 не хватает цифры для ?.</figcaption>
</figure>

Если в маске несколько вопросительных знаков, каждый заполняется независимо: они не обязаны обозначать одинаковые цифры.

Попробуйте сами: поменяйте маску или число и посмотрите, как цифры распределяются по её частям. Например, проверьте 12304, 1203 и 1239934 для маски `12*3?` или придумайте свою маску.

---

Это удобно для определения возможной длины звёздочки. В маске `12*3?` обязательных цифр четыре: две в `12`, одна `3` и одна для `?`. Поэтому при ограничении до шестизначных чисел звёздочка может содержать 0, 1 или 2 цифры. При произвольном ограничении `limit` безопасная верхняя оценка такая:

```python
max_star_length = len(str(limit)) - 4
```

После генерации всё равно нужно проверять `n <= limit`: количество цифр само по себе не гарантирует численную границу. Числа 120000 и 999999 оба шестизначные, но при ограничении 200000 второе уже не подходит.

И помните, что 10⁹ = 1000000000 имеет **десять** цифр. Формулировки «меньше 10⁹» и «не больше 10⁹» отличаются включением этой границы.

---

**Проверить соответствие готового числа маске можно стандартной функцией `fnmatch`.** Её подключают строкой {{import|`from fnmatch import fnmatch`}} и вызывают как `fnmatch(str(n), mask)`: первый аргумент — проверяемая строка, второй — маска.

```python
from fnmatch import fnmatch

print(fnmatch("1234", "12*3?"))
print(fnmatch("12304", "12*3?"))
```

```output
True
False
```

Функция сопоставляет строку с шаблоном целиком. В самой `fnmatch` знаки `?` и `*` работают с произвольными символами; когда передаём `str(n)` для натурального числа, строка состоит только из цифр, поэтому это соответствует смыслу числовой маски. [Python 3.14.8 documentation](https://docs.python.org/3/library/fnmatch.html)

При этом `fnmatch` проверяет только маску. Делимость числа, верхнюю границу, количество делителей и другие ограничения она не проверяет — их нужно учитывать отдельно.

---

**Если число должно делиться на k, выгодно перебирать только кратные k.** Это первый основной способ решения задач на маски.

Положительные числа, кратные k, — это k, 2k, 3k, 4k, … Для их перебора у {{for|`range`}} есть третий аргумент — шаг:

```python
for n in range(7, 31, 7):
    print(n)
```

```output
7
14
21
28
```

> Найти числа не больше 99 999, запись которых соответствует маске `12*3?`, а сами числа делятся на 13. Вывести числа и частные.

```python
from fnmatch import fnmatch

limit = 99_999
divisor = 13

for n in range(divisor, limit + 1, divisor):
    if fnmatch(str(n), "12*3?"):
        print(n, n // divisor)
```

```output
1235 95
12038 926
12233 941
12337 949
12532 964
12636 972
12831 987
12935 995
```

Подчёркивание в `99_999` нужно только для удобства чтения — это то же значение, что `99999`. Перебор уже обеспечивает положительность чисел (начали с 13), делимость на 13 (шаг 13), верхнюю границу и порядок возрастания. Внутри цикла остаётся проверить маску, а проверка `n % 13 == 0` здесь не нужна: она всегда истинна.

---

**При поиске кратных внутри отрезка важно правильно выбрать первое число.**

Частая ошибка — думать, что `range(L, R + 1, k)` перебирает кратные `k`. На самом деле он перебирает L, L + k, L + 2k, … — и если само L не кратно k, все эти числа имеют тот же ненулевой остаток:

```python
print(list(range(100, 151, 23)))
```

```output
[100, 123, 146]
```

Ни одно из них не кратно 23. Нужно сначала найти первое кратное, не меньшее L:

```python
start = L

if L % k != 0:
    start = L + (k - L % k)
```

Для L = 100 и k = 23: 100 = 23 · 4 + 8, до следующего кратного не хватает 23 − 8 = 15, поэтому start = 100 + 15 = 115. Теперь `range(start, R + 1, k)` даёт нужные кратные.

Ту же границу можно вычислить одной формулой — она округляет L / k вверх до целого и умножает на k. Для понимания достаточно сначала уверенно пользоваться вариантом через остаток.

```python
start = ((L + k - 1) // k) * k
```

---

**Второй основной способ решения масок — создавать числа сразу по маске.** Иногда это значительно быстрее перебора кратных.

Если искать до 10⁹ среди кратных 23, получится примерно 10⁹ / 23 ≈ 43,5 млн кандидатов. Но если маска содержит только два вопросительных знака и больше никаких переменных мест, ей соответствуют всего 10 · 10 = 100 записей — при условии, что первая цифра уже фиксирована и не равна нулю. Вместо десятков миллионов проверок можно выполнить сто.

Например, в одной из задач такого типа используется маска `12345?7?8`, требуется делимость на 23, а верхняя граница равна 10⁹.

Обозначим цифры на местах вопросительных знаков через `a` и `b`: число имеет вид `12345 a 7 b 8`, и каждая из цифр принимает значения от 0 до 9. Вложенные циклы перебирают для каждого `a` все десять значений `b`:

```python
answers = []

for a in range(10):
    for b in range(10):
        s = "12345" + str(a) + "7" + str(b) + "8"
        n = int(s)

        if n <= 10 ** 9 and n % 23 == 0:
            answers.append(n)

for n in sorted(answers):
    print(n, n // 23)
```

```output
123450798 5367426
123451718 5367466
123453788 5367556
123454708 5367596
123456778 5367686
123459768 5367816
```

Соответствие маске здесь гарантируется самим способом построения числа.

То же число можно собрать арифметически: n = 123450708 + 1000a + 10b, потому что `a` стоит в разряде тысяч, а `b` — в разряде десятков. Строковый вариант обычно проще читать, а арифметический помогает увидеть связь маски с разрядами числа.

```python
n = 123450708 + 1000 * a + 10 * b
```

---

**Количество кандидатов нужно оценивать до запуска программы.** Это помогает выбрать между перебором кратных и генерацией по маске.

Для маски без звёздочек с q вопросительными знаками число комбинаций обычно 10<sup>q</sup>. Если вопросительный знак стоит первым, нельзя разрешать ему принимать 0 в обычной записи многозначного числа.

Для одной звёздочки длиной от 0 до s количество вариантов её заполнения — 1 + 10 + 10² + … + 10<sup>s</sup>. Первый член равен 1, потому что пустая строка — один вариант; длина 1 даёт десять вариантов `0`–`9`, длина 2 — сто вариантов `00`–`99`, длина 3 — тысячу. Если дополнительно есть q вопросительных знаков, количество сочетаний при фиксированном ненулевом начале — 10<sup>q</sup> · (1 + 10 + … + 10<sup>s</sup>).

Например, у маски `12*3?` при ограничении до шести цифр один вопросительный знак и звёздочка длиной от 0 до 2. Получаем 10 · (1 + 10 + 100) = 1110 кандидатов.

Это число сравнивают с количеством кратных в разрешённом диапазоне и выбирают более короткий перебор. Учитывать нужно и стоимость проверки: найти остаток от деления обычно дешевле, чем полностью найти делители большого числа.

---

**Генерация звёздочки требует сохранять нули внутри подстановки.** Это одна из самых частых ошибок в задачах на маски.

Если звёздочка должна заменять две цифры, нужны все варианты `00`, `01`, …, `09`, `10`, …, `99`. Но `str(7)` даёт `"7"`, а не `"07"`: если напрямую использовать числа от 0 до 99, вставки `00`–`09` не будут двухсимвольными строками. Дополнить строку нулями слева до нужной длины помогает метод `zfill` — действие, которое вызывают через точку у строки:

```python
print(str(7).zfill(2), str(0).zfill(2))
print(str(42).zfill(2), str(7).zfill(3))
```

```output
07 00
42 007
```

Теперь построим числа по маске `12*3?` для уже знакомого условия: `n <= 99_999` и число кратно 13.

```python
limit = 99_999
divisor = 13

mandatory_length = 4
max_star_length = len(str(limit)) - mandatory_length

answers = []

for length in range(max_star_length + 1):
    for value in range(10 ** length):
        if length == 0:
            star = ""
        else:
            star = str(value).zfill(length)

        for digit in range(10):
            s = "12" + star + "3" + str(digit)
            n = int(s)

            if n <= limit and n % divisor == 0:
                answers.append(n)

for n in sorted(answers):
    print(n, n // divisor)
```

```output
1235 95
12038 926
12233 941
12337 949
12532 964
12636 972
12831 987
12935 995
```

Ответ совпал с перебором кратных. В маске четыре обязательные цифры, звёздочка добавляет к ним новые. Внешний цикл перебирает длину вставки, начиная с нулевой, а следующий — значения, которыми можно заполнить вставку этой длины: при `length == 2` это 0, 1, …, 99, а после `zfill(2)` — `00`, `01`, …, `99`.

Нулевая длина обрабатывается отдельно. При ней `range(10 ** 0)` — это `range(1)`, один проход со значением 0, но нужна не строка `"0"`, а отсутствие символов — `""`. В этом примере верхняя граница пятизначная, поэтому звёздочка имеет длину 0 или 1. Если заменить `limit` на `999_999`, та же программа сама начнёт рассматривать и двухсимвольные вставки, включая `00`.

**Нули внутри числа не исчезают при преобразовании всей записи в `int`.** `int("12" + "00" + "3" + "4")` даёт 120034. Проблема возникает тогда, когда нужные нули потеряны ещё до соединения частей.

---

**Начальные нули и несколько звёздочек требуют отдельного внимания.**

Обычная десятичная запись натурального числа не начинается с нуля: `int("0123")` даёт 123, а запись `str(123)` — это `"123"`, не `"0123"`. Поэтому при генерации четырёхзначного числа по маске `?123` первый вопросительный знак должен принимать значения от 1 до 9:

```python
for first_digit in range(1, 10):
    n = int(str(first_digit) + "123")
```

Если маска начинается со звёздочки или устроена сложнее, полезно дополнительно проверять уже полученное число через `fnmatch(str(n), mask)`: так с маской сравнивается именно обычная запись числа.

При нескольких звёздочках одно число иногда можно получить разными способами. Для маски `1*2*3` число 1223 собирается и как 1 + "" + 2 + "2" + 3, и как 1 + "2" + 2 + "" + 3: число одно, а способов подстановки два. Если генерация допускает такие совпадения, результаты удобно складывать в {{set|множество}} — повторов в нём не будет:

```python
answers = set()
```

Число добавляют через `answers.add(n)`, а после завершения выводят по возрастанию:

```python
for n in sorted(answers):
    print(n)
```

Для масок с несколькими звёздочками перебор кратных с проверкой `fnmatch` часто оказывается проще по устройству. Его всё равно нужно предварительно оценить по количеству кандидатов.

---

**Условия на маску и делители можно объединять в одной программе.** Здесь полезно сначала выполнять проверки, которые быстро отбрасывают неподходящие числа.

Пусть число должно соответствовать маске, делиться на заданное `k` и иметь ровно определённое количество делителей. Разумный порядок: получить кратные `k` или сразу сгенерировать числа по маске, проверить оставшееся простое условие и только затем искать делители.

```python
from fnmatch import fnmatch

limit = 100_000
k = 37

for n in range(k, limit + 1, k):
    if fnmatch(str(n), "1?2*"):
        D = get_divisors(n)

        if len(D) == 8:
            print(n)
```

Сначала маска отбирает небольшую часть кандидатов, и полный поиск делителей выполняется только для них.

Маска может относиться и не к исходному числу, а к его делителю. Здесь ищутся делители, запись которых начинается на 1 и заканчивается на 7 с допустимой вставкой между ними:

```python
selected = []

for d in get_divisors(n):
    if fnmatch(str(d), "1*7"):
        selected.append(d)
```

Поэтому сначала нужно определить **объект условия**: маска самого числа, маска делителя, окончание суммы делителей или простота вычисленной величины. В коде эти проверки выглядят похоже, но выполняются над разными переменными.

---

**Определение знаков маски всегда читаем в условии.** В тренировочных работах встречаются маски, где `?` означает не любую цифру, а только **чётную** или только **нечётную**.

`fnmatch` позволяет записать набор допустимых символов в квадратных скобках: `[02468]` — одна чётная цифра, `[13579]` — одна нечётная. Например, если `?` в маске `5?8*1` означает чётную цифру, для `fnmatch` ту же маску пишут как `5[02468]8*1`. Посчитаем кратные 701 не больше 10⁷, подходящие под неё:

```python
from fnmatch import fnmatch

count = 0

for n in range(701, 10 ** 7 + 1, 701):
    if fnmatch(str(n), "5[02468]8*1"):
        count += 1

print(count)
```

```output
9
```

Если же числа генерируются по маске, для такого `?` вместо `range(10)` перебирают `[0, 2, 4, 6, 8]`.

---

**Итого.**

- `?` — ровно одна цифра; `*` — любая последовательность, **в том числе пустая**.
- Готовое число проверяем `fnmatch(str(n), mask)`. Сама маска не проверяет делимость и границы.
- При делимости на k перебираем кратные: `range(первое_кратное, R + 1, k)`.
- Если переменных мест мало, строим числа по маске. Вставки звёздочки дополняем нулями: `zfill`.
- Перед запуском оцениваем число кандидатов обоими способами и выбираем меньший перебор.
