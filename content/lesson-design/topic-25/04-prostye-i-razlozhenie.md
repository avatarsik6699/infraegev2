Главная идея подтемы: **каждое число больше 1 раскладывается на простые множители, и по этому разложению сразу видны все его простые делители**. Это самый частый приём в задачах 2025–2026 годов: он нужен в 16 из 27 задач этих лет, в том числе в задачах основной волны ЕГЭ-2026.

Функцию `get_divisors` из подтемы 2 считаем определённой выше в программе.

---

**Простые числа нужны тогда, когда условие говорит именно о простых делителях или простых множителях.** Дадим точное определение.

**Простое число** — натуральное число больше 1, имеющее ровно два натуральных делителя: 1 и само число. Например, 2, 3, 5, 7, 11, 13, 17. **Составное число** — натуральное число больше 1, у которого есть делитель, отличный от 1 и самого числа: так, 12 делится на 2, 3, 4 и 6. Число 1 ни простое, ни составное — у него только один натуральный делитель.

Чтобы проверить простоту, не обязательно искать все делители. Достаточно попытаться найти хотя бы один делитель между 2 и √n: если число составное, оно раскладывается в произведение двух чисел больше 1, и хотя бы одно из них не превосходит корня — это уже доказанное свойство пар делителей.

```python
def is_prime(n):
    if n < 2:
        return False

    for d in range(2, isqrt(n) + 1):
        if n % d == 0:
            return False

    return True
```

Числа меньше 2 не простые. Если найден хотя бы один делитель, число составное. А `return True` стоит после цикла: после одной неудачной попытки деления ещё нельзя объявлять число простым. Например, 25 не делится на 2, но делится на 5 — ответ «простое» сразу после проверки 2 был бы ошибкой.

```python
print(is_prime(1), is_prime(2), is_prime(49), is_prime(97))
```

```output
False True False True
```

У 2 цикл не выполнится ни разу: между 2 и `isqrt(2)` нет проверяемых чисел. После предварительной проверки `n < 2` это нормальная ситуация, и функция вернёт `True`.

Теперь можно найти простые делители — отобрать среди всех делителей простые:

```python
n = 84
D = get_divisors(n)

prime_divisors = []

for d in D:
    if is_prime(d):
        prime_divisors.append(d)

print(prime_divisors)
```

```output
[2, 3, 7]
```

Такой способ понятен, но если требуются только простые делители, удобнее использовать разложение на простые множители.

---

**Разложение на простые множители показывает, из каких простых чисел составлено исходное число.** Это не то же самое, что список всех его делителей.

Например, 72 = 2 · 2 · 2 · 3 · 3. Одинаковые множители можно объединить в степени: 72 = 2³ · 3² — двойка встречается три раза, тройка два. Для одного и того же числа легко перепутать три разных объекта. Выберите, о чём спрашивает условие:

:::pick Три разных объекта для числа 72
- *все натуральные делители | 1, 2, 3, 4, 6, 8, 9, 12, 18, 24, 36, 72 | их 12
- различные простые делители | 2, 3 | их 2
- простые множители с повторениями | 2, 2, 2, 3, 3 | их 5
:::

Эти количества — 12, 2 и 5 — нельзя смешивать.

Разложение получают последовательным делением. Возьмём 360 и будем делить на 2, пока это возможно: 360 → 180 → 90 → 45 — извлекли три двойки. Оставшееся 45 делим на 3: 45 → 15 → 5 — извлекли две тройки. Остался простой множитель 5, и 360 = 2³ · 3² · 5.

В тетради такое разложение удобно записывать «лесенкой»: слева то, что осталось от числа, справа — простой множитель, на который делим.

<figcaption>Разложение 360 лесенкой. Каждая строка — одно деление. Правый столбец сверху вниз и есть все простые множители с повторениями.</figcaption>
</figure>

Программа делает то же самое:

```python
def prime_factors(n):
    factors = []
    m = n
    d = 2

    while d * d <= m:
        while m % d == 0:
            factors.append(d)
            m //= d

        d += 1

    if m > 1:
        factors.append(m)

    return factors
```

`m` — рабочая копия числа, её уменьшаем делением; `m //= d` означает `m = m // d`. Внутренний цикл `while m % d == 0` нужен, чтобы извлечь **все повторения** множителя `d`: с `if` удалился бы только один множитель, и у 72 вместо трёх двоек нашлась бы одна.

Посмотрим, как программа работает на числе 1050. На нём видно всё сразу: множитель 5 повторяется, составной кандидат 4 проверяется, но ничего не делит, а после цикла остаётся последний множитель.

%%factor_stepper(1050)%%

Остаются два вопроса, которые возникают при чтении кода.

Почему перебираем не только простые `d`, а в список всё равно попадают только простые множители? Когда цикл доходит до составного `d`, его меньшие простые множители уже полностью удалены из `m`. Поэтому составное `d` разделить оставшееся число не может.

Почему остаток `m > 1` после цикла можно дописать как простой множитель? Если бы он был составным, у него нашёлся бы делитель не больше его квадратного корня, и цикл нашёл бы этот делитель. Раз цикл закончился, оставшееся число больше 1 — простое.

```python
print(prime_factors(360))
```

```output
[2, 2, 2, 3, 3, 5]
```

Убрать повторения помогает {{set|множество}}: в нём каждое значение хранится один раз, так что `set([2, 2, 2, 3, 3, 5])` содержит только 2, 3 и 5. Множество само по себе не упорядочено, поэтому, чтобы брать первый, последний и другие элементы, сначала применяем `sorted`:

```python
unique_factors = sorted(set(prime_factors(360)))
print(unique_factors)
```

```output
[2, 3, 5]
```

---

**Простые делители числа — это различные множители его разложения.** Чтобы получить их по возрастанию, достаточно убрать повторы и отсортировать:

```python
print(sorted(set(prime_factors(84))))
print(sorted(set(prime_factors(72))))
```

```output
[2, 3, 7]
[2, 3]
```

Это быстрее, чем искать все делители и проверять каждый на простоту: разложение делает не больше √n шагов и сразу выдаёт только простые числа. Любые величины из условия получаются из этого списка `P`. Выберите, что требуется, — значение показано для 84, у которого `P = [2, 3, 7]`:

:::pick Что требуется и выражение по списку P простых делителей
- *наименьший простой делитель | `P[0]` → 2
- наибольший простой делитель | `P[-1]` → 7
- сумма наименьшего и наибольшего | `P[0] + P[-1]` → 9
- сумма всех различных | `sum(P)` → 12
- количество различных | `len(P)` → 3
:::

**«Не считая самого числа» меняет ответ только для простых чисел.** У простого числа 97 разложение — `[97]`, и его единственный простой делитель — оно само. Если условие говорит «не считая самого числа», список становится пустым, и величину нужно взять такой, как велит условие (обычно 0).

```python
def prime_divisors(n):
    P = sorted(set(prime_factors(n)))
    return [p for p in P if p != n]

print(prime_divisors(84))
print(prime_divisors(97))
print(prime_divisors(49))
```

```output
[2, 3, 7]
[]
[7]
```

У 49 = 7 · 7 простой делитель 7 не совпадает с самим числом, поэтому он остаётся.

---

**«Произведение ровно двух простых множителей» и «ровно два различных простых делителя» — разные условия.**

| Число | Разложение | Множителей с повторениями | Различных простых делителей |
|---:|---|---:|---:|
| 15 | 3 · 5 | 2 | 2 |
| 9 | 3 · 3 | 2 | 1 |
| 12 | 2 · 2 · 3 | 3 | 2 |
| 30 | 2 · 3 · 5 | 3 | 3 |
| 8 | 2 · 2 · 2 | 3 | 1 |

Поэтому:

- «представимо в виде произведения ровно двух простых множителей, **не обязательно различных**» — `len(prime_factors(n)) == 2`. Подходят 15 и 9;
- «имеет ровно два **различных** простых делителя» — `len(set(prime_factors(n))) == 2`. Подходят 15 и 12.

Слова «не обязательно различных» в условии важны: они разрешают квадраты простых чисел вроде 9 = 3 · 3.

**Условие на цифры множителей проверяется у каждого множителя отдельно.**

> Найти три наименьших числа, больших 100, которые представимы в виде произведения ровно двух простых множителей, не обязательно различных, и каждый из множителей содержит в записи цифру 1.

Порядок рассуждений: для n = 101, 102, … раскладываем n на простые множители, проверяем, что их ровно два и в записи каждого есть цифра 1, и останавливаемся после третьего найденного числа.

```python
n = 101
found = 0

while found < 3:
    f = prime_factors(n)
    if len(f) == 2 and all("1" in str(p) for p in f):
        print(n, f)
        found += 1
    n += 1
```

```output
121 [11, 11]
143 [11, 13]
169 [13, 13]
```

`all("1" in str(p) for p in f)` читается так: для каждого множителя `p` из `f` проверить, что в его записи есть `1`, и ответить «да», только если это верно для всех. Похожая функция `any` отвечает «да», если условие выполнено **хотя бы для одного** элемента: она нужна в условии «хотя бы один из множителей содержит цифру…».

В ответе есть 121 = 11 · 11: множители одинаковые, и слова «не обязательно различных» это разрешают.

---

**Разложение работает быстро даже для чисел около 10¹⁰.** Цикл проверяет d только пока d·d не больше оставшегося числа. В худшем случае, когда число простое, это около √n шагов. Для числа около 5·10⁹ это примерно 70 тысяч проверок, а для большинства чисел намного меньше: маленькие множители быстро уменьшают m.

Поэтому задачи вида «перебирать числа больше 4 500 000 000 и найти первые пять подходящих» решаются прямым перебором с разложением. Нужные числа встречаются часто, и перебрать придётся немного.

---

**Итого.**

- Простое число имеет ровно два делителя; 1 не простое. Простоту проверяем до √n.
- Разложение: делим на d, пока делится (`while`, не `if`), потом переходим к следующему d; остаток больше 1 — последний простой множитель.
- Простые делители — `sorted(set(prime_factors(n)))`; «не считая самого числа» убирает n у простых чисел.
- «Ровно k простых множителей» — длина разложения с повторениями; «k различных простых делителей» — длина множества.
- Условие на цифры каждого множителя — `all(...)`, хотя бы одного — `any(...)`.
