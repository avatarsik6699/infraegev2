Главная идея урока: **строка — упорядоченная неизменяемая последовательность символов, к частям которой обращаются по индексам и срезам**. Опора — `for` по строке и правило `range` «начало включено, остановка нет» из прошлого урока: срезы устроены точно так же.

Сквозной пример урока — строка `"ABCDEFG"` и слово `"PYTHON"`: на них разберём индексы, срезы и неизменяемость.

---

**У строки есть длина и элементы, пронумерованные с нуля.** Строка — упорядоченная последовательность символов. У неё есть длина, элементы и фрагменты. Порядок существенен: `"кот"` и `"ток"` состоят из одинаковых букв, но являются разными строками.

```python
word = "PYTHON"
print(len(word))
print(word[0])
print(word[2])
print(word[-1])
```

```output
6
P
T
N
```

`len` получает количество элементов. **Индекс** — номер позиции. Положительные индексы начинаются с 0: это удобно понимать как число шагов от начала. Для строки длины `n` допустимы индексы от 0 до `n - 1`. Отрицательные индексы считают с конца: −1 — последний элемент, −2 — предпоследний.

<figure class="plate-figure">
%%slice("PYTHON", 0, 0)%%
<figcaption>Над буквой — индекс от начала, под ней — с конца. У последней буквы N индексы 5 и −1.</figcaption>
</figure>

Обращение к `word[6]` вызывает ошибку: такой позиции нет.

```python
word = "PYTHON"
print(word[6])
```

```error
IndexError: string index out of range
```

У пустой строки `""` длина 0, поэтому в ней нет даже элемента с индексом 0. Отдельного встроенного типа «символ» в Python нет: `word[0]` тоже строка, просто длины 1.

---

**Срез берёт элементы от начала до остановки, не включая её.** **Срез** получает последовательность элементов по правилу `s[start:stop:step]`. Остановка не включается, как в `range`.

```python
s = "ABCDEFG"
print(s[1:4])
print(s[:3])
print(s[4:])
print(s[::2])
print(s[::-1])
print(s[5:1:-1])
```

```output
BCD
ABC
EFG
ACEG
GFEDCBA
FEDC
```

<figure class="plate-figure">
%%slice("ABCDEFG", 1, 4)%%
<figcaption>Границы среза стоят между символами: start = 1 перед B, stop = 4 перед E. Поэтому E в срез не входит, а длина среза 4 − 1 = 3.</figcaption>
</figure>

`s[1:4]` берёт индексы 1, 2, 3 — ровно как `range(1, 4)`. Для положительного шага пропущенное начало означает начало строки, пропущенная остановка — её конец. Для отрицательного шага значения по умолчанию меняются: движение начинается с конца и идёт до начала. Поэтому `s[::-1]` разворачивает всю строку, а `s[5:1:-1]` идёт от индекса 5 вниз до 2.

<figure class="plate-figure">
%%slice("ABCDEFG", 5, 1, -1)%%
<figcaption>При шаге −1 срез идёт справа налево: от индекса 5 к индексу 2; F берётся первой, C — последней, индекс 1 уже не входит.</figcaption>
</figure>

Важно различать пропущенную границу и явно написанное `-1`. В `s[5:-1:-1]` явное `-1` сначала означает последний индекс. При строке длины 7 движение от позиции 5 назад к границе 6 не даёт ни одного элемента. Пропущенная остановка при отрицательном шаге — особое обозначение движения за начало.

Срез за пределами длины обрезается: `s[:100]` вернёт всю строку. Одиночный неверный индекс вызывает ошибку. Срез может быть пустым; это нормальный результат. Шаг 0 недопустим.

Проверь срезы сам: поле start или stop можно оставить пустым, шаг — сделать отрицательным. Номер под буквой — очередь, в которой срез её берёт.

---

**Строку нельзя изменить на месте — можно только построить новую.** **Неизменяемость** означает, что нельзя заменить элемент внутри существующей строки:

```python
s = "кот"
s[0] = "р"
```

```error
TypeError: 'str' object does not support item assignment
```

Можно построить новую строку и связать с ней имя:

```python
s = "кот"
s = "р" + s[1:]
print(s)
```

```output
рот
```

`+` соединяет строки. Это действие называют **конкатенацией**. `"ab" * 3` повторяет текст и создаёт `"ababab"`. Старый объект не переписывается, даже если имя переменной осталось прежним.

---

**Метод — действие, которое вызывают у объекта через точку.** Запись `s.lower()` означает «вызвать действие `lower` для строки `s`». Точка связывает действие с объектом, скобки запускают его.

Частые методы строки на примере `s = "Banana"` — выбери метод, чтобы увидеть результат:

:::pick Методы строки `s = "Banana"`
- *lower / upper | `s.lower()` → `'banana'` | новая строка в нижнем регистре; `s.upper()` — в верхнем
- strip | `"  Banana  ".strip()` → `'Banana'` | пробелы и переводы строки по краям; `rstrip` — только справа
- replace | `s.replace("a", "o")` → `'Bonono'` | все вхождения; с третьим аргументом `1` — только первое
- find | `s.find("an")` → `1` | индекс первого вхождения, −1 если нет
- count | `s.count("an")` → `2` | неперекрывающиеся вхождения
- startswith | `s.startswith("Ba")` → `True` | `endswith` — проверка конца
- zfill | `"101".zfill(8)` → `'00000101'` | нули слева до длины 8
- in | `"nan" in s` → `True` | есть ли фрагмент внутри строки
:::

Методы не меняют исходную строку. Вызов `s.replace("a", "b")` с проигнорированным результатом не обновляет `s`; для этого нужно присваивание.

```python
s = "  Python  "
clean = s.strip().lower()
print(clean)
print("th" in clean, clean.find("th"))
print("101".zfill(8))
```

```output
python
True 2
00000101
```

Сначала `strip` создаёт промежуточную строку без крайних пробелов; затем `lower` вызывается уже для неё. Это два последовательных действия. `zfill` удобен, когда запись числа нужно выровнять по длине, например двоичную запись до восьми знаков.

Не проверяй поиск как `if s.find(part):`: индекс 0 ложен, а отсутствие с индексом −1 истинно. Используй `part in s` или явное сравнение с −1.

<details class="proof" markdown="1">
<summary>Тонкости: что именно убирает strip</summary>

`strip("ab")` убирает по краям любой набор символов `a` и `b`, а не обязательно целую подстроку `"ab"`. Для удаления ровно одного известного префикса существует `removeprefix`.

</details>

---

**`count` не считает перекрывающиеся вхождения.** В `"AAAA"` фрагмент `"AA"` начинается на позициях 0, 1 и 2. Но `"AAAA".count("AA")` возвращает 2: после найденного совпадения поиск продолжится за ним.

<figure class="plate-figure">
%%overlap("AAAA", "AA")%%
<figcaption>«AA» начинается в «AAAA» с позиций 0, 1 и 2. <code>count</code> находит начала 0 и 2, а начало 1 пропускает: оно перекрывается с найденным.</figcaption>
</figure>

Для подсчёта всех начал можно проверить каждую позицию:

```python
s = "AAAA"
part = "AA"
count = 0
for i in range(len(s) - len(part) + 1):
    if s[i:i + len(part)] == part:
        count += 1
print(count, s.count(part))
```

```output
3 2
```

Последнее допустимое начало — `len(s) - len(part)`. Именно поэтому верхняя граница `range` на 1 больше. Если шаблон длиннее текста, диапазон пуст. С пустым шаблоном `count` ведёт себя неожиданно: `"abc".count("")` равно 4 — пустая строка «находится» перед каждым символом и в конце. Если шаблон может оказаться пустым, обработай этот случай отдельно.

---

**Некоторые символы записывают через обратный слеш, а сами символы — это коды Unicode.** `\n` внутри обычной строки означает перевод строки, `\t` — табуляцию, `\\` — один обратный слеш. Чтобы увидеть представление со специальными символами, используй `repr`:

```python
s = "A\nB"
print(len(s))
print(repr(s))
print(ord("A"), chr(66))
```

```output
3
'A\nB'
65 B
```

Длина 3: A, перевод строки, B. Python хранит строки как Unicode-текст. `ord("A")` возвращает код символа, `chr(66)` — символ по коду. Обычная сортировка строк основана на кодах, а не на словарных правилах русского языка.

<details class="proof" markdown="1">
<summary>Тонкости: Unicode, эмодзи и isdigit</summary>

Некоторые визуально единые знаки, особенно эмодзи с модификаторами, состоят из нескольких кодовых точек: `len` считает именно кодовые точки, а не всегда видимые «картинки».

Строковые методы `isdigit()` и `isalpha()` работают шире набора английских букв и цифр ASCII. Если условие разрешает строго цифры `0`–`9`, проверяй соответствующий набор. Пустая строка для `isdigit()` даёт `False`.

</details>

---

**Итого.**

- Индексы с 0 до `len(s) - 1`, отрицательные — с конца; неверный индекс даёт `IndexError`.
- Срез `s[start:stop:step]` не включает `stop`; `s[::-1]` разворачивает строку.
- Строка неизменяема: методы и `+` создают новые строки.
- `count` считает без перекрытий; с перекрытием — проверка каждой позиции срезом.
- `in` проверяет вхождение; `find` возвращает −1 при отсутствии, а 0 — это найденное начало.
