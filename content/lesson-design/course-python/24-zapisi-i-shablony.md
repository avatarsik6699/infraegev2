Главная идея урока: **число и его запись — разные вещи: Python переводит запись в число и обратно, умеет работать с отдельными битами и проверять запись по шаблону**. Опора — цифры числа через `%` и `//` из уроков о числах и `while` и строковые методы: двоичная запись устроена так же, как десятичная, только с другими весами разрядов.

Сквозной пример урока — число 47: его двоичная запись `101111`, биты и проверка записей по маске.

---

**Запись числа зависит от основания, а `int(text, base)` переводит запись в число.** Число само по себе не «двоичное» или «десятичное»: так называют его запись. У записи с основанием `base` разряды имеют веса `1`, `base`, `base ** 2` и далее. Например, `1011` в двоичной записи означает `1*8 + 0*4 + 1*2 + 1 = 11`.

<figure class="plate-figure">
%%place_value("1011", 2)%%
<figcaption>Та же схема разрядов, что для десятичного числа 472 в уроке о числах, только веса — степени двойки: 8, 4, 2, 1.</figcaption>
</figure>

```python
print(int("1011", 2))
print(int("101111", 2))
print(int("FF", 16))
print(bin(47), oct(47), hex(255))
print(bin(47)[2:])
```

```output
11
47
255
0b101111 0o57 0xff
101111
```

`int(text, base)` разбирает запись в заданном основании. Встроенные `bin`, `oct`, `hex` создают записи с префиксами `0b`, `0o`, `0x`. Для неотрицательного числа часто используют `bin(n)[2:]`. Для отрицательного такой срез неверен из-за начального минуса; обрабатывай знак отдельно.

Последний разряд записи определяется остатком `n % base`, остальные остаются в `n // base` — та же идея, что с десятичными цифрами в уроке о `while`. Полный алгоритм перевода в любое основание разобран в теме 14.

`format(n, "b")` даёт двоичную запись без префикса, а `format(n, "08b")` — дополненную нулями слева до восьми знаков:

```python
print(format(47, "b"))
print(format(5, "08b"))
print(format(255, "x"))
```

```output
101111
00000101
ff
```

---

**Битовые операции обрабатывают соответствующие разряды целых независимо.** **Бит** — двоичный разряд. Побитовые операции независимо обрабатывают соответствующие разряды целых. Возьмём `a = 6`, то есть двоичное `110`, и `b = 3`, то есть `011`.

<figure class="plate-figure">
%%bits(6, 3)%%
<figcaption>Каждый разряд результата зависит только от двух битов над ним, соседние разряды не влияют. Сдвиги переносят всю запись: влево — умножение на 2, вправо — целое деление на 2.</figcaption>
</figure>

```python
a = 6
b = 3
print(a & b, a | b, a ^ b, a << 1, a >> 1)
print((47).bit_count(), (47).bit_length())
```

```output
2 7 5 12 3
5 6
```

Сдвиг влево на `k >= 0` соответствует умножению на `2 ** k`, вправо — целочисленному делению на `2 ** k`. `~n` для Python-целых равно `-n - 1`: целые не ограничены автоматически восьмью или тридцатью двумя битами. Для отрицательных чисел важно понимать представление, поэтому начинай с неотрицательных.

`n.bit_count()` считает единицы в двоичной записи модуля числа. `n.bit_length()` даёт число разрядов модуля без ведущих нулей; для 0 это 0, хотя текстовая запись `"0"` имеет длину 1. У 47 = `101111` пять единиц и шесть разрядов. Скобки вокруг 47 нужны, чтобы точку не приняли за дробную часть числа.

**Маска `fnmatch` проверяет запись целиком: `?` — один символ, `*` — любая последовательность.** В распространённой записи масок `?` означает ровно один символ, а `*` — любую последовательность, включая пустую. Для строк, состоящих только из цифр, это соответствует одной цифре и произвольному количеству цифр.

```python
from fnmatch import fnmatchcase

print(fnmatchcase("102", "1?2*"))
print(fnmatchcase("15200", "1?2*"))
print(fnmatchcase("12", "1?2*"))
```

```output
True
True
False
```

В первом случае `*` пустая; в последнем на месте `?` нет символа: после 1 сразу 2, и шаблону не хватает длины. Сам `fnmatchcase` не ограничивает подстановки цифрами. Ограничение обеспечивается тем, что проверяется `str(n)` для неотрицательного целого. Функция проверяет всю строку. `case` в имени означает, что большие и маленькие буквы различаются на любом компьютере; для цифр это не важно. В темах ЕГЭ встречается и `fnmatch` без `case` — для строк из цифр результат одинаков.

Проверь маску на своих записях: схема показывает, какие цифры заняли `?` и `*`, а если запись не подходит — говорит об этом.

%%mask_try("1?2*", "15200")%%

```python
from fnmatch import fnmatchcase

answers = []
for n in range(7, 10_000, 7):
    if fnmatchcase(str(n), "1?2*"):
        answers.append((n, n // 7))
print(answers[:5])
```

```output
[(112, 16), (182, 26), (1022, 146), (1029, 147), (1120, 160)]
```

Граница исключает 10 000. Перебор по возрастанию даёт упорядоченные ответы без дополнительной сортировки. `?` нельзя заменить пустотой; `*` может означать ноль символов — этот случай легко забыть при ручном построении кандидатов.

**Регулярное выражение — другой язык шаблонов со своими правилами.** **Регулярное выражение** описывает текстовый шаблон с собственными правилами. В нём `*` не значит «любой текст»: это повторение предыдущего элемента ноль или более раз. Основные записи — выбери запись, чтобы увидеть, какие строки она описывает целиком:

:::pick Запись regex и строки, которые она описывает целиком
- *[0-9] | подходят `"7"`; не подходят `"a"` | одна ASCII-цифра
- [ABC] | подходят `"B"`; не подходят `"D"` | один символ из набора
- . | подходят `"?"`; не подходят `""` | любой символ, обычно кроме перевода строки
- X* | подходят `""`, `"XXX"`; не подходят `"XY"` | ноль или более повторений X
- X+ | подходят `"XXX"`; не подходят `""` | одно или более повторений
- X? | подходят `""`, `"X"`; не подходят `"XX"` | ноль или одно повторение
- X{3} | подходят `"XXX"`; не подходят `"XX"` | ровно три повторения
- X{2,4} | подходят `"XX"`, `"XXXX"`; не подходят `"X"` | от двух до четырёх повторений
- A|B | подходят `"A"`; не подходят `"AB"` | одно из двух
- (AB)+ | подходят `"ABAB"`; не подходят `"ABA"` | группа: повторяется целиком
:::

Эквивалент маски `1?2*` для десятичных записей — `1[0-9]2[0-9]*`:

```python
import re

pattern = r"1[0-9]2[0-9]*"
print(re.fullmatch(pattern, "15200") is not None)
print(re.fullmatch(pattern, "12") is not None)
```

```output
True
False
```

Префикс `r` создаёт сырую строку, удобную для обратных слешей в шаблоне. Сам regex всё равно понимает свои специальные символы. `fullmatch` требует совпадения со всей строкой; `search` ищет где угодно; `match` — только с начала, но не обязательно до конца. Успех возвращается объектом совпадения, неуспех — `None`.

Объект совпадения знает найденный текст и его место. `re.finditer` перебирает все совпадения по очереди:

```python
import re

for m in re.finditer(r"[0-9]+", "a12b345c6"):
    print(m.group(), m.start(), m.end())
```

```output
12 1 3
345 4 7
6 8 9
```

`group()` — найденный текст, `start()` — индекс его начала, `end()` — индекс сразу после конца, как граница среза: `"a12b345c6"[4:7]` — это `"345"`. `re.findall` возвращает список найденных строк, но, как и `count`, без перекрытий: пересекающиеся фрагменты им не посчитать. Сложные регулярные выражения иногда много раз возвращаются к прежним выборам и работают медленно; простой цикл бывает яснее и надёжнее.

---

**Итого.**

- `int(text, base)` — запись в число; `bin`, `oct`, `hex` — число в запись с префиксом, `format(n, "08b")` — без префикса и с нулями.
- `&`, `|`, `^`, `<<`, `>>` работают с разрядами; `bit_count` и `bit_length` — единицы и длина записи.
- `fnmatchcase(text, mask)`: `?` — ровно один символ, `*` — любая последовательность, в том числе пустая.
- В regex `*` — повторение предыдущего; `fullmatch` проверяет всю строку.
- `finditer` даёт совпадения с `group`, `start` и `end`.
