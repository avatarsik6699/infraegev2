Главная идея урока: **функция — именованное действие: параметры получают входные данные, `return` отдаёт результат туда, где произошёл вызов, а имена внутри функции живут отдельно от внешних**. Опора — `print`, `len` и методы, которые ты уже вызывал, и модель «имя ссылается на объект»: теперь ты сам создаёшь такие действия.

Сквозной пример урока — прямоугольник 3 × 5: функция вычислит его площадь, а потом на нём же разберём `return`, локальные имена и изменение переданных данных.

---

**Функция даёт имя действию с входными данными и результатом.** Если одну проверку приходится повторять или её смысл теряется среди остальных строк, полезно дать ей имя. **Функция** объединяет инструкции в действие с входными данными и, возможно, возвращаемым результатом.

```python
def rectangle_area(width, height):
    return width * height

area = rectangle_area(3, 5)
print(area)
print(rectangle_area(2, 10))
```

```output
15
20
```

`def` создаёт функцию. `rectangle_area` — её имя. `width` и `height` — **параметры**, то есть локальные имена для входных данных. В вызове числа 3 и 5 — **аргументы**, конкретные переданные значения.

При выполнении определения тело не запускается. Оно выполняется при вызове. Поэтому одинаковую функцию можно вызвать много раз с разными аргументами: здесь второй вызов дал 20. Программа должна успеть выполнить определение до момента вызова; определение другой функции может находиться ниже, если до реального вызова оно уже будет выполнено.

---

**`return` передаёт значение месту вызова, `print` только показывает текст.** `return` завершает текущий вызов и передаёт значение тому месту, где он произошёл. `print` показывает текст, но не делает этот текст возвращаемым результатом.

```python run square.py
def square(number):
    return number * number

result = square(4) + square(3)
print(result)
```

```output
25
```

Запусти программу по шагам. При вызове у функции появляются свои переменные — рамка «вызов square(4)» внутри программы; после `return` она исчезает, а значение возвращается в строку, где был вызов.

Если вместо `return` поставить `print`, квадраты будут видны на экране, но сложение результатов вызовов не сработает: оба вызова вернут `None`.

```python
def square(number):
    print(number * number)

result = square(4)
print(result)
```

```output
16
None
```

Функция без выполненного `return` со значением возвращает `None`. Запись `return` без выражения тоже возвращает `None`. Инструкции после выполненного `return` в этом вызове уже не исполняются.

```python
def describe_sign(number):
    if number > 0:
        return "положительное"
    if number < 0:
        return "отрицательное"
    return "ноль"

print(describe_sign(-4), describe_sign(0))
```

```output
отрицательное ноль
```

Ранний возврат позволяет последовательно исключить случаи без лишней вложенности: третий `return` выполняется, только если первые два не сработали.

---

**Имена внутри функции локальны: они не заменяют внешние.** **Область видимости** — часть программы, в которой имя разрешается определённым способом. Параметры и присваивания внутри функции обычно создают локальные имена, существующие для данного вызова.

```python run local_names.py
x = 10

def calculate():
    x = 3
    return x + 1

print(calculate())
print(x)
```

```output
4
10
```

Внутреннее `x` не заменяет внешнее. При поиске имени Python рассматривает локальную область, окружающие области функций, область модуля и встроенные имена. Этот порядок часто сокращают как LEGB; полезнее понимать сами уровни, чем заучивать буквы.

Запусти программу выше по шагам: `x = 3` появляется в рамке вызова `calculate`, а внешнее `x` в программе остаётся 10.

Если внутри функции есть присваивание имени, Python обычно считает его локальным во всём теле. Поэтому попытка сначала прочитать его, а потом присвоить приводит к ошибке:

```python
x = 10

def show():
    print(x)
    x = 3

show()
```

```error
UnboundLocalError: cannot access local variable 'x' where it is not associated with a value
```

Строка `x = 3` сделала `x` локальным во всей функции, и `print(x)` обратился к локальному имени, которое ещё не получило значения. Конструкции `global` и `nonlocal` позволяют явно выбрать внешнюю область, но для первых программ чаще проще передать нужное значение параметром и вернуть новое.

У `if` и `for` нет собственной отдельной области имён, как у функции. Переменная, присвоенная внутри выполненной ветки, остаётся доступной после неё в окружающей области.

---

**Присвоить параметру и изменить переданный объект — разные действия.** Аргументы передаются как объекты, а параметры связываются с ними.

```python run rebind_mutate.py
def rebind(items):
    items = [99]

def mutate(items):
    items.append(99)

a = [1, 2]
rebind(a)
print(a)
mutate(a)
print(a)
```

```output
[1, 2]
[1, 2, 99]
```

В `rebind` заменяется локальная связь имени. В `mutate` меняется тот же список, на который ссылается внешнее `a`. Это та же модель «имя — ссылка на объект», что и в уроке о списках: параметр — ещё одно имя того же списка. Изменение данных вне возвращаемого результата называют **побочным эффектом**. Вывод и запись файла — тоже побочные эффекты.

Запусти программу по шагам. Пока выполняется `rebind`, стрелки от `a` и `items` сначала ведут к одному списку, а после `items = [99]` — к разным. В `mutate` обе стрелки ведут к одному списку, и `append` меняет именно его.

В описании функции полезно явно указывать, меняет ли она переданную коллекцию. Если изменение не нужно, создавай отдельный результат.

---

**Итого.**

- `def имя(параметры):` создаёт функцию; тело выполняется только при вызове.
- `return` отдаёт значение и завершает вызов; без него функция возвращает `None`.
- Присваивание внутри функции создаёт локальное имя; внешнее не меняется.
- Чтение имени до его присваивания в той же функции — `UnboundLocalError`.
- Параметр — ещё одно имя переданного объекта: `append` меняет внешний список, присваивание параметру — нет.
