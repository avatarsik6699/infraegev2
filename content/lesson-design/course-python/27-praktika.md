2. **Определи данные.** Типы, диапазоны, число элементов, заголовок файла, разрешённые отрицательные значения и повторы.

8. **Запиши код.** Сначала ясно, затем при необходимости компактнее.
9. **Проверь границы и результат.** При возможности сравни с простым эталоном.
10. **Проверь формат ответа.** Порядок столбцов, направление сортировки, округление или отбрасывание дробной части.

Шаги 4–6 — это инвариант и завершение из урока о `while`, перенесённые на любую программу. Шаг 7 — урок о скорости и памяти. Шаг 9 — урок об исключениях и отладке.

| Ошибочная идея | Почему неверна | Правильный вопрос |
| --- | --- | --- |
| `range(a, b)` включает b | Остановка исключена | Какая последняя допустимая позиция? |
| `x == 2 or 3` | Второй операнд не сравнение | Повторено ли сравнение с x? |

<summary>Решения и объяснения задач 1–8</summary>

**1.** Для последней цифры достаточно остатка по модулю 10:

```python
def last_digit_of_power(base, power):
    if base < 0 or power < 0:
        raise ValueError("Нужны неотрицательные значения")
    result = 1
    for _ in range(power):
        result = (result * base) % 10
    return result

print(last_digit_of_power(7, 4), last_digit_of_power(2, 100))
```

```output
1 6
```

Если заменить промежуточное произведение на его остаток, будущий остаток произведения не изменится: отброшенная часть кратна 10 и после умножения останется кратна 10. Этот вариант выполняет `power` шагов. Стандартная `pow(base, power, 10)` считает модульную степень существенно эффективнее за счёт последовательного возведения в квадрат. Третий аргумент — модуль, а не точность округления.

**2.** Множество убирает повторы, сортировка задаёт порядок:

```python
def second_distinct_maximum(numbers):
    unique = sorted(set(numbers), reverse=True)
    if len(unique) < 2:
        return None
    return unique[1]

print(second_distinct_maximum([9, 9, 4, 7]))
print(second_distinct_maximum([5, 5]))
```

```output
7
None
```

Если бы требовался второй элемент по величине с учётом повторов, ответ для этого примера был бы 9. Можно разработать вариант за один проход с двумя лучшими различными значениями, но сначала нужно точно понимать требование.

**3.** Множество отвечает за быструю проверку, список — за порядок результата:

```python
def unique_in_order(items):
    seen = set()
    result = []
    for item in items:
        if item not in seen:
            seen.add(item)
            result.append(item)
    return result

print(unique_in_order([3, 1, 3, 2, 1]))
print(unique_in_order("abracadabra"))
```

```output
[3, 1, 2]
['a', 'b', 'r', 'c', 'd']
```

У каждой структуры отдельное назначение. Более короткое `list(dict.fromkeys(items))` использует порядок словаря, но первый вариант лучше раскрывает алгоритм.

**4.** Сначала приводим регистр, затем отбираем буквы:

```python
def letter_counts(text):
    counts = {}
    for letter in text.lower():
        if letter.isalpha():
            counts[letter] = counts.get(letter, 0) + 1
    return counts

print(letter_counts("Аа! Б"))
```

```output
{'а': 2, 'б': 1}
```

Метод `isalpha` принимает и буквы других письменностей; если по задаче они недопустимы, нужно отдельно ограничить алфавит. Для универсального сравнения текста по регистру существует `casefold`, но правила языкового сравнения — самостоятельная задача.

**5.** `max` с одинаковым ключом оставляет первый элемент:

```python
def first_longest_word(text):
    return max(text.split(), key=len, default=None)

print(first_longest_word("кот дом окно"))
print(first_longest_word("кот дом"))
print(first_longest_word(""))
```

```output
окно
кот
None
```

Дополнительная сортировка дала бы больше работы без необходимости. Определение слова здесь специально простое; для естественного языка потребуются другие правила.

**6.** `balance` — число ещё не закрытых открывающих скобок:

```python
def valid_parentheses(text):
    balance = 0
    for char in text:
        if char == "(":
            balance += 1
        elif char == ")":
            balance -= 1
        else:
            return False
        if balance < 0:
            return False
    return balance == 0

for s in ["(()())", ")(", "(()"]:
    print(valid_parentheses(s))
```

```output
True
False
False
```

Равенство общего количества открывающих и закрывающих недостаточно: `)(` имеет одинаковые количества, но неверный порядок. Для нескольких видов скобок нужен стек, чтобы помнить не только количество, но и вид последней незакрытой скобки.

**7.** В словаре находятся только прежние позиции:

```python
def find_pair_with_sum(numbers, target):
    positions = {}
    for i, number in enumerate(numbers):
        needed = target - number
        if needed in positions:
            return positions[needed], i
        positions[number] = i
    return None

print(find_pair_with_sum([4, 7, 2, 9], 11))
print(find_pair_with_sum([5, 5], 10))
```

```output
(0, 1)
(0, 1)
```

Поэтому одна позиция не используется дважды. Проверка выполняется **до** добавления текущего числа: иначе единственная пятёрка могла бы ошибочно составить пару сама с собой. Обычная ожидаемая сложность — `O(n)` времени и `O(n)` памяти.

**8.** Выбирается доступная встреча, которая заканчивается раньше всех:

```python
def choose_meetings(meetings):
    selected = []
    last_end = None
    by_end = sorted(meetings, key=lambda meeting: meeting[1])
    for start, end in by_end:
        if last_end is None or start >= last_end:
            selected.append((start, end))
            last_end = end
    return selected

print(choose_meetings([(0, 3), (1, 2), (2, 4), (3, 5)]))
```

```output
[(1, 2), (2, 4)]
```

Почему это допустимо? Возьми оптимальное расписание и замени его первую встречу на самую раннюю по окончанию. Новая встреча заканчивается не позже, поэтому не мешает остальным выбранным. Количество не уменьшается. Затем тот же аргумент применяется к оставшейся части времени.

Это доказательство зависит от цели «максимум количества». Для максимальной суммарной ценности встреч тот же жадный выбор не гарантирует оптимальность.
