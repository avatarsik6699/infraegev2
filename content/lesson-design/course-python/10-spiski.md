Главная идея урока: **список — изменяемая последовательность, и имя списка — ссылка на один общий объект**. Отсюда и удобство (метод меняет список на месте), и главная ловушка (присваивание не копирует). Опора — индексы и срезы строк (у списка они те же) и модель «имя ссылается на объект» из урока о значениях: здесь она становится главной.

Сквозной пример урока — список `[4, 7, 2]`: будем его менять, обходить, копировать и собирать из текста.

---

**Список хранит много значений под одним именем и, в отличие от строки, изменяется.** Для тысячи измерений неудобно создавать тысячу имён. **Список** хранит последовательность элементов под одним именем:

```python
temperatures = [18, 21, 19, 23]
print(temperatures[1])
print(len(temperatures))
```

```output
21
4
```

Индексы и срезы работают похоже на строки. Главное различие: список изменяем. Он может хранить значения разных типов, но для обработки чисел обычно удобен однородный список.

```python
numbers = [4, 7, 2]
numbers[1] = 10
numbers.append(8)
print(numbers)
```

```output
[4, 10, 2, 8]
```

`append` добавляет один элемент в конец: если передать ему список, он станет одним вложенным элементом.

Остальные действия со списком — каждый пример начинается с того же `a = [4, 7, 2]`:

:::pick Методы списка `a = [4, 7, 2]`
- *append | `a.append(5)`: `a` → `[4, 7, 2, 5]` | один элемент в конец
- extend | `a.extend([5, 6])`: `a` → `[4, 7, 2, 5, 6]` | элементы источника по одному
- insert | `a.insert(1, 9)`: `a` → `[4, 9, 7, 2]` | перед позицией 1
- pop | `a.pop()`: вернул `2`, `a` → `[4, 7]` | удаляет и возвращает последний; `a.pop(i)` — элемент на позиции `i`
- remove | `a.remove(7)`: `a` → `[4, 2]` | первое равное значение; ошибка, если его нет
- del | `del a[0]`: `a` → `[7, 2]` | удаляет по индексу
- clear | `a.clear()`: `a` → `[]` | удаляет все элементы
- reverse | `a.reverse()`: `a` → `[2, 7, 4]` | разворачивает на месте
- index | `a.index(7)` → `1`, список не изменился | индекс первого равного; ошибка, если нет
- count | `a.count(7)` → `1`, список не изменился | сколько раз встречается
:::

Методы вроде `append`, `extend` и `reverse` меняют список и возвращают `None`. Поэтому `a = a.append(5)` теряет связь имени `a` со списком: результат метода — `None`.

```python
a = [4, 7, 2]
a = a.append(5)
print(a)
```

```output
None
```

---

**Список обходят по значениям, когда нужны элементы, и по индексам, когда нужны позиции.**

```python
a = [4, 7, 2]
for value in a:
    print(value)

for i in range(len(a)):
    a[i] *= 2
print(a)
```

```output
4
7
2
[8, 14, 4]
```

Первый вариант удобен, когда нужны сами элементы. Второй — когда нужны позиции, соседние значения или замена элементов. Инструкция `value *= 2` в первом цикле с целыми числами изменила бы только привязку имени `value`, а не список.

Не удаляй элементы из того же списка во время обычного прямого обхода, если не контролируешь смещение позиций: после удаления следующий элемент может быть пропущен. Проще собрать новый список подходящих элементов.

---

**Присваивание не копирует список: два имени смотрят на один объект.**

```python run shared_list.py
a = [1, 2]
b = a
b.append(3)
print(a)
```

```output
[1, 2, 3]
```

`a` и `b` — два имени одного объекта. Поэтому изменение видно через оба имени. Запусти пример по шагам: после `b = a` обе стрелки ведут к одному списку, и `append` через `b` меняет то, что видно через `a`. Чтобы создать отдельный внешний список, используют `a.copy()`, `a[:]` или `list(a)`.

```python
a = [1, 2]
b = a.copy()
b.append(3)
print(a)
print(b)
print(a == b)
print(a is b)
```

```output
[1, 2]
[1, 2, 3]
False
False
```

`==` сравнивает содержимое, `is` — являются ли значения одним и тем же объектом. Два разных списка `[1, 2]` могут быть равны по содержимому. Для чисел и строк сравнивай значения через `==`; детали повторного использования объектов не должны влиять на программу. Уместное применение `is` — `value is None`.

---

**Копия внешнего списка не копирует вложенные списки.** Список может содержать другие списки: так удобно представлять таблицу. Но копирование внешнего списка не копирует автоматически его внутренние элементы.

```python
a = [[1, 2], [3, 4]]
b = a.copy()
b[0][0] = 99
print(a)
```

```output
[[99, 2], [3, 4]]
```

Созданы два внешних списка, но их элементы указывают на прежние общие строки таблицы. Такая копия называется **поверхностной**. Полную копию вместе с вложенными списками делает функция `deepcopy` стандартного модуля `copy`, но чаще проще создать каждую внутреннюю строку заново — как ниже.

Особенно опасна запись:

```python
table = [[0] * 3] * 2
table[0][0] = 9
print(table)
```

```output
[[9, 0, 0], [9, 0, 0]]
```

Внешнее умножение повторило ссылку на одну строку. Создай каждую строку отдельно:

```python
table = []
for row in range(2):
    table.append([0] * 3)
table[0][0] = 9
print(table)
```

```output
[[9, 0, 0], [0, 0, 0]]
```

`[0] * 3` безопасно для последующей замены отдельных чисел: целые неизменяемы, а присваивание элементу заменяет ссылку. Проблема возникает при изменении повторённых вложенных объектов.

**`split` превращает строку в список частей, `join` — список строк обратно в строку.**

```python
print("  10   20  30 ".split())
print("a,,b".split(","))
```

```output
['10', '20', '30']
['a', '', 'b']
```

Без аргумента разделителями служат серии пробельных символов, лишние края исчезают. С явным разделителем правило другое: два разделителя подряд дают пустую часть. Поэтому `.split()` и `.split(" ")` не взаимозаменяемы.

Разберём несколько чисел из одной строки без сокращений:

```python
line = "10 20 30"
parts = line.split()
numbers = []
for part in parts:
    numbers.append(int(part))
print(numbers)
```

```output
[10, 20, 30]
```

Обратное соединение строк выполняет `join`:

```python
words = ["Учимся", "писать", "программы"]
print(" ".join(words))
```

```output
Учимся писать программы
```

Объект перед точкой — разделитель. Элементы должны быть строками: целые сначала преобразуют. Для последовательного вывода чисел позже пригодится также `print(*numbers)`.

---

**Новый список подходящих элементов оставляет исходный нетронутым.** Из `[5, -2, 0, 8, -1]` создадим отдельный список неотрицательных значений:

```python
source = [5, -2, 0, 8, -1]
result = []
for value in source:
    if value >= 0:
        result.append(value)
print(result)
print(source)
```

```output
[5, 0, 8]
[5, -2, 0, 8, -1]
```

Пустой результат допустим. Отдельное имя `result` сразу обозначает отдельный созданный список, а не вторую ссылку на исходный.

**Сквозная задача курса: числа лежат в списке.** Раньше числа 5, −2, 10, 7 были четырьмя именами, потом вводились по одному. Список хранит их все под одним именем, а `for` проходит по ним без ручного счётчика:

```python
numbers = [5, -2, 10, 7]
total = 0
best = numbers[0]
for x in numbers:
    total += x
    if x > best:
        best = x
print(total, best)
```

```output
20 10
```

Внутри цикла — те же две строки, что в уроке о `while`. Изменилось только то, откуда берутся числа.

---

**Итого.**

- Список изменяем: `a[i] = x`, `append`, `insert`, `pop`, `remove`, `reverse`.
- Методы, меняющие список, возвращают `None`: не пиши `a = a.append(x)`.
- `b = a` — второе имя того же списка; копия — `a.copy()`, `a[:]`, `list(a)`.
- Копия поверхностная: вложенные списки остаются общими; `[[0] * 3] * 2` повторяет одну строку.
- `split()` режет по пробелам, `split(",")` — по запятой с пустыми частями; `join` склеивает строки.

1. Из списка `[3, -4, 0, 6, -2]` создай отдельный список неотрицательных значений. Исходный список должен сохраниться.

2. Начни с `a = [3, 1, 4]` и выполни по очереди: `a.append(1)`, `a.insert(0, 9)`, `x = a.pop()`, `a.remove(1)`. Чему равны `a` и `x`?

3. После `a = [1, 2, 3]`, `b = a`, `b[0] = 10` чему равен `a`? А если вместо `b = a` написать `b = a.copy()`?

4. Для `a = [1, 2]` и `b = [1, 2]` чему равны `a == b` и `a is b`?

5. Что выведет `t = [[0] * 2] * 3`, `t[1][0] = 5`, `print(t)`?

6. Что дадут `"3;8;;1".split(";")` и `" 3 8  1 ".split()`?

7. Что даст `"-".join(["2026", "10", "10"])`? Что случится с `"-".join([2026, 10, 10])`?

8. Что выведет программа `a = [5, 2, 8]`, `a = a.reverse()`, `print(a)`?

9. Напиши программу: строка `"4 -1 7 0 -3"` превращается в список целых, затем выводятся количество отрицательных и сумма всех чисел.

1. [3, 0, 6].
2. a = [9, 3, 4], x = 1.
3. [10, 2, 3]; с копией [1, 2, 3].
4. True и False: содержимое равно, объекты разные.
5. [[5, 0], [5, 0], [5, 0]]: все три строки — один объект.
6. ['3', '8', '', '1'] и ['3', '8', '1'].

9. 2 7: отрицательные −1 и −3, сумма 4 − 1 + 7 + 0 − 3.
