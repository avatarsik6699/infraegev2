**У каждого значения есть тип, а имя — это ярлык, который присваивание связывает со значением в конкретный момент**. Без этой модели непонятно, почему `"27"` и `27` ведут себя по-разному и почему изменение одной переменной не меняет другую. Урок продолжает первый: там `print` показывал значения, теперь у значений появятся типы и имена.

Продолжим с той же покупкой, что в прошлом уроке: цена тетради 40 рублей, количество 3, стоимость 120. Теперь у каждого числа появится имя.

---

**Число и текст — разные данные, даже если выглядят одинаково.** `27` и `"27"` выглядят похоже, но решают разные задачи. Первое — число, второе — последовательность символов. С числом выполняют арифметику; текст можно соединять с другим текстом:

```python
print(27 + 3)
print("27" + "3")
```

```output
30
273
```

Знак `+` один и тот же, но для чисел он складывает, а для строк склеивает:

</figure>

**Тип** определяет, как устроено значение и какие операции для него имеют смысл. Для начала хватит пяти типов:

<figure class="plate-figure">
%%type_cards()%%
<figcaption>Целые числа <code>int</code> — для счёта и точных вычислений, дробные <code>float</code> (их называют числами с плавающей точкой) — для измерений. Строка <code>str</code> — любой текст, даже из цифр или пустой. <code>bool</code> — ответ на вопрос «выполнено ли условие». <code>None</code> — единственное значение своего типа: «результата нет».</figcaption>
</figure>

Названия других типов появятся вместе с задачами, для которых они нужны. `None` — специальное значение, а не строка `"None"`, не число 0 и не пустой текст.

---

**Присваивание сначала вычисляет правую часть, потом связывает с ней имя.**

```python
price = 40
quantity = 3
cost = price * quantity
print(cost)
```

```output
120
```

В строке `cost = price * quantity` сначала вычисляется выражение справа. Затем имя `cost` связывается с полученным значением. Такая операция называется **присваиванием**, а имя для обращения к значению — **переменной**.

<figure class="plate-figure">
%%assign()%%
<figcaption>Присваивание выполняется справа налево: сначала из текущих значений <code>price</code> и <code>quantity</code> вычисляется 120, и только потом имя <code>cost</code> связывается с готовым числом.</figcaption>
</figure>

Знак `=` здесь не утверждает математическое равенство навсегда. Он задаёт действие в конкретный момент:

```python run assignment.py
x = 5
y = x + 2
x = 100
print(y)
```

```output
7
```

При создании `y` выражение `x + 2` уже вычислено. В `y` не сохраняется формула, которая автоматически пересчитывается при изменении `x`. Проследим значения после каждой строки:

<figure class="plate-figure">
%%bind_strip()%%
<figcaption>Выделено имя, которое изменила строка. Третья строка меняет только <code>x</code>: у <code>y</code> осталось 7.</figcaption>
</figure>

Так же и с покупкой: если после вычисления `cost` изменить `price`, стоимость останется 120, пока её не вычислят заново.

Нажми «Запуск» в шапке примера: после каждой строки видно, какое значение у каждой переменной. Изменившееся значение выделено.

---

**Запись `x = x + 1` не противоречие, а шаг вычисления.**

```python
count = 4
count = count + 1
print(count)
```

```output
5
```

Сначала читается прежнее значение `count`, к нему прибавляется 1, и имя связывается с результатом:

<figure class="plate-figure">
%%refs([["count", 1]], ["4", "5"], old=[["count", 0]])%%
<figcaption>Справа вычислено <code>4 + 1</code>, и <code>count</code> теперь связано с 5; прежняя связь с 4 — пунктиром.</figcaption>
</figure>

Сокращённая запись для этого случая — `count += 1`. Так же работают `-=`, `*=` и другие: `x *= 2` означает `x = x * 2`. У Python нет операции увеличения `count++`.

---

**Имя ссылается на объект, а тип принадлежит объекту.** Удобная первая метафора — «переменная хранит значение». Более точная модель Python: в памяти существуют **объекты**, а имена ссылаются на них. Объект — конкретные данные с типом и состоянием. Если два имени относятся к одному изменяемому списку, изменение через одно имя будет видно через второе. Эту важную ситуацию подробно разберём в уроке о списках.

Вернёмся к `x` и `y`. В этой модели присваивание не кладёт число в коробку, а проводит связь от имени к объекту:

<figure class="plate-figure">
%%refs([["x", 2], ["y", 1]], ["5", "7", "100"], old=[["x", 0]])%%
<figcaption>После <code>x = 100</code> имя x связано с новым объектом, а прежняя связь с 5 разорвана (пунктир). y по-прежнему ссылается на 7: формула <code>x + 2</code> не запоминалась.</figcaption>
</figure>

Тип принадлежит объекту. Одно имя разрешено сначала связать с целым числом, затем со строкой:

```python
value = 10
print(type(value))
value = "десять"
print(type(value))
```

```output
<class 'int'>
<class 'str'>
```

`type(...)` сообщает тип. Возможность менять тип значения у имени называют динамической типизацией. Это не означает, что Python автоматически складывает любые данные:

```python
print(10 + "5")
```

```error
TypeError: unsupported operand type(s) for +: 'int' and 'str'
```

`TypeError` — ошибка неподходящего типа: число и строку нельзя сложить, Python не угадывает, нужно ли 15 или `"105"`.

---

**Хорошее имя объясняет смысл значения.** Используй понятные имена: `total`, `count`, `max_value`, `student_name`. Слова обычно разделяют подчёркиваниями. Имя не начинается с цифры, не содержит пробелов и не совпадает со служебным словом языка, например `if` или `for`. Регистр различается.

Не называй переменные `list`, `str`, `sum`, `max`: это имена полезных встроенных средств. Такое присваивание разрешено, но закрывает доступ к прежнему значению имени в этой области программы. Для короткого номера позиции обычно уместно `i`, а для суммы — `total`.

Комментарий объясняет причину, условие или назначение, которое неочевидно из кода:

```python
discount = 10  # Скидка в процентах, а не в рублях
```

---

**Итого.**

- Тип определяет, какие операции имеют смысл: `27 + 3` — 30, `"27" + "3"` — `"273"`.
- Присваивание вычисляет правую часть и связывает имя с результатом; формула не запоминается.
- `x = x + 1` и `x += 1` берут прежнее значение и заменяют его новым.
- Имя ссылается на объект, тип принадлежит объекту; Python не угадывает смысл: `10 + "5"` — `TypeError`.
- Имена выбирают по смыслу и не занимают имена встроенных средств.
