**Сортировка сравнивает не сами элементы, а их ключи, поэтому любой порядок задаётся функцией-ключом, а несколько критериев — кортежем ключей**. Опора — передача функции без скобок и `lambda` из урока о договорённости функции: ключ сортировки — это функция, которую `sorted` вызывает для каждого элемента.

Сортировать будем слова `["арбуз", "кот", "дом", "окно"]` и баллы учеников: по длине, по нескольким критериям, а лучшего выберем без полной сортировки.

---

**`sorted` возвращает новый список, а `sort` меняет список на месте.**

```python
a = [8, 2, 5]
b = sorted(a)
print(a)
print(b)
a.sort(reverse=True)
print(a)
```

```output
[8, 2, 5]
[2, 5, 8]
[8, 5, 2]
```

`sorted` принимает перебираемый источник и возвращает новый список. `.sort()` доступен у списка, меняет его на месте и возвращает `None`. Параметр `reverse=True` задаёт обратный порядок.

Строки из цифр сортируются как текст: `"100"` идёт раньше `"20"`, потому что сначала сравниваются первые символы. Если нужен числовой порядок, преобразуй данные в числа либо задай числовой ключ.

```python
print(sorted(["20", "100", "3"]))
print(sorted(["20", "100", "3"], key=int))
```

```output
['100', '20', '3']
['3', '20', '100']
```

---

**Ключ сортировки — значение, по которому сравнивают элемент; сам элемент не меняется.**

```python
words = ["арбуз", "кот", "дом", "окно"]
print(sorted(words, key=len))
```

```output
['кот', 'дом', 'окно', 'арбуз']
```

Передаётся функция `len`, а не результат `len(...)`. При сортировке Python применяет функцию ключа к каждому элементу и использует полученные значения для упорядочивания. Здесь ключи такие: у «арбуз» — 5, у «кот» и «дом» — 3, у «окно» — 4. Упорядочены ключи 3, 3, 4, 5, а в результате стоят сами слова.

---

**Несколько критериев задают кортежем: кортежи сравниваются слева направо.** Кортежи сравниваются **лексикографически**: сначала первые элементы; если они равны — вторые, и так далее. Это похоже на порядок слов в словаре, но применяется к любым сравнимым элементам.

```python
students = [("Анна", 91), ("Илья", 84), ("Марк", 91)]
ordered = sorted(
    students, key=lambda student: (-student[1], student[0])
)
print(ordered)
```

```output
[('Анна', 91), ('Марк', 91), ('Илья', 84)]
```

Балл сортируется по убыванию благодаря минусу: 91 превращается в −91, что меньше −84. При равных баллах имя сортируется по возрастанию. `reverse=True` для всего кортежа развернул бы оба критерия, поэтому это не то же самое.

---

**Сортировка устойчива, а один лучший элемент находят без сортировки.** Сортировка Python **устойчива**: элементы с одинаковым ключом сохраняют взаимный исходный порядок. Например, слова `"кот"` и `"дом"` имеют одинаковую длину и остались в исходной последовательности.

Если нужен только лучший элемент, нет необходимости сортировать всё:

```python
words = ["арбуз", "кот", "дом", "окно"]
longest = max(words, key=len)
print(longest)
print(min([], default=None))
```

```output
арбуз
None
```

При одинаковом максимальном ключе `max` вернёт первый встретившийся элемент. Для возможно пустого источника можно указать `default=None`. Аргумент `default` применяется к форме с одним перебираемым источником.

Сквозная задача курса получает продолжение: не одно наибольшее, а два. Для `[5, -2, 10, 7]` выражение `sorted(numbers, reverse=True)[:2]` даёт `[10, 7]` — сортировка по убыванию и срез первых двух.

---

**Сортировка по одному показателю не доказывает, что жадный выбор верен.** Выбор «самого выгодного сейчас» называют **жадным алгоритмом**. Иногда его правильность можно доказать. Например, если нужно купить максимум предметов при ограниченном бюджете и все цены неотрицательны, выгодно брать самые дешёвые: любой набор из `k` предметов стоит не меньше суммы `k` минимальных цен.

```python
prices = [50, 20, 70, 10, 40]
budget = 100
count = 0
spent = 0
for price in sorted(prices):
    if spent + price > budget:
        break
    spent += price
    count += 1
print(count, spent)
```

```output
3 70
```

Самые дешёвые 10, 20 и 40 стоят 70; следующая цена 50 уже не помещается. Никакие четыре предмета не уложатся в 100: четыре самых дешёвых стоят 120.

Но сортировка по одному показателю не решает произвольный выбор оптимального набора. Если у предметов разные цены и полезности, выбор по цене или отношению полезности к цене для неделимых предметов может оказаться неверным. Сначала доказательство подхода, затем код.

---

**Итого.**

- `sorted(x)` создаёт новый список, `x.sort()` меняет `x` и возвращает `None`; `reverse=True` — по убыванию.
- `key=функция` сортирует по значению функции; передаётся функция без скобок.
- Несколько критериев — кортеж ключей; минус перед числом даёт убывание только этого критерия.
- Сортировка устойчива; один лучший элемент — `max(x, key=…)`, пустой источник — `default=`.
- Жадный выбор после сортировки верен только с доказательством.
