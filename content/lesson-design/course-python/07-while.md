**Цикл повторяет действия, а правильность цикла видна по его состоянию — что означают переменные перед каждой проверкой**. Опора — условие из прошлых уроков и запись `x = x + 1` из урока о значениях: цикл — это условие, которое проверяется снова и снова, пока шаги меняют переменные.

Начнём с суммы чисел от 1 до 4: найдём её циклом, проследим состояние по шагам и докажем, что ответ 10 не случаен. Потом тот же приём накопления сложит цифры числа.

---

**`while` повторяет блок, пока условие истинно.** **Цикл** повторяет блок действий. `while` перед каждым повторением проверяет условие. Если оно истинно, выполняется тело цикла; затем проверка начинается заново.

```python
i = 1
while i <= 4:
    print(i)
    i += 1
```

```output
1
2
3
4
```

После четвёртого вывода `i` станет 5, и условие окажется ложным. Одно выполнение тела называют **итерацией**.

Если перед первой проверкой условие ложно, тело не выполняется ни разу. Если забыть изменение `i`, в примере выше условие будет оставаться истинным — получится бесконечный цикл. Его можно остановить кнопкой остановки среды или обычно сочетанием Ctrl+C.

---

**Счётчик считает события, накопитель собирает результат.** Найдём сумму чисел от 1 до 4:

```python run sum_1_to_4.py
i = 1
total = 0
while i <= 4:
    total += i
    i += 1
print(total)
```

```output
10
```

`i` указывает следующее добавляемое число. `total` хранит сумму уже обработанных чисел. Такая переменная называется **накопителем**. Если переменная хранит количество событий, её называют **счётчиком**.

Перед каждой проверкой условия `i` равно 1, 2, 3, 4, 5, а `total` — 0, 1, 3, 6, 10. Это суммы «ничего», 1, 1 + 2, 1 + 2 + 3 и 1 + 2 + 3 + 4: в `total` всегда сложены числа до `i - 1`.

Сумма начинается с 0, потому что прибавление 0 не меняет результат. Произведение обычно начинают с 1 по аналогичной причине. Если начать произведение с нуля, оно навсегда останется нулевым.

Нажми «Запуск» в шапке примера и пройди цикл по шагам. Строка `while` выполняется пять раз: четыре проверки дают `True`, пятая — `False`, и только тогда выполнение переходит к `print`. Значения `i` и `total` в моменты проверки — те самые 1 и 0, 2 и 1 и так далее.

---

**Цикл верен, если его утверждение о состоянии сохраняется и он обязательно заканчивается.** Утверждение «перед проверкой `total` равен сумме чисел от 1 до `i - 1`» верно перед первой итерацией: `i = 1`, сумма пустого набора — 0. Тело добавляет число `i` и увеличивает `i`, поэтому утверждение остаётся верным. Когда цикл останавливается при `i = 5`, обработаны именно числа от 1 до 4.

Утверждение, сохраняющееся на одинаковом этапе каждой итерации, называется **инвариантом цикла**. Это способ понимать и доказывать решение, а не дополнительная команда Python.

Отдельно объясни завершение: `i` возрастает на 1 и неизбежно превышает 4. Правильное состояние без гарантии завершения ещё не даёт работающего алгоритма.

**Цифры числа снимают по одной справа: `% 10` берёт последнюю, `// 10` её отбрасывает.**

```python
number = -5072
n = abs(number)
digit_sum = 0
while n > 0:
    digit = n % 10
    digit_sum += digit
    n //= 10
print(digit_sum)
```

```output
14
```

Это тот же накопитель, только складываются цифры. Проследим `n` и сумму по шагам:

%%digits_stepper(5072)%%

После выделения последней цифры она удаляется из рабочего числа. Поэтому следующая итерация рассматривает соседнюю цифру слева. `number` сохраняет исходное значение, а `n` — рабочая переменная, которую цикл уменьшает. Для числа 0 сумма цифр тоже 0: ноль итераций здесь дают правильный результат.

Но для **количества** цифр ноль — отдельный случай: в его записи одна цифра, а цикл `while n > 0` не выполнится ни разу и насчитает 0. Аналогично нельзя оставить отрицательное `n` и ожидать, что `n //= 10` обязательно доведёт его до нуля: `-1 // 10` остаётся −1. Поэтому сначала берут модуль.

**`break` завершает цикл досрочно, `continue` пропускает остаток итерации.** `break` немедленно завершает ближайший окружающий цикл. `continue` пропускает оставшуюся часть текущей итерации и переходит к следующей проверке.

```python
total = 0
while True:
    n = int(input())
    if n == 0:
        break
    total += n
print(total)
```

```console
⟪5⟫
⟪7⟫
⟪0⟫
12
```

Здесь 0 — заранее выбранный признак окончания ввода, а не часть суммы. `while True` сам по себе бесконечен; выход задаёт `break`. Нужно понимать, что будет, если пользователь никогда не введёт 0.

При `continue` легко пропустить изменение управляющей переменной. Если оно стоит ниже `continue`, программа может застрять на одном значении. Поэтому в примере ниже увеличение `i` стоит первым, до проверки:

```python
i = 0
total = 0
while i < 9:
    i += 1
    if i % 2 == 0:
        continue
    total += i
print(total)
```

```output
25
```

Чётные `i` пропускаются, складываются 1, 3, 5, 7 и 9. Если поставить `i += 1` в конец тела, на первом же чётном числе `continue` перескочит увеличение и цикл никогда не закончится.

**Цикл может искать первую степень, которая достигла границы.** Найдём наименьшее целое `k >= 0`, для которого `2 ** k >= n`, где `n` — положительное целое, без логарифма:

```python
n = 17
k = 0
power = 1
while power < n:
    power *= 2
    k += 1
print(k)
```

```output
5
```

На каждом шаге `power == 2 ** k` — это инвариант этого цикла. Цикл прекращается при первом достижении границы: 2⁴ = 16 ещё меньше 17, а 2⁵ = 32 уже нет. Для `n = 1` ответ 0 получается без единой итерации.

**Сквозная задача курса: цикл заменяет повторяющиеся `if`.** В уроке о ветвлении сумма и наибольшее из 5, −2, 10, 7 потребовали четырёх имён и трёх `if`. С `while` числа можно вводить по одному до признака окончания 0, и программа не зависит от их количества:

```python
n = int(input())
total = 0
best = n
while n != 0:
    total += n
    if n > best:
        best = n
    n = int(input())
print(total, best)
```

```console
⟪5⟫
⟪-2⟫
⟪10⟫
⟪7⟫
⟪0⟫
20 10
```

`total` — накопитель, `best` — лучшее найденное, и начинается он с первого числа из данных, как в уроке о ветвлении. Три `if` из прошлого урока стали одним `if` внутри цикла.

---

**Итого.**

- `while` проверяет условие перед каждой итерацией; ложное сразу условие — ноль итераций.
- Счётчик и сумма начинаются с 0, произведение — с 1.
- Правильность цикла объясняет инвариант, а завершение — изменение переменной к границе.
- Цифры: `n % 10` и `n //= 10`; ноль и отрицательные числа обрабатывают отдельно.
- `break` выходит из цикла, `continue` пропускает остаток итерации; изменение управляющей переменной не должно оказаться за `continue`.
