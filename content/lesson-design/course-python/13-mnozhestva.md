Главная идея урока: **множество хранит только различные значения и быстро отвечает «есть ли элемент», но не хранит порядок и повторы**. Опора — ключи словаря: множество — это словарь без значений, с теми же требованиями к элементам.

Сквозной пример урока — список `[3, 1, 3, 2, 1]` и два списка участников, в которых найдём общих людей.

---

**Множество оставляет только различные значения.** **Множество** (`set`) хранит различные хешируемые элементы и удобно для проверки принадлежности.

```python
values = [3, 1, 3, 2, 1]
unique = set(values)
print(len(unique))
print(2 in unique)
```

```output
3
True
```

Из пяти чисел различных три: 1, 2 и 3. Множество не сохраняет смыслового порядка и не поддерживает обращение по индексу. То, что в отдельном запуске вывод выглядит упорядоченным, не даёт права на это рассчитывать. Как получить упорядоченный результат, покажет урок о сортировке.

Пустое множество — `set()`. Запись `{}` создаёт пустой словарь. Непустое множество можно записать `{1, 2, 3}`.

```python
print(type({}), type(set()), type({1, 2}))
```

```output
<class 'dict'> <class 'set'> <class 'set'>
```

---

**Множества объединяют, пересекают и вычитают.**

```python
a = {1, 2, 3}
b = {3, 4}
print(a | b)
print(a & b)
print(a - b)
print(a ^ b)
print({1, 2} <= a)
```

```output
{1, 2, 3, 4}
{3}
{1, 2}
{1, 2, 4}
True
```

`a | b` — объединение: элементы из любого множества. `a & b` — пересечение: элементы одновременно в обоих. `a - b` — разность: элементы `a`, отсутствующие в `b`. `a ^ b` — элементы ровно одного из двух множеств. `<=` проверяет, что первое множество — подмножество второго.

`add(x)` добавляет элемент, `update(items)` — все элементы источника, `discard(x)` удаляет, если он присутствует. `remove(x)` тоже удаляет, но отсутствие вызывает ошибку:

```python
s = {1, 2}
s.add(2)
s.update([3, 4])
s.discard(9)
print(s)
s.remove(9)
```

```output
{1, 2, 3, 4}
```

```error
KeyError: 9
```

Повторное `add(2)` ничего не изменило: элемент уже есть. `frozenset` — неизменяемое множество, которое может быть ключом словаря.

У одинакового знака могут быть разные операции для разных типов: для целых `&` работает с битами, для множеств находит пересечение. Значение определяется типами операндов. Логическое `and` — отдельная операция.

---

**Структуру данных выбирают по тому, какие действия нужны.** Список — когда важны порядок и повторы, а элементы меняются. Кортеж — короткая неизменяемая запись. Словарь — когда значение ищут по ключу. Множество — когда важны только различные значения и вопрос «есть ли такое». Сводка всех пяти — в конце модуля, в уроке о включениях.

Выбор зависит от нужных действий, а не только от вида исходных данных. Чтобы посчитать **количество разных** слов, достаточно множества. Чтобы посчитать **частоту каждого**, нужен словарь.

---

**Общие элементы двух списков — пересечение их множеств.** Есть два списка участников; найдём людей, присутствующих в обоих. Пока порядок результата не важен.

```python
first = ["Анна", "Илья", "Анна"]
second = ["Илья", "Марк"]
common = set(first) & set(second)
print(common)
```

```output
{'Илья'}
```

Повторяющаяся Анна в первом списке не создаёт вторую копию человека во множестве. Если повторы означают отдельные события и должны учитываться, множество теряет нужную информацию.

---

**Итого.**

- `set(items)` оставляет различные значения; порядка и индексов нет.
- `{}` — пустой словарь, пустое множество — `set()`.
- `|`, `&`, `-`, `^` — объединение, пересечение, разность, «ровно в одном».
- `add`, `update`, `discard` меняют множество; `remove` отсутствующего даёт `KeyError`.
- Количество разных — множество, частота каждого — словарь.
