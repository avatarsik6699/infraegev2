Главная идея урока: **у функции есть договорённость — какие аргументы она принимает, что возвращает и меняет ли данные; значения по умолчанию, именованные аргументы и кортеж результатов делают эту договорённость удобной**. Опора — функции прошлого урока и распаковка кортежа: несколько результатов функции — это один кортеж.

Сквозной пример урока — функция цены со скидкой `final_price(price, discount=0)` и функция суммы цифр, которую в конце оформим по всем правилам.

---

**Параметр со значением по умолчанию можно не передавать, а аргумент можно назвать по имени.**

```python
def final_price(price, discount=0):
    return price * (100 - discount) / 100

print(final_price(200))
print(final_price(200, 10))
print(final_price(discount=10, price=200))
```

```output
200.0
180.0
180.0
```

`discount=0` в определении — значение по умолчанию. В вызове именованные аргументы уточняют, какому параметру соответствует значение. Обычные позиционные аргументы записывают перед именованными. Одному параметру нельзя передать значение дважды:

```python
def final_price(price, discount=0):
    return price * (100 - discount) / 100

print(final_price(200, price=100))
```

```error
TypeError: final_price() got multiple values for argument 'price'
```

Значения по умолчанию вычисляются при выполнении определения, а не заново для каждого вызова. Поэтому изменяемый список в параметре по умолчанию будет общим между вызовами:

```python run default_list.py
def add_item_bad(item, items=[]):
    items.append(item)
    return items

print(add_item_bad(1))
print(add_item_bad(2))
```

```output
[1]
[1, 2]
```

Второй вызов увидел единицу из первого: список по умолчанию создан один раз. Запусти программу по шагам: во втором вызове `items` ведёт к тому же списку, что и в первом, — он создан, когда выполнилось `def`, и уже содержит 1.

Правильный приём — `None` по умолчанию и новый список внутри:

```python
def add_item(item, items=None):
    if items is None:
        items = []
    items.append(item)
    return items

print(add_item(1))
print(add_item(2))
```

```output
[1]
[2]
```

`None` обозначает отсутствие переданного списка. В таком случае создаётся новый. Если пользователь явно передал список, функция изменит именно его. Эта договорённость должна быть понятна из описания.

---

**Функция может вернуть несколько значений — на самом деле один кортеж.**

```python
def quotient_and_remainder(a, b):
    return a // b, a % b

q, r = quotient_and_remainder(23, 5)
print(q, r)
```

```output
4 3
```

Фактически возвращается один кортеж, который распаковывается. Для этой конкретной операции уже существует `divmod(a, b)`, но пример показывает общую механику.

Параметр `*values` собирает произвольное число позиционных аргументов в кортеж. `**options` так же собирает именованные аргументы в словарь. Звёздочки здесь — не умножение и не степень: в списке параметров у них свой смысл.

```python
def total_of(*values):
    return sum(values)

print(total_of(2, 3, 5))
print(total_of())
```

```output
10
0
```

Звёздочка без имени в списке параметров заставляет последующие параметры передавать по имени: `def show(value, *, label="Результат"):`. Символ `/` в списке параметров означает, что предшествующие параметры только позиционные. Эти формы полезно узнавать в документации; для собственных первых функций они не обязательны.

---

**Функцию можно передать как значение; `lambda` создаёт короткую функцию из одного выражения.** Имя функции можно передать другой функции. Без скобок это сама функция; со скобками — результат её вызова.

```python
def last_digit(number):
    return abs(number) % 10

rule = last_digit
print(rule(47))
short_rule = lambda number: abs(number) % 10
print(short_rule(-123))
```

```output
7
3
```

`lambda number: abs(number) % 10` создаёт короткую функцию с одним выражением. Она делает то же, что `last_digit`, только у неё нет собственного имени. Она автоматически возвращает результат выражения. Несколько инструкций в `lambda` не помещают: используй `def`. Чаще всего `lambda` передают другой функции — например, как правило сортировки в уроке о сортировке.

---

**Хорошая функция начинается с договорённости о входе, результате и особых случаях.** Сначала сформулируй **договорённость**: что функция принимает, что возвращает, какие случаи допускаются, меняет ли аргументы. Например: «принимает целое число, возвращает сумму цифр его модуля».

```python
def digit_sum(number):
    """Вернуть сумму десятичных цифр модуля целого числа."""
    number = abs(number)
    total = 0
    while number > 0:
        total += number % 10
        number //= 10
    return total

print(digit_sum(-5072), digit_sum(0))
```

```output
14 0
```

Первая строка текста в теле функции — **строка документации**, или docstring. Её может показывать `help(digit_sum)`. Тройные кавычки позволяют записывать многострочный текст; это не особый вид комментария.

---

**Возврат ставят после цикла, когда просмотрены все элементы.** Напишем `count_even(numbers)`, возвращающую количество чётных элементов без изменения списка:

```python
def count_even(numbers):
    count = 0
    for number in numbers:
        if number % 2 == 0:
            count += 1
    return count

print(count_even([0, 3, -4, 7]))
print(count_even([]))
```

```output
2
0
```

Возврат стоит после цикла. Если поставить его внутри тела, функция закончится после первого элемента. Для пустого списка корректно возвращается 0.

---

**Итого.**

- `def f(a, b=0)` — `b` можно не передавать; `f(b=1, a=2)` — аргументы по имени.
- Изменяемое значение по умолчанию общее для всех вызовов: используй `None` и новый объект внутри.
- `return a, b` возвращает кортеж, его распаковывают: `q, r = f(...)`.
- `*values` собирает лишние позиционные аргументы в кортеж.
- Функцию передают без скобок; `lambda x: выражение` — короткая функция; docstring описывает договорённость.
