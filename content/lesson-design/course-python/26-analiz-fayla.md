**Законченная программа начинается с договорённости о входе, выходе и спорных случаях, а дальше собирается из уже знакомых частей: чтение, вычисление, вывод и обработка ожидаемых ошибок**. Урок собирает почти весь курс: файл, функции, словарь, исключения и разделение программы на части. Так же устроено решение задачи экзамена с файлом.

Программа будет разбирать файл `numbers.txt` из урока о файлах:

```numbers.txt
5
-2
10
7
```

Программа выведет его количество, сумму, минимум, максимум и среднее, а на испорченных файлах — понятные сообщения.

---

**Сначала формулируется договорённость: что программа принимает и что делает в спорных случаях.** Сделаем программу, которая читает текстовый файл с одним целым на строке и выводит количество, сумму, минимум, максимум и среднее. Заголовка нет. Пустой файл разрешён; пустая строка внутри непустого файла считается нарушением формата. Числа могут быть отрицательными. Программа рассчитана на обычные по величине целые; среднее вычисляется приближённо через `float`.

Путь передаётся аргументом командной строки. Командная строка — способ передать программе настройки при запуске. Если путь не указан, читается `numbers.txt` в рабочей папке. Вычисление сделаем отдельной функцией, чтобы оно не зависело от файла.

---

**Полный код собирает чтение, вычисление и вывод в три функции.** Сохрани следующий код в `analyze_numbers.py`. Все его определения находятся в одном блоке; другие уроки для запуска копировать не нужно. Длинные строки перенесены внутри скобок — Python продолжает выражение до закрывающей скобки.

```python
import sys
from pathlib import Path


def read_numbers(path):
    numbers = []
    with path.open(encoding="utf-8") as file:
        for line_number, line in enumerate(file, start=1):
            try:
                number = int(line)
            except ValueError as error:
                raise ValueError(
                    f"Строка {line_number}: "
                    "ожидалось целое число"
                ) from error
            numbers.append(number)
    return numbers


def summarize(numbers):
    if not numbers:
        return {
            "count": 0,
            "total": 0,
            "minimum": None,
            "maximum": None,
            "average": None,
        }
    total = sum(numbers)
    return {
        "count": len(numbers),
        "total": total,
        "minimum": min(numbers),
        "maximum": max(numbers),
        "average": total / len(numbers),
    }


def main():
    if len(sys.argv) > 2:
        print(
            "Использование: python analyze_numbers.py [путь]",
            file=sys.stderr,
        )
        return 2
    if len(sys.argv) == 2:
        path = Path(sys.argv[1])
    else:
        path = Path("numbers.txt")
    try:
        numbers = read_numbers(path)
    except (OSError, ValueError) as error:
        print(
            f"Не удалось прочитать данные: {error}",
            file=sys.stderr,
        )
        return 1

    report = summarize(numbers)
    print("Количество:", report["count"])
    print("Сумма:", report["total"])
    if report["count"] == 0:
        print(
            "Файл пуст: минимум, максимум "
            "и среднее не определены"
        )
    else:
        print("Минимум:", report["minimum"])
        print("Максимум:", report["maximum"])
        print(f"Среднее: {report['average']:.3f}")
    return 0


if __name__ == "__main__":
    raise SystemExit(main())
```

```output
Количество: 4
Сумма: 20
Минимум: -2
Максимум: 10
Среднее: 5.000
```

Программа запущена без аргумента, поэтому прочитала `numbers.txt`. Каждая функция отвечает за своё: `read_numbers` — за формат файла, `summarize` — за вычисление по готовому списку, `main` — за запуск и вывод.

Это последняя версия сквозной задачи курса: сумма и наибольшее из 5, −2, 10, 7 начинались с четырёх имён и трёх `if`, затем были цикл, список, `sum` и `max`, файл. Теперь к ним добавились количество, минимум и среднее, разбор ошибок формата и запуск из терминала.

---

**Новые детали — аргументы запуска, цепочка исключений, поток ошибок и код завершения.** `sys.argv` — список аргументов запуска. Первый элемент содержит имя запускаемого скрипта; следующие — переданные пользователем строки. Если в пути есть пробелы, в терминале его заключают в кавычки.

`except ValueError as error` даёт имя пойманному исключению. `raise ... from error` сохраняет исходную причину и добавляет понятный контекст с номером строки. `OSError` объединяет проблемы доступа к файлу и другие ошибки операционной системы. `UnicodeDecodeError` при неверной кодировке относится к семейству `ValueError` и также будет обработан.

`sys.stderr` — стандартный поток ошибок, отдельный от обычного вывода. `SystemExit` завершает программу с кодом: 0 обычно означает успех, ненулевое значение — проблему. Это полезно при запуске из других программ. Мы не перехватываем все возможные исключения: ошибка внутри вычисляющей функции должна быть замечена при разработке.

---

**Программу проверяют не только на обычном файле, но и на пустом, коротком и испорченном.** Запуск из терминала:

```shell
python analyze_numbers.py numbers.txt
```

Проверь также пустой файл, одну строку `-5`, отсутствующий файл и строку `abc`. Для неверной строки программа должна сообщить её номер, а не незаметно пропустить запись. Функции можно проверить и без терминала — их вызывают напрямую. Пусть файл `bad.txt` содержит строки `5`, `abc`, `7`:

```python
for name in ["bad.txt", "missing.txt"]:
    try:
        read_numbers(Path(name))
    except (OSError, ValueError) as error:
        print(type(error).__name__, error)
print(summarize([]))
print(summarize([-5])["average"])
```

```output
ValueError Строка 2: ожидалось целое число
FileNotFoundError [Errno 2] No such file or directory: 'missing.txt'
{'count': 0, 'total': 0, 'minimum': None, 'maximum': None, 'average': None}
-5.0
```

`type(error).__name__` — имя типа исключения. Отсутствующий файл дал `FileNotFoundError` — это один из видов `OSError`, поэтому `main` перехватил бы и его. Пустой список даёт отчёт с `None`, а не ошибку: так записано в договорённости.

---

**Развивать программу стоит через новую договорённость, а не случайными правками.** Для огромного файла список не обязателен: можно одновременно обновлять количество, сумму, минимум и максимум по мере чтения. Здесь список оставлен, чтобы функция `summarize` легко принимала готовые данные и чтобы было видно разделение ответственности.

Следующие самостоятельные улучшения: добавить отдельный JSON-отчёт, подсчёт чётных значений, проверку точного количества строк по заголовку или обработку нескольких файлов. Каждое изменение сначала сформулируй как новую договорённость, затем проверь старые и новые случаи.

---

**Итого.**

- Программа начинается с договорённости: формат входа, выход, спорные случаи.
- Чтение, вычисление и вывод разделены по функциям; вычисление проверяется на списках.
- `sys.argv` — аргументы запуска, `sys.stderr` — сообщения об ошибках, `SystemExit` — код завершения.
- `raise … from error` добавляет контекст (номер строки), не теряя причину.
- Проверочные случаи: обычный, пустой, одна строка, отсутствующий файл, испорченная строка.
