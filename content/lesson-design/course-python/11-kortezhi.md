**Кортеж — короткая неизменяемая запись, а распаковка раздаёт элементы последовательности по именам за одно присваивание**. Опора — список прошлого урока: кортеж — его неизменяемый родственник, а распаковка работает для обоих.

Данные урока — результаты учеников парами «имя и балл»: `("Анна", 91)`, `("Илья", 84)`, `("Марк", 95)`.

---

**Кортеж похож на список, но его нельзя изменить.** **Кортеж** (`tuple`) похож на список, но нельзя заменить его элемент, добавить или удалить позицию. Он подходит для небольшой записи: координат, пары «имя и результат», нескольких возвращаемых значений.

```python
point = (3, 5)
print(point[0])
single = (8,)
empty = ()
print(type((8)), type(single), len(empty))
```

```output
3
<class 'int'> <class 'tuple'> 0
```

Кортеж создаёт запятая, а не только круглые скобки. `(8)` — просто число в скобках, `(8,)` — кортеж из одного элемента. Попытка заменить элемент остановит программу:

```python
point = (3, 5)
point[0] = 4
```

```error
TypeError: 'tuple' object does not support item assignment
```

Неизменяемость внешнего кортежа не делает неизменяемым список внутри него: содержимое такого списка по-прежнему можно менять.

---

**Распаковка связывает несколько имён с элементами последовательности.**

```python
point = (3, 5)
x, y = point
print(x, y)

a = 10
b = 20
a, b = b, a
print(a, b)
```

```output
3 5
20 10
```

Справа сначала вычисляются прежние значения `b` и `a`, затем выполняется присваивание. Обычные последовательные строки `a = b` и `b = a` обмена не дадут: прежнее `a` будет потеряно — после них оба имени будут равны 20.

Количество значений должно совпадать с количеством имён:

```python
x, y = (1, 2, 3)
```

```error
ValueError: too many values to unpack (expected 2, got 3)
```

Можно обозначить имя для остальных элементов звёздочкой:

```python
first, *middle, last = [10, 20, 30, 40]
print(first, middle, last)
```

```output
10 [20, 30] 40
```

`middle` получает список. Распаковка работает и для списков, строк и других перебираемых объектов, а не только кортежей.

---

**Пары из списка удобно распаковывать прямо в заголовке `for`.** Выведем имена тех, у кого результат не меньше 90:

```python
students = [("Анна", 91), ("Илья", 84), ("Марк", 95)]
for name, score in students:
    if score >= 90:
        print(name)
```

```output
Анна
Марк
```

Пара из списка сразу распаковывается в `name` и `score`. Без распаковки пришлось бы писать `for student in students:` и обращаться к `student[0]` и `student[1]`.

---

**`enumerate` добавляет номер к каждому элементу, `zip` соединяет источники по позициям.** `enumerate` выдаёт пары «номер и элемент»:

```python
names = ["Анна", "Илья", "Марк"]
for position, name in enumerate(names, start=1):
    print(position, name)
```

```output
1 Анна
2 Илья
3 Марк
```

`start=1` меняет выдаваемые номера, но не индексы исходного списка. В каждой итерации пара распаковывается в два имени.

`zip` соединяет несколько источников по позициям:

```python
names = ["Анна", "Илья"]
scores = [91, 84]
for name, score in zip(names, scores):
    print(name, score)
```

```output
Анна 91
Илья 84
```

Обычный `zip` заканчивается при исчерпании самого короткого источника. Если длины по смыслу обязаны совпадать, используй `zip(names, scores, strict=True)` в Python 3.10+ или отдельно проверь длины: так потеря данных не пройдёт незаметно.

Звёздочка в вызове функции означает ещё одно применение распаковки:

```python
numbers = [10, 20, 30]
print(*numbers)
print(*numbers, sep=", ")
```

```output
10 20 30
10, 20, 30
```

Элементы передаются отдельными аргументами, как в `print(10, 20, 30)`. Это не умножение: значение знака зависит от его места в синтаксисе.

---

**Итого.**

- Кортеж создаёт запятая: `(8,)` — кортеж, `(8)` — число; элементы менять нельзя.
- `x, y = point` раздаёт элементы по именам; число имён должно совпадать.
- `a, b = b, a` меняет значения местами: правая часть вычисляется целиком до присваивания.
- `for name, score in pairs` распаковывает каждую пару; `enumerate` даёт номер, `zip` — элементы по позициям.
- `print(*items)` передаёт элементы отдельными аргументами.
