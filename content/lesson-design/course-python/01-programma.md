Этот курс рассчитан на начало с нуля. Его цель — научить читать программу как последовательность понятных действий, самостоятельно строить решения и проверять их. Подготовка к ЕГЭ — одно из применений этих знаний. Большая часть примеров относится к обычному программированию: обработке текста, чисел, файлов и записей.

Главная идея урока: **программа — это точная запись действий, и компьютер выполняет ровно написанное, а не задуманное**. На этом держится всё остальное: и чтение чужого кода, и поиск ошибок по сообщению Python.

Сквозной пример урока — стоимость трёх тетрадей по 40 рублей. Мы запишем её программой, разберём, из каких частей она состоит, а потом намеренно испортим и прочитаем, что ответит Python.

---

**Программа описывает действия, которые человек выполняет в уме.** Предположим, нужно найти стоимость трёх тетрадей по 40 рублей. Человек может сразу получить 120. Для компьютера нужно описать действия: взять количество, взять цену, перемножить их, показать результат.

**Алгоритм** — точное описание действий для решения задачи. **Программа** — запись этих действий на языке, который может обрабатывать компьютер. Один алгоритм можно записать на Python, другом языке или сначала обычными словами.

**Исходный код** — текст программы. Python — и название языка, и привычное название программы, которая выполняет код. Такую исполняющую программу называют **интерпретатором**. Он разбирает записи и организует вычисления.

**Первая программа — это файл с расширением `.py`, который запускает интерпретатор.** Установи Python 3 с официального сайта [python.org](https://www.python.org/downloads/) или используй уже установленную учебную среду. **Редактор** помогает писать текст; **интерпретатор** выполняет его. **IDE** — среда, объединяющая редактор, запуск и средства поиска ошибок. Для обучения достаточно редактора и способа запустить файл; IDLE входит во многие установки Python.

Создай файл `main.py`. Расширение `.py` обозначает исходный файл Python. Запиши:

```python
print("Привет!")
print(3 * 40)
```

```output
Привет!
120
```

В IDLE сохрани файл и выбери Run Module. При запуске из терминала перейди в папку файла и выполни одну подходящую команду:

```shell
python main.py
```

На некоторых компьютерах команда называется `python3`, а в Windows может быть доступна `py`. Используй ту, для которой проверка версии показывает Python 3:

```shell
python --version
```

Терминал — окно, принимающее команды операционной системы. Он отличается от интерактивной оболочки Python, где приглашение часто выглядит как `>>>`. В оболочку вводят Python-код, а не команду `python main.py`. Само приглашение `>>>` в файл копировать не надо.

`print` — готовая функция вывода. Пока считай функцию именованным действием, которому можно передать данные. Скобки после имени означают **вызов**: просьбу выполнить это действие. Переданные внутри скобок данные называются **аргументами**. В первом вызове передаётся текст, во втором — результат умножения. Строки программы выполняются сверху вниз, поэтому «Привет!» напечатано раньше числа.

Курс использует Python 3.10 и новее, без сторонних библиотек в основных примерах. Перед экзаменом проверь, какая версия стоит на твоём компьютере.

**Пример мало прочитать — его запускают и меняют.** У чтения кода и написания кода разные задачи. Когда читаешь, нужно понимать, что делает каждая строка. Когда пишешь, сначала объясни будущие действия по-русски. Проверяй не только совпадение ответа, но и своё понимание причин.

Для каждого примера полезен такой порядок:

1. Прочитай условие и выпиши исходные данные.
2. Прочитай разбор и запусти программу сам: результат должен совпасть с выводом под кодом.
3. Измени одно значение: например, положительное число на отрицательное, непустую строку на пустую.
4. Объясни, почему результат изменился или остался прежним.
5. Через некоторое время восстанови решение без подсматривания.

**Как читать примеры.** В шапке блока — условное имя файла примера, ниже — программа, под ней «Вывод»: всё, что программа покажет на экране, строка в строку. Если программа что-то спрашивает, набранный пользователем текст в выводе показан в рамке, как клавиша, со знаком ↵ — это нажатие Enter. Сообщение об ошибке в выводе выделено красным. Строки после знака `#` — пояснения, не команды.

Короткий фрагмент иногда продолжает предыдущий: если в нём используется уже введённое имя, сохрани предыдущие строки. Законченные программы и функции содержат необходимые определения. Команды для терминала отличаются от кода Python: их запускают в командной строке операционной системы.

**Критерий понимания.** Недостаточно знать, что цикл «что-то перебирает». Нужно уметь сказать, какое значение он рассматривает сейчас, какие данные уже обработаны и что означает каждая изменяющаяся переменная.

**Выражение вычисляет значение, инструкция задаёт действие.** **Выражение** вычисляет значение: `3 * 40`, `2 + 5`, `"Привет!"`. **Инструкция** задаёт действие программы: присваивание, условие, цикл. Вызов функции тоже является выражением, хотя на первых шагах нас часто интересует его действие — например, вывод.

В интерактивной оболочке результат введённого выражения обычно показывается автоматически. В файле строка `3 * 40` сама по себе ничего не напечатает. Чтобы увидеть результат, используй `print(3 * 40)`:

```python
3 * 40
print(3 * 40)
print("3 * 40")
```

```output
120
3 * 40
```

Первая строка вычислила 120, но результат никуда не попал. Вторая передала то же значение в `print`. Третья напечатала текст: кавычки превращают запись в текстовые данные, и Python не вычисляет арифметику внутри обычной строки.

**Программа не догадывается о намерениях.** Python различает `price` и `Price`. Пропущенная кавычка, неверный знак или отступ могут изменить смысл либо сделать запись недопустимой. Правила допустимой записи называются **синтаксисом**. Если правила записи соблюдены, это ещё не доказывает, что решена нужная задача.

Испортим сквозной пример тремя способами и посмотрим, что ответит Python. Здесь пропущена закрывающая скобка:

```python
print(3 * 40
```

```error
SyntaxError: '(' was never closed
```

Здесь переставлены буквы в имени функции:

```python
pritn(3 * 40)
```

```error
NameError: name 'pritn' is not defined. Did you mean: 'print'?
```

А здесь всё записано верно, но вместо умножения стоит сложение:

```python
print(3 + 40)
```

```output
43
```

Это три разные проблемы. **Синтаксическая ошибка** означает, что запись нельзя корректно разобрать: забыто двоеточие, не закрыта кавычка или скобка. **Исключение при выполнении** означает, что очередная операция не может завершиться обычным образом: например, вызвать функцию с неизвестным именем или разделить на ноль. **Логическая ошибка** означает, что программа выполняется, но вычисляет не то, что требуется. О ней Python не сообщает вовсе: 43 выглядит как обычное число, и только сверка с ручным расчётом показывает, что ответ неверен.

**Сообщение об ошибке читают с последней строки.** Когда программа останавливается, Python печатает **traceback** — сообщение с цепочкой мест, через которые выполнение дошло до ошибки. Начни с последней строки: там тип и пояснение. Затем найди последнюю относящуюся к твоему коду строку и проверь значения её частей. Иногда синтаксическая ошибка обнаруживается строкой ниже настоящей причины: например, незакрытой скобки.

Вот полное сообщение для программы, которая делит стоимость на ноль:

```python run zero_division.py
print(3 * 40)
print(120 / 0)
```

```output
120
```

```error
Traceback (most recent call last):
  File "main.py", line 2, in <module>
    print(120 / 0)
          ~~~~^~~
ZeroDivisionError: division by zero
```

Первая строка программы успела выполниться: 120 напечатано. Последняя строка сообщения называет тип ошибки `ZeroDivisionError` и пояснение «деление на ноль». Строка `File "main.py", line 2` указывает место: вторая строка файла. Значки `~` и `^` в новых версиях Python подчёркивают виновную часть выражения.

<figcaption>Сообщение читают снизу вверх: сначала тип и пояснение, затем файл и номер строки, затем саму строку программы.</figcaption>
</figure>

В шапке этого примера справа есть кнопка «Запуск». Она выполняет программу по одной строке: подсвечивает строку, которая только что выполнилась, объясняет её, показывает переменные и всё, что уже выведено. Здесь на втором шаге видно, где программа остановилась и что первая строка успела напечатать. Такая кнопка есть у примеров курса, где важен порядок выполнения строк.

Тип ошибки подсказывает, где искать причину. `SyntaxError` и его родственник `IndentationError` (лишние пробелы в начале строки) появляются ещё при разборе записи: проверь скобки, кавычки и отступы. `NameError` и `ZeroDivisionError` появляются при выполнении: в первом случае имя написано с опечаткой или ещё не создано, во втором делитель оказался нулём. Другие типы ошибок появятся вместе с конструкциями, которые их вызывают: неподходящее значение при преобразовании текста в число, несуществующая позиция строки или ключ словаря, отсутствующий файл.

---

**Итого.**

- Программа — точная запись алгоритма; интерпретатор выполняет её строки сверху вниз.
- `print(...)` показывает значение; выражение без `print` в файле ничего не выводит.
- Кавычки делают запись текстом: `"3 * 40"` не вычисляется.
- Синтаксическая ошибка, исключение и логическая ошибка — разные проблемы; о логической Python не сообщает.
- Сообщение об ошибке читают с последней строки, затем ищут номер строки своего файла.

**Чтобы проверить понимание, реши задачи сначала рассуждением, а затем при необходимости программой.**

1. Напиши программу, выводящую своё имя, затем результат `12 + 8`, затем текст `12 + 8`. Объясни разницу двух последних строк.

2. Сколько строк напечатает программа и какие?

   ```python
   7 * 6
   print(7 * 6)
   print("7 * 6")
   ```

3. Пять ручек стоят по 23 рубля. Напиши программу, которая выводит стоимость покупки.

4. Программа `print(5 * 23` остановилась с ошибкой. Какой у неё тип и как исправить запись?

5. Какую ошибку выдаст `Print(5 * 23)` и почему, хотя `print` написан «почти правильно»?

6. Нужно напечатать стоимость трёх тетрадей по 40 рублей и двух ручек по 15 рублей. Программа `print(3 * 40 + 2 + 15)` работает без сообщений об ошибке. Что она выводит и к какому виду относится её ошибка?

7. Программа из двух строк `print(100 / 4)` и `print(100 / 0)` остановилась. Что успело напечататься и что будет в последней строке сообщения?

8. Напиши программу, которая выводит три строки: стоимость трёх тетрадей по 40 рублей, стоимость двух ручек по 15 рублей и общую стоимость покупки. Каждую стоимость вычисли выражением, а не готовым числом.

**Ответы для проверки:**

1. Например, `print("Анна")`, `print(12 + 8)`, `print("12 + 8")`; вывод: Анна, 20, 12 + 8. Без кавычек выражение вычисляется, в кавычках печатается как текст.
2. Две строки: 42 и 7 * 6. Первая строка программы вычисляет 42, но ничего не выводит.
3. `print(5 * 23)` выводит 115.
4. `SyntaxError: '(' was never closed` — не закрыта скобка; верно `print(5 * 23)`.
5. `NameError`: имени `Print` нет, Python различает заглавные и строчные буквы.
6. Выводит 137 — это логическая ошибка: вместо `2 * 15` записано `2 + 15`; верная стоимость 150.
7. Успело напечататься 25.0; последняя строка — `ZeroDivisionError: division by zero`.
8. `print(3 * 40)`, `print(2 * 15)`, `print(3 * 40 + 2 * 15)`; вывод: 120, 30, 150.
