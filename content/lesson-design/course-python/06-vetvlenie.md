**`if` выбирает, какие строки выполнять, по значению условия; порядок проверок в цепочке `elif` выводится из условий, а не выбирается наугад**. Опора — логические выражения прошлого урока: `if` получает именно их значение `True` или `False`.

Разберём это на уровне ученика по баллу: от 85 — высокий, от 60 — средний, ниже — начальный. На нём видно и выбор одной ветки, и цену неверного порядка проверок.

---

**Ветвление выбирает действия на основании условия.** Программа расчёта доставки может действовать по-разному: при большой сумме заказа доставка бесплатна, иначе стоит 300 рублей. **Ветвление** — выбор действий на основании условия.

```python
order_total = 2400
if order_total >= 2000:
    delivery = 0
else:
    delivery = 300
print(delivery)
```

```output
0
```

`if` проверяет условие. Двоеточие открывает блок связанных инструкций. Строки с одинаковым увеличенным отступом принадлежат блоку. Обычно используют четыре пробела. `else` означает альтернативу, когда условие `if` ложно. После возврата к прежнему отступу выполнение продолжается вне ветвления: `print(delivery)` выполняется в любом случае.

**Отступ — часть смысла программы.** Это не украшение, как выравнивание текста в тетради. Не смешивай табуляции и пробелы. Если отступ у строки внутри блока пропущен, Python сообщит `IndentationError`; если лишний отступ стоит у строки вне блока — тоже.

---

**`elif` проверяет следующий случай, только если предыдущие не подошли.**

```python run level.py
score = 73
if score >= 85:
    level = "высокий"
elif score >= 60:
    level = "средний"
else:
    level = "начальный"
print(level)
```

```output
средний
```

`elif` — следующая проверка, если предыдущие не подошли. Здесь выбирается ровно одна ветка. Во вторую ветку попадают значения от 60 до 84: верхняя граница уже следует из неуспеха первой проверки. Проверим границы. 85 ещё «высокий»: `>=` включает саму границу. 84 уже «средний», 60 — тоже «средний», 59 — «начальный». Для 90 и 85 вторая проверка не выполняется вовсе: ответ найден на первой.

Если сначала проверить `score >= 60`, а потом `score >= 85`, высокий результат захватит первая ветка: для 90 получится «средний», а ветка «высокий» не выполнится никогда. Поэтому порядок проверок нужно выводить из условий, а не выбирать наугад.

Запусти программу с баллом 73 по шагам: проверка `score >= 85` даёт `False`, `score >= 60` — `True`, и строки ветки `else` уже не рассматриваются.

---

**Если у значения может быть несколько признаков сразу, нужны отдельные `if`.**

```python
n = 12
if n % 2 == 0:
    print("чётное")
if n % 3 == 0:
    print("делится на 3")
```

```output
чётное
делится на 3
```

Будут напечатаны обе строки. Замена второго `if` на `elif` запретила бы второй вывод после успешного первого: цепочка `if`–`elif` выбирает не больше одной ветки.

---

**Имя должно получить значение на каждом пути, где оно понадобится.** Здесь `result` получает значение и в ветке `if`, и в ветке `else`:

```python
x = -2
if x > 0:
    result = "положительное"
else:
    result = "неположительное"
print(result)
```

```output
неположительное
```

Если убрать `else`, при `x = -2` имя `result` в свежем запуске не появится:

```python
x = -2
if x > 0:
    result = "положительное"
print(result)
```

```error
NameError: name 'result' is not defined
```

Интерактивная среда может скрыть ошибку, если от прошлого запуска осталось старое значение; поэтому регулярно запускай весь файл заново.

Для простого выбора значения есть условное выражение:

```python
x = -2
absolute = x if x >= 0 else -x
print(absolute)
```

```output
2
```

Сначала проверяется условие, затем вычисляется только выбранная часть. Для сложных действий обычный `if` читается лучше.

---

**Наибольшее из нескольких чисел ищут, сравнивая с лучшим найденным.** Найдём наибольшее из трёх целых без `max`, разрешая равные и отрицательные значения:

```python
a = -5
b = -2
c = -9
best = a
if b > best:
    best = b
if c > best:
    best = c
print(best)
```

```output
-2
```

Начальное значение взято из данных. Если начать с нуля, все отрицательные значения ошибочно проиграют числу, которого среди данных нет: программа напечатала бы 0. Здесь нужны именно отдельные `if`, а не `elif`: каждое следующее число сравнивается с лучшим на данный момент.

---

**Сквозная задача курса: сумма и наибольшее — пока для отдельных чисел.** Через весь курс пройдёт одна задача: найти сумму и наибольшее из чисел 5, −2, 10, 7. С каждым модулем её решение будет становиться короче, а данные — больше. Сейчас у нас есть только переменные и `if`, поэтому каждое число получает своё имя:

```python
a = 5
b = -2
c = 10
d = 7
total = a + b + c + d
best = a
if b > best:
    best = b
if c > best:
    best = c
if d > best:
    best = d
print(total, best)
```

```output
20 10
```

Для тысячи чисел так писать нельзя: понадобилась бы тысяча имён и тысяча `if`. Это решат циклы следующего модуля.

---

**Итого.**

- `if` выполняет блок с отступом, только если условие истинно; `else` — иначе.
- Цепочка `if`–`elif`–`else` выбирает ровно одну ветку; порядок проверок выводится из условий.
- Несколько независимых признаков проверяют отдельными `if`.
- Имя должно получить значение на каждом пути; иначе `NameError`.
- Максимум начинают с первого значения из данных, а не с нуля.
