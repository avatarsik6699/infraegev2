# Какие конструкции Python нужны темам ЕГЭ

Файл сгенерирован скриптом `needs_report.py` из исходников тем ЕГЭ (`constructs.py` → `SOURCES`) и привязки конструкций к разделам учебника (`constructs.py` → `CONSTRUCTS`). Руками не правится.

## Итог

- Исходников тем: **16**, программ Python: **1159**, разобрано: **1158**.
- Различных конструкций: **116**; все объяснены в уроках основного уровня: **да**.
- Уроков курса, ни один раздел которых не нужен темам напрямую: **7** (список в конце).

**Правило уровней.** Конструкция, которую использует хотя бы одна тема ЕГЭ, объясняется в уроке основного уровня. Разделы, которые не нужны ни одной теме, остаются основными, если без них не читаются следующие уроки (например, строка документации или `try`); иначе это дополнительный уровень: классы, дополнительные механизмы языка, аннотации и тесты. Инструмент, который нужен одной теме и объясняется в ней самой (сети `ipaddress`, куча `heapq`, геометрия точек), помечен «тема NN».

Файл `10.md` — исходник задания 13 (IP-адреса), поэтому в отчёте он подписан номером 13. В исходниках заданий 4 и 7 программ на Python нет. Раздел со знаком «+» — пробел исходника учебника: урок курса добавляет конструкцию к этому разделу (список — в [карте курса](py-map.html)).
