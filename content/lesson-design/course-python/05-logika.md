**Условие — это выражение, которое вычисляется в `True` или `False`, а `and`, `or` и `not` собирают из простых ответов сложные**. Опора — `bool` из урока о значениях и остаток `%` из урока о числах: «делится» — это `n % d == 0`. Почти все ошибки здесь — неверный перевод слов «и», «или», «не» в код.

Проверять условия будем на числе `x = 12`: лежит ли оно в интервале, чётно ли, делится ли на 3.

---

**Сравнение отвечает на вопрос и даёт логическое значение.**

```python
temperature = 18
is_warm = temperature >= 15
print(is_warm)
```

```output
True
```

Результат сравнения — логическое значение: `True` означает «истина», `False` — «ложь». Это не текстовые подписи, а значения типа `bool`.

Сравнений шесть. `==` спрашивает, равны ли значения, `!=` — различаются ли они. `<` и `>` — строго меньше и строго больше, `<=` и `>=` — меньше либо равно и больше либо равно. Знаки из двух символов пишутся слитно: `<=`, а не `< =`.

`=` присваивает, `==` сравнивает. В записи `is_warm = temperature >= 15` правая часть отвечает на вопрос, левая сохраняет ответ под именем.

---

**`and` требует обоих условий, `or` — хотя бы одного, `not` меняет ответ на противоположный.** У двух логических значений `a` и `b` всего четыре сочетания. Разложим их клетками и отметим, где выражение истинно:

<figure class="plate-figure">
%%truth_grids()%%
<figcaption><code>and</code> истинно в одной клетке — когда истинны оба. <code>or</code> ложно в одной клетке — когда ложны оба. <code>a != b</code> истинно на диагонали: ровно одно из двух.</figcaption>
</figure>

Обрати внимание на нижнюю правую клетку `or`: `or` истинно и тогда, когда верны оба условия, — это не «одно из двух». «Ровно одно из двух» записывают как `a != b`. Здесь `a` и `b` именно логические значения; для произвольных чисел `a != b` означает различие чисел, а не различие их истинности.

Интервал удобно записывать цепочкой:

```python
x = 12
print(5 <= x < 20)
print(x % 2 == 0 and x > 0)
print(not x % 3 == 0)
```

```output
True
True
False
```

`5 <= x < 20` означает выполнение обоих сравнений:

<figure class="plate-figure">
%%interval(5, 20, 12)%%
<figcaption>Закрашенный конец 5 входит в интервал (<code>&lt;=</code>), пустой конец 20 — нет (<code>&lt;</code>). 12 лежит внутри, поэтому ответ <code>True</code>.</figcaption>
</figure>

Третья строка: 12 делится на 3, сравнение даёт `True`, а `not` превращает его в `False`.

Частая ошибочная идея: записать «x равно 2 или 3» как `x == 2 or 3`. Посмотрим, что получится:

```python
x = 12
print(x == 2 or 3)
print(x == 2 or x == 3)
```

```output
3
False
```

Справа от `or` стоит отдельное число 3, которое рассматривается как истинное значение, поэтому первое условие «выполнено» для любого `x`. Нужно повторить сравнение: `x == 2 or x == 3`.

---

**Python не вычисляет часть условия, которая уже не влияет на ответ.** В `a and b` значение `b` не нужно, если `a` ложно. В `a or b` значение `b` не нужно, если `a` истинно. Это называют коротким вычислением.

```python
x = 0
print(x != 0 and 10 / x > 2)
```

```output
False
```

<figure class="plate-figure">
%%short_circuit()%%
<figcaption>Как только левой части хватает для ответа, правая пропускается. Поэтому <code>10 / x</code> при <code>x = 0</code> не выполняется ни в одной строке.</figcaption>
</figure>

Деления на ноль нет: `x != 0` ложно, и правая часть не вычислялась. Порядок частей значим: безопасная проверка должна стоять раньше действия, которому она даёт разрешение. Если переставить части, `10 / x > 2 and x != 0` остановится с `ZeroDivisionError`.

---

**Любое значение в условии считается истинным или ложным.** В условии ноль, пустая строка и `None` считаются ложными; ненулевые числа и непустые строки — истинными. Позднее к ложным добавятся пустые коллекции.

<figure class="plate-figure">
%%truthy()%%
<figcaption>Ложных значений немного, их легко запомнить: ноль, пустая строка, <code>None</code> и сам <code>False</code>. Всё остальное истинно, в том числе строки <code>"0"</code>, <code>"False"</code> и строка из одного пробела.</figcaption>
</figure>

`bool(value)` явно получает логическую оценку. `bool("False")` равно `True`, потому что строка непустая. Python не переводит её английский текст в логическое значение.

Для произвольных объектов `and` и `or` возвращают один из операндов, а не обязательно `bool`:

```python
print("" or "Без названия")
print(5 and 8)
```

```output
Без названия
8
```

В первом случае первая строка ложна, поэтому возвращается запасная. Во втором первый операнд истинен, поэтому результатом становится второй. При обычных сравнениях операнды уже логические, поэтому результат тоже выглядит как `True` или `False`. Этим же объясняется вывод 3 в ошибочной записи `x == 2 or 3` выше.

---

**Отрицание составного условия меняет `and` на `or`.** Выражение `not (a and b)` истинно, когда хотя бы одно из условий ложно; оно равносильно `(not a) or (not b)`. Аналогично `not (a or b)` равносильно `(not a) and (not b)`. Проверим на `x = 12`: «неверно, что x чётно и больше 20» — то же, что «x нечётно или не больше 20»:

```python
x = 12
print(not (x % 2 == 0 and x > 20))
print(x % 2 != 0 or x <= 20)
```

```output
True
True
```

**Импликация** «если A, то B» ложна только при истинном A и ложном B. Её можно записать `(not A) or B`.

<figure class="plate-figure">
%%truth_grids(["(not A) or B"], ["A", "B"])%%
<figcaption>Единственная ложная клетка — A истинно, B ложно: обещание «если A, то B» нарушено. Если A ложно, обещание не проверяется, и импликация истинна.</figcaption>
</figure>

Это полезно в задачах на формальную логику; не путай такую проверку логического отношения с инструкцией `if`, которая управляет выполнением кода.

---

**Итого.**

- Сравнения дают `True` или `False`; `=` присваивает, `==` сравнивает.
- `and` — оба условия, `or` — хотя бы одно, в том числе оба; `a != b` для логических — «ровно одно».
- Сравнение повторяют для каждой части: `x == 2 or x == 3`.
- Короткое вычисление: безопасная проверка ставится первой.
- `not (a and b)` = `not a or not b`; импликация A → B — `(not A) or B`.

**Чтобы проверить понимание, реши задачи сначала рассуждением, а затем при необходимости программой.**

1. Запиши условие «число делится на 3 или на 5, но не на оба сразу». Проверь его на числах 9, 10, 7 и 15.

2. Чему равны `7 > 3 and 2 > 5`, `7 > 3 or 2 > 5` и `not 7 > 3`?

3. Пусть `x = 7`. Чему равны `0 < x < 10` и `0 < x > 5`? Перепиши второе выражение через `and`.

4. Что выведет `print(x == 1 or 2)` при `x = 5`? Как записать условие «x равно 1 или 2» правильно?

5. Что выведет `print(0 and 10 / 0)`? А `print(10 / 0 and 0)`?

6. Чему равны `bool("")`, `bool("0")`, `bool(0)` и `bool(" ")`?

7. Пусть A — «n больше 10», B — «n чётное». Вычисли импликацию A → B для n = 7, 12 и 15.

8. Год високосный, если делится на 4 и не делится на 100 или если делится на 400. Запиши условие и проверь его на 1900, 2000, 2024 и 2023.

**Ответы для проверки:**

1. `(n % 3 == 0) != (n % 5 == 0)`: для 9 и 10 — True, для 7 и 15 — False.
2. False, True и False.
3. Оба True; второе означает `0 < x and x > 5`.
4. 2: второй операнд `or` — само число 2. Верно: `x == 1 or x == 2`.
5. 0 — правая часть не вычислялась; во втором случае `ZeroDivisionError`.
6. False, True, False и True: только пустая строка ложна, а `"0"` и `" "` — непустые.
7. True, True и False: ложно только при n = 15 — оно больше 10, но нечётное.
8. `y % 4 == 0 and y % 100 != 0 or y % 400 == 0`: 1900 — False, 2000 — True, 2024 — True, 2023 — False.
