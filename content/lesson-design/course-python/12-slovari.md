Главная идея урока: **словарь находит значение по смысловому ключу, а не по номеру позиции, и поэтому естественно хранит частоты**. Опора — счётчик из урока о `while`: частотная таблица — это много счётчиков сразу, по одному на каждое значение.

Сквозной пример урока — баллы учеников `{"Анна": 91, "Илья": 84}` и слово `"BANANA"`, в котором посчитаем буквы.

---

**Словарь хранит пары «ключ — значение» и ищет значение по ключу.** В списке элемент ищут по позиции. Иногда нужен доступ по имени: «балл Анны», «количество буквы A». **Словарь** (`dict`) хранит соответствия между ключами и значениями.

```python
scores = {"Анна": 91, "Илья": 84}
print(scores["Анна"])
scores["Марк"] = 88
scores["Анна"] = 95
print(scores)
```

```output
91
{'Анна': 95, 'Илья': 84, 'Марк': 88}
```

Ключ уникален: новое присваивание тому же ключу заменяет его значение. Значения могут повторяться. Чтение отсутствующего ключа через квадратные скобки вызывает ошибку:

```python
scores = {"Анна": 91, "Илья": 84}
print(scores["Ольга"])
```

```error
KeyError: 'Ольга'
```

Безопасное чтение и проверка ключа:

```python
scores = {"Анна": 91, "Илья": 84}
print(scores.get("Ольга", 0))
print("Анна" in scores)
print(91 in scores)
```

```output
0
True
False
```

`get(key, default)` возвращает значение либо указанное значение по умолчанию; ключ от этого не добавляется. Без второго аргумента значение по умолчанию — `None`. Операция `in` для словаря проверяет ключи, а не значения: 91 есть среди значений, но ключом не является.

---

**Ключом может быть только хешируемое значение: число, строка, кортеж из таких.** Для быстрого поиска словарь вычисляет по ключу число — **хеш** — и по нему сразу находит место хранения, не перебирая все пары. Поэтому ключ не должен меняться, пока лежит в словаре: иначе изменится его хеш и пара потеряется. Значения, для которых хеш определён, называют **хешируемыми**: это числа, строки и кортежи из хешируемых элементов. Список, словарь и обычное множество изменяемы и ключами быть не могут:

```python
d = {[1, 2]: 3}
```

```error
TypeError: cannot use 'list' as a dict key (unhashable type: 'list')
```

Кортеж, содержащий список, тоже не годится: сам кортеж не меняется, но список внутри него может.

Значения словаря такими ограничениями не связаны: можно хранить под именем пользователя целый список его результатов.

---

**Словарь обходят по ключам или по парам; порядок — порядок добавления.**

```python
scores = {"Анна": 91, "Илья": 84}
for name in scores:
    print(name)

total = 0
for name, score in scores.items():
    print(name, score)
    total += score
print(total)
```

```output
Анна
Илья
Анна 91
Илья 84
175
```

`.items()` позволяет получать пары, `.keys()` — ключи, `.values()` — значения. Это представления данных словаря, а не обязательно отдельные списки. `list(scores)` создаёт список ключей.

В Python 3.7+ сохраняется порядок добавления ключей. Это не сортировка: ключи не выстраиваются автоматически по алфавиту или величине. Замена значения существующего ключа не переносит его в конец. Не меняй количество ключей во время обхода того же словаря.

---

**Частотная таблица — словарь «значение → сколько раз встретилось».** **Частота** — число появлений значения. Пройдём по буквам и увеличим соответствующий счётчик:

```python run letter_counts.py
text = "BANANA"
counts = {}
for letter in text:
    counts[letter] = counts.get(letter, 0) + 1
print(counts)
```

```output
{'B': 1, 'A': 3, 'N': 2}
```

Если буква встретилась впервые, `get` даёт 0. После прибавления записывается 1. При следующих появлениях читается накопленное значение: для первой A `get` даёт 0, и в словаре появляется `'A': 1`, а для второй A — уже 1, и запись становится `'A': 2`.

Инвариант: после обработки первых `k` символов словарь содержит точные частоты в этой части текста.

Запусти подсчёт по шагам: на каждой итерации `for` берёт очередную букву, а следующая строка увеличивает её счётчик в словаре.

---

**Самое частое значение находят вторым проходом по парам словаря.** По списку `['a', 'b', 'a', 'c', 'b', 'a']` найдём значение с наибольшей частотой; при равенстве выберем то, которое впервые встретилось раньше:

```python
items = ['a', 'b', 'a', 'c', 'b', 'a']
counts = {}
for item in items:
    counts[item] = counts.get(item, 0) + 1

best_item = None
best_count = 0
for item, count in counts.items():
    if count > best_count:
        best_item = item
        best_count = count
print(best_item, best_count)
```

```output
a 3
```

Строгое `>` оставляет прежнего победителя при равенстве. Порядок словаря совпадает с порядком первых появлений. Для пустого входа ответ остаётся `None, 0` — это выбранное обозначение отсутствия результата.

<details class="proof" markdown="1">
<summary>Тонкости: равные ключи разных типов</summary>

Ключи `1`, `1.0` и `True` сравниваются равными и используются как один ключ. Поэтому в смысловых идентификаторах лучше не смешивать числа и логические значения без необходимости.

</details>

---

**Итого.**

- `d[key]` читает значение, отсутствующий ключ даёт `KeyError`; `d.get(key, default)` безопасен.
- Присваивание по существующему ключу заменяет значение; ключи уникальны.
- Ключи хешируемые: строки, числа, кортежи из них; список ключом быть не может.
- `in` проверяет ключи; `.items()` даёт пары, `.values()` — значения; порядок — порядок добавления.
- Частоты: `counts[x] = counts.get(x, 0) + 1`.
