**`for` берёт значения из готового источника по одному, а `range(start, stop, step)` — источник чисел, в котором начало включено, а остановка исключена**. Опора — `while` прошлого урока: `for` делает то же повторение, но счётчик и границу ведёт за тебя.

Числа возьмём от 100 до 200, а делитель — 17: найдём первое кратное, научимся перебирать только кратные и считать их.

---

**`for` по очереди получает элементы источника и выполняет тело для каждого.** Источник, из которого можно последовательно получать элементы, называют **перебираемым объектом**. Примерами будут строка, диапазон и список.

```python
for letter in "CODE":
    print(letter)
```

```output
C
O
D
E
```

На каждой итерации `letter` связывается с очередной буквой. Получатся четыре строки. Имя можно выбрать другое; слово `letter` не является специальной командой. В отличие от `while`, здесь не нужно самому увеличивать номер и следить за границей: источник сам кончается.

---

**`range` описывает арифметическую последовательность целых чисел.** Он хранит её параметры, а не заранее созданный список всех чисел. `range(4)` даёт 0, 1, 2, 3, а `range(2, 6)` — 2, 3, 4, 5: сама остановка, 4 в первом случае и 6 во втором, в перебор не попадает.

В форме `range(start, stop, step)` начало включено, остановка исключена. При положительном шаге перебор продолжается, пока значение меньше `stop`; при отрицательном — пока больше `stop`: `range(5, 0, -2)` даёт 5, 3, 1. Шаг 0 запрещён. `range(5, 0)` пуст: шаг по умолчанию 1, а 5 уже не меньше 0.

<figure class="plate-figure">
%%range(2, 9, 3)%%
<figcaption><code>range(2, 9, 3)</code>: от 2 шагами по 3 получаются 2, 5 и 8; следующее значение 11 уже не меньше 9. Сама остановка 9 в перебор не входит, даже если на неё попал бы шаг.</figcaption>
</figure>

Чтобы пройти целые от `a` до `b` включительно при `a <= b`, используют `range(a, b + 1)`. Исключённая правая граница удобна: количество целых от 0 до `n - 1` равно `n`; соседние диапазоны `range(0, k)` и `range(k, n)` не перекрываются.

Проверь правило на своих числах: меняй start, stop и step — схема и список значений пересчитываются сразу.

**Присваивание переменной цикла не меняет следующие значения `for`.**

```python
for i in range(3):
    print(i)
    i = 100
```

```output
0
1
2
```

Присваивание меняет текущее имя, но не источник будущих значений. Следующая итерация снова получает очередной элемент `range`. Для изменения правил перехода чаще нужен `while`.

**Во вложенных циклах внутренний выполняется целиком для каждого значения внешнего.**

```python run nested_loops.py
for row in range(2):
    for column in range(3):
        print(row, column)
```

```output
0 0
0 1
0 2
1 0
1 1
1 2
```

Для каждого `row` внутренний цикл выполняется целиком: пары `(0, 0)`, `(0, 1)`, `(0, 2)`, затем `(1, 0)`, `(1, 1)`, `(1, 2)`. Всего 2 × 3 итерации внутреннего тела. `break` внутри него завершает только внутренний цикл.

**Перебор по возрастанию с `break` находит наименьшее подходящее значение.**

```python
answer = None
for n in range(100, 201):
    if n % 17 == 0:
        answer = n
        break
print(answer)
```

```output
102
```

Перебор идёт по возрастанию, поэтому первый найденный результат минимален. Если подходящего числа нет, сохраняется `None`. Проверять отсутствие результата следует как `answer is None`; слово `is` сравнивает тождественность объектов. Подробно отличим его от `==` в уроке о списках.

У цикла также бывает `else`: он выполняется при нормальном исчерпании перебора, если `break` не был выполнен. Для `while` это завершение по ложному условию. `else` может выполниться и при нуле итераций. Это конструкция «не встретился выход через break», а не «условие последней итерации было ложным». Пока такая запись непривычна, явное `answer = None` обычно понятнее. Вот как выглядит поиск кратного 17 там, где его нет:

```python
for n in range(103, 119):
    if n % 17 == 0:
        print(n)
        break
else:
    print("нет")
```

```output
нет
```

Между 103 и 118 кратных 17 нет (102 и 119 — за границами), `break` не сработал, и выполнилась ветка `else`.

**Шаг `range` позволяет перебирать только нужные числа.** Найдём количество и сумму чисел от 1 до 100 включительно, кратных 7:

```python
count = 0
total = 0
for n in range(1, 101):
    if n % 7 == 0:
        count += 1
        total += n
print(count, total)
```

```output
14 735
```

Можно перебирать только нужные числа с помощью `range(7, 101, 7)`: тогда проверка не нужна, а цикл делает 14 итераций вместо 100. Такой переход полезен, когда понятно, почему он охватывает все и только нужные значения: 7 — первое кратное, шаг 7 даёт каждое следующее, а 100 < 105.

**Порядок выполнения строк задают три способа — и других нет.** Модули «Старт», «Условия» и «Циклы» вместе дали всё, чем программа управляет своим ходом:

<figure class="plate-figure">
%%control_flow()%%
<figcaption><strong>Подряд</strong>: присваивание, <code>print</code>, <code>input</code> выполняются сверху вниз по одной. <strong>Выбор</strong>: <code>if</code>, <code>elif</code>, <code>else</code> выполняют один блок из нескольких или ни одного. <strong>Повтор</strong>: <code>while</code> и <code>for</code> возвращаются к началу блока, пока условие истинно или есть значения.</figcaption>
</figure>

Любая программа курса — сочетание этих трёх способов, вложенных друг в друга. Поэтому чтение незнакомого кода сводится к одному вопросу на каждой строке: какая строка выполнится следующей и какие значения у имён сейчас. Именно это показывает запуск примера по шагам: подсвеченная строка и значения переменных.

---

**Итого.**

- `for x in источник` берёт значения по одному; источник сам кончается.
- `range(a, b)` — числа от `a` до `b − 1`; чтобы включить `b`, пишут `range(a, b + 1)`.
- Отрицательный шаг идёт вниз, пока значение больше `stop`.
- Вложенный цикл выполняется целиком для каждого значения внешнего.
- Первый найденный при переборе по возрастанию — наименьший; отсутствие ответа — `None`.
