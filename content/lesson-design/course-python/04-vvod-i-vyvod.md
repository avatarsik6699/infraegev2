Главная идея урока: **`input` всегда возвращает текст, а превратить его в число — решение автора программы**. Отсюда и правило вывода: печатать только то, что требуется, в нужном виде. Опора — уроки о типах и числах: `int(...)` и `float(...)` превращают введённый текст в значения, с которыми работает арифметика.

Сквозной пример урока — прямоугольник, длина и ширина которого вводятся с клавиатуры: найдём его площадь и периметр.

---

**`input()` ждёт строку от пользователя и возвращает её как `str`.** Нажатие Enter завершает ввод, а завершающий перевод строки не входит в результат.

```python
name = input("Как тебя зовут? ")
print("Привет,", name)
```

```console
Как тебя зовут? ⟪Анна⟫
Привет, Анна
```

Так это выглядит на экране: «Анна» в рамке набрал пользователь, остальное напечатала программа. Подсказка `input` стоит на той же строке, что и набранный текст, а Enter (↵) переводит строку.

Введённое `25` будет строкой `"25"`. Python не может знать, является это возрастом, кодом товара или частью телефонного номера. Поэтому решение о преобразовании принимает автор программы.

```python
age_text = input()
age = int(age_text)
print(age + 1)
```

```console
⟪25⟫
26
```

Сокращённая запись `age = int(input())` означает те же этапы: сначала внутренний вызов `input`, затем преобразование его результата с помощью `int`. Без `int` выражение `age_text + 1` остановилось бы с `TypeError`: строку нельзя сложить с числом.

**Преобразование возможно, только если текст записывает число в ожидаемом формате.**

```python
print(int("-12"))
print(float("2.75"))
print(str(123))
```

```output
-12
2.75
123
```

Последнее 123 — уже текст: `str` превращает число в строку. А вот целое число из записи с точкой не получится:

```python
print(int("2.75"))
```

```error
ValueError: invalid literal for int() with base 10: '2.75'
```

`ValueError` означает, что тип подходит, а конкретное значение — нет: строка не записывает целое число в ожидаемом формате. `int(2.75)` допустимо и даёт 2 — здесь исходное значение уже является числом. `float("2,75")` тоже не подходит: десятичный разделитель Python — точка. Если формат входа специально использует запятую, её заменяют осознанно после знакомства со строковыми методами.

Преобразование не исправляет смысл само. Например, индекс предмета `"007"` после `int` превратится в 7. Если ведущие нули значимы, оставь текст.

---

**`print` выводит несколько значений через разделитель и заканчивает переводом строки.**

```python
print(10, 20, 30)
print(10, 20, 30, sep="; ")
print("Начало", end=" ")
print("продолжение")
```

```output
10 20 30
10; 20; 30
Начало продолжение
```

Обычные аргументы — значения для вывода. `sep=` задаёт разделитель между ними, `end=` — окончание вывода. Такая запись передаёт аргумент по имени. По умолчанию разделитель — пробел, окончание — перевод строки. Поэтому третий и четвёртый вызовы дали одну строку.

**f-строка подставляет вычисленные значения прямо в текст.**

```python
count = 7
price = 12.5
print(f"Количество: {count}; стоимость: {count * price:.2f}")
```

```output
Количество: 7; стоимость: 87.50
```

Буква `f` перед кавычками включает подстановку выражений из фигурных скобок. `count * price` вычисляется обычным образом. Часть `:.2f` задаёт формат вывода: две цифры после десятичной точки. Она меняет представление при выводе, а не превращает исходное число в точное десятичное.

При автоматической проверке задач обычно выводят только требуемые значения. Подсказки внутри `input("Введите...")` удобны человеку, но становятся лишним текстом для проверяющей системы.

---

**Сквозной пример: площадь и периметр прямоугольника по вводу.** Длина и ширина вводятся на двух отдельных строках, поэтому нужны два вызова `input`. Сначала решим для дробных значений:

```python
length = float(input())
width = float(input())
area = length * width
perimeter = 2 * (length + width)
print(area, perimeter)
```

```console
⟪5⟫
⟪3⟫
15.0 16.0
```

Даже целые 5 и 3 после `float` стали дробными, поэтому ответ напечатан как 15.0 и 16.0. Если по условию данные целые и нужен точный целочисленный результат, замени `float` на `int`: тогда вывод будет 15 16.

---

**Итого.**

- `input()` возвращает строку без перевода строки; число получают через `int` или `float`.
- Неверный формат даёт `ValueError`: `int("2.75")`, `float("2,75")`.
- `print` разделяет значения `sep` и заканчивает `end`; по умолчанию пробел и перевод строки.
- f-строка подставляет выражения в `{}`; `:.2f` — две цифры после точки.
- Для автоматической проверки выводят только требуемые значения, без подсказок.

**Ответы для проверки:**
