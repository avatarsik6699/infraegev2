Главная идея урока: **целое деление `//` и остаток `%` вместе описывают одно равенство `a = (a // b) * b + a % b`**. Из него следуют проверка делимости, последняя цифра числа и разложение секунд на часы и минуты. Опора — урок о значениях: здесь те же `int` и `float`, но с операциями над ними.

Сквозной пример урока — число 23 и делитель 5: в 23 содержатся четыре полные пятёрки и ещё 3.

---

**В Python семь основных арифметических операций.** Три из них работают как в математике: сложение `+`, вычитание `-` и умножение `*`. Новое — три вида деления и степень `**`: `2 ** 5` — это 2⁵ = 32.

Обычное деление `/` всегда даёт дробное число, даже если делится нацело: `8 / 2` — это `4.0`, а не `4`.

Для целых `a` и `b` с ненулевым `b` выполняется:

`a = (a // b) * b + a % b`.

Это объясняет одновременно частное и остаток. Разделим 23 на 5 тремя способами:

```python
print(23 / 5)
print(23 // 5)
print(23 % 5)
print(23 // 5 * 5 + 23 % 5)
```

```output
4.6
4
3
23
```

`/` даёт точное частное 4.6, `//` — сколько в 23 полных пятёрок, то есть 4, а `%` — сколько осталось сверх них, то есть 3. Последняя строка собирает 23 обратно из частного и остатка.

%%remainder_widget(23, 5, [[23, 5], [30, 6], [7, 9]])%%

Проверь равенство на своих числах: при 30 и 6 остатка нет — 30 делится на 6, а при 7 и 9 нет ни одной полной порции: 7 // 9 = 0, 7 % 9 = 7.

Умножение записывается явно: `2 * x`, а не `2x`. Степень обозначается `**`, а не `^`. Знак `^` имеет другое назначение, которое будет объяснено в уроке о битах.

---

**«Отбросить дробную часть» и «округлить вниз» — разные действия.** Для положительных чисел они совпадают, поэтому разницу видно только на отрицательных:

```python
print(-7 / 3)
print(-7 // 3)
print(-7 % 3)
print(int(-7 / 3))
```

```output
-2.3333333333333335
-3
2
-2
```

Вниз означает к меньшему числу: среди целых, не превышающих −2.333…, наибольшее — −3. Остаток согласован с частным: `-7 = (-3) * 3 + 2`. При положительном делителе остаток неотрицателен и меньше делителя. В общем случае ненулевой остаток имеет знак делителя.

<figure class="plate-figure">
%%floor_line()%%
<figcaption><code>//</code> всегда идёт влево по числовой прямой, к меньшему целому. <code>int()</code> идёт к нулю. Для 4.6 это одно и то же направление, а для −2.33 — противоположные.</figcaption>
</figure>

`int` для конечного дробного числа отбрасывает дробную часть по направлению к нулю. Поэтому заменять `//` на `int(a / b)` нельзя: мешают и отрицательные значения, и потеря точности при переходе больших целых во `float`.

---

**Порядок операций такой же, как в математике, но степень группируется справа.** Сначала выполняются выражения в скобках, затем степени, умножение и деления, затем сложение и вычитание. Операции одной обычной арифметической ступени выполняются слева направо. Для степеней есть особенность: цепочка группируется справа.

```python
print(2 + 3 * 4)
print((2 + 3) * 4)
print(2 ** 3 ** 2)
print(-3 ** 2)
print((-3) ** 2)
```

```output
14
20
512
-9
9
```

`2 ** 3 ** 2` — это `2 ** (3 ** 2)`, то есть 2⁹ = 512. `-3 ** 2` — это `-(3 ** 2)`: минус применяется после степени.

Порядок удобно видеть деревом: каждая операция ждёт значения своих веток, поэтому нижние операции выполняются первыми.

<figcaption>В <code>2 + 3 * 4</code> умножение стоит ниже сложения и выполняется первым. В цепочке степеней ниже оказывается правая часть, а минус в <code>-3 ** 2</code> стоит над степенью и применяется к готовому 9.</figcaption>

Не превращай знание приоритетов в соревнование. Скобки полезны, если по ним сразу понятен математический смысл.

---

**Целые числа точные, а дробные — приближённые.** Python умеет работать с целыми намного больше привычных 32- или 64-битных диапазонов: например, `2 ** 200` остаётся точным целым. Ограничения задаются ресурсами компьютера, а операции с огромными числами занимают больше времени. «Целое произвольной точности» не означает «вычисления любой величины бесплатны».

`float` хранит приближение числа в двоичной форме. Так же как десятичная запись 1/3 бесконечна, некоторые короткие десятичные дроби не имеют конечной двоичной записи.

```python
print(0.1 + 0.2 == 0.3)
print(0.1 + 0.2)
```

```output
False
0.30000000000000004
```

`==` здесь проверяет равенство и отвечает `True` или `False`; подробно сравнения разберём в уроке о логических выражениях. Это свойство выбранного представления, а не случайная поломка Python. Для проверки целочисленной делимости используй `%`, не дробное деление. Если задача по смыслу целочисленная, сохраняй целые как можно дольше.

Для сравнения результатов приближённых вычислений подходит `math.isclose` — он появится в уроке о стандартной библиотеке. Допуск зависит от масштаба и смысла задачи, его нельзя выбирать механически.

---

**Модуль, минимум, максимум и округление — готовые действия.**

```python
print(abs(-12))
print(min(5, 2, 9))
print(max(5, 2, 9))
print(round(2.5))
print(round(3.5))
```

```output
12
2
9
2
4
```

`abs` даёт модуль числа, `min` и `max` — наименьшее и наибольшее из переданных значений. `round` округляет до ближайшего; при точном равенстве расстояний используется ближайшее чётное. Поэтому 2.5 превратилось в 2, а 3.5 — в 4.

<details class="proof" markdown="1">
<summary>Тонкости: округление дробных</summary>

Из-за представления `float` некоторые десятичные «половинки» внутри компьютера не точные половинки: поэтому `round(2.675, 2)` даёт `2.67`. Для денежных сумм часто подходят целые копейки или `Decimal` из стандартной библиотеки.

</details>

---

**Делимость и цифры числа — это остатки.** Условие «`n` делится на `d`» означает нулевой остаток: `n % d` равно 0. Нельзя делить на ноль. Чётность проверяется остатком от деления на 2, в том числе для отрицательных целых.

Если `n` — неотрицательное целое, то `n % 10` — последняя десятичная цифра, а `n // 10` — число без неё. Почему? Любое такое число представимо как `10 * q + r`, где `r` — от 0 до 9. Эти `q` и `r` и вычисляют две операции. Например, 472 = 10 · 47 + 2.

```python
n = 472
print(n % 10)
print(n // 10)
print(n // 10 % 10)
```

```output
2
47
7
```

Третья строка сначала отбрасывает последнюю цифру, а затем берёт последнюю цифру того, что осталось, — получается вторая цифра справа. Для цифр отрицательного числа обычно сначала берут `abs(n)`: знак не является цифрой.

<figure class="plate-figure">
%%place_value("472")%%
<figcaption>Каждая цифра записи весит своё: 472 = 4 · 100 + 7 · 10 + 2 · 1. <code>n % 10</code> берёт цифру с весом 1, а <code>n // 10</code> сдвигает остальные на разряд вправо: 47 = 4 · 10 + 7.</figcaption>
</figure>

Те же две операции раскладывают время. В 3671 секунде содержится 1 полный час (3600 секунд), в остатке 71 секунда, из них 1 полная минута и 11 секунд:

```python
seconds = 3671
hours = seconds // 3600
minutes = seconds % 3600 // 60
remaining_seconds = seconds % 60
print(hours, minutes, remaining_seconds)
```

```output
1 1 11
```

<figure class="plate-figure">
%%time_split(3671)%%
<figcaption>Каждая операция отделяет свою часть: <code>// 3600</code> — полные часы, <code>% 3600 // 60</code> — полные минуты из того, что осталось после часов, <code>% 60</code> — секунды сверх полных минут.</figcaption>
</figure>

`print` с несколькими значениями через запятую печатает их через пробел; подробнее — в следующем уроке. Остаток от деления на 3600 удаляет полные часы. Деление оставшегося количества на 60 выделяет полные минуты. Для неотрицательной длительности это именно требуемое разложение.

---

**Итого.**

- `//` — частное с округлением вниз, `%` — остаток; вместе `a = (a // b) * b + a % b`.
- `//` округляет вниз, `int(a / b)` — к нулю: при отрицательном частном не нацело ответы расходятся; остаток при положительном делителе неотрицателен.
- Степень `**` группируется справа, а `-3 ** 2` равно −9.
- Целые точные, `float` приближённые: `0.1 + 0.2` не равно `0.3`.
- `n % 10` — последняя цифра, `n // 10` — число без неё; делимость — нулевой остаток.
