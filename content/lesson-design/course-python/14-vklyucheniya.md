Главная идея урока: **списковое включение — короткая запись уже понятного цикла с `append`, а `sum`, `min`, `max`, `all` и `any` заменяют типовые циклы-накопители**. Опора — цикл с `append` из урока о списках и накопители из урока о `while`: здесь у них появляется короткая запись.

Сквозной пример урока — квадраты чисел от 1 до 5 и строка `"10 -2 7"`, которую превратим в список чисел.

---

**Включение записывает правило построения списка, которое раньше давал цикл.** Построим квадраты чисел:

```python
squares = []
for n in range(1, 6):
    squares.append(n * n)
print(squares)
```

```output
[1, 4, 9, 16, 25]
```

Тот же смысл можно выразить **списковым включением** — записью правила построения списка:

```python
squares = [n * n for n in range(1, 6)]
print(squares)
```

```output
[1, 4, 9, 16, 25]
```

Читай по смыслу: «для каждого `n` из диапазона взять `n * n`». Хотя выражение результата стоит слева, значение `n` появляется из части `for`.

**`if` после источника отбирает элементы, а условное выражение перед `for` выбирает значение.**

```python
even_squares = [n * n for n in range(1, 8) if n % 2 == 0]
print(even_squares)
```

```output
[4, 16, 36]
```

`if` после источника — фильтр: неподходящий элемент вовсе не попадает в результат. Условное выражение перед `for` решает другую задачу:

```python
a = [-3, 0, 5]
labels = ["plus" if x > 0 else "other" for x in a]
print(labels)
```

```output
['other', 'other', 'plus']
```

Здесь результат имеет столько же элементов, сколько исходный список. Меняется выбираемое значение, а не число элементов.

---

**Несколько `for` во включении идут в том же порядке, что вложенные циклы.**

```python
pairs = [(x, y) for x in range(2) for y in range(3)]
print(pairs)
```

```output
[(0, 0), (0, 1), (0, 2), (1, 0), (1, 1), (1, 2)]
```

Части `for` идут в том же порядке, что обычные вложенные циклы. Внешний — по `x`, внутренний — по `y`. Не используй чрезмерно длинные включения: если пояснение становится труднее исходного цикла, лучше оставить цикл.

Независимые строки таблицы теперь можно создавать так:

```python
table = [[0] * 3 for _ in range(2)]
table[0][0] = 9
print(table)
```

```output
[[9, 0, 0], [0, 0, 0]]
```

Каждое повторение вычисляет `[0] * 3` заново, поэтому строки не связаны — в отличие от `[[0] * 3] * 2` из урока о списках. Имя `_` — обычная переменная, которой по соглашению обозначают ненужное значение.

---

**Бывают включения для множеств и словарей, а частые циклы заменяют готовые функции.**

```python
unique_lengths = {len(word) for word in ["кот", "дом", "окно"]}
squares_by_number = {n: n * n for n in range(4)}
print(unique_lengths)
print(squares_by_number)
```

```output
{3, 4}
{0: 0, 1: 1, 2: 4, 3: 9}
```

Фигурные скобки с одним выражением дают множество, с парой `ключ: значение` — словарь.

`sum(a)` складывает элементы, `min(a)` и `max(a)` находят крайние значения. `sum([])` равно 0, но `min([])` и `max([])` без значения по умолчанию вызывают ошибку: у пустого набора нет минимума или максимума.

```python
print(sum([]))
print(min([]))
```

```output
0
```

```error
ValueError: min() iterable argument is empty
```

`all(...)` проверяет, что все элементы истинны, `any(...)` — что истинен хотя бы один. Они останавливаются, когда ответ уже известен. Для пустого источника `all` возвращает `True`, а `any` — `False`: нет ни одного нарушения первого требования и ни одного подтверждения второго.

```python
numbers = [2, 4, 8]
print(all([x % 2 == 0 for x in numbers]))
print(any([x < 0 for x in numbers]))
```

```output
True
False
```

Позднее уберём создание промежуточного списка с помощью генераторного выражения. На этом этапе явный список помогает увидеть логические значения, которые получает функция: `[True, True, True]` и `[False, False, False]`.

---

**Числа из строки собирает одно включение.** Преобразуем строку `"10 -2 7"` в список целых одной понятной записью:

```python
line = "10 -2 7"
numbers = [int(part) for part in line.split()]
print(numbers)
print(sum(numbers), min(numbers), max(numbers))
```

```output
[10, -2, 7]
15 -2 10
```

В этой строке нет новой магии: `split` создаёт части, цикл перебирает их, `int` преобразует каждую, включение собирает список.

Сквозная задача курса — сумма и наибольшее из 5, −2, 10, 7 — теперь записывается одной строкой: `print(sum(numbers), max(numbers))` для `numbers = [5, -2, 10, 7]` выводит `20 10`. Внутри `sum` и `max` — тот же накопитель и тот же поиск лучшего, что мы писали руками в уроках о `while` и списках.

---

**Модуль целиком: пять видов данных и одна запись для их построения.** Строки и коллекции различаются тем, что они хранят и что с ними можно делать, а включение строит любую из изменяемых коллекций одной записью:

| Тип | Что хранит | Изменяется | Доступ | Построение включением |
| --- | --- | --- | --- | --- |
| `str` | Символы по порядку | Нет | По индексу и срезу | — |
| `list` | Значения по порядку, с повторами | Да | По индексу и срезу | `[x * x for x in a]` |
| `tuple` | Короткую запись | Нет | По индексу, распаковкой | — |
| `dict` | Пары «ключ — значение» | Да | По ключу | `{x: x * x for x in a}` |
| `set` | Различные значения | Да | Только проверкой `in` | `{x % 10 for x in a}` |

Все пять — перебираемые объекты: по каждому ходит `for`, к каждому применимы `len`, `in`, `sum`, `min`, `max`. Выбор между ними — по нужным действиям, как в уроке о множествах.

---

**Итого.**

- `[выражение for x in источник]` — тот же цикл с `append`, записанный правилом.
- `if` в конце отбирает элементы; `a if c else b` в начале выбирает значение.
- Несколько `for` — вложенные циклы в том же порядке.
- `{x for …}` — множество, `{k: v for …}` — словарь.
- `sum` пустого — 0, `min`/`max` пустого — ошибка; `all` пустого — `True`, `any` пустого — `False`.
