**Стандартная библиотека даёт готовые инструменты для частых задач — подсчёта, очереди, точных дробей и перебора комбинаций; пользоваться ими можно, когда понятно, что они делают внутри**. Опора — модули и словари: каждое средство урока делает то, что ты уже умеешь писать сам, только короче и надёжнее.

Инструменты покажем на слове `"BANANA"` для `Counter` и буквах `"ABC"` для перебора слов.

---

**Каждый инструмент библиотеки опирается на уже знакомую идею.** Для подсчёта и хранения есть `collections`: `Counter` — словарь частот, `defaultdict` — словарь, который сам создаёт значение для нового ключа, `deque` — очередь с быстрыми концами. Куча `heapq` даёт быстрый доступ к наименьшему элементу; её разбирает тема ЕГЭ, где она нужна. Для перебора — `itertools`, для запоминания результатов — `functools.cache`. Точные вычисления дают `math`, `decimal` и `fractions`, работу с файлами и текстом — `pathlib`, `csv`, `json`, `re` и `fnmatch`.

Перед каждым средством стоит один вопрос: что оно делает внутри и какие условия нужны, чтобы ответ был верным. `cache` требует, чтобы аргументы полностью определяли результат, а `itertools` — понимания, сколько вариантов получится.

---

**`Counter` — готовый словарь частот, `defaultdict` сам создаёт значение для нового ключа.**

```python
from collections import Counter, defaultdict

counts = Counter("BANANA")
print(counts["A"])
print(counts["Z"])
print(counts.most_common(2))

groups = defaultdict(list)
groups["python"].append("Анна")
print(groups["python"])
```

```output
3
0
[('A', 3), ('N', 2)]
['Анна']
```

`Counter` делает то же, что цикл `counts[x] = counts.get(x, 0) + 1` из урока о словарях, и для отсутствующего ключа возвращает 0 без ошибки. `most_common(k)` даёт `k` самых частых пар. `defaultdict(list)` получает функцию `list` без вызова: при новом ключе она создаёт новый список.

---

**`deque` — очередь: добавляют в конец, забирают из начала быстро.** У списка `pop(0)` сдвигает все остальные элементы, а `deque` забирает первый элемент сразу:

```python
from collections import deque

queue = deque([1, 2, 3])
queue.append(4)
first = queue.popleft()
print(first, list(queue))
```

```output
1 [2, 3, 4]
```

`append` добавляет справа, `popleft` удаляет и возвращает элемент слева. **Очередь** работает по правилу «первым пришёл, первым вышел» — так обслуживают заявки по порядку поступления.

---

**`Fraction` и `Decimal` считают точно там, где `float` ошибается.**

```python
from fractions import Fraction
from decimal import Decimal
from math import isclose

print(Fraction(1, 3) + Fraction(1, 6))
print(Decimal("0.1") + Decimal("0.2"))
print(isclose(0.1 + 0.2, 0.3))
```

```output
1/2
0.3
True
```

`Fraction` хранит числитель и знаменатель, поэтому 1/3 + 1/6 даёт ровно 1/2. Для Decimal использованы строки: `Decimal(0.1)` перенёс бы уже имеющееся двоичное приближение. Decimal тоже имеет настраиваемую точность вычислений; деление 1 на 3 не превращается в конечную точную десятичную дробь.

`isclose(a, b)` сравнивает разность с допусками. Около нуля часто нужен явно выбранный `abs_tol`: например, `isclose(value, 0.0, abs_tol=1e-9)`, если именно такая абсолютная погрешность допустима по смыслу измерений. Запись `1e-9` означает 10 в степени −9.

---

**`product` перебирает все слова заданной длины, и перебор надёжен, только если набор полный.** **Полный перебор** рассматривает все допустимые варианты и проверяет нужное свойство. Он надёжен, если набор действительно полный, проверка верна и число вариантов посильно. Перед кодом ответь: из чего состоит один вариант, как его породить без пропусков и сколько вариантов получится.

`itertools.product` создаёт все комбинации выбора по позициям, разрешая повторения:

```python
from itertools import product

count = 0
for letters in product("ABC", repeat=3):
    word = "".join(letters)
    if word.count("A") == 1:
        count += 1
print(count)
```

```output
12
```

`product` выдаёт кортежи букв, например `('A', 'B', 'C')`; `"".join` склеивает их в слово. На каждой позиции три выбора, всего `3 ** 3 = 27` слов. Подходящих 12: выбрать одну из трёх позиций A, затем по два варианта для двух оставшихся. Это независимая ручная проверка программы.

---

**Перестановки, сочетания и слова различаются тем, важен ли порядок и можно ли повторять.** `product` строит слова, `permutations` — расстановки разных предметов, `combinations` — выбор группы, `combinations_with_replacement` — выбор с повторениями без порядка. Разницу видно на парах из букв A, B, C:

<figure class="plate-figure">

<figcaption><code>product</code> берёт все 9 клеток. <code>permutations</code> убирает диагональ — повтор буквы. <code>combinations</code> оставляет одну пару из AB и BA — порядок не важен. С <code>_with_replacement</code> диагональ возвращается.</figcaption>

```python
from itertools import combinations, permutations, product

items = "ABC"
print(len(list(product(items, repeat=2))))
print(len(list(permutations(items, 2))))
print(len(list(combinations(items, 2))))
print(["".join(p) for p in combinations(items, 2)])
```

```output
9
6
3
['AB', 'AC', 'BC']
```

Числа получаются выбором по позициям: 3 · 3 = 9; 3 · 2 = 6 — вторая буква не может повторить первую; 6 / 2 = 3 — пары AB и BA становятся одной группой.

Функции считают различными позиции исходного источника. Если в нём одинаковые символы, текстовые результаты перестановок могут повторяться. `set(permutations(...))` устраняет дубликаты, но сначала может потребовать огромного перебора и памяти.

Если данные образуют запись числа, первый разряд обычно не ноль. Ограничение на первую цифру нужно добавить отдельно. Не сохраняй все варианты в `list`, если достаточно обрабатывать их по одному.

---

**Итого.**

- `Counter` считает частоты, `most_common` даёт самые частые; `defaultdict` создаёт значение для нового ключа.
- `deque`: `append` в конец, `popleft` из начала — очередь.
- `Fraction` точна для дробей, `Decimal` создают из строк, `isclose` сравнивает приближённые числа.
- `product` — слова с повторами, `permutations` — порядок без повторов, `combinations` — группы.
- Перед перебором считают число вариантов и проверяют полноту набора.
