Главная идея урока: **файл — это внешние данные со своим форматом, и программа читает их по этому формату: целиком или по строкам, с заголовком или без**. Опора — `for` по источнику, `split` и `int` для разбора строк, `None` как «ответа нет»: файл — ещё один источник строк для того же цикла.

Сквозной пример урока — файл `numbers.txt` с одним целым числом на строке:

```numbers.txt
5
-2
10
7
```

Найдём сумму, количество, отрицательный максимум и разберём, что меняется, если у файла есть заголовок.

---

**Чтобы прочитать файл, программа открывает его по пути и в кодировке.** Переменные обычного запуска исчезают после завершения процесса. **Файл** сохраняет байты на носителе. Чтобы прочитать текст, программа должна знать путь к файлу и способ преобразовать байты в символы — **кодировку**.

**Путь** указывает расположение файла. Абсолютный путь задаётся от корня файловой системы. Относительный отсчитывается от текущей рабочей папки процесса. Она может не совпадать с папкой исходного `.py`-файла, особенно в IDE.

```python
with open("numbers.txt", "r", encoding="utf-8") as file:
    text = file.read()
print(repr(text))
```

```output
'5\n-2\n10\n7\n'
```

Этот пример требует существующего `numbers.txt`. `open` открывает файл. `"r"` означает чтение. `with` организует работу с ресурсом так, чтобы файл закрылся при выходе из блока, в том числе при обычной ошибке внутри. `as file` даёт имя открытому объекту. `read()` вернул весь текст одной строкой — `repr` показывает в ней переводы строк `\n`.

Если файла нет по указанному пути, программа остановится:

```python
with open("missing.txt", encoding="utf-8") as file:
    print(file.read())
```

```error
FileNotFoundError: [Errno 2] No such file or directory: 'missing.txt'
```

У открытого файла есть **позиция** — место, с которого начнётся следующее чтение. Каждое чтение сдвигает её вперёд. Если вызвать `file.read()` второй раз, получится пустая строка: всё уже прочитано. Можно открыть файл заново либо вернуть позицию к началу: `file.seek(0)`.

---

**Небольшой файл читают целиком, большой — построчно.** Если файл небольшой и содержит целые числа, разделённые пробельными символами:

```python
with open("numbers.txt", encoding="utf-8") as file:
    numbers = [int(part) for part in file.read().split()]
print(sum(numbers))
```

```output
20
```

`read()` загружает весь текст в память. Если файл большой и одна строка содержит одно число, можно обрабатывать постепенно:

```python
total = 0
count = 0
with open("numbers.txt", encoding="utf-8") as file:
    for line in file:
        number = int(line)
        total += number
        count += 1
print(count, total)
```

```output
4 20
```

Цикл `for line in file` выдаёт строки файла по одной, вместе с переводом строки в конце. `int` допускает окружающие пробельные символы, включая перевод строки, поэтому `.strip()` здесь не требуется. Пустая строка вызовет ошибку — и это полезно, если формат обещал число на каждой строке. Пропускать пустые или повреждённые данные следует только при явно выбранном правиле.

В `numbers.txt` лежат те же 5, −2, 10, 7 из сквозной задачи курса. Цикл по файлу устроен так же, как цикл по списку в уроке о списках, — меняется только источник строк.

Для задач обработки текста не удаляй все пробелы через `.strip()` автоматически: крайние пробелы могут быть частью данных. Если нужно снять только окончание строки, подходит `.rstrip("\r\n")`.

---

**Заголовок файла — часть формата, а не очередное значение.** Файл может начинаться количеством записей или настройками. Нельзя автоматически считать каждое число полезным измерением. Пусть в файле `header.txt` первая строка — количество чисел:

```header.txt
3
4
-1
6
```

```python
with open("header.txt", encoding="utf-8") as file:
    expected_count = int(file.readline())
    numbers = [int(line) for line in file]

if len(numbers) != expected_count:
    print("Количество записей не совпадает с заголовком")
else:
    print(sum(numbers))
```

```output
9
```

`readline()` читает одну строку, дальнейший обход продолжает с текущей позиции. Поэтому 3 не попало в сумму: 4 − 1 + 6 = 9. Пройди это чтение по шагам — стрелка показывает позицию:

Если первая строка содержит сразу два числа, сначала разбей её через `split`, затем преобразуй и распакуй:

```python
header = "100 2500"
count, capacity = [int(part) for part in header.split()]
print(count, capacity)
```

```output
100 2500
```

Реальный формат диктует условие. Иногда заголовка нет вообще. Самая частая ошибка работы с файлами — правильно написать цикл для неверно понятой структуры входа.

---

**Режим открытия решает, читать, перезаписать или дописать файл.** `r` — читать существующий файл, это режим по умолчанию. `w` — писать заново: файл создаётся, а если он был, его содержимое сразу стирается. `a` — дописывать в конец, не трогая прежнее. `x` — создать новый файл и остановиться с ошибкой, если такой уже есть. Буква `b` добавляется к режиму для работы с байтами, например `rb`.

```python
with open("result.txt", "w", encoding="utf-8") as file:
    file.write("Готово\n")
    file.write(str(42) + "\n")
```

`write` принимает строку и сам не добавляет перевод строки. Другой способ — `print(42, file=file)`. Не открывай входной файл в режиме `w`: он будет очищен ещё до записи новых данных.

---

**`pathlib` строит пути предсказуемо.** Модуль `pathlib` подключается так же, как `math` в уроке о модулях: `from pathlib import Path` делает доступным готовое средство работы с путями.

```python
from pathlib import Path

path = Path("data") / "numbers.txt"
print(path.resolve())
```

Знак `/` между объектом `Path` и строкой соединяет части пути; он не выполняет арифметическое деление. `resolve()` помогает увидеть абсолютное расположение — у каждого компьютера оно своё, поэтому вывод здесь не показан.

<details class="proof" markdown="1">
<summary>Тонкости: путь рядом со скриптом</summary>

В обычном скрипте путь рядом с ним можно построить как `Path(__file__).resolve().parent / "numbers.txt"`. Специальное имя `__file__` задаётся для файла модуля; в интерактивной оболочке или ноутбуке его может не быть.

</details>

**Для таблиц и вложенных записей есть готовые форматы CSV и JSON.** **CSV** — текстовая таблица, где записи занимают строки, а поля разделяются заданным разделителем. Некоторые поля содержат кавычки, разделители и даже переводы строк. Поэтому простое `split(",")` не является универсальным чтением CSV. В стандартной библиотеке есть модуль `csv`:

```students.csv
name;score
Анна;91
Илья;84
Марк;88
```

```python
import csv

with open("students.csv", encoding="utf-8", newline="") as file:
    reader = csv.DictReader(file, delimiter=";")
    for row in reader:
        print(row["name"], int(row["score"]))
```

```output
Анна 91
Илья 84
Марк 88
```

Первая строка файла — заголовок `name;score`. `DictReader` сопоставляет имена столбцов со строковыми значениями: каждая `row` — словарь. Параметр `newline=""` передаёт обработку переводов строк CSV-модулю.

**JSON** — формат записи вложенных объектов из словарей, списков, строк, чисел и нескольких специальных значений. В JSON нет произвольных объектов Python; например, множества напрямую не сохраняются.

```python
import json

data = {"name": "Анна", "scores": [91, 84]}
text = json.dumps(data, ensure_ascii=False, indent=2)
restored = json.loads(text)
print(restored == data)
```

```output
True
```

`dumps` создаёт текст, `loads` разбирает текст. `dump` и `load` работают с файловым объектом. У JSON строковые ключи; JSON-массив восстанавливается как список, даже если перед сохранением использовался кортеж. `ensure_ascii=False` сохраняет читаемую кириллицу, `indent=2` добавляет отступы.

---

**Отсутствие подходящего элемента обозначают `None`.** Найдём максимальное отрицательное число файла или сообщим, что отрицательных нет:

```python
best = None
with open("numbers.txt", encoding="utf-8") as file:
    for line in file:
        value = int(line)
        if value < 0 and (best is None or value > best):
            best = value

if best is None:
    print("Отрицательных чисел нет")
else:
    print(best)
```

```output
-2
```

`None` явно обозначает отсутствие подходящего элемента. Короткое вычисление `or` не допускает сравнения числа с `None`: при `best is None` правая часть не вычисляется. При пустом файле программа также даёт осмысленный результат.

---

**Итого.**

- `with open(путь, encoding="utf-8") as file:` открывает файл и закрывает его после блока.
- `read()` — весь текст сразу, `for line in file` — по строке, `readline()` — одна строка.
- Заголовок читают отдельно; остальные строки — данные.
- `w` очищает файл, `a` дописывает; `write` не добавляет перевод строки.
- CSV читают модулем `csv`, вложенные записи сохраняют в JSON.
