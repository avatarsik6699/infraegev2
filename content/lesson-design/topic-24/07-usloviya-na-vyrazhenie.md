**Дополнительный урок — для продвинутых.** Он для тех, кто хочет закрыть все возможные случаи задания 24: здесь от выражения требуют больше, чем корректность, — не более K чисел, порядок действий слева направо или наибольшее значение суммы после буквы. На реальных экзаменах такие условия не встречались. Задачи основных подтем решаются без него.

**Дополнительное требование к выражению проверяют отдельно от его корректности: сначала находят корректные выражения, затем внутри них разбирают числа, знаки или значения.** Шаблон числа, шаблон выражения и `re.finditer` — из подтемы 6.

Сквозные примеры — короткие строки `1+2+345678`, `6*2-3*4-5` и `C12+5-30+7D3+4`: на каждой видно одно требование.

---

**Ограничение на количество чисел в выражении лучше переносить на последовательность самих чисел.**

Например:

> Найти самое длинное корректное выражение, содержащее не более двух чисел.

В строке `1+2+345678` лучший ответ — `2+345678`, длина 8. Если искать неперекрывающиеся выражения сразу с ограничением в два числа, можно получить сначала `1+2`, а затем `345678`, и пропустить лучший фрагмент.

Надёжный подход:

1. Найти длинные корректные выражения без ограничения на количество чисел.
2. Внутри каждого выписать границы чисел.
3. Рассмотреть окна из не более `K` последовательных чисел.

Для простоты возьмём числа из цифр `1–9`, операции `+` и `*`:

```python
import re

s = '1+2+345678'
K = 2    # K >= 1
best = 0

expression_pattern = r'[1-9]+(?:[+*][1-9]+)*'

for expression_match in re.finditer(expression_pattern, s):
    expression = expression_match.group()

    numbers = list(re.finditer(r'[1-9]+', expression))

    for j in range(len(numbers)):
        i = max(0, j - K + 1)

        length = numbers[j].end() - numbers[i].start()
        best = max(best, length)

print(best)
```

```output
8
```

`list(...)` собирает найденные совпадения в список, и к ним можно обращаться по номеру: `numbers[i].start()` — начало `i`-го числа. Для каждого правого числа `j` берём максимально раннее левое число, при котором их не больше `K`.

Почему невыгодно начинать посередине первого числа? Это уменьшит длину, но не уменьшит количество чисел. Почему невыгодно заканчивать посередине последнего? По той же причине.

Так задача о строке превращается в задачу о последовательности чисел с известными позициями — это окно из подтемы 4, только длина считается по символам, а ограничение — по числам.

**Дополнительные требования к выражениям нужно рассматривать отдельно от их обычной корректности.**

Например:

> Порядок действий слева направо совпадает с порядком по правилам математики.

Сравним `2*3+4` и `2+3*4`. В первом случае обычное движение слева направо соответствует приоритетам. Во втором сначала нужно выполнить умножение, которое находится правее сложения.

Для выражений с `+`, `-`, `*`, без скобок, это означает:

> После появления сложения или вычитания в выбранном фрагменте не должно быть умножения.

То есть сначала могут идти умножения, затем — сложения и вычитания. Можно работать с уже выделенными выражениями:

- пока условие соблюдается, продолжаем фрагмент;
- если встретилось умножение после сложения или вычитания, переносим начало к числу после последней такой операции.

Здесь проверяется именно **порядок операций**, а не случайное совпадение итоговых значений.

В программе `start` — начало текущего фрагмента внутри выражения, `last` — позиция последнего `+` или `-`. Умножение после такого знака внутри фрагмента переносит начало за этот знак; длина фрагмента, который заканчивается на символе `i`, — `i - start + 1`:

```python
import re

s = '6*2-3*4-5'
number = r'(?:0|[1-9][0-9]*)'
pattern = number + r'(?:[-+*]' + number + r')*'
best = 0

for match in re.finditer(pattern, s):
    text = match.group()
    start = 0
    last = -1
    for i in range(len(text)):
        if text[i] in '+-':
            last = i
        elif text[i] == '*' and last >= start:
            start = last + 1
        best = max(best, i - start + 1)

print(best)
```

```output
5
```

Подходят `6*2-3` и `3*4-5`; всё выражение не подходит — умножение `3*4` стоит после вычитания. Если числа записаны в другом основании, меняется только шаблон числа: для шестеричных — `(?:0|[1-5][0-5]*)`.

**Найти выражение с наибольшим значением — это не то же самое, что найти самое длинное.**

Например, среди выражений, начинающихся сразу после `B`, в строке `B20-300+4` самое длинное выражение имеет значение −276, а короткий допустимый фрагмент `20` имеет большее значение:

```python
print(20 - 300 + 4, 20)
```

```output
-276 20
```

Если разрешены только сложение и вычитание неотрицательных чисел, нужно учитывать результаты допустимых начальных частей выражения. Проверки только самого длинного совпадения недостаточно.

**Всегда разделяй:**

- корректность записи;
- длину записи;
- количество чисел или операций;
- значение выражения;
- правила выбора при равенстве.

**Для наибольшего значения суммы после буквы достаточно перебрать начальные части, которые заканчиваются целым числом.**

Учебное условие:

> Сумма — запись из одного или нескольких натуральных чисел (цифры 1–9), между соседними числами ровно один знак `+` или `-`. Найти наибольшее значение суммы, которая стоит сразу после буквы `C`.

Почему хватает начальных частей, оканчивающихся целым числом? Если последнее число стоит после `+`, обрезать его невыгодно: целое число больше любой своей начальной части. Если после `-` — выгоднее вовсе остановиться перед этим минусом: вычитать хоть что-то хуже, чем ничего. Поэтому кандидаты — накопленные суммы после каждого целого числа.

Шаблон `([-+]?)([1-9]+)` разбирает сумму на знак и число; `match.group(1)` и `match.group(2)` — текст первой и второй круглых скобок:

```python
import re

s = 'C12+5-30+7D3+4'
best = None

for match in re.finditer(r'C([1-9]+(?:[-+][1-9]+)*)', s):
    total = 0
    for term in re.finditer(r'([-+]?)([1-9]+)', match.group(1)):
        value = int(term.group(2))
        if term.group(1) == '-':
            total -= value
        else:
            total += value
        if best is None or total > best:
            best = total

print(best)
```

```output
17
```

Начальные части `12`, `12+5`, `12+5-30`, `12+5-30+7` дают 12, 17, −13, −6; наибольшее — 17. Сумма `3+4` стоит после `D` и не рассматривается.

Если же нужна **самая длинная** сумма после буквы, это просто самое длинное совпадение шаблона, а значение считают уже у неё. При равной длине выбирают по правилу условия — например, большее значение, как в подтеме 3.

---

**Итого.**

- Сначала — корректные выражения целиком (`re.finditer`), потом — дополнительное требование внутри каждого.
- «Не более `K` чисел» — окно по списку чисел выражения: от начала `i`-го до конца `j`-го, `i = max(0, j - K + 1)`.
- Порядок действий слева направо — умножение не стоит после `+` или `-` внутри фрагмента; начало переносится за последний такой знак.
- Значение и длина — разные критерии; наибольшее значение суммы — среди накопленных сумм после каждого целого числа.
