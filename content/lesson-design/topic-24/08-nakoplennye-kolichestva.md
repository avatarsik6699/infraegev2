**Четвёртый приём — заранее посчитать накопленные количества, чтобы быстро отвечать на вопросы об отдельных фрагментах.** Окно — из подтемы 4, список позиций с искусственными границами — из подтемы 5, просмотр совпадений `re.finditer` — из подтемы 6.

Начнём с короткой строки `BABA` и букв `A` в ней.

**Префиксные суммы отвечают на вопрос «сколько букв в фрагменте» одним вычитанием.**

Предположим, нужно много раз узнавать:

> Сколько букв `A` между позициями `left` и `right`?

Можно каждый раз писать `s[left:right + 1].count('A')`. Но это создаёт срез и повторно просматривает его. Вместо этого построим список `prefix`, где `prefix[i]` хранит количество `A` **среди первых `i` символов**. Начальный участок строки называется **префиксом**, отсюда название. Запись {{listrepeat|`[0] * (len(s) + 1)`}} создаёт список нужной длины, заполненный нулями.

```python
s = 'BABA'
prefix = [0] * (len(s) + 1)

for i in range(len(s)):
    prefix[i + 1] = prefix[i]

    if s[i] == 'A':
        prefix[i + 1] += 1

print(prefix)
print(prefix[4] - prefix[1])
```

```output
[0, 0, 1, 1, 2]
2
```

Количество `A` в окне с включёнными границами — `prefix[right + 1] - prefix[left]`. Почему? `prefix[right + 1]` учитывает всё до правого конца включительно, `prefix[left]` учитывает всё, что находится строго левее окна, а вычитание убирает лишнюю левую часть.

<figure class="plate-figure">

<figcaption>prefix[t] записан на черте после первых t символов: в окне с 1 по 3 букв A 2 − 0 = 2.</figcaption>
</figure>

Это называют **префиксными суммами**, хотя здесь мы суммируем количества символов.

**Совмещённые условия часто решаются сочетанием позиций и накопленных количеств.**

Рассмотрим учебную задачу:

> Найти самый длинный фрагмент, в котором ровно `K` букв `Y` и не менее `T` вхождений `ABA`.

Можно действовать так:

1. По позициям `Y` перебрать самые широкие окна с ровно `K` такими буквами.
2. Для каждого окна быстро проверить количество `ABA`.
3. Среди подходящих окон выбрать самое длинное.

Сначала накопим количество **начал** `ABA`: `prefix[t]` означает, сколько вхождений слова начинается на позициях, меньших `t`. Теперь важная граница. Чтобы слово длины `m` целиком лежало в окне от `left` до `right`, его начало должно находиться от `left` до `right - m + 1` включительно. Поэтому число вхождений внутри окна — `prefix[right - m + 2] - prefix[left]`, если длина окна хотя бы `m`.

```python
s = 'ABAYABABAYXYABA'
K = 2
T = 2

word = 'ABA'
m = len(word)
n = len(s)

prefix = [0] * (n + 1)

for i in range(n):
    prefix[i + 1] = prefix[i]

    if s[i:i + m] == word:
        prefix[i + 1] += 1

positions = [-1]

for i in range(n):
    if s[i] == 'Y':
        positions.append(i)

positions.append(n)

best = 0

for j in range(1, len(positions) - K):
    left = positions[j - 1] + 1
    right = positions[j + K] - 1

    count_word = 0

    if right - left + 1 >= m:
        count_word = prefix[right - m + 2] - prefix[left]

    if count_word >= T:
        best = max(best, right - left + 1)

print(best)
```

```output
11
```

Оба самых широких окна с двумя `Y` — `ABAYABABAYX` и `ABABAYXYABA` — содержат по три `ABA`, длина 11.

Почему достаточно самых широких окон с выбранными `Y`? Если в самом широком окне недостаточно вхождений `ABA`, то в его части их не станет больше. А если вхождений достаточно, самое широкое окно лучше по длине.

Здесь мы используем не просто сочетание двух шаблонов, а свойство условия «не менее»: расширение фрагмента не уменьшает количество уже имеющихся вхождений. Для условия «ровно `T` вхождений» такое упрощение уже не подходит.

**Если фрагмент обязан начинаться со слова, его левая граница — начало одного из вхождений.**

Учебная задача: фрагмент начинается со слова `2025`, содержит ровно `K` таких слов и не менее `T` букв `Y`; нужна наибольшая длина.

Начнём с вхождения номер `j`. Внутри должны целиком лежать вхождения `j`, …, `j + K − 1`, а вхождение `j + K` — нет: правая граница может дойти до его предпоследнего символа, `starts[j + K] + m - 2`. Искусственное вхождение `n - m + 1` в конце списка даёт правую границу `n - 1` — конец строки. Количество `Y` проверяем префиксными суммами.

```python
s = '2025YY2025AY2025Y'
word = '2025'
m = len(word)
K = 2
T = 2
n = len(s)

prefix_y = [0] * (n + 1)
for i in range(n):
    prefix_y[i + 1] = prefix_y[i]
    if s[i] == 'Y':
        prefix_y[i + 1] += 1

starts = []
for i in range(n - m + 1):
    if s[i:i + m] == word:
        starts.append(i)
starts.append(n - m + 1)

best = 0
for j in range(len(starts) - K):
    left = starts[j]
    right = starts[j + K] + m - 2
    if prefix_y[right + 1] - prefix_y[left] >= T:
        best = max(best, right - left + 1)

print(starts, best)
```

```output
[0, 6, 12, 14] 15
```

С первого вхождения фрагмент доходит до позиции 14 — до предпоследнего символа третьего `2025`, длина 15, в нём три `Y`. Со второго вхождения — до конца строки, длина 11.

**Не каждое условие позволяет сжимать окно по правилу «пока плохо».**

Например:

> Найти самый длинный фрагмент, в котором одинаковое количество `A` и `B`.

При добавлении символов условие может то выполняться, то нарушаться, то выполняться снова. На строке `AABB` префиксы `A`, `AA`, `AAB` не содержат поровну букв, а `AABB` — содержит. Если начать удалять символы сразу после нарушения равенства, можно потерять будущий ответ.

Здесь помогает **накопленная разность**: за `A` прибавляем `1`, за `B` вычитаем `1`. Эту разность удобно называть балансом. Если на двух границах баланс одинаков, значит между ними суммарное изменение равно нулю: количество A − количество B = 0. То есть количеств поровну.

Для строки только из `A` и `B` — запусти по шагам и следи за словарём `first`:

```python run balance.py
s = 'AABB'
balance = 0
first = {0: -1}
best = 0

for i in range(len(s)):
    if s[i] == 'A':
        balance += 1
    else:
        balance -= 1

    if balance in first:
        best = max(best, i - first[balance])
    else:
        first[balance] = i

print(best)
```

```output
4
```

Запись `first = {0: -1}` говорит:

> До начала строки, на условной позиции `-1`, баланс был равен нулю.

Для каждого баланса сохраняем самое раннее положение. Тогда при его повторении получаем самый длинный фрагмент. Это принцип первого появления из подтемы 3: при фиксированной правой границе выгодна самая ранняя левая.

Если в алфавите есть другие символы, нужно отдельно решить по условию, дают ли они нулевой вклад или разрывают допустимый фрагмент. В таком случае безусловный `else: balance -= 1` уже использовать нельзя.

**Если все символы фрагмента должны быть различными, полезно помнить последние позиции их появления.**

Здесь нельзя просто сравнивать соседние символы, как в подтеме 2. Будем хранить словарь `last`: `last[c]` — последний просмотренный индекс символа `c`. Если текущий символ уже встречался внутри окна, левую границу нужно перенести за его предыдущее появление:

```python
s = 'ABCDEBFGA'
left = 0
best = 0
last = {}

for right in range(len(s)):
    c = s[right]

    if c in last:
        left = max(left, last[c] + 1)

    last[c] = right

    best = max(best, right - left + 1)

print(best)
```

```output
7
```

Почему `max(left, last[c] + 1)`, а не просто `left = last[c] + 1`? Потому что предыдущее появление символа могло уже остаться левее окна. Здесь вторая `B` сдвинула левый край на позицию 2. У последней `A` предыдущее появление — позиция 0, левее окна. Нельзя вернуть `left` на позицию 1: тогда внутрь снова попадут две `B`. Левая граница должна двигаться только вперёд — лучший фрагмент `CDEBFGA`.

Тот же эффект на строке `ABBA`: после второй `B` левый край уже сдвинут на позицию 2, а у последней `A` предыдущее появление — позиция 0.

**Перекрывающиеся совпадения особенно важны, если подходящие фрагменты могут делить общую границу.**

Пусть дано `A12A345A`, и ищем фрагменты вида «`A`, затем цифры, затем `A`». Есть два: `A12A` и `A345A`. Они используют общую `A`. Обычный поиск первого совпадения займёт эту букву и может пропустить начало второго.

Для проверки совпадений без «занятия» найденного текста существует конструкция `(?=...)`. Она называется **просмотром вперёд**: проверяет, что с текущей позиции начинается нужная последовательность.

```python
import re

s = 'A12A345A'
best = 0

for match in re.finditer(r'(?=(A[0-9]+A))', s):
    fragment = match.group(1)
    print(fragment)
    best = max(best, len(fragment))

print(best)
```

```output
A12A
A345A
5
```

Обычные круглые скобки внутри сохраняют найденный фрагмент в группу номер `1`. Поэтому здесь используется `match.group(1)`. Сам внешний просмотр ничего не занимает, и поиск может проверить следующее начало.

Но этот приём не следует механически добавлять в любую задачу. Если с каждой позиции повторно просматриваются длинные одинаковые участки, программа может работать медленно. Для фиксированного короткого слова явный перебор позиций часто проще и понятнее.

**Если «число» определено как группа цифр между буквами, границы становятся частью условия.**

Например, в строке `A123B4C5D` группы цифр — `123`, `4`, `5`. Но если искомая подстрока должна сама содержать обе ограничивающие буквы, то для двух последних чисел нужен фрагмент `B4C5D` длины 5. Вырезать только `4C5` в такой постановке нельзя: у крайних чисел внутри фрагмента не будет обеих буквенных границ.

Порядок действий:

1. Найти все полные объекты «буква — цифры — буква».
2. Сохранить их начала и концы.
3. Для `K` последовательных объектов взять от начала первого до конца последнего.

Объекты могут делить общую букву, поэтому ищем их просмотром вперёд. Для заглавных латинских букв:

```python
import re

s = 'A123B4C5D'
starts = []
ends = []

for match in re.finditer(r'(?=([A-Z][0-9]+[A-Z]))', s):
    starts.append(match.start(1))
    ends.append(match.end(1) - 1)

K = 2
best = len(s) + 1

for j in range(len(starts) - K + 1):
    length = ends[j + K - 1] - starts[j] + 1
    best = min(best, length)

print(best)
```

```output
5
```

Указание `(1)` означает границы первой сохранённой группы. Это та же идея, что и для `K` вхождений слова в подтеме 5. Только теперь у объектов разная длина. «Слова» из букв между цифрами ищут так же — шаблоном `[0-9][A-Z]+[0-9]`.

Нужно внимательно читать определение и пример: иногда ограничивающие символы должны входить в искомую подстроку, иногда границы объектов определяются только в исходном файле.

---

**Итого.**

- `prefix[i]` — количество нужных символов среди первых `i`; в окне — `prefix[right + 1] - prefix[left]`, для слова — `prefix[right - m + 2] - prefix[left]`.
- Два условия сразу — самые широкие окна по позициям одного и быстрая проверка другого префиксами; так можно, когда второе условие «не менее».
- Равенство количеств — баланс и словарь первых появлений `first = {0: -1}`.
- Все символы различны — последние позиции и `left = max(left, last[c] + 1)`.
- Объекты с общими границами — просмотр вперёд `(?=(...))`, затем `K` подряд идущих объектов.
