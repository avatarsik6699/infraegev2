**Третий основной приём — хранить позиции только тех символов, которые влияют на условие.** Так решаются задачи о самом коротком фрагменте с K буквами или парами, о фрагментах с особыми началом и концом, о частях строки между разделителями и о блоке, где есть все символы набора.

Позиции разберём на той же строке `BABAACB`, что и окно в подтеме 4, — так видно, что оба приёма дают одни ответы. Перекрывающиеся вхождения слова — из подтемы 3.

---

**Список позиций нужных символов собирается одним проходом.**

Допустим, нас интересуют буквы `A`. Создадим {{list|список}} их индексов:

```python
s = 'BABAACB'
positions = []

for i in range(len(s)):
    if s[i] == 'A':
        positions.append(i)

print(positions)
```

```output
[1, 3, 4]
```

Теперь некоторые задачи удобнее решать по этому списку.

**Самый короткий фрагмент с `K` буквами начинается на одной из них и заканчивается на `K`-й по счёту.**

Пусть нужен самый короткий фрагмент с `K` буквами `A`, например с двумя. В `BABAACB` две соседние по списку `A` — это позиции 1 и 3 (фрагмент `ABA`, длина 3) или 3 и 4 (фрагмент `AA`, длина 2). В общем случае: если выбраны `K` последовательных вхождений с номерами `j`, `j + 1`, …, `j + K − 1`, то самый короткий охватывающий их фрагмент начинается на первой `A` и заканчивается на последней. Его длина — `positions[j + K - 1] - positions[j] + 1`.

```python
s = 'BABAACB'
positions = [1, 3, 4]
K = 2
best = len(s) + 1

for j in range(len(positions) - K + 1):
    length = positions[j + K - 1] - positions[j] + 1
    best = min(best, length)

if best == len(s) + 1:
    print('Подходящего фрагмента нет')
else:
    print(best)
```

```output
2
```

Здесь `K >= 1`. Почему достаточно последовательных вхождений? Если между выбранными `A` есть ещё одна `A`, она всё равно попадёт внутрь непрерывного фрагмента. Пропустить её нельзя.

---

**Для максимальной длины с ровно `K` буквами нужно растянуть границы до соседних лишних вхождений.**

В строке `BABAACB` возьмём две первые `A` — на позициях 1 и 3. Левее первой можно идти до начала строки, а правее второй — только до позиции 3: следующая `A` на позиции 4 уже лишняя. Получается `BABA`, длина 4. Для двух последних `A` (позиции 3 и 4) левее можно идти до позиции 2, правее — до конца строки: `BAACB`, длина 5.

В общем случае выбираем группу из `K` последовательных `A`: левее первой выбранной `A` можно идти до предыдущей `A`, не включая её; правее последней — до следующей `A`, не включая её.

Чтобы одинаково обрабатывать начало и конец строки, добавим две искусственные позиции: `-1` и `len(s)`. Это **не настоящие символы**, а удобные обозначения границ. Для нашего примера список становится `[-1, 1, 3, 4, 7]`.

Если первая выбранная `A` находится в `positions[j]`, то предыдущая лишняя `A` — `positions[j - 1]`, а следующая — `positions[j + K]`. Следовательно, `left = positions[j - 1] + 1`, `right = positions[j + K] - 1`, а длина right − left + 1 = positions[j + K] − positions[j − 1] − 1.

<figure class="plate-figure">
%%string_positions("BABAACB", "A", 2)%%
<figcaption>Пунктирные клетки −1 и 7 — искусственные границы: окно BABA упирается в начало строки, окно BAACB — в конец, а длина обоих считается одной формулой.</figcaption>
</figure>

```python
s = 'BABAACB'
positions = [-1]

for i in range(len(s)):
    if s[i] == 'A':
        positions.append(i)

positions.append(len(s))

K = 2
best = 0

for j in range(1, len(positions) - K):
    length = positions[j + K] - positions[j - 1] - 1
    best = max(best, length)

print(best)
```

```output
5
```

**Смысл искусственных границ стоит запомнить:**

> Они позволяют применить одну формулу и к середине строки, и к фрагментам, упирающимся в её края.

---

**Позиционный подход работает и для нескольких вхождений слова, в том числе перекрывающихся.**

Пусть ищем минимальный фрагмент с `K` вхождениями слова `ABA`. Сначала получаем позиции всех начал — перебором из подтемы 3. Если первое выбранное слово начинается на `positions[j]`, а последнее — на `positions[j + K - 1]`, его конец находится на `positions[j + K - 1] + m - 1`. Поэтому длина — `positions[j + K - 1] - positions[j] + m`.

```python
s = 'ABABABA'
word = 'ABA'
m = len(word)

positions = []
for i in range(len(s) - m + 1):
    if s[i:i + m] == word:
        positions.append(i)

K = 2
best = len(s) + 1
for j in range(len(positions) - K + 1):
    length = positions[j + K - 1] - positions[j] + m
    best = min(best, length)

print(positions, best)
```

```output
[0, 2, 4] 5
```

Самый короткий фрагмент с двумя вхождениями — `ABABA`, длина `5`. Почему не `6`? Потому что вхождения перекрываются. Для одного символа `m = 1`, и получается уже знакомая формула. Та же формула годится для пар вроде `TT`: самый короткий фрагмент, где пар не менее `K`, содержит их ровно `K`.

**Замены и разбиение строки удобны, когда они сохраняют смысл задачи.**

Пусть запрещена буква `X`. {{splitsep|`s.split('X')`}} разбивает строку по указанному разделителю, и самый длинный фрагмент без `X` — самая длинная часть:

```python
s = 'ABXXCDEFXGH'
parts = s.split('X')
print(parts)

best = 0
for part in parts:
    best = max(best, len(part))

print(best)
```

```output
['AB', '', 'CDEF', 'GH']
4
```

Пустые фрагменты возникают, например, между соседними разделителями. Здесь они не мешают.

Если запрещены `X` и `Y`, можно превратить их в общий разделитель: `t = s.replace('X', ' ').replace('Y', ' ')`, а затем перебрать `t.split()`. {{strmeth|`replace()`}} возвращает строку с заменами, исходная строка сама не изменяется. `split()` без аргумента разбивает по пробельным промежуткам и не создаёт пустых частей.

**Опасная замена — удаление символа вместо создания границы.** Если в `AAAXAAAA` выполнить `s.replace('X', '')`, получится `AAAAAAA`. Но такой непрерывной цепочки в исходной строке не было.

Также будь осторожен с заменой длинного слова одним символом: `s.replace('ABC', '*')` меняет длину и позиции. Иногда это полезно, но тогда нужно отдельно восстанавливать длину исходного фрагмента.

Прежде чем применять замену, спроси:

> Не создам ли я соседство, которого раньше не было? Не потеряю ли перекрывающиеся вхождения? Смогу ли восстановить исходные позиции?

---

**Части между разделителями можно собирать в цепочку, если условие разрешает сам разделитель.**

Учебная задача:

> Найти самый длинный фрагмент, который начинается и заканчивается буквой `F`, а между любыми двумя соседними буквами `F` содержит не более двух букв `A`.

После `s.split('F')` первая и последняя части не лежат между двумя `F`, поэтому рассматриваем только `parts[1:-1]`. Подходящая часть продолжает цепочку: к длине добавляются сама часть и закрывающая `F`. Неподходящая часть обрывает цепочку — сброс до нуля, как в подтеме 2. Пройди программу по шагам:

```python run chain.py
s = 'BFAAFCFAAAFDFAB'
parts = s.split('F')
current = 0
best = 0

for part in parts[1:-1]:
    if part.count('A') <= 2:
        if current == 0:
            current = 1
        current += len(part) + 1
    else:
        current = 0

    best = max(best, current)

print(best)
```

```output
6
```

Здесь `current = 1` — первая `F` новой цепочки. Лучший фрагмент — `FAAFCF`: часть `AAA` содержит три `A` и обрывает цепочку.

---

**Если разделители перекрываются и удаляются с разбиением строки, нужно пометить все занятые ими позиции.**

Допустим, разделителем является любая тройка, содержащая по одному разу `A`, `B`, `C`. В строке `QABCABR` есть перекрывающиеся разделители `ABC`, `BCA` и `CAB`. Они вместе покрывают весь участок `ABCAB`. После удаления с разбиением остаются отдельные фрагменты `Q` и `R`. Их нельзя склеить в `QR`.

Для проверки состава тройки удобно {{set|множество}}: оно хранит различные элементы и повторения не учитывает. Поскольку в тройке ровно три позиции, условие `set(s[i:i + 3]) == {'A', 'B', 'C'}` означает, что каждая из этих букв встретилась ровно один раз.

Сначала пометим все позиции разделителей в списке {{listrepeat|`[False] * len(s)`}}, потом найдём максимальную цепочку непомеченных позиций:

```python
s = 'QABCABR'
removed = [False] * len(s)

for i in range(len(s) - 2):
    if set(s[i:i + 3]) == {'A', 'B', 'C'}:
        for j in range(i, i + 3):
            removed[j] = True

current = 0
best = 0

for i in range(len(s)):
    if not removed[i]:
        current += 1
    else:
        current = 0

    best = max(best, current)

print(best)
```

```output
1
```

Здесь все разделители определяются **в исходной строке**. Последовательное удаление и повторный поиск могли бы изменить соседства и привести к другому результату.

---

**Ограничения на начало и конец фрагмента часто позволяют резко сократить перебор.**

Например:

> Фрагмент заканчивается гласной, содержит только одну гласную и ровно `K` букв `T`. Нужна минимальная длина.

Вместо перебора любых правых концов достаточно рассмотреть позиции гласных. Для каждой такой позиции предыдущая гласная не должна попасть внутрь; берём последние `K` букв `T`, расположенные после предыдущей гласной, и начало ставим на первую из этих `K` букв.

```python
s = 'ATBTCTEXTYTTO'
K = 2
vowels = 'AEIOUY'

positions_t = []
best = len(s) + 1

for i in range(len(s)):
    if s[i] == 'T':
        positions_t.append(i)

    elif s[i] in vowels:
        if len(positions_t) >= K:
            left = positions_t[-K]
            best = min(best, i - left + 1)

        positions_t = []

print(best)
```

```output
3
```

`positions_t[-K]` — `K`-й элемент с конца. Почему после каждой гласной список очищается? Следующий подходящий фрагмент не может пересекать эту гласную: иначе гласных будет уже две. Здесь подходят `TCTE` и `TTO`, короче — `TTO`; перед `Y` только одна `T`.

Набор гласных берём именно из условия задачи. Например, включение `Y` должно определяться формулировкой.

---

**Если концы фрагмента — одинаковые символы, а внутри таких символов быть не должно, концами служат соседние вхождения.**

Другой пример:

> Начало и конец — одинаковые цифры, внутри только буквы.

Тогда концами могут быть только **соседние цифры исходной строки**. Если между выбранными крайними цифрами находится третья цифра, условие уже нарушено. Поэтому достаточно перебрать соседние позиции цифр и проверить равенство крайних цифр, необходимую чётность, наличие букв между ними и дополнительные условия на эти буквы.

Учебная задача: фрагмент начинается и заканчивается одной и той же нечётной цифрой, между ними только буквы, гласных и согласных поровну; нужен самый длинный, при равенстве — с наибольшим номером начала (нумерация с нуля):

```python
s = '5BA57OK7TEX2KA2'
digits = '0123456789'
vowels = 'AEIOUY'

where = []
for i in range(len(s)):
    if s[i] in digits:
        where.append(i)

best_length = 0
best_start = -1
for k in range(len(where) - 1):
    a = where[k]
    b = where[k + 1]
    if s[a] == s[b] and int(s[a]) % 2 == 1 and b - a > 1:
        inside = s[a + 1:b]
        v = 0
        for c in inside:
            if c in vowels:
                v += 1
        if 2 * v == len(inside):
            length = b - a + 1
            if length > best_length or (
                length == best_length and a > best_start
            ):
                best_length = length
                best_start = a

print(best_length, best_start)
```

```output
4 4
```

Подходят `5BA5` (начало 0) и `7OK7` (начало 4) — обе длины 4, выбрано большее начало. Фрагмент `2KA2` тоже сбалансирован, но цифра 2 чётная. Правило при равенстве и нумерация — как в подтеме 3.

Тот же приём — для букв. «Фрагмент от `E` до `E`, внутри нет других `E`» — это часть между соседними `E`, то есть элемент `s.split('E')[1:-1]`; длина фрагмента — длина части плюс две буквы `E`. Посчитаем фрагменты длиной не меньше 4 без буквы `F` внутри:

```python
s = 'EABEFEXYZE'
count = 0

for part in s.split('E')[1:-1]:
    if len(part) + 2 >= 4 and 'F' not in part:
        count += 1

print(count)
```

```output
2
```

Подходят `EABE` и `EXYZE`; `EFE` короче четырёх и содержит `F`.

Такое выделение возможных границ нередко проще общего скользящего окна.

---

**Требование «встречаются все символы набора» тоже нужно сочетать с остальными условиями.**

Например:

> Найти самый длинный фрагмент только из цифр, содержащий все десять цифр.

Сначала последовательность разбивается буквами на цифровые блоки. Если некоторый цифровой блок содержит все десять цифр, для максимума выгодно брать его целиком: дополнительные цифры не нарушают условие. Можно поддерживать длину текущего цифрового блока и множество встреченных цифр:

```python
s = 'AB0123456789X98765432101C'
digits = '0123456789'

current = 0
seen = set()
best = 0

for c in s:
    if c in digits:
        current += 1
        seen.add(c)
    else:
        current = 0
        seen = set()

    if len(seen) == 10:
        best = max(best, current)

print(best)
```

```output
11
```

`set()` создаёт пустое множество. `seen.add(c)` добавляет символ; повторное добавление того же символа не увеличивает размер множества. Здесь `len(seen) == 10` означает, что встретились все десять различных цифр.

А вот для **минимального** фрагмента, содержащего все нужные символы, потребуется сжимать окно, пока каждый нужный символ ещё представлен хотя бы один раз — как в подтеме 4. Снова видно, что слова «минимальный» и «максимальный» меняют алгоритм.

---

**Итого.**

- Позиции нужных символов — список; самый короткий фрагмент с `K` вхождениями — `positions[j + K - 1] - positions[j] + m`.
- Самый длинный с ровно `K` — от соседних лишних вхождений: искусственные границы `-1` и `len(s)` и `positions[j + K] - positions[j - 1] - 1`.
- `split` создаёт границы, а `replace(…, '')` их уничтожает; перекрывающиеся разделители помечают в исходной строке.
- Особые концы сокращают перебор: соседние вхождения граничного символа, последние `K` нужных букв перед концом.
- «Все символы набора» в блоке — множество встреченных; для максимума блок берут целиком.
