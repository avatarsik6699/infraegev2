**Короткие образцы, повторяющиеся цепочки и частоты символов решаются одним проходом, если заранее понять, что проверять на каждой позиции.** Это повторяющийся образец вида `XYZXYZ…`, цепочки целых пар и троек, самый частый символ в окружении и файлы из многих строк.

Примеры здесь — короткие строки вроде `ABABA` и `ABACABAD`: на них всё проверяется руками. Цепочку с текущей длиной `current` и лучшей `best` считаем знакомой по подтеме 2.

---

**Для поиска короткого образца нужно перебрать все возможные позиции его начала.**

Пусть требуется посчитать вхождения `word = 'ABA'` в строке `ABABA`. Вхождений два: с позиции `0` (символы `0–2`) и с позиции `2` (символы `2–4`). Они имеют общий символ, то есть **перекрываются**.

Проверяем каждый возможный старт:

```python
s = 'ABABA'
word = 'ABA'
m = len(word)
count = 0

for i in range(len(s) - m + 1):
    if s[i:i + m] == word:
        count += 1

print(count)
```

```output
2
```

Почему диапазон заканчивается на `len(s) - m + 1`? Последнее возможное начало имеет индекс `len(s) - m`. Но правая граница `range()` не включается. Поэтому прибавляем один.

**Метод `count()` не всегда заменяет такой перебор.** Он считает неперекрывающиеся вхождения: найдя вхождение, продолжает поиск после его конца.

<figure class="plate-figure">
%%overlap("ABABA", "ABA")%%
<figcaption>ABA в ABABA начинается на позициях 0 и 2; count находит первое вхождение и пропускает второе, потому что оно перекрывается с найденным.</figcaption>
</figure>

```python
print('ABABA'.count('ABA'), 'ABABA'.count('A'))
```

```output
1 3
```

Поэтому при допустимых перекрытиях нужно проверять позиции самостоятельно. Для одного символа проблемы нет: `s.count('A')` корректно считает все буквы `A`.

---

**Условия на короткие фрагменты проверяются тем же перебором начал.** Например:

> Сколько троек имеют одинаковые крайние символы?

```python
s = 'ABACABAD'
count = 0

for i in range(len(s) - 2):
    if s[i] == s[i + 2]:
        count += 1

print(count)
```

```output
3
```

Подходят тройки `ABA`, `ACA` и ещё раз `ABA`. Средний символ здесь может быть любым, если условие не говорит обратного.

---

**Для повторяющейся последовательности важно знать, какой символ должен идти следующим.**

Рассмотрим цепочку `ABCABCABC...`. Пусть она должна начинаться с `A`, а последний блок может быть неполным. Тогда подходят `A`, `AB`, `ABC`, `ABCA`, `ABCAB`, `ABCABC`… Но не подходит `BCA`, если начало именно с `A` обязательно.

Обозначим уже набранную длину через `current`. После `ABC` снова ожидается `A`, после `ABCA` — `B`: ожидание повторяется через каждые три символа. Номер ожидаемого символа в образце — остаток от деления {{intdiv|`%`}}: `0 % 3`, `1 % 3`, `2 % 3`, `3 % 3` дают 0, 1, 2, 0. Поэтому ожидаемый символ — `pattern[current % 3]`, где `pattern = 'ABC'`.

<figure class="plate-figure">
%%string_expected("ABC", 7)%%
<figcaption>Набрано current символов — следующим ожидается pattern[current % 3]: после 0, 3, 6 символов снова A.</figcaption>
</figure>

Полный код:

```python
s = 'BABCABCABB'
pattern = 'ABC'
current = 0
best = 0

for c in s:
    expected = pattern[current % 3]

    if c == expected:
        current += 1
    elif c == 'A':
        current = 1
    else:
        current = 0

    best = max(best, current)

print(best)
```

```output
8
```

При несовпадении новый `A` начинает новую цепочку, а `B` или `C` не могут её начать. В строке `BABCABCABB` первая `B` цепочку не начинает, а лучшая цепочка — `ABCABCAB` с позиции 1: последний блок `AB` неполный.

**Этот простой перезапуск нельзя без проверки переносить на любой повторяющийся образец.** Например, для образца `AAB` в строке `AAAB` при несовпадении нужно сохранить две последние `A`. Сброс до одной `A` потеряет правильное начало. Для `ABC` показанный алгоритм работает благодаря структуре образца: буква `A` встречается в нём один раз.

Если разрешены только целые блоки `ABC`, длина должна быть кратна трём. В рамках именно этой модели из найденной максимальной длины можно убрать неполный последний блок: `answer = best - best % 3`. Для нашей строки это 8 − 8 % 3 = 6 — два целых блока `ABCABC`.

---

**Цепочки из пар или троек нужно отличать от проверки всех соседних пар или троек.**

Сравни:

> Каждые две соседние буквы различны.

Проверяются пары с началами `0`, `1`, `2`, `3`… И другое условие:

> Фрагмент состоит из пар «согласная + гласная».

Здесь фрагмент разбивается на непересекающиеся пары, например `BA CE FA`. Начала пар отличаются на два. Но подходящая цепочка может начаться как на чётной, так и на нечётной позиции исходной строки. Поэтому проверяем оба варианта:

<figure class="plate-figure">
%%string_offsets("ABACEFAED", "BCDF", "AE")%%
<figcaption>Пары с начал 0, 2, 4, 6 не подходят, а пары с начал 1, 3, 5 — BA, CE, FA — дают цепочку из трёх пар.</figcaption>
</figure>

{{for|Третий аргумент `range()`}} — шаг: `range(1, 8, 2)` даёт 1, 3, 5, 7. Сначала проверяем пары с началами `0, 2, 4, ...`, затем — `1, 3, 5, ...`:

```python
s = 'ABACEFAED'
consonants = 'BCDF'
vowels = 'AE'

best_pairs = 0

for offset in range(2):
    current_pairs = 0

    for i in range(offset, len(s) - 1, 2):
        if s[i] in consonants and s[i + 1] in vowels:
            current_pairs += 1
        else:
            current_pairs = 0

        best_pairs = max(best_pairs, current_pairs)

print(best_pairs, 2 * best_pairs)
```

```output
3 6
```

Если спрашивают количество пар, выводим `best_pairs`; если количество символов — `2 * best_pairs`. Для блоков длины три аналогично проверяют три возможных смещения.

---

**Когда нужно посчитать частоты разных символов, удобно хранить отдельный счётчик для каждого.**

Например:

> Какая буква чаще всего встречается непосредственно после `A`?

В строке `ABACABAD` после `A` стоят `B`, `C`, `B`, `D`. Значит, `B` — два раза, `C` — один, `D` — один.

Для хранения соответствий «буква → количество» используется {{dict|словарь}}: `freq = {}` — пустой словарь, `freq['B'] = 2` сохраняет для буквы `B` значение `2`. Чтобы увеличить счётчик, пишут {{dictget|`freq[c] = freq.get(c, 0) + 1`}}: `freq.get(c, 0)` возвращает уже сохранённое значение, если буква есть в словаре, и `0`, если её пока нет. Запусти программу по шагам и посмотри, как растёт словарь:

```python run freq.py
s = 'ABACABAD'
freq = {}

for i in range(len(s) - 1):
    if s[i] == 'A':
        c = s[i + 1]
        freq[c] = freq.get(c, 0) + 1

print(freq)
```

```output
{'B': 2, 'C': 1, 'D': 1}
```

Последнюю позицию не рассматриваем как начало пары: после неё нет символа.

---

**Если при равных частотах нужно выбрать одну букву, правило выбора записывают явно.**

Допустим, при равных частотах нужно выбрать букву, которая раньше в алфавите. {{sorted|`sorted(freq)`}} перебирает буквы в отсортированном порядке:

```python
freq = {'D': 2, 'B': 2, 'C': 1}
answer = ''
best_count = 0

for c in sorted(freq):
    if freq[c] > best_count:
        best_count = freq[c]
        answer = c

print(answer)
```

```output
B
```

Почему сравнение строгое — `>`? Первой встретится меньшая по алфавиту буква. При равной частоте следующая буква её не заменит. Если требовалась последняя по алфавиту, можно было бы обновлять ответ и при равенстве (`>=`).

**Если нужно сохранить все буквы с максимальной частотой, выбрать одну нельзя.** Тогда сначала находим наибольшую частоту, а затем собираем в {{list|список}} все буквы с ней:

```python
freq = {'D': 2, 'B': 2, 'C': 1}
best_count = 0
for c in freq:
    best_count = max(best_count, freq[c])

winners = []
for c in freq:
    if freq[c] == best_count:
        winners.append(c)

print(winners)
```

```output
['D', 'B']
```

---

**При равенстве основного критерия нужно явно реализовать дополнительный.**

Например:

> Найти самый длинный фрагмент; если таких несколько, выбрать начинающийся правее.

Храним `best_length` и `best_start`. Для каждого кандидата с концами `left` и `right` длина `length = right - left + 1`; если она больше лучшей, запоминаем обе величины, а если равна и начало правее — только начало. Применим это к цепочкам `X` из подтемы 2: цепочка, заканчивающаяся на `right`, начинается на `right - current + 1`.

```python
s = 'XXAXXBXXAX'
current = 0
best_length = 0
best_start = -1

for right in range(len(s)):
    if s[right] == 'X':
        current += 1
    else:
        current = 0

    left = right - current + 1
    length = current

    if length > best_length:
        best_length = length
        best_start = left
    elif length == best_length and left > best_start:
        best_start = left

print(best_length, best_start)
```

```output
2 6
```

Три цепочки длины 2 начинаются на позициях 0, 3 и 6, выбрана самая правая. Если нужно вывести начальную позицию, печатаем `best_start`, а не `best_length`.

Обрати внимание и на нумерацию: если в условии позиции считаются с нуля, используем индекс Python; если с единицы — прибавляем один. Не следует автоматически прибавлять единицу только потому, что в обычной речи говорят «первый символ».

**Если в файле много строк, счётчики заводятся заново для каждой строки.**

При обработке многих строк внимательно различай счётчики внутри одной строки и общий результат по всему файлу. Внутренние счётчики создаются заново для каждой строки, а лучший результат — один раз до цикла.

Учебное условие для файла `24-stroki.txt` из подтемы 1:

> Найти строку, в которой больше всего букв `A` (если таких несколько — первую), и определить, какая буква встречается в ней чаще всего (если несколько — та, что позже в алфавите).

Строку выбираем по одному признаку, а ответ берём по другому:

```python
best_line = ''
best_a = -1

with open('24-stroki.txt') as f:
    for line in f:
        s = line.rstrip('\r\n')
        if s.count('A') > best_a:
            best_a = s.count('A')
            best_line = s

freq = {}
for c in best_line:
    freq[c] = freq.get(c, 0) + 1

answer = ''
best_count = 0
for c in sorted(freq):
    if freq[c] >= best_count:
        best_count = freq[c]
        answer = c

print(best_line, answer)
```

```output
ABBACAB B
```

В строке `ABBACAB` три буквы `A` и три `B`; при равенстве выбрана `B` — она позже в алфавите, поэтому сравнение нестрогое. Строгое `>` при выборе строки оставляет первую из строк с равным количеством `A`.

---

**Для максимального расстояния между одинаковыми буквами достаточно помнить их первые появления.**

Предположим, буква `A` встретилась на позициях 2, 7, 11, 18. Самое большое расстояние между двумя `A` — 18 − 2. Нет необходимости проверять все пары позиций. При движении слева направо для каждой новой `A` выгоднее всего брать самую первую `A`.

```python
s = 'CABBAGE'
first = {}
best = 0

for i in range(len(s)):
    c = s[i]

    if c in first:
        distance = i - first[c]
        best = max(best, distance)
    else:
        first[c] = i

print(best)
```

```output
3
```

Здесь расстояние — разность номеров: две `A` стоят на позициях 1 и 4. `first[c]` не обновляется после первого появления.

Это общий принцип:

> Если при фиксированной правой границе выгодна максимально ранняя левая, сохраняй самое раннее подходящее положение.

Он появится снова в дополнительном уроке 8 — там самое раннее положение хранится для накопленной разности.

---

**Итого.**

- Короткий образец ищут перебором всех начал `range(len(s) - m + 1)`; `count` не видит перекрытий.
- Для повторяющегося образца ожидаемый символ — `pattern[current % len(pattern)]`; перезапуск при несовпадении зависит от образца.
- Цепочки целых пар проверяют с шагом 2 от двух смещений.
- Частоты — словарь `freq[c] = freq.get(c, 0) + 1`; правило при равенстве задаёт строгость сравнения и порядок перебора.
- Счётчики строки создаются заново для каждой строки; выбор и ответ — разные величины.
