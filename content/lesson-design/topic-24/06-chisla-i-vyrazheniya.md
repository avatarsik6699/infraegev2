**Корректное арифметическое выражение ищут не вычислением, а проверкой структуры записи: число, знак, число, знак…** Тот же шаблон числа описывает и запись числа в системе счисления.

Сквозной пример — строка `03+5**7+0*12`: в ней есть ведущий ноль и два знака подряд. Срезы и включённые границы — из подтемы 1, сравнение кандидатов по длине — из подтем 2–5.

---

**Регулярные выражения полезны, когда фрагмент описывается повторяющейся структурой.**

Например: одна или несколько цифр; число, затем несколько пар «операция + число»; буква, затем цифры, затем буква. Всё, что нужно из модуля `re`, уже знакомо по курсу Python — {{regex|регулярное выражение}}: классы `[0-9]` и `[ABC]`, повторения `+`, `*`, `?`, выбор `A|B`, проверка всей строки `re.fullmatch` и поиск `re.finditer` с `group()`, `start()`, `end()`. Длина совпадения — `match.end() - match.start()`, а совпадения `finditer` **не перекрываются**: следующее ищется после конца предыдущего.

Новое для нас одно — **группа без сохранения** `(?:...)`. Как и обычные скобки, она объединяет элементы, чтобы повторение относилось ко всей группе, но ничего не запоминает. Например, `ABC+` означает `AB`, затем одну или несколько `C`, а `(?:ABC)+` — один или несколько блоков `ABC`:

```python
import re

print(re.fullmatch(r'ABC+', 'ABCCC') is not None)
print(re.fullmatch(r'ABC+', 'ABCABC') is not None)
print(re.fullmatch(r'(?:ABC)+', 'ABCABC') is not None)
```

```output
True
False
True
```

---

**Чтобы составить шаблон арифметического выражения, сначала нужно точно определить допустимое число.**

Предположим:

- разрешены десятичные неотрицательные целые числа;
- ведущие нули запрещены;
- отдельное число `0` разрешено;
- разрешены операции `+` и `*`;
- унарных знаков нет, то есть выражение не начинается с `+` или `-`.

Подходящие числа — `0`, `5`, `10`, `204`; неподходящие — `00`, `03`, `007`. Значит, число — это либо `0`, либо ненулевая цифра, после которой идёт любое количество цифр. Шаблон:

```python
number = r'(?:0|[1-9][0-9]*)'
```

Разберём: `0` — отдельный ноль; `|` — выбор другого варианта; `[1-9]` — первая ненулевая цифра; `[0-9]*` — остальные цифры, которых может не быть; `(?:...)` — объединение вариантов в одну группу. Проверим шаблон на числах из списка:

```python
import re

number = r'(?:0|[1-9][0-9]*)'
for text in ['0', '5', '10', '204', '00', '03', '007']:
    print(text, re.fullmatch(number, text) is not None)
```

```output
0 True
5 True
10 True
204 True
00 False
03 False
007 False
```

---

**Выражение — это число, затем ноль или больше повторений «операция + число».**

Почему так? Выражение начинается числом; между числами ровно одна операция; выражение заканчивается числом; соседних операций нет. Шаблон:

```python
pattern = number + r'(?:[+*]' + number + r')*'
```

Внутри `[+*]` символы `+` и `*` обозначают сами знаки операций.

Полный поиск максимальной длины:

```python
import re

s = '03+5**7+0*12'
number = r'(?:0|[1-9][0-9]*)'
pattern = number + r'(?:[+*]' + number + r')*'

best = 0

for match in re.finditer(pattern, s):
    best = max(best, match.end() - match.start())

print(best)
```

```output
6
```

Самый длинный подходящий фрагмент — `7+0*12`, длина `6`.

<figure class="plate-figure">
%%string_matches("03+5**7+0*12", "(?:0|[1-9][0-9]*)(?:[+*](?:0|[1-9][0-9]*))*")%%
<figcaption>finditer находит 0, 3+5 и 7+0*12: ведущий ноль 03 обрывает первое совпадение на нуле, два знака ** — второе.</figcaption>
</figure>

Заметь: наличие `03` в исходной строке не запрещает начать подходящий фрагмент с символа `3`. Мы ищем подстроку, а не обязательно используем всю соседнюю группу цифр. Если по условию нужно брать только целые группы цифр, ограниченные другими символами, это уже дополнительное требование к границам.

**Вычислять значение выражения для поиска его длины не нужно.** Здесь проверяется структура записи.

---

**Шаблон числа и знаков меняют по условию задачи, а не по привычке.**

Если условие разрешает только некоторые цифры или накладывает особые ограничения на ноль, шаблон числа нужно изменить. Например, запрет ведущих нулей и запрет знака операции рядом с любой цифрой `0` — разные условия. Выбери условие:

:::pick Условие задачи и как меняется шаблон
- *цифры 0, 6, 7, 8, 9 | `(?:0|[6-9][06-9]*)` | в наборах — только разрешённые цифры
- знаки − и * | `[-*]` вместо `[+*]` | минус ставят в наборе первым, иначе он означает диапазон
- числа натуральные | `[1-9][0-9]*` | отдельного числа 0 нет, ноль бывает только внутри числа
- перед выражением буква A | `'A' + pattern` | буква входит в длину найденного фрагмента
:::

Например, фрагмент «буква `A`, за которой следует корректное выражение со знаками `−` и `*`»:

```python
import re

s = 'BA12*3-04A7-0*5'
number = r'(?:0|[1-9][0-9]*)'
pattern = 'A' + number + r'(?:[-*]' + number + r')*'

best = 0
for match in re.finditer(pattern, s):
    print(match.group())
    best = max(best, match.end() - match.start())

print(best)
```

```output
A12*3-0
A7-0*5
7
```

Число `04` с ведущим нулём обрывает первое выражение на нуле: `0` — допустимое число, а `4` уже не может продолжить его.

---

**Число в задаче может означать либо запись в системе счисления, либо целую группу цифр с заданными границами.**

Это разные модели. Если ищется запись числа в основании `14`, допустимы символы `0123456789ABCD`. Буквы `E`, `F`, … разрывают такую запись.

Если ищется самая длинная запись, которая может быть числом в основании 24, допустимы цифры `0`–`9` и буквы `A`–`N` (24 знака), а число не может начинаться с нуля. Это тот же шаблон, что и для числа без ведущих нулей:

```python
import re

s = '00A1NZ0FM3K'
best = 0
for match in re.finditer(r'[1-9A-N][0-9A-N]*', s):
    best = max(best, match.end() - match.start())

print(best)
```

```output
4
```

Подходят `A1N` и `FM3K`: `Z` — не цифра основания 24, а ноль перед `F` не может быть первым.

---

**Если ищется максимальное числовое значение, сначала нужно разобраться с ведущими нулями.**

Например, у записи `00099` больше символов, чем у `100`, но второе число больше. После удаления незначащих ведущих нулей:

> Любое положительное число с большим количеством цифр в одной системе счисления больше любого числа с меньшим количеством цифр.

При одинаковой длине сравниваются цифры слева направо. Для стандартной записи цифрами `0–9`, затем заглавными буквами `A–Z`, порядок символов соответствует порядку значений цифр.

<details class="proof" markdown="1">
<summary>Почему более длинная запись всегда больше</summary>

Для основания b наименьшее положительное L-значное число — bᴸ⁻¹ (единица и L − 1 нулей), а наибольшее число с L − 1 цифрами — bᴸ⁻¹ − 1. Первое больше второго на единицу.

</details>

**Чётность по последней цифре определяется только в чётном основании.** В основании `14` число чётное, если последняя цифра имеет чётное значение: `0 2 4 6 8 A C`, потому что `A = 10`, `C = 12`. В нечётном основании правило другое: все степени основания нечётны, поэтому чётность зависит от суммы значений цифр.

Если в допустимом блоке ищется максимальное чётное число в чётном основании, обычно выгодно:

1. убрать незначащие нули слева;
2. закончить на самой правой допустимой чётной цифре;
3. сравнить получившийся кандидат с другими.

Случай числа `0` рассматривается отдельно: после удаления ведущих нулей запись не должна ошибочно превратиться в «несуществующее число». Кандидатов удобно сравнивать парой (длина, запись): сначала по длине, при равной длине — по символам слева направо.

```python
import re

s = 'Z0090B3X1C47DE0A5'
digits = '0123456789ABCD'
best = ''

for match in re.finditer('[0-9A-D]+', s):
    block = match.group().lstrip('0')
    end = -1
    for i in range(len(block)):
        if digits.index(block[i]) % 2 == 0:
            end = i
    if end >= 0:
        candidate = block[:end + 1]
    elif '0' in match.group():
        candidate = '0'
    else:
        candidate = ''
    if (len(candidate), candidate) > (len(best), best):
        best = candidate

print(best, len(best))
```

```output
1C4 3
```

Блоки здесь — `0090B3`, `1C47D` и `0A5`. Из первого остаётся `90`: после нуля чётных цифр нет; из второго — `1C4`: `7` и `D` нечётные; из третьего — `A`. Наибольшее — `1C4`. `digits.index(c)` даёт значение цифры: для `C` это 12.

---

**Итого.**

- Регулярное выражение описывает структуру; группа `(?:...)` нужна, чтобы повторялся целый блок.
- Число без ведущих нулей — `(?:0|[1-9][0-9]*)`; выражение — `number + r'(?:[+*]' + number + r')*'`.
- `re.finditer` выдаёт совпадения без перекрытий; длина — `end() - start()`; самое длинное корректное выражение — максимум по совпадениям.
- Цифры, знаки, ноль и буква перед выражением — из условия: шаблон меняется под них.
- Запись в основании b — свой набор цифр; большее число — длиннее после удаления ведущих нулей; чётность в чётном основании — по последней цифре.
