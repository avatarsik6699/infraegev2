**Первый основной приём — хранить длину подходящей цепочки, заканчивающейся в текущем месте.** Так решаются задачи, где условие касается отдельного символа, пары соседей или тройки: цепочка одной буквы, различные соседи, запрещённые пары.

Начнём со строки `XXAXXXXBXX` из файла `24.txt` подтемы 1: в ней ищем самую длинную цепочку букв `X`. Чтение файла и индексы считаем знакомыми по подтеме 1.

---

**Для цепочки нужны две переменные: длина текущей цепочки и лучшая длина.**

Начнём с простой задачи:

> Найти максимальное количество букв `X`, идущих подряд.

В строке `XXAXXXXBXX` ответ: `4`. Нужны две переменные: `current` — длина цепочки `X`, которая продолжается прямо сейчас, и `best` — наибольшая длина среди всех уже просмотренных цепочек. Обе начинаются с нуля.

Пройди строку по шагам: заливка показывает текущую цепочку, скобка — лучшую из уже найденных.

%%string_run_stepper("XXAXXXXBXX", "only", "X")%%

Алгоритм:

```python
with open('24.txt') as f:
    s = f.readline().rstrip('\r\n')

current = 0
best = 0

for c in s:
    if c == 'X':
        current += 1
    else:
        current = 0

    best = max(best, current)

print(best)
```

```output
4
```

**Почему при `A` мы записываем ноль?** Потому что подходящий фрагмент должен состоять только из `X`. Сам символ `A` не может входить даже в цепочку длины один.

---

**Максимум обновляется после каждого символа — так учитывается и цепочка в конце файла.**

Если обновлять максимум только в момент разрыва, последняя цепочка может остаться неучтённой. Возьмём строку, где самая длинная цепочка стоит в конце, и обновим `best` только при разрыве:

```python
s = 'XXAXXXXBXXXXX'
current = 0
best = 0

for c in s:
    if c == 'X':
        current += 1
    else:
        best = max(best, current)
        current = 0

print(best)
```

```output
4
```

Цепочка `XXXXX` длины 5 в конце строки не попала в ответ: после неё разрыва уже не было. Программа с обновлением после каждого символа на этой строке печатает 5.

---

**Та же идея работает для разных условий на отдельный символ.** Меняется только проверка в `if`. Выбери условие, чтобы увидеть, какую цепочку оно описывает:

:::pick Условие на символ и цепочка, которую оно описывает
- *c == 'X' | цепочка только из `X` | любой другой символ разрывает её
- c in 'ABC' | цепочка только из `A`, `B`, `C` | `in` проверяет символ по набору
- c != 'D' | цепочка без `D` | разрывает только `D`
- c in '0123456789' | цепочка десятичных цифр | буквы и знаки разрывают её
:::

У всех этих задач одинаковая логика:

> Текущий символ сам по себе либо допустим, либо полностью разрывает цепочку.

---

**Если условие связывает соседние символы, при разрыве часто остаётся цепочка длины один.**

Теперь требуется:

> Найти самую длинную цепочку одинаковых символов.

Например, в строке `AABBBBCCAAA` ответ: `4`.

```python
s = 'AABBBBCCAAA'
current = 0
best = 0

for i in range(len(s)):
    if i > 0 and s[i] == s[i - 1]:
        current += 1
    else:
        current = 1

    best = max(best, current)

print(best)
```

```output
4
```

Почему здесь `current = 1`, а не `0`? Допустим, после нескольких `A` встретилась `B`. Цепочка из `A` закончилась. Но символ `B` **сам образует новую подходящую цепочку длины один**.

Это различие нужно понимать, а не заучивать:

| Условие | Что происходит при нарушении |
|---|---|
| Фрагмент состоит только из `X`, встретилась `A` | `A` непригодна сама по себе → длина `0` |
| Все символы фрагмента одинаковы, после `A` встретилась `B` | `B` начинает новую цепочку → длина `1` |

Проверка `i > 0 and s[i] == s[i - 1]` сначала проверяет `i > 0`. Если это неправда, вторая часть не вычисляется. Поэтому в начале строки мы не сравниваем первый символ с последним — ту самую ловушку `s[i - 1]` при `i = 0` из подтемы 1.

---

**Условие «каждые два соседних символа различны» проверяется почти так же.**

Подходит, например, строка `ABACA`: несмотря на повторение `A`, каждая соседняя пара состоит из разных символов. Пройди по шагам строку `ABBACAB`:

%%string_run_stepper("ABBACAB", "diff")%%

```python
s = 'ABBACAB'
current = 0
best = 0

for i in range(len(s)):
    if i > 0 and s[i] != s[i - 1]:
        current += 1
    else:
        current = 1

    best = max(best, current)

print(best)
```

```output
5
```

Ответ: `5`, фрагмент `BACAB`.

**Не путай два разных требования:** соседние символы различны и все символы фрагмента различны. В `ABACA` первое требование выполнено, второе — нет. Для второго нужен другой алгоритм; он разобран в дополнительном уроке 8.

---

**Другие условия на соседей меняют только проверку пары.** Цикл, `i > 0` и сброс до единицы остаются прежними. Выбери условие:

:::pick Условие на соседей и проверка пары
- *различны | `s[i] != s[i - 1]` | соседние символы разные
- одинаковы | `s[i] == s[i - 1]` | цепочка одного символа
- цифры строго убывают | `s[i] < s[i - 1]` | символы цифр сравниваются в том же порядке, что и сами цифры: `'3' < '7'`
- буква и цифра чередуются | `(s[i] in digits) != (s[i - 1] in digits)` | `digits = '0123456789'`; рядом не стоят две буквы или две цифры
:::

---

**Запрет на определённые соседние пары тоже решается через текущую длину.**

Например:

> Никакие две буквы из набора `ABC` не должны стоять рядом, в том числе одинаковые.

Запрещены пары `AA`, `AB`, `AC`, `BA`, `BB`, `BC`, `CA`, `CB`, `CC`. Нарушение возникает, когда **оба** соседних символа принадлежат набору: `s[i - 1] in 'ABC' and s[i] in 'ABC'`. Проверку удобно записать цепочкой {{elif|`elif`}} — «иначе, если выполнено следующее условие»:

```python
s = 'DXABY'
current = 0
best = 0

for i in range(len(s)):
    if i == 0:
        current = 1
    elif s[i - 1] in 'ABC' and s[i] in 'ABC':
        current = 1
    else:
        current += 1

    best = max(best, current)

print(best)
```

```output
3
```

При запрещённой паре отбрасываем предыдущую цепочку, но оставляем текущий символ. В строке `DXABY` пара `AB` запрещена. Однако фрагмент `BY` допустим. Поэтому обнулить длину на `B` было бы ошибкой. Лучший фрагмент здесь — `DXA`.

---

**Иногда условие проверяется по тройкам, а при нарушении нужно сохранить два последних символа.**

Пусть строка состоит из цифр. Требуется максимальный фрагмент, в котором для каждых трёх соседних цифр:

> Сумма первых двух больше третьей.

Например, тройка `245` подходит: 2 + 4 > 5. А `124` не подходит: 1 + 2 не больше 4. Если встретилась плохая тройка `124`, фрагмент `24` всё ещё допустим: в нём пока нет ни одной тройки, нарушающей правило.

```python
s = '2451246'
current = min(len(s), 2)
best = current

for i in range(2, len(s)):
    a = int(s[i - 2])
    b = int(s[i - 1])
    c = int(s[i])

    if a + b > c:
        current += 1
    else:
        current = 2

    best = max(best, current)

print(best)
```

```output
5
```

Первоначально учитываем первые два символа. Если строка короче, берём её фактическую длину. Здесь лучший фрагмент — `24512`: тройка `124` его обрывает, и с цифр `24` начинается новый фрагмент, а тройка `246` (2 + 4 = 6, не больше) снова оставляет два символа.

Этот алгоритм предполагает, что фрагменты длины один и два разрешены. Если условие отдельно требует хотя бы три символа, это ограничение нужно учитывать при обновлении ответа.

---

**Общая причина сбросов `0`, `1`, `2` теперь видна.**

> После нарушения нужно оставить самый длинный конец текущего фрагмента, который всё ещё удовлетворяет условию.

Условие на один символ — недопустимый символ не остаётся вовсе, сброс до 0. Условие на пару — остаётся текущий символ, сброс до 1. Условие на тройку — остаются два последних символа, сброс до 2. В других задачах длина такого конца может быть и больше двух.

---

**Итого.**

- `current` — длина подходящей цепочки, которая заканчивается на текущем символе; `best` — лучшая из уже просмотренных.
- `best` обновляется после каждого символа, иначе теряется цепочка в конце файла.
- Сброс равен длине самого длинного конца, который ещё подходит: 0 для условия на символ, 1 для пары соседей, 2 для тройки.
- Сравнение с предыдущим символом защищается проверкой `i > 0 and …`.
- Запрещённая пара — условие `s[i - 1] in набор and s[i] in набор` и сброс до 1.
