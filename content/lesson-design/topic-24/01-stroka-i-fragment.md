**Задание 24 лучше изучать через несколько общих способов рассуждения.** Тогда новые условия будут восприниматься как сочетания знакомых идей: продолжить цепочку, передвинуть границу, посчитать нужные символы, выделить числа или проверить структуру выражения.

На экзамене дают файл примерно из миллиона символов, и почти всегда нужно найти в нём самый длинный или самый короткий непрерывный фрагмент с заданным свойством: цепочку одинаковых символов, фрагмент с ограничением на количество букв, запись числа или корректное арифметическое выражение. Разберём весь этот круг задач.

Сначала разберём, что такое фрагмент строки и как правильно прочитать файл, затем постепенно перейдём к алгоритмам. Все маленькие примеры ниже — учебные: на них удобно понимать и проверять решение, прежде чем запускать его на большом файле. Основы Python — {{eq|сравнения `==` и `!=`}}, {{augassign|`+=`}}, {{in|`in`}}, {{andor|`and` и `or`}}, {{agg|`max` и `min`}}, {{if|`if`}} и {{elif|`elif`}}, {{for|`for` и `range`}}, {{while|`while`}} — уже объяснены в курсе Python, подсказка у термина напомнит главное.

---

**Строка — это последовательность символов, у которых есть определённый порядок.**

Например, в строке `s = 'AB12CA'` шесть символов: `'A'`, `'B'`, `'1'`, `'2'`, `'C'`, `'A'`. Здесь `'1'` и `'2'` — символы, а не числа. Поэтому `'1' + '2'` склеивает строки, а сложение чисел получится только после преобразования {{str|`int()`}}:

```python
print('1' + '2')
print(int('1') + int('2'))
```

```output
12
3
```

Функция `int()` преобразует подходящую строку в целое число. Это понадобится, например, если в условии требуется сравнивать суммы соседних цифр.

---

**В большинстве задач 24 нас интересует непрерывный фрагмент исходной строки.** Его также называют **подстрокой**.

Пусть дана строка `ABCDE`. Выбери фрагмент, чтобы увидеть, подстрока ли он:

:::pick Фрагмент строки ABCDE и подстрока ли он
- *ABC | подстрока | первые три символа подряд
- BCD | подстрока | со второго по четвёртый символ подряд
- E | подстрока | один символ — тоже фрагмент
- ABCDE | подстрока | вся строка
- ACE | не подстрока | для её получения пришлось пропустить символы
:::

Вообще последовательность с пропусками называют *подпоследовательностью*. В формулировках задач это слово иногда используется вместе с уточнением «непрерывная» или «идущие подряд». Именно это уточнение определяет, разрешены ли пропуски.

**Если сказано «идущие подряд», нельзя удалять внутренние символы, переставлять их или склеивать раздельные участки.** Например, в строке `AAAXAAAA` самая длинная цепочка букв `A` имеет длину `4`, а не `7`.

---

**Чтобы указывать на символы строки, используются их номера — индексы.** В Python нумерация начинается с нуля, а {{len|`len`}} даёт количество символов. Поэтому последний неотрицательный индекс равен `len(s) - 1`. Python также позволяет считать с конца: `s[-1]` — последний символ, `s[-2]` — предпоследний.

Возьмём строку `CABAC`:

```python
s = 'CABAC'
print(s[0], s[2], s[4])
print(len(s), len(s) - 1)
print(s[-1], s[-2])
```

```output
C B C
5 4
C A
```

Обращение `s[5]` в этом примере приведёт к ошибке: шестого символа нет.

Отсюда возникает важная ловушка. Запись `s[i - 1]` при `i = 0` — это не «несуществующий предыдущий символ», а **последний символ строки**:

```python
s = 'CABAC'
i = 0
print(s[i - 1])
```

```output
C
```

Поэтому при сравнении с предыдущим символом обычно начинают с индекса `1` либо отдельно проверяют, что `i > 0`.

---

**Несколько соседних символов можно получить срезом.** {{slice|Срез}} `s[a:b]` означает: взять символы от индекса `a` включительно до индекса `b` не включительно. Поэтому длина такого среза, если границы находятся внутри строки, равна b − a. Например, `s[1:4]` для `CABAC` — это `'ABA'`:

<figure class="plate-figure">
%%slice("CABAC", 1, 4)%%
<figcaption>Срез s[1:4] берёт символы с индексами 1, 2, 3: правая граница 4 не входит, длина 4 − 1 = 3.</figcaption>
</figure>

Часто удобнее рассуждать о двух **включённых** границах: `left` и `right`. Тогда фрагмент — это `s[left:right + 1]`, а его длина — `right - left + 1`.

Почему появляется `+1`? Например, позиции `2`, `3`, `4` — это три символа: 4 − 2 + 1 = 3.

```python
s = 'XXAXXXXBXX'
left = 3
right = 6
print(s[left:right + 1], right - left + 1)
```

```output
XXXX 4
```

Полезно сразу различать три величины, которые получаются из тех же двух концов: длину фрагмента вместе с обоими концами, количество символов строго между концами и разность номеров позиций.

<figure class="plate-figure">
%%string_bounds("XXAXXXXBXX", 3, 6)%%
<figcaption>Концы left = 3 и right = 6: длина фрагмента 4, строго между концами 2 символа, разность номеров 3.</figcaption>
</figure>

Если задача использует слово «расстояние», нужно проверить по условию и примеру, какая именно величина имеется в виду.

**Прежде чем решать задачу, нужно правильно прочитать файл.** Если в файле одна строка с исходной последовательностью, её читает {{readline|`readline()`}}:

```python
with open('24.txt') as f:
    s = f.readline().rstrip('\r\n')

print(s, len(s))
```

```output
XXAXXXXBXX 10
```

Здесь {{file|`with open`}} открывает файл и закрывает его после чтения, `readline()` читает одну строку, а `rstrip('\r\n')` удаляет с правого края символы перевода строки.

**Перевод строки — тоже символ.** Если его оставить, программа иногда посчитает его частью последовательности. Например, проверка `c != 'A'` истинна и для буквы `B`, и для символа перевода строки. Посчитаем символы, отличные от `A`, в прочитанной строке с переводом и без него:

```python
with open('24.txt') as f:
    line = f.readline()

s = line.rstrip('\r\n')
with_newline = 0
for c in line:
    if c != 'A':
        with_newline += 1

clean = 0
for c in s:
    if c != 'A':
        clean += 1

print(len(line), len(s))
print(with_newline, clean)
```

```output
11 10
10 9
```

Поэтому лишний перевод строки способен увеличить ответ.

---

**Сокращения при чтении удобны, только если понятно, что именно они удаляют.**

Часто встречается сокращение `s = open('24.txt').readline().strip()`. {{strip|`strip()`}} удаляет пробельные символы с обоих краёв. Для последовательности из букв и цифр это обычно подходит. Но если пробелы являются частью данных, удалять их без причины нельзя.

Также не стоит автоматически писать `s = f.readline()[:-1]`. Это удаляет **последний символ независимо от того, является ли он переводом строки**. Если файл заканчивается без перевода строки, потеряется полезный символ:

```python
s = 'XXAXXXXBXX'
print(s[:-1])
```

```output
XXAXXXXBX
```

Если нужно прочитать весь файл, используют `f.read()`. Но `read()` сохраняет внутренние переводы строк. Поэтому сначала выясняем, что дано:

- одна последовательность;
- несколько независимых строк;
- последовательность, специально разбитая на строки.

---

**Если строки файла независимы, обрабатываем их отдельно.** Цикл `for line in f` выдаёт строки по одной, и каждую нужно очистить от перевода строки. Например, посчитаем буквы `B` в каждой строке маленького файла:

```python
with open('24-stroki.txt') as f:
    for line in f:
        s = line.rstrip('\r\n')

        # Здесь обработка одной строки.
        print(s, s.count('B'))
```

```output
ABBACAB 3
BCCB 2
CAXXXAB 1
AAB 1
```

Комментарий начинается с `#`; Python его не выполняет. Метод {{strmeth|`count`}} считает, сколько раз символ встречается в строке.

**Далее в примерах `s` — уже прочитанная строка.** Разные алгоритмы ниже — самостоятельные варианты решения, а не части одной программы, которую нужно целиком скопировать.

---

**Перед написанием кода полезно разделить условие на три вопроса.**

1. **Какие фрагменты допустимы?** Например, содержат не более трёх букв `A`.
2. **Что нужно оптимизировать?** Например, длину: найти самую большую.
3. **Что нужно вывести?** Длину, начальную позицию, количество фрагментов, букву, значение выражения?

Последние два вопроса могут иметь разные ответы. Например:

> Найдите самый длинный подходящий фрагмент и укажите номер его первого символа.

Здесь выбираем по длине, а выводим позицию. Ещё пример:

> Найдите букву, образующую самую длинную цепочку, и укажите количество этой буквы во всей строке.

Здесь длина цепочки определяет выбор, но сама по себе не является ответом. Это одна из причин, по которым механическое использование шаблонов приводит к ошибкам.

---

**Полный перебор всех подстрок обычно слишком медленный.**

В строке длины n с первой позиции начинается n непустых подстрок, со второй — n − 1, с третьей — n − 2, с последней — одна. Всего n + (n − 1) + … + 1 = n(n + 1)/2. Посчитаем это число для разных длин:

```python
for n in [10, 1000, 1000000]:
    print(n, n * (n + 1) // 2)
```

```output
10 55
1000 500500
1000000 500000500000
```

При миллионе символов это примерно 5 · 10¹¹ фрагментов. Причём каждый фрагмент ещё нужно проверить. Поэтому задача обычно состоит в том, чтобы **не рассматривать каждую подстроку отдельно**.

Если число действий растёт примерно пропорционально длине строки, говорят о **линейном алгоритме** и обозначают его сложность как `O(n)`. Если число действий растёт примерно как квадрат длины строки — {{bigo|`O(n²)`}}.

Для задания 24 особенно полезны алгоритмы, которые проходят по данным один или несколько раз.

---

**Итого.**

- Подстрока — непрерывный фрагмент: «идущие подряд» запрещают пропуски и склеивание.
- Индексы идут с нуля; `s[i - 1]` при `i = 0` — последний символ, а не «пустота».
- Фрагмент с включёнными концами — `s[left:right + 1]`, его длина `right - left + 1`; «между» и «разность номеров» — другие числа.
- Строку файла читают `readline().rstrip('\r\n')`; многострочный файл — по одной строке.
- Перед кодом три вопроса: что допустимо, что оптимизируем, что выводим. Перебор всех подстрок — n(n + 1)/2 фрагментов, поэтому нужны линейные алгоритмы.
