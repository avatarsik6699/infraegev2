**Проверка решения должна начинаться с маленьких строк, для которых ответ очевиден.** Выбери случай, чтобы увидеть, какую ошибку он ловит:

:::pick Проверочный случай и что он проверяет
- *один символ | `A` | начальные значения
- вся строка подходит | `AAAAA` | учёт последней цепочки
- ни один символ не подходит | `BBBBB` при поиске `A` | возможный ответ `0`
- лучший фрагмент в начале | `AAAABC` | левый край
- лучший фрагмент в конце | `BCAAAA` | правый край
- несколько равных максимумов | `AAABAAA` | правило выбора при равенстве
- соседние запрещённые символы | `ABXXCD` | пустые части после разбиения
- перекрывающиеся слова | `ABABA` и образец `ABA` | правильный подсчёт вхождений
- ровно нужное число вхождений | `BAAB`, `K = 2` | отличие `<` от `<=`
- одно лишнее вхождение | `BAAAB`, `K = 2` | сжатие окна
- ведущие нули | `0012+3` | правило записи чисел
- соседние операции | `12++3` | граница корректного выражения
:::

Для сложного алгоритма можно временно написать медленное решение, перебирающее все подстроки **короткой** строки, и сравнивать результаты. Такой перебор не годится для большого экзаменационного файла, но отлично помогает проверить рассуждение. Например, сравним окно из подтемы 4 с перебором всех подстрок на всех строках из букв `A` и `B` длиной до восьми — их перебирает {{product|`product`}}, а обе программы оформлены {{def|функциями}}:

```python
from itertools import product


def by_window(s, K):
    left = 0
    count_a = 0
    best = 0
    for right in range(len(s)):
        if s[right] == 'A':
            count_a += 1
        while count_a > K:
            if s[left] == 'A':
                count_a -= 1
            left += 1
        best = max(best, right - left + 1)
    return best


def by_search(s, K):
    best = 0
    for i in range(len(s)):
        for j in range(i, len(s)):
            if s[i:j + 1].count('A') <= K:
                best = max(best, j - i + 1)
    return best


checked = 0
for n in range(1, 9):
    for letters in product('AB', repeat=n):
        s = ''.join(letters)
        if by_window(s, 2) != by_search(s, 2):
            print('Разные ответы:', s)
        checked += 1

print('Проверено строк:', checked)
```

```output
Проверено строк: 510
```

Ни одной строки с разными ответами: окно и перебор согласны на всех 510 строках. Если бы окно ошибалось, программа напечатала бы строку, на которой это видно, — её удобно разобрать руками.

**Вот ошибки, которые стоит научиться замечать ещё до запуска программы.** Выбери ошибку, чтобы увидеть, что проверить:

:::pick Ошибка и что проверить
- *количество вместо длины | пять букв `A` внутри фрагмента не означают, что длина фрагмента равна пяти | что спрашивают: длину или количество
- «ровно» и «не более» | окно с одной `A` не подходит, если требуется ровно две | ответ обновляется только при `count == K`
- неправильный сброс | после нарушения остаётся `0`, `1`, `2` или другая длина | какой самый длинный конец ещё подходит
- потеря последнего фрагмента | ответ обновляется только при разрыве | `best = max(…)` после каждого символа
- символ на границе | лишний или недостающий символ | включённый конец против правой границы среза
- левая граница назад | `left` вернулась к старому появлению | нужен `max(left, …)`
- `count()` для перекрывающихся слов | `'ABABA'.count('ABA')` даёт 1 | перебор всех начал
- склеивание частей | разделитель удалили без разбиения | `split`, а не `replace(…, '')`
- только первая строка | многострочный файл прочитан одним `readline` | цикл `for line in f`
- счётчики между строками | счётчики не созданы заново для новой строки | счётчики строки — внутри цикла по строкам
- дорогая операция в цикле | длинный срез и `.count()` на каждом шаге | накопленные счётчики или префиксы
- величина выбора вместо ответа | вывели длину, а спрашивали позицию или букву | третий вопрос: что выводим
- русская буква вместо латинской | латинская `A` и русская `А` для Python — разные символы | набирать буквы условия латиницей
:::
