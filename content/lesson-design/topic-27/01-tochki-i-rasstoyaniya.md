**Задание 27 на кластеризацию удобнее понимать как несколько отдельных задач:** прочитать точки, правильно распределить их по группам, вычислить характеристики этих групп и собрать ответ по условию. Если разобраться в каждом шаге, решение можно будет строить самостоятельно.

В задачах подборок встречаются разные определения центра: через сумму расстояний, через сумму квадратов расстояний, через расстояние до самой далёкой точки. Есть задания с исключением отдельных кластеров, точками-аномалиями и дополнительными вычислениями после кластеризации. Поэтому одного неизменного шаблона для всей подборки недостаточно.

Но **все 50 задач начинаются одинаково**: точка — это пара чисел, а расстояние между точками считается по формуле. С этого и начнём.

Ниже будем писать на **Python**. Все небольшие числовые примеры — учебные: их координаты подобраны так, чтобы вычисления можно было проверить вручную. Первые примеры — точки A (2; 5) и B (−3; 4).

---

**Начнём с того, что именно находится в файле.** Обычно каждая строка описывает одну точку на плоскости:

```file.txt
1.5 3.2
2.1 4.8
7.3 1.4
```

У точки есть две координаты: `x` — положение по горизонтали, `y` — положение по вертикали. Например, запись A = (2; 5) означает: точка расположена на 2 единицы правее начала координат и на 5 единиц выше него. Отрицательная координата задаёт **противоположное направление**: B = (−3; 4) — это 3 единицы влево и 4 единицы вверх.

В условиях часто используют слова **абсцисса** и **ордината**. За ними не скрывается ничего дополнительного: абсцисса — это координата `x`, ордината — координата `y`.

Звёзды, результаты эксперимента, населённые пункты — это сюжет. Для программы во всех этих случаях важны прежде всего пары чисел.

---

**В Python одну точку удобно хранить кортежем, а несколько точек — списком.** Упорядоченная группа значений `(2.0, 5.0)` называется {{tuple|кортежем}}; здесь в нём два элемента. Нумерация элементов в Python начинается с нуля: `point[0]` — координата `x`, `point[1]` — координата `y`. Можно сразу разложить пару по двум переменным: `x, y = point`.

Несколько точек будем хранить в {{list|списке}}. Список отличается от кортежа, в частности, тем, что его удобно изменять: добавлять и удалять элементы.

Метод `append` добавляет один элемент в конец списка, {{len|`len`}} даёт количество элементов, а цикл {{for|`for`}} перебирает точки — сразу с координатами:

```python
point = (2.0, 5.0)
x, y = point
print(point[0], point[1], x, y)

points = [
    (2.0, 5.0),
    (-3.0, 4.0),
    (7.0, 1.0)
]
points.append((8.0, 2.0))
print(len(points))

for x, y in points:
    print(x, y)
```

```output
2.0 5.0 2.0 5.0
4
2.0 5.0
-3.0 4.0
7.0 1.0
8.0 2.0
```

Переменные `x` и `y` в заголовке цикла последовательно принимают координаты каждой точки. Запись `for point in points:` перебрала бы те же точки целиком.

---

**Кластер в программе — это тоже список точек.** А все кластеры вместе — список таких списков:

```python
clusters = [
    [(0, 0), (1, 1), (2, 0)],
    [(10, 8), (11, 9), (12, 8)]
]

print(len(clusters))      # количество кластеров
print(len(clusters[0]))   # количество точек первого кластера
print(clusters[1])        # второй кластер
```

```output
2
3
[(10, 8), (11, 9), (12, 8)]
```

`clusters[0]` — первый кластер, `clusters[1]` — второй. Важно различать два количества: **сколько групп** — `len(clusters)` — и **сколько точек внутри группы** — `len(clusters[0])`.

---

**Расстояние между точками получается из теоремы Пифагора.** Возьмём A = (1; 2) и B = (4; 6). По горизонтали точки отличаются на 4 − 1 = 3, по вертикали — на 6 − 2 = 4. Эти два перемещения образуют катеты прямоугольного треугольника, а отрезок между точками — его гипотенузу.

<figure class="plate-figure">
%%cl_plane(points=(), segment=[(1, 2), (4, 6)])%%
<figcaption>Катеты треугольника — разности координат 3 и 4, гипотенуза — расстояние между точками: √(3² + 4²) = √25 = 5.</figcaption>
</figure>

Поэтому для точек A = (x₁; y₁) и B = (x₂; y₂) длина отрезка:

d(A, B) = √((x₂ − x₁)² + (y₂ − y₁)²).

Буквой d здесь обозначено расстояние. Для нашего примера d(A, B) = √(3² + 4²) = √25 = 5. Такое расстояние называется **евклидовым**: это обычная длина прямого отрезка.

---

**В Python формулу можно записать самостоятельно, но в модуле `math` уже есть нужная функция.** Своя функция ({{def|`def`}} создаёт функцию, `return` возвращает результат) повторяет формулу: `** 2` — возведение в квадрат, `** 0.5` — извлечение квадратного корня.

```python
from math import dist


def distance(a, b):
    dx = a[0] - b[0]
    dy = a[1] - b[1]

    return (dx ** 2 + dy ** 2) ** 0.5


print(distance((1, 2), (4, 6)))
print(dist((1, 2), (4, 6)))
```

```output
5.0
5.0
```

{{import|`from math import dist`}} означает: взять функцию `dist` из математического модуля. Она вычисляет евклидово расстояние между точками. Дальше будем в основном использовать её.

Заметь несколько свойств: d(A, B) = d(B, A); d(A, A) = 0; d(A, B) ≥ 0. Они пригодятся при объяснении алгоритмов и ускорений.

---

**Иногда достаточно квадрата расстояния.** Если нужно лишь проверить d(A, B) ≤ r, где r ≥ 0, можно проверить равносильное условие (x₂ − x₁)² + (y₂ − y₁)² ≤ r². Корень не понадобится:

```python
a, b, r = (1, 2), (4, 6), 5

dx = a[0] - b[0]
dy = a[1] - b[1]

if dx * dx + dy * dy <= r * r:
    print("Точки достаточно близки")
```

```output
Точки достаточно близки
```

Почему это допустимо? Для неотрицательных чисел возведение в квадрат сохраняет порядок: если одно расстояние меньше другого, его квадрат тоже меньше. Здесь 25 ≤ 25 — ровно потому, что 5 ≤ 5.

**Но заменять сумму расстояний суммой их квадратов нельзя.** Это уже другая величина. В подтеме о центре кластера разберём конкретный пример, где из-за такой замены выбирается другая точка.

---

**Ответ задания 27 обычно просят как целую часть произведения на 10 000.** Значение 2,718281 умножают на 10 000 и **отбрасывают дробную часть**: 27182,81 → 27182. В Python это одна строка — `int(value * 10000)`: {{num|`int`}} отбрасывает дробную часть. Чем `int` отличается от `round` и где брать модуль, разберём в подтеме 5; до неё все значения в задачах положительные.

---

**Итого.**

- Точка — пара чисел; в Python — кортеж `(x, y)`, кластер — список точек, все кластеры — список списков.
- `len(clusters)` — сколько групп, `len(clusters[0])` — сколько точек в первой группе.
- Евклидово расстояние — гипотенуза треугольника с катетами |x₂ − x₁| и |y₂ − y₁|; в Python — `dist(a, b)`.
- Сравнить одно расстояние с порогом можно по квадратам, а суммы расстояний — нельзя.
- Ответ — `int(value * 10000)`: целая часть, а не округление.
