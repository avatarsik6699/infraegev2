**Перед тем как делить точки на группы, их нужно без потерь прочитать из файла.** Чтение нужно во всех 50 задачах подборок, а в семи из них — в том числе в обеих задачах основной волны ЕГЭ-2026 и в демоверсии 2027 года — в строке кроме координат есть характеристика объекта. Ошибка при чтении (пропущенная точка, запятая вместо точки, лишний столбец) портит ответ так же, как ошибка в алгоритме.

Будем читать файл `example27.txt` — восемь точек с заголовком `X Y`; к нему мы вернёмся, когда соберём решение целиком. Точки и расстояния — из подтемы 1.

---

**Перед написанием алгоритма нужно посмотреть первые строки файла.** В разных заданиях формат немного различается. Возможен файл без заголовка:

```file.txt
1.25 3.70
2.80 4.10
```

Возможен файл с заголовком:

```file.txt
X Y
1.25 3.70
2.80 4.10
```

Дробная часть может отделяться запятой:

```file.txt
1,25 3,70
2,80 4,10
```

Для Python запись `"1,25"` не является стандартной записью дробного числа. Перед преобразованием запятую заменяют точкой.

---

**Одна строка разбирается в три действия: заменить запятые, разделить, превратить части в числа.** Метод {{strmeth|`replace`}} заменяет запятые точками, {{split|`split()`}} делит строку на части, а {{num|`float`}} превращает часть в дробное число:

```python
line = "1,25 3,70"
line = line.replace(",", ".")
parts = line.split()
print(line)
print(parts)

x = float(parts[0])
y = float(parts[1])
print(x, y)
```

```output
1.25 3.70
['1.25', '3.70']
1.25 3.7
```

`split()` без аргументов разделяет строку по пробельным символам. Поэтому ему подходят и несколько пробелов подряд, и табуляция. Пока элементы списка `parts` — **строки**, то есть текст. Числами они становятся только после `float`.

---

**Полная функция чтения собирает точки файла в список.** Координаты берём из первых двух частей строки — так функция подойдёт и для файлов, где после координат записано что-то ещё:

```python
def read_points(filename, has_header=False):
    points = []

    with open(filename, encoding="utf-8-sig") as f:
        if has_header:
            f.readline()

        for line in f:
            if not line.strip():
                continue

            parts = line.replace(",", ".").split()

            x = float(parts[0])
            y = float(parts[1])

            points.append((x, y))

    return points
```

Что здесь происходит:

- `has_header` сообщает, есть ли в начале строка с названиями столбцов; `False` — {{defarg|значение по умолчанию}}, «нет».
- {{file|`with open(...) as f`}} открывает файл, а после окончания блока автоматически его закрывает; `for line in f` перебирает оставшиеся строки.
- `f.readline()` читает одну строку. В данном случае мы её намеренно пропускаем.
- {{strip|`line.strip()`}} убирает пробелы и перевод строки по краям, поэтому `if not line.strip()` проверяет, не является ли строка пустой; {{continue|`continue`}} пропускает оставшуюся часть текущего прохода цикла.
- `encoding="utf-8-sig"` подходит для UTF-8 и корректно обрабатывает возможную служебную метку в начале такого файла.

После чтения полезно проверить, что программа действительно прочитала ожидаемые данные. Запись `points[:5]` — {{slice|срез}}: первые пять элементов списка.

```python
points = read_points("example27.txt", has_header=True)

print("Количество точек:", len(points))
print("Первые точки:", points[:5])
```

```output
Количество точек: 8
Первые точки: [(0.0, 0.0), (0.0, 2.0), (1.0, 1.0), (2.0, 0.0), (2.0, 2.0)]
```

---

**Не пропускай первую строку автоматически в любом файле.** Если в файле есть заголовок, а мы его не пропустили, программа остановится на первой же строке — это хотя бы заметно:

```python
points = read_points("example27.txt")
```

```error
ValueError: could not convert string to float: 'X'
```

Опаснее обратная ошибка. В файле `27-1.txt` заголовка нет, но если пропустить первую строку «на всякий случай», программа молча потеряет первую точку:

```python
print(len(read_points("27-1.txt")))
print(len(read_points("27-1.txt", has_header=True)))
```

```output
205
204
```

Если в начале указано количество точек, эту строку тоже нужно обрабатывать отдельно, но уже в соответствии с таким форматом. И ещё одна мелочь: латинская `A` и кириллическая `А` в имени файла выглядят почти одинаково, но для компьютера это разные символы.

---

**Дополнительные столбцы не нужно смешивать с координатами.** В некоторых вариантах у объекта кроме положения есть тип, категория или другой признак:

```file.txt
1.25 3.70 red
2.80 4.10 blue
```

Третий столбец здесь — текстовая характеристика, а не третья пространственная координата. Её сохраняют вместе с координатами в одной записи, а для расстояния используют только координаты — срез `[:2]` берёт первые два элемента:

```python
from math import dist

record1 = (1.25, 3.70, "red")
record2 = (2.80, 4.10, "blue")

print(record1[2], record2[2])
print(dist(record1[:2], record2[:2]))
```

```output
red blue
1.600781059358212
```

**Характеристику звезды разбирают по позициям символов.** В задачах ЕГЭ-2026 у каждой звезды записан код вроде `K3V` слитно: латинская буква — спектральный класс (цвет), цифра — подкласс, римское число — класс светимости. Так устроен и наш файл `27-3.txt`:

```27-3.txt
4,387365 8,408613 A0III
1,932849 1,048969 K3V
3,921424 2,369304 VII
```

Буква задаёт цвет, римское число — размер звезды. Таблицы соответствия даны в условии; выбери обозначение, чтобы увидеть, что оно значит:

:::pick Спектральный класс → цвет
- O | голубая
- B | бело-голубая
- A | белая
- F | жёлто-белая
- *G | жёлтая
- K | оранжевая
- M | красная
:::

:::pick Класс светимости → размер
- I | сверхгигант
- II | яркий гигант
- *III | гигант
- IV | субгигант
- V | карлик
- VI | субкарлик
- VII | белый карлик
:::

«Красный гигант» в условии буквально переводится в **две проверки**: класс `M` и светимость `III`.

Обрати внимание на третью строку: у белых карликов в файле записан **только класс светимости** `VII`, без буквы и цифры. Поэтому `code[0]` не всегда спектральный класс.

Сначала проверяем, буква ли это, и только потом разбираем код по позициям. Запусти функцию по шагам и посмотри, какую ветвь проходит каждый код:

```python run parse_kind.py
def parse_kind(code):
    if code[0] in "OBAFGKM":
        return code[0], code[1], code[2:]
    return "", "", code


print(parse_kind("M4III"))
print(parse_kind("VII"))
```

```output

('', '', 'VII')
```

Для `M4III` выполняется строка 3: буква, цифра и всё остальное — срез `code[2:]`. Для `VII` проверка в строке 2 ложна, и функция возвращает пустой класс. Записи файла читаем так же, как точки, только сохраняем ещё и код:

```python
def read_stars(filename):
    stars = []

    with open(filename, encoding="utf-8-sig") as f:
        for line in f:
            parts = line.replace(",", ".").split()
            x, y = float(parts[0]), float(parts[1])
            stars.append((x, y, parts[2]))

    return stars
```

```python
stars = read_stars("27-3.txt")
print(len(stars))
print(stars[:2])
```

```output
601
[(4.387365, 8.408613, 'A0III'), (1.932849, 1.048969, 'K3V')]
```

**Строка частицы содержит шесть значений, и кластер определяется величиной, вычисленной по ним.** В демоверсии 2027 года каждая строка — частица: координаты `x` и `y`, проекции скорости `vx` и `vy`, масса `m` и признак — римское число. Значения разделены табуляцией, дробная часть — запятой. Так устроен файл `27-4.txt`. `split()` справляется и с табуляцией, поэтому чтение не меняется:

```python
def read_particles(filename):
    particles = []

    with open(filename, encoding="utf-8-sig") as f:
        for line in f:
            parts = line.replace(",", ".").split()
            x, y, vx, vy, m = [float(v) for v in parts[:5]]
            particles.append((x, y, vx, vy, m, parts[5]))

    return particles
```

Первые пять частей становятся числами и раскладываются по именам, признак остаётся строкой. В записи частицы `p` номер части — номер элемента кортежа:

<figcaption>Первая строка файла 27-4.txt: шесть частей через табуляцию. Скорость — p[2] и p[3], масса — p[4], признак p[5] остаётся строкой.</figcaption>
</figure>

Кинетическая энергия частицы массы m со скоростью (vx; vy) — E = m · (vx² + vy²) / 2. Например, для массы 0,8 и скорости (2; −1,5): E = 0,8 · (4 + 2,25) / 2 = 2,5. Запишем формулу функцией и проверим её на этом примере и на первой частице файла:

```python
def energy(p):
    vx, vy, m = p[2], p[3], p[4]
    return m * (vx ** 2 + vy ** 2) / 2
```

```python
print(energy((1.25, -3.4, 2.0, -1.5, 0.8, "III")))

particles = read_particles("27-4.txt")
print(len(particles))
print(particles[0], energy(particles[0]))
```

```output

402
(-12.554, 9.248, 1.957, 1.743, 1.768, 'VII') 6.071221832
```

У первой частицы файла энергия около 6,07.

---

**Итого.**

- Сначала посмотри на первые строки файла: заголовок, количество записей, запятая в дробях, лишние столбцы.
- Строка разбирается так: `replace(",", ".")`, `split()`, `float` для чисел.
- Первую строку пропускают, только если это заголовок; иначе потеряется точка.
- Характеристику хранят рядом с координатами, а расстояние считают по `[:2]`.
- Код звезды разбирают по позициям, но сначала проверяют, есть ли в нём буква класса.
- Строка частицы — шесть частей: числа `p[0]` … `p[4]` и признак `p[5]`; энергия E = m · (vx² + vy²) / 2.
