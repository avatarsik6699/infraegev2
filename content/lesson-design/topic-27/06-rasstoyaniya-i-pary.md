**После центров ответ чаще всего собирают из расстояний: между центрами, от центра до точек и между самими точками.** С демоверсии 2026 года это главный тип вопроса: расстояния после центров нужны в 17 задачах подборок, диаметры и пары точек — ещё в 9, все 2025–2026 годов. Каждый раз важно ответить на два вопроса: от чего до чего считаем расстояние и среди каких точек выбираем.

Будем считать расстояния в двух кластерах файла `example27.txt`: левый — пять точек с центром (1; 1), правый — три точки с центром (11; 1). Функции `center_sum` (подтема 4), `read_stars`, `parse_kind` (подтема 2) и `split_stars` (подтема 5) считаем определёнными выше в программе.

**Расстояние от центра до точки своего кластера и расстояние до точки другого кластера — разные вычисления.** Возьмём кластеры по размеру: `small` — правый из трёх точек, `big` — левый из пяти, центры уже найдены. Максимальное расстояние от центра малого кластера до точки большого и максимальное расстояние от любого центра до точки **его собственного** кластера:

```python
small = [(10, 0), (12, 0), (11, 1)]
big = [(0, 0), (0, 2), (1, 1), (2, 0), (2, 2)]
clusters = [small, big]
centers = [center_sum(c) for c in clusters]

small_center = centers[0]
answer = max(
    dist(small_center, point)
    for point in big
)
print(answer)

answer = 0.0

for i in range(len(clusters)):
    center = centers[i]

    for point in clusters[i]:
        answer = max(answer, dist(center, point))

print(answer)
```

```output
11.045361017187261
1.4142135623730951
```

Функция `max(a, b)` возвращает большее из двух чисел. Первое число — расстояние от (11; 1) до самой далёкой точки чужого кластера, (0; 0) или (0; 2). Второе — наибольший **радиус**: расстояние от центра до самой далёкой точки своего кластера; у обоих кластеров оно равно √2.

Центры уже вычислены. Внутри этого цикла **их не нужно искать повторно**.

Особенно опасна конструкция вида `max(dist(center_sum(cluster), point) for point in cluster)`: она снова вызывает поиск центра для каждой точки. То, что можно было сделать один раз, повторяется много раз. Сначала `center = center_sum(cluster)`, и только затем `radius = max(dist(center, point) for point in cluster)`.

**Диаметр кластера — обычно максимальное расстояние между двумя его точками.** Но окончательное определение, как всегда, берём из условия: D = max d(A, B), где A и B принадлежат кластеру C. Для перебора пар одного кластера:

```python
def diameter_of(cluster):
    diameter = 0.0

    for i in range(len(cluster)):
        for j in range(i + 1, len(cluster)):
            diameter = max(
                diameter,
                dist(cluster[i], cluster[j])
            )

    return diameter
```

```python
print(diameter_of(small), diameter_of(big))
```

```output
2.0 2.8284271247461903
```

Внутренний цикл начинается с `i + 1`: каждая пара проверяется один раз, а точка не сравнивается сама с собой.

Если требуется не только расстояние, но и координаты точек, образующих диаметр, нужно запоминать найденную пару. У левого кластера диаметр 2√2 дают сразу две пары — две диагонали квадрата; поэтому в задачах, где важны концы диаметра, условие гарантирует, что пара единственная.

Диаметр не обязан совпадать с расстоянием от выбранного центра до самой далёкой точки. Если известен центр и его радиус R, то диаметр не больше 2R, но равенство выполняется не всегда. Поэтому **автоматически писать `diameter = 2 * radius` нельзя**. У правого кластера радиус √2 ≈ 1,414, а диаметр 2 — меньше, чем 2√2.

**Для межкластерного диаметра берут по одной точке из двух разных кластеров.** В подборке он определяется как наибольшее расстояние между такими точками, причём дальнейшие вычисления зависят и от самих концов этого отрезка. Запусти функцию по шагам на двух маленьких кластерах и посмотри, как обновляется лучшая пара: сначала 12 для (0; 0), затем ≈ 12,166 для (0; 2).

```python run farthest_pair.py
from math import dist


def farthest_pair(cluster1, cluster2):
    best_distance = -1.0
    best_pair = None

    for point1 in cluster1:
        for point2 in cluster2:
            d = dist(point1, point2)

            if d > best_distance:
                best_distance = d
                best_pair = (point1, point2)

    return best_distance, best_pair


print(farthest_pair([(0, 0), (0, 2)], [(12, 0)]))
```

```output
(12.165525060596439, ((0, 2), (12, 0)))
```

{{none|`None`}} — специальное значение, означающее, что результат пока не установлен. Оба кластера здесь предполагаются непустыми, поэтому пара обязательно будет найдена. Функция возвращает {{multiret|два значения}}, их раскладывают по именам — и теперь можно вычислить, например, модуль разности абсцисс концов и сумму их ординат:

```python
diameter, pair = farthest_pair(small, big)
point1, point2 = pair

x_difference = abs(point1[0] - point2[0])
y_sum = point1[1] + point2[1]
print(diameter, pair, x_difference, y_sum)
```

```output
12.165525060596439 ((12, 0), (0, 2)) 12 2
```

Если кластеров три, межкластерных диаметров тоже три — по одному на каждую пару кластеров. Пары номеров перебирают так же, как пары точек, — с `i + 1`:

```python
total = 0.0

for i in range(len(clusters)):
    for j in range(i + 1, len(clusters)):
        d, pair = farthest_pair(clusters[i], clusters[j])
        total += d

print(total)
```

```output
12.165525060596439
```

Здесь кластеров два, и сумма состоит из одного диаметра.

Если требуется минимальное расстояние между кластерами, организация похожая, но начальное значение — положительная бесконечность, а сравнение — `<`.

**Расстояние между центрами не заменяет расстояния между крайними или ближайшими точками кластеров.** Здесь расстояние между центрами — 10, а межкластерный диаметр ≈ 12,166.

И ещё: когда нужно найти минимальное расстояние между **различными** точками одного кластера, нельзя включать пару точки с самой собой. Иначе минимум всегда получится нулевым. Для различения записей надёжнее использовать разные индексы. Проверка `point1 != point2` исключит также разные записи с одинаковыми координатами.

**При подсчёте точек около центра нужно точно определить, какие точки разрешено учитывать.** Например, число точек на расстоянии не больше `r` от центра `center`:

```python
count = 0

for point in points:
    if dist(center, point) <= r:
        count += 1
```

Фраза «на плоскости» может означать все допустимые точки файла. Фраза «этого кластера» — только точки соответствующего кластера: `for point in cluster:`. Нельзя менять область перебора по привычке. Слова в условии переводятся буквально:

:::pick Формулировка в условии и проверка в Python
- *меньше r | `dist(center, point) < r`
- не больше r | `dist(center, point) <= r`
- больше r | `dist(center, point) > r`
- не меньше r | `dist(center, point) >= r`
:::

Если центр является одной из перебираемых точек, его расстояние до себя равно нулю. При условии `<= r` и неотрицательном `r` **он будет посчитан**. Это правильно, если условие включает центр. Если требуется считать только остальные точки, его нужно исключить как конкретную запись.

Посчитаем для центра (1; 1) и r = 10 все три варианта:

```python
points = small + big
center = (1, 1)

print(sum(1 for p in points if dist(center, p) <= 10))
print(sum(1 for p in points if dist(center, p) < 10))
print(sum(1 for p in big if dist(center, p) <= 10))
```

```output
7
6
5
```

**Ближайший объект нужного вида ищут среди отобранных точек, а расстояние считают от центра.** В задачах ЕГЭ-2026 спрашивают, например, координаты ближайшего к центру красного гиганта или расстояние между двумя жёлтыми карликами одного кластера. Решение — те же циклы, только перебор идёт по объектам нужного вида. Найдём белый карлик, ближайший к центру самого большого кластера файла `27-3.txt`:

```python
clusters = split_stars(read_stars("27-3.txt"))
big = max(clusters, key=len)
center = center_sum([s[:2] for s in big])

dwarfs = [s for s in big if s[2] == "VII"]
nearest = min(dwarfs, key=lambda s: dist(center, s[:2]))

print(center, len(dwarfs))
print(nearest, dist(center, nearest[:2]))
```

```output
(3.943346, 1.288606) 20
(3.107868, 1.047377, 'VII') 0.8696061861124266
```

Центр ищем по координатам `s[:2]` — **по всем звёздам кластера**, а не только по белым карликам.

`max(clusters, key=len)` возвращает сам кластер с наибольшим числом точек, `min(dwarfs, key=…)` — сам ближайший объект, а не расстояние до него; запись `lambda s: …` — короткая функция для ключа. Если нужен вид, который определяется буквой и светимостью, отбор пишут через `parse_kind`.

Пары объектов одного вида внутри одного кластера перебирают по индексам, как пары точек для диаметра. Наименьшее расстояние между двумя **разными** белыми карликами одного кластера:

```python
best = float("inf")

for cluster in clusters:
    dw = [s[:2] for s in cluster if s[2] == "VII"]

    for i in range(len(dw)):
        for j in range(i + 1, len(dw)):
            best = min(best, dist(dw[i], dw[j]))

print(best)
```

```output
0.014400764736637813
```

Пары из разных кластеров сюда не попадают: список `dw` собирается заново для каждого кластера.

---

**Итого.**

- Радиус — от центра до самой далёкой точки своего кластера; центр ищут один раз, до цикла.
- Диаметр — наибольшее расстояние между двумя точками кластера; пары перебирают с `j` от `i + 1`; диаметр не обязан быть 2R.
- Межкластерный диаметр — по одной точке из двух кластеров; концы пары запоминают вместе с расстоянием.
- Подсчёт в радиусе: сначала определи, среди каких точек считаем и строгое ли неравенство.
- Объекты нужного вида сначала отбирают, потом ищут ближайший или пару — внутри одного кластера.
