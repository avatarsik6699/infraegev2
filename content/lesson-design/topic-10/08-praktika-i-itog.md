**Любая задача задания 10 сводится к одной границе — длине префикса p: её дают в условии или ищут, а программа с модулем `ipaddress` строит сеть для каждой нужной длины.** Ручное рассуждение — «И» одного октета, блок 256 − m, позиции L и C — проверяет ответ программы и помогает не ошибиться в постановке.

Всё главное из подтем собрано на одной схеме. Номер раздела ведёт на его подтему, а ниже схемы порядок решения разобран подробнее.

---

**При решении незнакомой задачи сначала переведи текст в точное условие.**

| Формулировка | Что нужно установить | Средство модуля |
|---|---|---|
| Найти адрес сети | Обнулить узловую часть | `network_address` |
| Найти количество всех адресов | Посчитать нули маски и вычислить 2ʰ | `num_addresses` |
| Найти количество обычных узлов | Учесть исключение двух специальных адресов | `num_addresses - 2` |
| Наибольший или наименьший адрес компьютера | Края сети без особых адресов | `broadcast_address - 1`, `network_address + 1` |
| Найти номер узла | Вычислить значение узловой части | `int(a) - int(net.network_address)` |
| Найти маску по IP и сети | Найти допустимые положения границы | перебор `p`, сравнение `network_address` |
| Два адреса в одной сети | Их сетевые части при общей маске совпадают | две сети, `==` |
| Два адреса в разных сетях | Их сетевые части при общей маске различаются | две сети, `!=` |
| Максимум или минимум адресов | Максимум или минимум свободных битов среди допустимых масок | `min` или `max` найденных `p` |
| Адреса с определёнными битовыми свойствами | Отделить фиксированный вклад от свободного | `for a in net`, `format(…, '032b')` |

---

**Дальше удобно придерживаться одной последовательности из пяти шагов.**

1. **Запиши, что дано и что требуется.** Особенно выдели слова «все», «компьютеров», «наименьшее», «наибольшее», «каждый».
2. **Определи известную границу или ограничения на неё.** Маска задана прямо либо её нужно восстановить.
3. **Работай с нужными октетами.** Октеты маски 255 сохраняют данные, нулевые — обнуляют. Полное двоичное преобразование часто не требуется.
4. **Получив кандидата, подставь его обратно.** Вычисленный адрес сети должен совпасть с условием.
5. **Проверь формат ответа.** Нужен целый адрес, один октет, число нулей, количество адресов, последовательность букв, сумма октетов или адрес без точек?

Полезные проверки результата:

- IP-адрес должен попадать между первым и последним адресами найденной сети;
- в адресе сети все узловые биты должны быть нулевыми;
- количество всех адресов должно быть степенью двойки;
- если увеличили длину префикса на один, количество адресов должно уменьшиться вдвое;
- подходящая маска не должна содержать единицы после первого нуля.

---

**Самые частые ошибки связаны с подменой одного понятия другим.** Выбери ошибку, чтобы увидеть, как рассуждать правильно:

:::pick Ошибка и как рассуждать правильно
- *три октета | сеть — это всегда первые три октета | число сетевых битов задаёт маска
- нули адреса | нули в адресе — это часть узла | положение части узла определяется маской, а не значениями битов IP
- /26 | в `/26` свободны 26 битов | свободны 32 − 26 = 6
- совпали октеты | одинаковые октеты IP и сети означают маску 255 | совпадение нулей не определяет соответствующие биты маски
- октеты по отдельности | в маске можно независимо выбрать любой допустимый октет | нужно соблюдать непрерывность единиц во всех 32 битах
- .0 | любой адрес `.0` — адрес сети | нулевой должна быть вся часть узла
- .255 | любой адрес `.255` — широковещательный | единичной должна быть вся часть узла
- минус два | после любого подсчёта вычитаем два | сначала проверяем, что именно считали и входили ли туда специальные адреса
- номер узла | номер узла равен последнему октету | часть узла может занимать несколько октетов
- после различия | после первого различия продолжаем искать совпадающие сетевые биты | префикс непрерывен, поэтому первое различие уже ограничивает его длину
- узел — край сети | самая длинная общая маска всегда `/C` | узел не может быть адресом сети или широковещательным — проверь края
- strict | `ip_network('…/26')` без `strict=False` для адреса узла | без него программа остановится: узловые биты адреса не нулевые
:::

**Задачи основных подтем в формате экзамена.** Подсказка в скобках называет подтему, приём которой нужен.

1. Узел имеет IP-адрес 93.180.214.77. Маска сети равна 255.255.255.192. Определите адрес сети и в ответе запишите сумму значений его октетов. (Подтема 2: адрес сети.)
2. Для узла с IP-адресом 140.33.118.46 адрес сети равен 140.33.112.0. Каково наименьшее возможное количество единиц в разрядах маски? (Подтема 4: L ≤ p ≤ C.)
3. Узлы с IP-адресами 66.12.250.3 и 66.12.236.190 находятся в одной сети. Укажите наибольшее возможное значение третьего слева байта маски этой сети. (Подтема 5: совпадающие биты.)
4. Сеть задана IP-адресом 150.8.64.0 и маской сети 255.255.255.224. Сколько в этой сети IP-адресов, для которых количество единиц в двоичной записи кратно 5? (Подтема 6: подсчёт по битам.)
5. Сеть задана IP-адресом одного из входящих в неё узлов 31.87.140.250 и сетевой маской 255.255.248.0. Найдите наибольший IP-адрес этой сети, который может быть назначен компьютеру. В ответе укажите найденный адрес без разделителей. (Подтема 2: края сети и форма ответа.)

**Ответы для проверки:**

1. 551: 77 И 192 = 64, адрес сети 93.180.214.64, 93 + 180 + 214 + 64.
2. 20: 118 = `01110110`, 112 = `01110000`, L = 20, C = 21, маски `/20` и `/21`.
3. 224: 250 = `11111010`, 236 = `11101100`, C = 16 + 3 = 19, маска `/19`.
4. 5: в фиксированной части 4 + 1 + 1 = 6 единиц, всего нужно 10, значит, в пяти свободных битах ровно один ноль — пять вариантов его места.
5. 3187143254: d = 8, 140 лежит в блоке 136–143, широковещательный 31.87.143.255, наибольший адрес компьютера 31.87.143.254.

**Что дальше.** Если задачи этой страницы получаются, основные подтемы освоены. Дополнительный урок 7 нужен для редких задач, где маску задаёт условие на биты адреса сети, маски или номера узла, а адреса большой сети считаются сочетаниями.
