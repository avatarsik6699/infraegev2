**Сетевые биты одинаковы у всех адресов сети, поэтому их вклад можно посчитать один раз, а затем исследовать свободные биты.** Программа просто перебирает адреса сети и проверяет условие для каждого, а рассуждение о фиксированных и свободных битах проверяет её ответ. Это 12 задач из 87, в том числе демоверсия и досрочная волна ЕГЭ-2024, пробный ЕГЭ 2025 и СтатГрад 2025.

Пример подтемы — сеть 192.168.10.0/28: 16 адресов от 192.168.10.0 до 192.168.10.15. Сеть и её края (подтема 2), маска по адресу сети (подтема 4) и два узла (подтема 5) считаем известными.

---

**Условия на двоичную запись требуют отделить фиксированные биты от свободных.** Могут спрашивать количество адресов с определённым числом единиц, с чётным числом единиц, с количеством нулей, кратным некоторому числу, с определённым соотношением единиц в разных частях адреса.

В сети `192.168.10.0/28` h = 32 − 28 = 4, всего 2⁴ = 16 адресов. Посчитаем единицы в фиксированной части: 192 = `11000000` — 2, 168 = `10101000` — 3, 10 = `00001010` — 2, первые четыре бита последнего октета `0000` — 0. Всего 2 + 3 + 2 = 7.

**Важно: 28 сетевых битов не означают 28 единиц в адресе.** Число 28 говорит, сколько позиций фиксировано. Среди их значений есть и нули, и единицы.

---

**Число единиц адреса — фиксированные единицы плюс единицы свободной части.** Пусть требуется ровно девять единиц во всём адресе. Семь уже находятся в фиксированной части. Значит, в четырёх свободных битах нужны 9 − 7 = 2 единицы. Подходят `0011`, `0101`, `0110`, `1001`, `1010`, `1100` — последние октеты 3, 5, 6, 9, 10, 12. Ответ — шесть адресов.

Программа перебирает все адреса сети: `for address in net` даёт их по очереди, от `.0` до `.15`, включая оба граничных. Для каждого берём 32 бита ({{format|format}}) и считаем символы `'1'` ({{strmeth|count}}); `count += 1` увеличивает счётчик найденных адресов ({{augassign|+=}}):

```python
from ipaddress import ip_network

net = ip_network('192.168.10.0/28')
count = 0
for address in net:
    bits = format(int(address), '032b')
    if bits.count('1') == 9:
        count += 1
print(count)
```

```output
6
```

Почему шесть и как считать без перебора при большом количестве битов, разбирает дополнительная подтема 7: это число способов выбрать две позиции из четырёх.

---

**Для чётности количества единиц часто достаточно рассуждения без перебора.** В нашем примере фиксированная часть содержит семь единиц — нечётное количество. Чтобы во всём адресе число единиц было чётным, в свободной части их должно быть нечётное количество: нечётное + нечётное = чётное.

Из всех комбинаций хотя бы одного свободного бита **ровно половина имеет чётное число единиц, а половина — нечётное.** Это видно, если разбить варианты на пары, отличающиеся только последним битом. При четырёх свободных битах 2⁴ / 2 = 8 — восемь адресов с чётным числом единиц.

<figcaption>Все 16 вариантов четырёх свободных битов сети 192.168.10.0/28 парами, отличающимися последним битом. Рядом — число единиц всего адреса (7 фиксированных плюс свободные): в каждой паре одно чётное и одно нечётное, всего 8 чётных.</figcaption>
</figure>

<details class="proof" markdown="1">
<summary>Почему ровно половина — для любого числа свободных битов</summary>

Разобьём варианты на пары, меняя один выбранный свободный бит: все остальные биты оставляем одинаковыми, в одном варианте выбранный бит равен `0`, в другом — `1`. Количество единиц отличается на один. Значит, в каждой паре один вариант имеет чётное количество единиц, другой — нечётное, и чётных ровно половина.

</details>

Чётность проверяют остатком от деления на 2 ({{intdiv|%}}): число чётное, если остаток от его деления на 2 равен нулю, — `bits.count('1') % 2 == 0`.

**Чётность самого адреса и чётность количества единиц — разные свойства.** Например, число 3 нечётное, но 3 = 11₂, и единиц в его записи две — чётное количество. Если спрашивают чётность числового значения, достаточно последнего бита. Если спрашивают чётность числа единиц, нужно считать единицы.

---

**При исключении специальных адресов проверяй каждый из них по дополнительному условию.** У сети `192.168.10.0/28` адрес сети содержит 7 единиц, последний адрес — 7 + 4 = 11 единиц. Оба количества нечётные. Следовательно, адресов с чётным числом единиц всего 8, и среди обычных узлов их тоже 8: ни один специальный адрес в эти восемь не входил. А для нечётного количества: всего 8, после исключения двух специальных остаётся 6.

Если нужны только обычные узлы, меняется источник перебора: `net.hosts()` даёт адреса без адреса сети и широковещательного, для этой `/28` — от `.1` до `.14`:

```python
from ipaddress import ip_network

net = ip_network('192.168.10.0/28')
even = odd = 0
for address in net.hosts():
    ones = format(int(address), '032b').count('1')
    if ones % 2 == 0:
        even += 1
    else:
        odd += 1
print(even, odd)
```

```output
8 6
```

**Поэтому механическое «посчитал подходящие адреса и вычел два» может дать неверный результат.** У `.hosts()` есть особое поведение для `/31` и `/32`, соответствующее особенностям этих сетей (подтема 2).

---

**Условие на часть адреса проверяют на части строки из 32 битов.** Полезные проверки собраны в переключателе — выбери условие:

:::pick Условие → проверка
- *ровно 12 единиц | `bits.count('1') == 12`
- не менее 12 единиц | `bits.count('1') >= 12`
- не более 12 единиц | `bits.count('1') <= 12`
- чётное число единиц | `bits.count('1') % 2 == 0`
- число единиц кратно 3 | `bits.count('1') % 3 == 0` | «кратно 3» — делится на 3 без остатка
- ровно 20 нулей | `bits.count('0') == 20`
- нулей больше, чем единиц | `bits.count('0') > bits.count('1')`
- единиц от 10 до 15 | `bits.count('1') >= 10 and bits.count('1') <= 15` | `and` соединяет условия и не заменяет `&`
:::

Для условий на части адреса выделяют части строки ({{slice|срезы}}): `bits[:16]` — первые 16 символов, то есть первые два октета; `bits[16:]` — символы начиная с индекса 16 и до конца, то есть последние 16 битов. Индексы начинаются с нуля, поэтому первые 16 символов имеют индексы от 0 до 15. Один октет — восемь символов: третий октет — `bits[16:24]`. Например, проверим, в скольких адресах нашей сети в первых двух октетах единиц больше, чем в последних двух:

```python
from ipaddress import ip_network

net = ip_network('192.168.10.0/28')
count = 0
for address in net:
    bits = format(int(address), '032b')
    left = bits[:16]
    right = bits[16:]
    if left.count('1') > right.count('1'):
        count += 1
print(count)
```

```output
11
```

Проверка рассуждением: слева 2 + 3 = 5 единиц у всех адресов, справа 2 + свободные. Нужно 2 + s < 5, то есть в свободных битах не больше двух единиц: 1 + 4 + 6 = 11 вариантов.

---

**Условия «для всех адресов» удобно проверять через крайние значения.** Если фиксированная часть содержит c единиц, а свободных битов h, то среди всех адресов минимум единиц — c, максимум — c + h. Минимум достигается при нулевой свободной части, максимум — при единичной.

Например, чтобы **каждый адрес** содержал не больше 15 единиц, достаточно проверить c + h ≤ 15. Чтобы **каждый адрес** содержал хотя бы 10 единиц — c ≥ 10. Если рассматриваются только обычные узлы с исключением обоих крайних адресов и h ≥ 2, границы будут c + 1 и c + h − 1. В нашей сети c = 7, h = 4: у всех адресов от 7 до 11 единиц, у обычных узлов — от 8 до 10.

Слова «каждый», «хотя бы один» и «сколько» задают разные задачи: «каждый» — условие не должно нарушиться ни для одного адреса; «хотя бы один» — достаточно одного подходящего; «сколько» — нужно посчитать все подходящие.

---

**Если нужен наименьший подходящий адрес, перебор идёт по порядку и останавливается на первом.** `hosts()` выдаёт адреса по возрастанию, поэтому первый подходящий и есть наименьший ({{break|break}}). Найдём наименьший адрес компьютера нашей сети, в записи которого ровно девять единиц. Запусти по шагам:

```python run first.py
from ipaddress import ip_network

net = ip_network('192.168.10.0/28')
for address in net.hosts():
    bits = format(int(address), '032b')
    if bits.count('1') == 9:
        break
print(address)
```

```output
192.168.10.3
```

Для наибольшего значения, например наибольшей суммы октетов среди подходящих адресов, перебор идёт до конца, а лучший результат обновляется ({{agg|max}}). Октеты получаются так же, как в подтеме 2:

```python
from ipaddress import ip_network

net = ip_network('192.168.10.0/28')
best = 0
for address in net.hosts():
    bits = format(int(address), '032b')
    if bits.count('1') == 9:
        octets = str(address).split('.')
        best = max(best, sum(int(x) for x in octets))
print(best)
```

```output
382
```

Подходящие последние октеты — 3, 5, 6, 9, 10, 12; наибольшая сумма у 192.168.10.12: 192 + 168 + 10 + 12 = 382.

---

**Перед перебором всех адресов оцени его размер.** Перебор всех 33 масок — маленькая задача. Перебор всех адресов может быть большим: `/28` — 16 адресов, `/24` — 256, `/16` — 65 536, `/8` — 16 777 216. Сеть `/12` — около миллиона адресов, программа проверит их за несколько секунд.

Если требуется только общее количество, используй формулу или `net.num_addresses`. Если условие сводится к выбору позиций единиц, можно применить сочетания (подтема 7). Полный перебор полезен там, где его объём разумен и условие проще непосредственно проверить.

---

**Если маска не задана, сначала выбирают крайнюю допустимую маску, а потом считают адреса в её сети.** Сеть с более длинной маской целиком лежит внутри сети с более короткой. Поэтому **наименьшее количество** подходящих адресов — в самой маленькой допустимой сети (наибольшее p), а **наибольшее** — в самой большой (наименьшее p).

Например, узлы 192.168.10.5 и 192.168.10.9 находятся в одной сети. Наименьшее число адресов этой сети, в записи которых ровно девять единиц? Последние октеты 5 = `00000101` и 9 = `00001001` совпадают в первых четырёх битах: C = 28 (подтема 5). Самая маленькая общая сеть — наша `192.168.10.0/28`, и ответ — те же 6 адресов. Программа ищет наибольшее подходящее `p` и считает адреса в этой сети:

```python
from ipaddress import ip_address, ip_network

a = ip_address('192.168.10.5')
b = ip_address('192.168.10.9')
best = 0
for p in range(33):
    net = ip_network(f'{a}/{p}', strict=False)
    ends = (net.network_address, net.broadcast_address)
    if b in net and a not in ends and b not in ends:
        best = p
net = ip_network(f'{a}/{best}', strict=False)
count = 0
for address in net:
    if format(int(address), '032b').count('1') == 9:
        count += 1
print(best, count)
```

```output
28 6
```

**Наибольшее значение ищут в самой большой допустимой сети.** Пусть для узла 192.168.10.5 адрес сети равен 192.168.10.0. Каково наибольшее число единиц в адресе, который можно назначить компьютеру этой сети? Подходящие маски — от `/23` до `/29` (подтема 4), самая большая сеть — `/23`: c = 2 + 3 + 2 = 7, h = 9, наибольшее у обычного узла c + h − 1 = 15. Программа подтверждает:

```python
from ipaddress import ip_address, ip_network

ip = '192.168.10.5'
expected = ip_address('192.168.10.0')
found = []
for p in range(33):
    net = ip_network(f'{ip}/{p}', strict=False)
    if net.network_address == expected:
        found.append(p)
net = ip_network(f'{ip}/{min(found)}', strict=False)
best = 0
for address in net.hosts():
    best = max(best, format(int(address), '032b').count('1'))
print(min(found), max(found), best)
```

```output
23 29 15
```

---

**Итого.**

- Фиксированные биты дают всем адресам одни и те же c единиц; условие проверяется на свободных битах.
- Программа: `for address in net` (или `net.hosts()`), `format(int(address), '032b')`, `count('1')`, `%`, срезы `bits[16:24]`.
- Половина вариантов свободных битов — с чётным числом единиц; особые адреса проверяются по условию, а не вычитаются вслепую.
- У всех адресов от c до c + h единиц, у обычных узлов — от c + 1 до c + h − 1.
- Наименьший подходящий — первый в переборе с `break`; наибольший — обновление лучшего до конца.
- Маска не задана: наименьший результат — в самой маленькой допустимой сети, наибольший — в самой большой.
