**Рекурсия часто считает понятную величину — сумму цифр, количество единиц, число множителей; когда смысл найден, огромный перебор заменяется подсчётом вариантов записи.** Так решаются задачи вида «сколько чисел до 10⁹ дают F(n) = 2» или «сколько n на отрезке длиной в миллиард дают F(n) > F(n + 1)».

Почти всё время будем смотреть на функцию F(0) = 0, F(n) = F(n // 10) + n mod 10 и число 472: F(472) = 13.

---

**Деление аргумента на основание системы счисления часто означает обработку цифр числа.** Начнём с десятичной записи. Для числа 472 выражение `472 // 10` даёт 47, а `472 % 10` даёт 2 ({{intdiv|целая часть и остаток}}). То есть:

- `n // 10` удаляет последнюю десятичную цифру;
- `n % 10` извлекает последнюю десятичную цифру.

Это следует из равенства 472 = 47 · 10 + 2.

Теперь рассмотрим:

F(0) = 0;  
F(n) = F(n // 10) + n mod 10, n > 0.

Для 472: F(472) = F(47) + 2, F(47) = F(4) + 7, F(4) = F(0) + 4. В итоге F(472) = 4 + 7 + 2 = 13. Следовательно, функция вычисляет **сумму десятичных цифр**.

В другой формулировке может быть: F(n) = n, n < 10; F(n) = F(n mod 10) + F(n // 10), n ≥ 10. Здесь n mod 10 — одна цифра, поэтому к ней сразу применяется база: F(n mod 10) = n mod 10. Получается тот же смысл — сумма цифр.

Для произвольного основания b: n = bq + r, 0 ≤ r < b. Здесь q = n // b, r = n mod b. Поэтому:

- `n // b` удаляет последнюю цифру записи в основании b;
- `n % b` возвращает эту цифру.

Несколько распространённых случаев при базе F(0) = 0:

:::pick Правило для n > 0 и его смысл
- *F(n) = F(n // 10) + n mod 10 | Сумма десятичных цифр
- F(n) = F(n // 2) + n mod 2 | Количество единиц в двоичной записи
- F(n) = 1 + F(n // 10) | Количество десятичных цифр положительного числа
- F(n) = 1 + F(n // b) | Количество цифр положительного числа в основании b
:::

Для последнего типа F(0) = 0 — заданная база алгоритма. Это не утверждение, что обычная запись числа 0 не содержит цифр.

Если в рекурсии встречается `n // 100`, за один шаг удаляются две десятичные цифры. В таких задачах особенно внимательно следи, какие позиции обрабатываются и от какого конца числа они отсчитываются.

---

**Рекурсия по двоичным цифрам может превратить перебор чисел в подсчёт вариантов записи.** Пусть F(0) = 0; F(n) = F(n // 2) + n mod 2, n > 0. Она складывает двоичные цифры. Поскольку каждая из них равна 0 или 1, результат равен **количеству единиц**.

Например, 27 = 11011₂, поэтому F(27) = 4. Рекурсивно: F(27) = F(13) + 1, F(13) = F(6) + 1, F(6) = F(3) + 0, F(3) = F(1) + 1, F(1) = F(0) + 1. Всего прибавлены четыре единицы.

Иногда условие записывают так:

F(n) = F(n / 2), n > 0 чётно;  
F(n) = 1 + F(n − 1), n нечётно.

Для нечётного n > 1 число n − 1 чётно, и следующий шаг делит его на 2. В результате снова обрабатывается последняя двоичная цифра. Для n = 1 сразу достигается база F(0).

В подтеме 4 перебор показал: среди чисел 1 ≤ n ≤ 63 условию F(n) = 2 удовлетворяют 15. Но можно рассуждать через двоичную запись.

Все числа от 0 до 63 представляются шестью двоичными цифрами, если разрешить дописывать слева нули. Нужно **выбрать две позиции для единиц**.

Первую можно выбрать шестью способами, вторую — пятью. Получается 6 · 5, но каждая пара посчитана дважды: сначала одна позиция, потом другая, и наоборот. Поэтому 6 · 5 / 2 = 15.

Число 0 не подходит, поэтому его включение в рассуждение не меняет ответ.

---

**Если учитываются только некоторые цифры, нужно выяснить вклад каждой цифры отдельно.** Например, F(0) = 0, а при n > 0:

F(n) = F(n // 10) + n mod 10, если n чётно;  
F(n) = F(n // 10), если n нечётно.

Чётность десятичного числа определяется его последней цифрой. Поэтому на каждом шаге:

- чётная последняя цифра прибавляется;
- нечётная пропускается;
- затем последняя цифра удаляется.

Значит, функция вычисляет **сумму чётных цифр**.

Когда результат равен нулю? Все слагаемые неотрицательны. Поэтому положительных чётных цифр в записи быть не должно. Разрешены 0, 1, 3, 5, 7, 9. Ноль разрешён: он не увеличивает сумму.

Например, количество трёхзначных чисел с такой записью:

- первая цифра — одна из 1, 3, 5, 7, 9: пять вариантов;
- вторая — любая из шести разрешённых;
- третья — любая из шести разрешённых.

Получаем 5 · 6 · 6 = 180. Умножение используется потому, что каждый выбор первой цифры можно сочетать с каждым выбором второй и третьей.

Если задан произвольный числовой интервал, его границы нужно учитывать отдельно. Число допустимых цифр на каждой позиции тогда может зависеть от уже выбранных старших цифр.

**Сравнение F(n) и F(n + 1) часто связано с переносом между разрядами.** Пусть F(n) — сумма десятичных цифр.

Если последняя цифра n меньше 9, при прибавлении единицы она просто увеличивается на 1. Поэтому F(n + 1) = F(n) + 1. Например, 243 → 244: сумма цифр 9 → 10.

Если число оканчивается девятками, появляется перенос: 2399 → 2400. Пусть в конце числа стоит t девяток. При прибавлении единицы:

- эти девятки превращаются в нули: сумма уменьшается на 9t;
- предыдущая цифра увеличивается на 1, либо появляется новая ведущая единица.

<figure class="plate-figure">
%%rec_carry(2399)%%
<figcaption>2399 → 2400: две девятки в конце стали нулями (по −9), тройка перед ними стала четвёркой (+1). Сумма цифр 23 → 6, изменение 1 − 9 · 2 = −17.</figcaption>
</figure>

Поэтому F(n + 1) = F(n) + 1 − 9t. Следовательно, F(n) > F(n + 1) тогда и только тогда, когда в конце есть хотя бы одна девятка, то есть n mod 10 = 9.

Теперь вместо вычисления рекурсивной функции для огромного диапазона можно посчитать числа 9, 19, 29, … На отрезке [L, R], где L ≥ 1, их количество — `(R + 1) // 10 - L // 10`. Например, для 123 ≤ n ≤ 987: 98 − 12 = 86. Сверим с перебором:

```python
def F(n):
    if n == 0:
        return 0
    return F(n // 10) + n % 10


L, R = 123, 987
count = 0

for n in range(L, R + 1):
    if F(n) > F(n + 1):
        count += 1

print(count, (R + 1) // 10 - L // 10)
```

```output
86 86
```

Почему формула такая? Чисел с последней цифрой 9, не превышающих R, ровно ⌊(R + 1) / 10⌋. Из них вычитаем такие числа, меньшие L: ⌊L / 10⌋. Знак ⌊x⌋ обозначает наибольшее целое число, не превосходящее x, то есть округление вниз.

**Вклад цифры может отличаться от самой цифры — тогда составь таблицу этих вкладов.** Например, при делении аргумента на 4 могут действовать правила:

- остаток 0 добавляет 0;
- остаток 1 добавляет 1;
- остаток 2 добавляет 1;
- остаток 3 добавляет 2.

Это обработка четверичных цифр с такими вкладами:

| Цифра | 0 | 1 | 2 | 3 |
|---|---:|---:|---:|---:|
| Вклад | 0 | 1 | 1 | 2 |

Функция вычисляет сумму вкладов цифр.

При увеличении числа на 1 конечные тройки превращаются в нули. **Каждая такая замена уменьшает результат на 2.** Изменение предыдущей цифры даёт:

- 0 → 1 — вклад +1;
- 1 → 2 — вклад не меняется;
- 2 → 3 — вклад +1.

Так можно анализировать условия сразу для F(n) и F(n + 1).

Например, требуется минимальное n, для которого F(n) = 7, F(n + 1) = 4. **Результат должен уменьшиться на 3.** Две конечные тройки дадут уменьшение на 4, а переход предыдущей цифры 0 → 1 или 2 → 3 добавит 1. Получится нужное изменение: −4 + 1 = −3.

Если взять окончание 233₄, его вклад 1 + 2 + 2 = 5. До общей суммы 7 не хватает 2. Минимальная запись из одной цифры с вкладом 2 — это 3. Получаем n = 3233₄.

Проверка: F(n) = 2 + 1 + 2 + 2 = 7; n + 1 = 3300₄; F(n + 1) = 2 + 2 = 4.

Окончание 033₄ потребовало бы более длинной записи: для недостающего вклада 3 одной цифры недостаточно. Следовательно, минимальное подходящее число 3233₄ = 3 · 4³ + 2 · 4² + 3 · 4 + 3 = 239.

Здесь мы использовали рекурсивное определение для выяснения смысла функции, а дальнейшее решение построили на устройстве записи числа.

**Рекурсия с делением на простые числа может считать их множители в разложении аргумента.** Рассмотрим функцию для натуральных n:

- если n чётно, F(n) = F(n / 2) + 3;
- иначе, если n делится на 3, F(n) = F(n / 3) + 2;
- иначе F(n) = 0.

Пусть число представлено как n = 2ᵃ · 3ᵇ · c, где c не делится ни на 2, ни на 3. Здесь:

- a — сколько множителей 2 входит в число;
- b — сколько множителей 3;
- c — оставшаяся часть.

Например, 72 = 2³ · 3². Каждое деление на 2 убирает один множитель 2 и прибавляет 3 — таких делений a. Каждое деление на 3 убирает один множитель 3 и прибавляет 2 — таких делений b. Следовательно, **F(n) = 3a + 2b**.

Найдём минимальное n, для которого F(n) = 14. Нужно 3a + 2b = 14, где a, b — целые неотрицательные числа. Подходящие пары:

| a | b | Минимальное число при этих показателях |
|---:|---:|---:|
| 0 | 7 | 3⁷ = 2187 |
| 2 | 4 | 2² · 3⁴ = 324 |
| 4 | 1 | 2⁴ · 3 = 48 |

Почему в последнем столбце нет множителя c? Для минимума выбираем c = 1. Любой больший положительный c увеличит число, не изменив значение функции. Ответ: 48.

Перебор всех натуральных чисел заменён перебором нескольких показателей степеней.

---

**Закономерность, замеченную по нескольким значениям, полезно доказать через само рекуррентное соотношение.** Пусть F(1) = 1; F(n) = F(n − 1) + 2n − 1, n > 1. Первые значения: 1, 4, 9, 16, … Похоже, что F(n) = n².

Но **несколько совпадений ещё не доказывают формулу** для всех аргументов. Проверим два пункта.

Для начального значения: F(1) = 1 = 1². Теперь допустим, что для предыдущего аргумента уже верно F(n − 1) = (n − 1)². Тогда по условию F(n) = (n − 1)² + 2n − 1. Раскрываем квадрат: F(n) = n² − 2n + 1 + 2n − 1 = n².

Получилось:

- формула верна в начале;
- если она верна на предыдущем шаге, то верна и на следующем.

Такой способ доказательства называют **математической индукцией**.

На том же принципе основана корректность табличного решения из подтемы 3: сначала записываются правильные базовые значения, затем из уже правильных результатов получается следующее правильное значение.

---

**Итого.**

- `n // b` и `n % b` в рекурсии — снятие последней цифры записи в основании b: функция складывает, считает или перемножает цифры.
- Количество чисел с заданным числом двоичных единиц — выбор позиций: из k позиций две выбираются k(k − 1) / 2 способами.
- Если цифры разрешены по правилу, количество чисел — произведение числа вариантов на каждой позиции, с отдельным учётом границ.
- F(n + 1) − F(n) для суммы цифр равно 1 − 9t, где t — число девяток в конце n.
- Деления на 2 и 3 считают показатели степеней: перебирают показатели, а не числа.
- Формулу, угаданную по первым значениям, доказывают индукцией.
