**Любая задача задания 16 решается одним порядком рассуждений: понять, что требуется, выяснить зависимости между значениями и только потом выбрать способ вычисления.** Ошибки удобнее ловить на маленьких аргументах, раскрыв несколько шагов руками, чем на большом ответе программы.

Всё главное из подтем собрано на одной схеме. Номер раздела ведёт на его подтему, а ниже схемы каждый шаг разобран подробнее.

%%cheatsheet("topic-16/cheatsheet.json")%%

---

**Для выбора решения удобно пользоваться одним и тем же порядком рассуждений.**

1. **Прочитай, что требуется получить.** Одно значение, разность, отношение, количество аргументов, минимальный аргумент или характеристику выполнения программы.
2. **Выпиши допустимые аргументы и базовые случаи.** Обрати внимание на 0, отрицательные значения, строгие и нестрогие неравенства.
3. **Определи зависимости.** Какие именно значения нужны для вычисления текущего? Уменьшаются аргументы, увеличиваются или меняются сложнее?
4. **Раскрой несколько шагов вручную.** Это помогает увидеть смысл функции, проверить условия и обнаружить сокращение.
5. **Выбери способ вычисления** — по тому, что видно из задачи (переключатель ниже).
6. **Проверь реализацию на маленьких аргументах.** Сравни несколько результатов с ручным вычислением.
7. **Вычисли именно требуемую величину.** Например, если в условии отношение, выведи отношение, а не два значения функции по отдельности.

:::pick Что видно из задачи и что стоит попробовать
- *Несколько небольших значений | Ручная таблица (подтема 1)
- Разность близких значений | Раскрытие прибавлений и сокращение (подтема 5)
- Отношение значений, связанных умножением | Выделение общего множителя (подтема 5)
- Много значений, зависимости ведут назад | Таблица по возрастанию (подтема 3)
- Зависимости ведут к большим аргументам | Вычисление от верхней базы (подтемы 2 и 3)
- Одни и те же подзадачи повторяются | Кэширование (подтема 4)
- Огромный аргумент быстро делится | Короткая рекурсия или цикл по цепочке (подтемы 4 и 5)
- Деление на основание системы счисления | Анализ цифр (подтема 6)
- Огромный диапазон аргументов | Математический подсчёт или подсчёт по цифрам (подтемы 6 и 7)
:::

Это универсальный порядок анализа. Конкретный код выбирается после выяснения зависимостей.

---

**Особенно полезно научиться замечать ошибки, которые программа может не обнаружить сама.** Выбери ошибку, чтобы увидеть, как себя проверить:

:::pick Ошибка и что проверить
- *F(n) − 1 вместо F(n − 1) | Где именно находится вычитание
- Неверно выбрана ветвь | Условие проверяется для текущего аргумента
- Перепутаны `<` и `<=` | Какой случай действует прямо на границе
- Не хватает базы | К каким аргументам реально приводят переходы
- `range` не дошёл до нужного значения | Правая граница не включается
- Список слишком короткий | Для индекса N нужны как минимум N + 1 элементов
- Использовано ещё не вычисленное значение | Правильно ли выбран порядок заполнения
- `f[-1]` принято за F(−1) | В Python это последний элемент списка
- Значение затёрто раньше времени | Сначала вычислить новое, потом обновлять старые
- `print` вместо `return` | Передаётся ли результат вызывающему коду
- `/` потерял точность | Является ли деление точным целочисленным
- `//` отбросило дробную часть | Допускает ли условие дробные промежуточные значения
- Кэш есть, а ошибка глубины осталась | Повторения и глубина — разные проблемы
- Поиск остановлен при F(n) > K | Доказано ли, что функция дальше не уменьшится
:::

При отладке таблицы иногда удобно заполнять её сначала значениями {{none|`None`}}: `f = [None] * (N + 1)`. Тогда попытка использовать незаполненное место в арифметике чаще проявится как ошибка, а не даст незаметно неверный результат из-за заготовленного нуля.

**Задачи основных подтем в формате экзамена.** Подсказка в скобках называет подтему, приём которой нужен.

1. Алгоритм вычисления значения функции F(n), где n — натуральное число, задан следующими соотношениями: F(n) = 2 при n = 1; F(n) = F(n − 1) + n, если n чётно; F(n) = 2 · F(n − 2) + n, если n > 1 и при этом n нечётно. Чему равно значение функции F(21)? (Подтема 2: ветвь для каждого вызова.)
2. Алгоритм вычисления значения функции F(n), где n — натуральное число, задан следующими соотношениями: F(n) = 1 при n = 1; F(n) = (n − 1) · F(n − 1), если n > 1. Чему равно значение выражения (F(2027) + 4 · F(2026)) / F(2025)? (Подтема 5: общий множитель.)
3. Алгоритм вычисления значения функции F(n), где n — натуральное число, задан следующими соотношениями: F(n) = n при n < 7; F(n) = n + 2 + F(n − 3), если n ≥ 7. Чему равно значение выражения F(4000) − F(3991)? (Подтема 5: разность.)
4. Алгоритм вычисления значения функции F(n), где n — целое неотрицательное число, задан следующими соотношениями: F(0) = 0; F(n) = F(n / 3), если n > 0 и n делится на 3; F(n) = (n mod 3) + F(n − (n mod 3)), если n не делится на 3. Назовите минимальное значение n, для которого F(n) = 9. (Подтема 4: перебор до первого совпадения.)
5. Алгоритм вычисления значений функций F(n) и G(n), где n — целое число, задан следующими соотношениями: F(n) = F(n − 3) + 7, если n ≥ 15; F(n) = 4 · (G(n + 2) − 3), если n < 15; G(n) = n / 4, если n ≥ 50; G(n) = G(n + 5) + 3, если n < 50. Чему равно значение функции F(100)? (Подтемы 3 и 5: две функции, точное деление.)

**Ответы для проверки:**

1. 7143: F(21) = 2 · F(19) + 21 = 2 · 3561 + 21; ветвь выбирается для каждого аргумента, первые значения 2, 4, 7, 11, 19, 25, 45.
2. 4110750: F(2027) = 2026 · F(2026), числитель равен 2030 · F(2026) = 2030 · 2025 · F(2025).
3. 11997: F(4000) = 4002 + 3999 + 3996 + F(3991).
4. 161: 161 = 12222₃, сумма троичных цифр 1 + 2 + 2 + 2 + 2 = 9; все меньшие n дают F(n) < 9.
5. 325: от 100 до 13 двадцать девять переходов F дают 203; G(15) = G(50) + 7 · 3 = 12,5 + 21 = 33,5, F(13) = 4 · 30,5 = 122. С `//` в базе G получилось бы 323.
