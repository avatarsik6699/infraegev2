**Рекурсивную функцию пишут прямо по определению, но сначала проверяют, что все вызовы дойдут до базы, а ветвь выбирают заново для каждого вызова.** С программой считаются значения, которые вручную считать долго: ветви по чётности или остатку есть в 19 задачах подборок, в том числе на экзаменах 2021, 2022 и 2026 годов.

Начнём с той же функции, что в подтеме 1: F(1) = 2, F(n) = F(n − 1) + 3n, F(4) = 29. Потом проверим, все ли вызовы доходят до базы, и добавим ветви.

---

**Рекурсивная функция повторяет определение: база — `return` без нового вызова, соотношение — `return` с вызовом той же функции.** Переведём пример на Python. Функцию описывает {{def|`def`}}: `def F(n):` — функция с именем `F` и **параметром** `n`, то есть именем, которым функция обозначает переданное ей значение. Когда мы пишем `F(4)`, число 4 становится значением параметра `n` в этом вызове. Нажми «Запуск» и пройди программу по шагам:

```python run f.py
def F(n):
    if n == 1:
        return 2
    return F(n - 1) + 3 * n


print(F(4))
```

```output
29
```

Строка `if n == 1:` означает: если значение `n` равно 1, выполнить следующий блок. Двойной знак {{eq|`==`}} проверяет равенство, одинарный `=` — присваивание.

`return 2` означает: завершить текущий вызов функции и передать число 2 туда, откуда этот вызов был сделан. После выполнения `return` оставшаяся часть данного вызова не выполняется. Поэтому при `n == 1` программа не дойдёт до строки `return F(n - 1) + 3 * n`.

Если же `n > 1`, первая проверка не сработает. Тогда программа:

1. вычислит `F(n - 1)`;
2. прибавит `3 * n`;
3. вернёт полученную сумму.

В пошаговом запуске видно то же, что в подтеме 1: вызовы F(4), F(3), F(2) ждут, у каждого свой `n`, а после базы результаты возвращаются 2, 8, 17, 29.

**`return` и `print` выполняют разные задачи.** `return` передаёт результат вызывающему коду, `print` показывает информацию на экране. Если внутри функции просто напечатать число, это **ещё не сделает его возвращаемым результатом**.

Функция, дошедшая до конца без `return` со значением, возвращает специальное значение {{none|`None`}}, обозначающее отсутствие обычного результата. А в выражении `F(n - 1) + 3 * n` нужен именно возвращённый результат.

Также обрати внимание на отступы. Они определяют, какие строки относятся к функции и к условию.

---

**Для правильной рекурсии нужно проверить, что все необходимые вызовы в итоге достигают базы.** В примере F(n) = F(n − 1) + 3n аргумент последовательно уменьшается на 1. Если начать с натурального числа, то в итоге получится 1.

Но самого уменьшения аргумента недостаточно. Предположим, задано:

F(1) = 1;  
F(n) = F(n − 2) + n, n > 1.

Для F(7) возникает цепочка аргументов 7, 5, 3, 1. База достижима. Для F(6) — цепочка 6, 4, 2, 0. Если функция определена только для натуральных аргументов, значение F(0) вообще не задано. **Этих формул недостаточно для вычисления F(6).**

Если же механически написать программу, F(7) она посчитает:

```python
def F(n):
    if n == 1:
        return 1
    return F(n - 2) + n


print(F(7))
```

```output
16
```

А вызов `F(6)` пойдёт дальше: 6, 4, 2, 0, −2, −4, … До 1 он не доберётся.

<figure class="plate-figure">

<figcaption>Шаг −2: цепочка от 7 попадает в базу 1 за 3 перехода, цепочка от 6 проходит через 0 и уходит в отрицательные числа, не задев 1.</figcaption>
</figure>

Причина понятна: **вычитание 2 сохраняет чётность**. Чётный аргумент остаётся чётным. Python в таком случае остановит программу ошибкой, когда незавершённых вызовов станет слишком много ({{reclimit|предел глубины рекурсии}}).

Поэтому при чтении условия проверяй:

- какие аргументы допускаются;
- для каких аргументов значение известно сразу;
- куда ведут переходы;
- покрываются ли формулами все достигнутые аргументы.

Что считать допустимыми аргументами, говорит условие:

- «целое неотрицательное число» — 0, 1, 2, 3, …;
- «натуральное число» — в наших примерах 1, 2, 3, …;
- просто «целое число» — могут допускаться и отрицательные аргументы.

**Аргумент рекурсии может увеличиваться.** Например:

F(n) = 1, n ≥ 10;  
F(n) = n + F(n + 1), n < 10.

Здесь вызов F(7) дойдёт до базы по аргументам 7, 8, 9, 10. Важна достижимость базы за конечное число шагов.

---

**Условия внутри рекурсивного определения выбираются заново для каждого аргумента.** Рассмотрим:

F(n) = n, n ≤ 2;  
F(n) = F(n − 1) + n, n > 2 и n чётно;  
F(n) = 2F(n − 2), n > 2 и n нечётно.

Пусть требуется F(8). Аргумент 8 чётный: F(8) = F(7) + 8.

Теперь вычисляем F(7). Для этого вызова **аргумент равен 7, поэтому выбираем нечётную ветвь**: F(7) = 2F(5). Далее F(5) = 2F(3), F(3) = 2F(1). Для F(1) действует база: F(1) = 1.

Возвращаемся: F(3) = 2, F(5) = 4, F(7) = 8, F(8) = 8 + 8 = 16.

**Нельзя выбрать ветвь один раз по исходному аргументу и использовать её во всех вложенных вызовах.**

В Python чётность проверяют остатком от деления {{intdiv|`%`}}: `8 % 2` равно 0, а `7 % 2` равно 1. Поэтому `n % 2 == 0` проверяет чётность, а `n % 2 != 0` — нечётность; знак {{eq|`!=`}} означает «не равно».

Рекурсивная запись, которая печатает значения F(1), …, F(8) подряд:

```python
def F(n):
    if n <= 2:
        return n
    elif n % 2 == 0:
        return F(n - 1) + n
    else:
        return 2 * F(n - 2)


for n in range(1, 9):
    print(F(n), end=" ")
```

```output
1 2 2 6 4 10 8 16
```

Последнее напечатанное число — F(8) = 16, как и при ручном раскрытии. Здесь:

- {{if|`if`}} проверяет первое условие;
- `elif` означает «иначе, если»;
- `else` обрабатывает оставшийся случай.

После того как случай `n <= 2` исключён, для допустимого натурального аргумента остаётся `n > 2`. Поэтому повторять эту проверку в остальных ветвях необязательно.

Обрати внимание: при переходе от n = 4 к n = 5 результат уменьшается с 6 до 4. **Увеличение аргумента не гарантирует увеличения функции.**

Также различай условия «n чётно» и «F(n − 1) чётно». В первом случае проверяется аргумент, во втором — уже вычисленное значение функции.

---

**Итого.**

- База — ветка с `return` без нового вызова; рекуррентное соотношение — `return` с вызовом той же функции.
- `return` передаёт результат вызывающему коду, `print` только показывает его.
- Перед программой проверь, что цепочка аргументов от каждого нужного n попадает в базу: шаг 2 сохраняет чётность, аргумент может и расти.
- Ветвь выбирается по аргументу текущего вызова: `n % 2 == 0` — чётность аргумента, а не значения.
- Функция с ветвями может уменьшаться при росте аргумента.
