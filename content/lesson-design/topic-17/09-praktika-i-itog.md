**Любая задача задания 17 решается одним порядком рассуждений: определить объект перебора, заранее найти величины всей последовательности, разложить условие группы на отдельные проверки и отдельно записать, что выводить.** Ошибки удобнее ловить на короткой последовательности, где одни группы подходят, а другие нет, чем на большом ответе программы.

Всё главное из подтем собрано на одной схеме. Номер раздела ведёт на его подтему, а ниже схемы каждый шаг разобран подробнее.

%%cheatsheet("topic-17/cheatsheet.json")%%

---

**Для решения новой задачи полезен один и тот же порядок рассуждения.**

1. **Определи объект перебора.** Отдельные элементы, соседние пары, соседние тройки или любые пары разных позиций?
2. **Уточни допустимые значения.** Возможны ли отрицательные числа и ноль? Нужно ли учитывать знак при проверке количества цифр?
3. **Выдели сведения обо всей последовательности.** Минимум, максимум, количество, сумма, среднее? По всем элементам или по некоторой их части?
4. **Разложи условие группы на отдельные проверки.** Например: «ровно два четырёхзначных», «есть кратное пяти», «сумма меньше порога».
5. **Отдельно выпиши, что требуется вывести.** Количество и максимум суммы? Количество и минимум суммы квадратов? Модуль окончательного максимума?
6. **Выбери способ накопления ответа.** Список подходящих значений либо счётчик и лучшее значение.
7. **Проверь решение на короткой последовательности.** Желательно такой, где одни группы подходят, другие — нет.
8. **Запусти программу на файле и перенеси ответ в нужном порядке.**

Например, из длинного условия может получиться такая рабочая запись:

- **Перебор:** соседние тройки.
- **Заранее:** минимальное положительное трёхзначное число.
- **Условия тройки:** не более двух трёхзначных чисел; сумма не меньше найденного минимума.
- **Ответ:** количество троек и максимальная сумма среди них.

После такой записи код становится переводом уже понятного решения.

**Проверять программу нужно на случаях, где возможна конкретная ошибка.**

Необязательно придумывать большой файл. Небольшие данные часто лучше обнаруживают неверную логику. Выбери, что проверяешь, чтобы увидеть полезный случай:

:::pick Что проверяем и полезный случай
- *«хотя бы одно» | подходят оба числа пары
- «ровно одно» | подходят оба — пара должна быть исключена
- работа со знаком | есть отрицательное число и ноль
- начальное значение максимума | все подходящие суммы отрицательны
- граница количества цифр | `99`, `100`, `999`, `1000`
- строгое или нестрогое сравнение | значение в точности равно порогу
- пересечение групп | подходят две пары с общим элементом
- одинаковые значения | повторяющиеся числа — разные элементы
- конец цикла | подходящей оказывается последняя пара или тройка
- порядок операций | максимальная сумма отрицательна, а в ответе нужен её модуль
:::

Во время отладки можно выводить проверяемые элементы:

```python
with open("17.txt") as f:
    a = [int(part) for part in f.read().split()]

for i in range(len(a) - 1):
    x = a[i]
    y = a[i + 1]

    condition = x % 4 == 0 or y % 4 == 0

    print(i, x, y, condition, x + y)
```

```output
0 8 -12 True -4
1 -12 5 True -7
2 5 20 True 25
3 20 -3 True 17
4 -3 14 False 11
```

Так видно:

- какие пары действительно перебираются;
- чему равно условие;
- какая величина вычислена.

После проверки вспомогательный вывод убирают.

Также полезно проверить разумные границы количества:

- соседних пар не может быть больше `n - 1`;
- соседних троек — больше `n - 2`;
- неупорядоченных пар разных позиций — больше `n * (n - 1) // 2`.

Если программа превышает соответствующую границу, она что-то считает повторно.

**Задачи основных подтем в формате экзамена.** Подсказка в скобках называет подтему, приём которой нужен. Во всех задачах под парой подразумевается два идущих подряд элемента последовательности, под тройкой — три, под четвёркой — четыре.

1. В файле [17-4.txt](topic-17/files/17-4.txt) содержится последовательность натуральных чисел, не превышающих 100 000. Определите количество пар, в которых ровно одно число делится на 3, а сумма элементов пары кратна 5. В ответе запишите количество найденных пар, затем максимальную из сумм элементов таких пар. (Подтемы 2 и 4.)
2. В файле [17-3.txt](topic-17/files/17-3.txt) содержится последовательность целых чисел от −100 000 до 100 000. Определите количество троек, в которых не более одного числа трёхзначное, а сумма элементов тройки не меньше минимального положительного элемента последовательности, оканчивающегося на 99. В ответе запишите количество найденных троек, затем минимальную из сумм элементов таких троек. (Подтемы 3 и 5: трёхзначное — по модулю, «не меньше» включает равенство.)
3. Для файла [17-4.txt](topic-17/files/17-4.txt) определите количество пар, для которых выполняются условия: остаток от деления на 3 хотя бы одного числа пары равен остатку от деления на 3 минимального элемента последовательности; остаток от деления на 7 хотя бы одного числа пары равен остатку от деления на 7 максимального элемента последовательности. В ответе запишите количество найденных пар, затем максимальную из сумм элементов таких пар. (Подтемы 5 и 6.)
4. Для файла [17-3.txt](topic-17/files/17-3.txt) определите количество троек, в которых все числа одного знака, а модуль суммы элементов тройки меньше максимального элемента последовательности, запись которого оканчивается на 77. В ответе запишите количество найденных троек, затем абсолютное значение максимальной из сумм элементов таких троек. (Подтемы 3, 5 и 6.)
5. Для файла [17-4.txt](topic-17/files/17-4.txt) определите количество четвёрок, в которых чисел, кратных 3, больше, чем чисел, кратных 7, а сумма элементов четвёрки больше утроенного среднего арифметического всех чётных элементов последовательности. В ответе запишите количество найденных четвёрок, затем максимальную из сумм элементов таких четвёрок. (Подтемы 2, 4 и 5: среднее — без деления.)

**Ответы для проверки:**

1. `92 172180`: «ровно одно» — `int(x % 3 == 0) + int(y % 3 == 0) == 1`; с «хотя бы одним» подошли бы и пары, где оба кратны трём.
2. `404 99`: минимальный положительный элемент на 99 — само число 99, и тройка с суммой ровно 99 подходит; со строгим «больше» ответ был бы другим.
3. `164 149944`: сравниваются остатки — `x % 3 == min(a) % 3`, а не `x % 3 == min(a)`.
4. `77 6498`: ноль не относится ни к положительным, ни к отрицательным, поэтому тройки с нулём не подходят.
5. `357 240298`: условие на среднее без деления — сумма четвёрки, умноженная на `k`, больше `3 * s`, где `s` и `k` — сумма и количество чётных элементов.

После каждой задачи попробуй объяснить без кода: **почему перебор охватывает все нужные группы, почему проверка точно соответствует словам условия и почему в ответ попадает именно требуемая величина**. Это упражнение помогает научиться самостоятельно строить решение для новой формулировки.
