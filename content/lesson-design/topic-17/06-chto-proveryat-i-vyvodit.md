**Формулировку условия и ответа читают как последовательность действий: что найти, что с ним сделать и в каком порядке.** Составные величины и модуль ответа нужны в 22 задачах подборки из 85, сравнение остатка элемента с наименьшим или наибольшим элементом — в 12 (среди них основная волна ЕГЭ-2026 и демоверсия 2025 года), порядок чисел внутри группы — в 7, и 5 из них — задачи 2025–2026 годов.

Порядок действий разберём на числах −20, −3, 8, а порядок внутри группы — на тройке 4, 10, 7. Порог всей последовательности считается заранее, как в подтеме 5.

---

**В длинных формулировках особенно важно соблюдать порядок операций.**

Рассмотрим:

> Квадрат минимального элемента.

**Сначала** находим минимум, **затем** возводим его в квадрат: `min(a) ** 2`. А «минимальный квадрат элемента» означает сначала возведение каждого элемента в квадрат, затем поиск минимума: `min([x ** 2 for x in a])`. Для −20, −3, 8:

```python
a = [-20, -3, 8]
print(min(a) ** 2, min([x ** 2 for x in a]))
```

```output
400 9
```

(min a)² = (−20)² = 400, но min(400, 9, 64) = 9. Разница огромна:

<figure class="plate-figure">
%%seq_order([-20, -3, 8])%%
<figcaption>Одни и те же два действия — найти минимум и возвести в квадрат. Если сначала взять минимум, получится 400; если сначала возвести всё в квадрат, отрицательное −20 превращается в самое большое число 400, и минимум — 9.</figcaption>
</figure>

Точно так же «абсолютное значение максимальной суммы» означает `abs(max(results))`, а «максимальное абсолютное значение суммы» — `max([abs(value) for value in results])`. Для сумм −20 и −3 первое выражение даёт `3`, второе — `20`:

```python
results = [-20, -3]
print(abs(max(results)), max([abs(v) for v in results]))
```

```output
3 20
```

Полезно разбирать формулировку как последовательность действий:

:::pick Формулировка и порядок действий
- *квадрат минимального числа | найти минимум → возвести в квадрат
- минимум квадратов чисел | возвести числа в квадрат → найти минимум
- модуль максимальной суммы | вычислить суммы → найти максимум → взять модуль
- максимальный модуль суммы | вычислить суммы → взять их модули → найти максимум
- квадрат количества элементов | посчитать элементы → возвести количество в квадрат
- сумма квадратов элементов | возвести элементы в квадрат → сложить
:::

Поэтому **нельзя** заранее брать модуль всех результатов, если в условии требуется модуль только окончательного максимума.

---

**Величина, по которой проверяют группу, может отличаться от величины, которую нужно вывести.**

Например:

> Сумма пары больше порога. Найти минимальную сумму квадратов подходящих пар.

Тогда:

```python
if x + y > threshold:
    results.append(x ** 2 + y ** 2)
```

А ответ — `print(len(results), min(results))`, при условии существования подходящих пар. Здесь:

- проверка относится к `x + y`;
- сохраняется `x ** 2 + y ** 2`;
- из сохранённого выбирается минимум.

В каждой задаче полезно отдельно выписать:

1. **условие отбора**;
2. **величину, которую сравниваем между подходящими группами**;
3. **окончательное преобразование ответа**, если оно требуется.

Так ты не будешь машинально искать максимум суммы в любой задаче.

---

**Остаток минимального элемента и минимальный остаток — тоже разные вещи.**

Предположим, последовательность 8, 12. Минимальный элемент — `8`, его остаток при делении на пять равен 3. Но остатки всех элементов — 3 и 2, и минимальный из них равен `2`. Поэтому `min(a) % 5` и `min([x % 5 for x in a])` не равны в общем случае:

```python
a = [8, 12]
print(min(a) % 5, min([x % 5 for x in a]))
```

```output
3 2
```

Ещё одно различие:

| Формулировка | Проверка |
|---|---|
| Остаток `x` равен минимальному элементу последовательности | `x % 5 == minimum` |
| Остаток `x` равен остатку минимального элемента | `x % 5 == minimum % 5` |

Нельзя добавлять `% 5` справа, если его нет в смысле условия. Обе формулировки встречаются на экзамене: первая — в основной волне ЕГЭ-2026 («остаток от деления хотя бы одного элемента на 33 равен минимальному числу последовательности»), вторая — в тренировочных работах.

Для задачи:

> У ровно одного числа тройки остаток от деления на пять совпадает с остатком минимального элемента всей последовательности,

пишем до перебора:

```python
minimum = min(a)
target_remainder = minimum % 5
```

А внутри перебора троек:

```python
matching_count = (
    int(x % 5 == target_remainder)
    + int(y % 5 == target_remainder)
    + int(z % 5 == target_remainder)
)

condition = matching_count == 1
```

Предварительный минимум вычисляем один раз, до цикла.

**Для работы с наибольшими и наименьшими числами внутри тройки удобно создать маленький список.**

Запишем `triple = [x, y, z]`. Теперь доступны `min(triple)`, `max(triple)`, `sum(triple)`.

Если нужна сумма двух наибольших элементов, можно **из общей суммы вычесть один наименьший**: `sum(triple) - min(triple)`. Почему это работает? Из трёх элементов мы убираем наименьший — остаются два наибольших. Для 4, 10, 7 получаем 4 + 10 + 7 − 4 = 17 — это сумма `10` и `7`.

Аналогично сумма двух наименьших — `sum(triple) - max(triple)`, а средний по величине элемент — `sum(triple) - min(triple) - max(triple)`:

```python
triple = [4, 10, 7]
print(sum(triple) - min(triple), sum(triple) - max(triple))
print(sum(triple) - min(triple) - max(triple))
```

```output
17 11
7
```

Повторяющиеся значения не мешают. Для 5, 5, 5 сумма двух наибольших: 15 − 5 = 10. Не нужно удалять все вхождения минимального значения: вычитается значение **одного** элемента.

Если нужно более подробно расположить три значения по величине, используется {{sorted|`sorted`}}: `ordered = sorted(triple)` создаёт новый список с элементами по возрастанию. Тогда `ordered[0]` — наименьший, `ordered[1]` — средний, `ordered[2]` — наибольший.

Это сортировка только текущей тройки. Исходная последовательность `a` не изменяется, поэтому соседство в ней сохраняется.

Для пары то же короче: «меньший элемент пары оканчивается на 5» — это `abs(min(x, y)) % 10 == 5`.

---

**«Два наибольших числа» выбираются до возведения в квадрат, если именно так сформулировано условие.**

Пусть тройка −10, 3, 4. Два наибольших числа — `3` и `4`. Сумма их квадратов: 3² + 4² = 25. Два наибольших квадрата — уже `100` и `16`, их сумма равна `116`.

Поэтому для суммы квадратов двух наибольших **чисел** сначала выбираем числа, затем возводим в квадрат. Можно обойтись и без сортировки: из суммы трёх квадратов вычитается квадрат наименьшего **исходного** числа.

Функции `min` и `max` умеют принимать как список, так и несколько отдельных значений: `min(x, y, z)`.

```python
x = -10
y = 3
z = 4
ordered = sorted([x, y, z])
print(ordered[1] ** 2 + ordered[2] ** 2)
print(x ** 2 + y ** 2 + z ** 2 - min(x, y, z) ** 2)
```

```output
25
25
```

Для других формулировок:

:::pick Требуемая величина и выражение
- *произведение минимума и максимума тройки | `min(triple) * max(triple)`
- сумма модулей минимума и максимума | `abs(min(triple)) + abs(max(triple))`
- модуль суммы минимума и максимума | `abs(min(triple) + max(triple))`
:::

Последние две строки тоже различаются. Для минимума `-9` и максимума `5`: |−9| + |5| = 14, но |−9 + 5| = 4.

---

**Итого.**

- Формулировка разбирается в порядке действий: «квадрат минимума» — `min(a) ** 2`, «минимум квадратов» — `min([x ** 2 for x in a])`, модуль берут только у того, у чего он назван.
- Отдельно выписываются условие отбора, сравниваемая величина и окончательное преобразование ответа.
- «Остаток равен минимальному элементу» — `x % m == minimum`, «остатку минимального» — `x % m == minimum % m`.
- Внутри тройки: два наибольших — `sum(triple) - min(triple)`, средний — без минимума и максимума, подробный порядок — `sorted`; сначала выбирают числа, потом возводят в квадрат.
