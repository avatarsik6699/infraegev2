**Дополнительный урок — для продвинутых.** Он для тех, кто хочет закрыть все возможные случаи задания 17: в подборке 10 задач, где пара — любые два элемента с разными номерами, все, по оценке, 2021 года; на экзаменах с 2022 года пары только соседние. Задачи основных подтем решаются без него.

**Если пара — любые два элемента с разными номерами, перебираются все пары индексов i < j, и их уже не n − 1, а n(n − 1)/2.** Перебор остаётся простым, но становится квадратичным; для больших файлов его ускоряют, объединяя числа с одинаковыми остатками.

Все примеры урока — на последовательности 4, 6, 11, 9.

---

**Если пара означает любые два разных элемента, перебор соседей не подходит.**

У последовательности 4, 6, 11, 9 соседних пар три: (4, 6), (6, 11), (11, 9). Но всех пар из разных позиций шесть:

<figure class="plate-figure">

<figcaption>Строка — индекс первого элемента, столбец — второго. Пары разных позиций — шесть клеток над диагональю, в них суммы. На диагонали элемент сам с собой, под ней те же пары в обратном порядке.</figcaption>
</figure>

Чтобы перебрать их, нужны {{nested|вложенные циклы}}. Внутренний цикл находится внутри внешнего. Это означает:

> Для каждого выбранного `i` перебрать все допустимые значения `j`.

Запись `range(start, stop)` даёт значения от `start` включительно до `stop` не включительно. Запусти по шагам и посмотри, в каком порядке появляются пары:

```python run pairs.py
a = [4, 6, 11, 9]
for i in range(len(a) - 1):
    for j in range(i + 1, len(a)):
        print(i, j, a[i] + a[j])
```

```output
0 1 10
0 2 15
0 3 13
1 2 17
1 3 15
2 3 20
```

Почему начинаем `j` с `i + 1`? Потому что рассматриваем только i < j. Так одновременно обеспечивается:

- элемент не соединяется с самим собой;
- одна пара не считается дважды в разном порядке.

Например, после `(0, 2)` пара `(2, 0)` уже не рассматривается.

Это решение применяется, когда порядок элементов в паре не важен. Если условие специально различает упорядоченные пары, нужно учитывать это отдельно.

**Разные элементы не обязательно имеют разные значения.**

Для последовательности 5, 5, 5 существуют три пары разных позиций: `(0, 1)`, `(0, 2)`, `(1, 2)`. Все они имеют значения `(5, 5)`. Добавлять проверку `a[i] != a[j]` можно только тогда, когда условие требует именно неравенства **значений**.

---

**Для произвольных пар полезно оценить количество проверок.**

Из `n` элементов получается n(n − 1)/2 неупорядоченных пар разных позиций. Почему? Для первого элемента есть `n - 1` партнёров справа, для второго — `n - 2`, затем `n - 3` и так далее до одного: (n − 1) + (n − 2) + … + 1 = n(n − 1)/2. На рисунке выше это клетки над диагональю: половина квадрата n × n без диагонали.

```python
for n in [10, 100, 1000, 10000]:
    print(n, n - 1, n * (n - 1) // 2)
```

```output
10 9 45
100 99 4950
1000 999 499500
10000 9999 49995000
```

При `n = 10 000` соседних пар — 9 999, произвольных пар — 49 995 000. Разница существенная.

Когда число действий растёт примерно пропорционально `n`, говорят о **линейной сложности**, обозначают O(n). Когда оно растёт примерно пропорционально n², говорят о **квадратичной сложности**, обозначают O(n²).

Эти обозначения описывают рост работы при увеличении данных, а не точное время в секундах.

Перебор всех произвольных пар логически прост, но на больших файлах может быть медленным. Скорость зависит от размера файла, проверяемых условий и среды выполнения.

**Некоторые задачи на произвольные пары можно ускорить, объединяя числа с одинаковыми свойствами.**

Этот приём сложнее основного перебора соседей. Он полезен для понимания того, как решать большие задачи на любые пары.

Учебное условие:

> Среди любых двух элементов с разными индексами найти количество пар с суммой, кратной пяти, и максимальную сумму.

Остатки от деления на пять — 0, 1, 2, 3, 4. Какие остатки совместимы? Остаток 0 — с остатком 0, 1 — с 4, 2 — с 3, 3 — с 2, 4 — с 1. Например, (5k + 2) + (5m + 3) = 5(k + m + 1): сумма кратна пяти.

Будем двигаться слева направо. Для каждого нового числа рассматриваем только уже встреченные элементы. Если новое число имеет остаток `2`, оно образует подходящую пару **с каждым предыдущим числом остатка `3`**.

Необязательно заново просматривать эти числа. Достаточно знать:

1. сколько их;
2. какое из них максимальное.

Количество нужно для подсчёта пар. Максимум нужен для максимальной суммы: при фиксированном новом `x` сумма `x + y` тем больше, чем больше `y`.

Создадим два списка по пять ячеек — по одной на каждый остаток. Запись `[0] * 5` создаёт `[0, 0, 0, 0, 0]`.

- `counts = [0] * 5`: `counts[r]` — количество предыдущих чисел с остатком `r`;
- `best_by_remainder = [None] * 5`: `best_by_remainder[r]` — наибольшее предыдущее число с таким остатком либо `None`, если их ещё не было.

Код обработки:

```python
a = [4, 6, 11, 9]

counts = [0] * 5
best_by_remainder = [None] * 5

count = 0
best = None

for x in a:
    remainder = x % 5
    needed = (-remainder) % 5

    count += counts[needed]

    previous = best_by_remainder[needed]

    if previous is not None:
        current_sum = x + previous

        if best is None or current_sum > best:
            best = current_sum

    counts[remainder] += 1

    if (
        best_by_remainder[remainder] is None
        or x > best_by_remainder[remainder]
    ):
        best_by_remainder[remainder] = x

if count > 0:
    print(count, best)
else:
    print("Подходящих пар нет")
```

```output
4 20
```

Запись `needed = (-remainder) % 5` вычисляет остаток, который в сумме с текущим даст число, кратное пяти. Например, при `remainder = 2` получается `needed = 3`, при `remainder = 0` — `needed = 0`.

**Сначала используем сведения о предыдущих числах, затем добавляем текущее.**

Если сделать наоборот, число с остатком ноль может образовать пару с самим собой.

Каждая настоящая пара учитывается при обработке её правого элемента. Поэтому повторного подсчёта нет. Для 4, 6, 11, 9 подходят (4, 6) → 10, (4, 11) → 15, (6, 9) → 15, (11, 9) → 20 — те же четыре пары, что в клетках рисунка с суммами, кратными пяти. Ответ: `4 20`.

Этот конкретный алгоритм предназначен для произвольных пар и делимости суммы. Его нельзя переносить на соседние пары: он учитывает всех предыдущих партнёров, а не только ближайшего.

Общая идея ускорения — хранить количество и нужные характеристики ранее встреченных чисел по признаку, от которого зависит совместимость. Но сам признак нужно выводить из конкретного условия.

---

**Итого.**

- Пары разных позиций перебирают вложенными циклами: `i` от 0, `j` от `i + 1` — без пары элемента с собой и без повторов.
- Таких пар n(n − 1)/2: при 10 000 чисел почти 50 миллионов проверок, рост квадратичный.
- Одинаковые значения на разных местах — разные элементы.
- Для делимости суммы пары хватает счёта по остаткам: каждое новое число сразу получает всех прежних партнёров с нужным остатком, а затем добавляется само.
