**После сортировки тройки p ≤ q ≤ r треугольник существует, когда p + q > r, а его вид определяет сравнение p² + q² с r².** Здесь всё держится на одном неравенстве и одном сравнении — их легко проверить на рисунке.

Будем проверять тройки 3, 4, 5; 2, 3, 4 и 1, 2, 3 — стороны, которые легко нарисовать. Сортировку тройки `sorted` из подтемы 6 считаем знакомой.

---

**В задачах на треугольники сначала нужно проверить, могут ли числа быть длинами сторон.**

Пусть три числа после упорядочивания: p ≤ q ≤ r. Для существования обычного, невырожденного треугольника нужно p > 0 и **p + q > r**.

Почему достаточно проверить сумму двух меньших сторон? Положим две меньшие стороны вдоль большей:

<figure class="plate-figure">
%%seq_triangle([[1, 2, 3], [2, 3, 4]])%%
<figcaption>Отрезки 1 и 2 вместе ровно равны 3 — их можно только уложить на одну прямую. Отрезки 2 и 3 вместе длиннее 4 — их концы можно приподнять и соединить вершиной треугольника.</figcaption>
</figure>

Другие неравенства выполняются автоматически:

- p + r > q, потому что r ≥ q и p > 0;
- q + r > p, потому что q ≥ p и r > 0.

А вот **две меньшие стороны могут оказаться слишком короткими**. Например, 1, 2, 3 не образуют треугольник: 1 + 2 = 3. Получается вырожденный случай: стороны можно расположить на одной прямой, а треугольника с ненулевой площадью нет.

---

**После проверки существования вид треугольника определяет квадрат наибольшей стороны.**

:::pick Вид треугольника и критерий
- *прямоугольный: один угол равен 90° | p² + q² = r²
- остроугольный: все углы меньше 90° | p² + q² > r²
- тупоугольный: один угол больше 90° | p² + q² < r²
:::

Сравниваем именно с квадратом **наибольшей стороны**.

Прямоугольный случай — теорема Пифагора.

<details class="proof" markdown="1">
<summary>Почему острый и тупой угол различает квадрат наибольшей стороны</summary>

Остальные критерии можно понять через угол напротив наибольшей стороны: увеличение этого угла при фиксированных двух других сторонах увеличивает противоположную сторону. При угле меньше прямого её квадрат меньше суммы квадратов двух других сторон, при угле больше прямого — больше.

</details>

Проверим примеры: 3, 4, 5 — 9 + 16 = 25; 4, 5, 6 — 16 + 25 > 36; 2, 3, 4 — 4 + 9 < 16, при этом 2 + 3 > 4; 1, 2, 3 — 1 + 2 = 3:

```python
for triple in [[3, 4, 5], [4, 5, 6], [2, 3, 4], [1, 2, 3]]:
    ordered = sorted(triple)
    p = ordered[0]
    q = ordered[1]
    r = ordered[2]
    if not (p > 0 and p + q > r):
        print(triple, "треугольника нет")
    elif p ** 2 + q ** 2 == r ** 2:
        print(triple, "прямоугольный")
    elif p ** 2 + q ** 2 > r ** 2:
        print(triple, "остроугольный")
    else:
        print(triple, "тупоугольный")
```

```output
[3, 4, 5] прямоугольный
[4, 5, 6] остроугольный
[2, 3, 4] тупоугольный
[1, 2, 3] треугольника нет
```

---

**Проверка существования нужна и для прямоугольного треугольника.**

Иначе тройка 0, 5, 5 удовлетворит равенству 0² + 5² = 5², но стороной длины ноль обычный треугольник обладать не может. **Её отсекает уже неравенство**: 0 + 5 = 5, а не больше. После сортировки отдельная проверка p > 0 следует из p + q > r — при p ≤ 0 сумма p + q не больше q, а q ≤ r. Но записать её явно не вредно: так проверка совпадает со словами «стороны положительны».

Если по условию при отсутствии подходящих троек требуется `0 0`, полный фрагмент обработки выглядит так:

```python
a = [5, 12, 13, 0, 5, 5]

results = []

for i in range(len(a) - 2):
    ordered = sorted([a[i], a[i + 1], a[i + 2]])

    p = ordered[0]
    q = ordered[1]
    r = ordered[2]

    is_triangle = p > 0 and p + q > r
    is_right = p ** 2 + q ** 2 == r ** 2

    if is_triangle and is_right:
        results.append(p + q + r)

if len(results) == 0:
    print(0, 0)
else:
    print(len(results), max(results))
```

```output
1 30
```

Подходит только тройка 5, 12, 13. Последняя тройка 0, 5, 5 удовлетворяет равенству Пифагора, но `is_triangle` для неё ложно; без этой проверки программа вывела бы `2 30`.

---

**Итого.**

- Тройку сортируют: p ≤ q ≤ r. Треугольник существует, когда p + q > r; две другие проверки выполняются сами.
- Вид определяет квадрат наибольшей стороны: равно — прямоугольный, меньше суммы квадратов — остроугольный, больше — тупоугольный.
- Без проверки существования равенство Пифагора пропускает вырожденные тройки вроде 0, 5, 5.
- Если подходящих троек нет, выводится то, что требует условие, например `0 0`.
