**Цифры записи числа берутся у его модуля, а знак проверяется отдельно и с учётом нуля.** Окончания и цифры записи нужны в 39 задачах подборки, количество цифр — в 38, знак — в 10. В задачах 2025–2026 годов числа почти всегда бывают отрицательными: «трёхзначное по модулю», «оканчивается на 7» и «ровно одно отрицательное» нужно проверять с оглядкой на минус.

Главный пример подтемы — число −17 и его последняя цифра; знак разберём на паре (−8, 0) и тройке −2, −3, 5.

---

**Для проверки последних цифр отрицательного числа сначала нужен модуль.**

Для положительного числа `347 % 10` равно 7, а `347 % 100` — 47. Почему это работает? 347 = 34 · 10 + 7: при делении на десять остатком остаётся последняя цифра. А 347 = 3 · 100 + 47: при делении на сто остатком остаются последние две цифры.

Но в Python **`-17 % 10` равно 3**. Причина связана с правилами деления отрицательных чисел: −17 = (−2) · 10 + 3. При положительном делителе Python возвращает неотрицательный остаток, меньший делителя, а `//` округляет частное вниз: `-17 // 10` равно −2.

<figure class="plate-figure">
%%seq_negmod(-17, 10)%%
<figcaption>Остаток отсчитывается от ближайшего кратного 10 слева: для −17 это −20, до −17 от него 3 шага, поэтому −17 % 10 = 3. Последняя цифра записи 7 — остаток модуля 17.</figcaption>
</figure>

```python
print(347 % 10, 347 % 100)
print(-17 % 10, -17 // 10, abs(-17) % 10)
```

```output
7 47
3 -2 7
```

Поэтому `% 10` для отрицательного числа **нельзя** напрямую трактовать как последнюю цифру его записи. Чтобы проверить окончание записи, берут {{absval|модуль}}: `abs(x) % 10 == 7`. Так подойдут 7, 17, 127, −7, −17, −127.

:::pick Свойство записи числа и проверка
- *оканчивается на 3 | `abs(x) % 10 == 3`
- оканчивается на 17 | `abs(x) % 100 == 17`
- оканчивается на 123 | `abs(x) % 1000 == 123`
- последние цифры двух чисел одинаковы | `abs(x) % 10 == abs(y) % 10`
:::

---

**Модуль нужен для работы с цифрами, но не должен добавляться во все проверки подряд.**

Если условие говорит:

> Остаток от деления числа на пять равен двум,

то проверяется `x % 5 == 2`. Для `x = -8` это истинно: −8 = (−2) · 5 + 2. Но `abs(-8) % 5` равно 3:

```python
print(-8 % 5, abs(-8) % 5)
```

```output
2 3
```

Замена `x` на `abs(x)` здесь **меняет условие**.

Есть небольшая тонкость с окончаниями, начинающимися с нуля. Проверка `abs(x) % 100 == 7` выполнена и для числа `7`. Если требуется именно запись, заканчивающаяся двумя символами `07`, у числа должно быть достаточно цифр: `abs(x) >= 10 and abs(x) % 100 == 7`.

---

**Количество цифр надёжно проверяется через числовые границы.**

Положительное трёхзначное число находится между `100` и `999`. Поэтому `100 <= x <= 999`. Если отрицательные числа тоже допускаются как трёхзначные, **знак минус не считается цифрой**: `100 <= abs(x) <= 999`.

:::pick Требование и проверка
- двузначное по модулю | `10 <= abs(x) <= 99`
- *трёхзначное по модулю | `100 <= abs(x) <= 999`
- четырёхзначное по модулю | `1000 <= abs(x) <= 9999`
- пятизначное по модулю | `10000 <= abs(x) <= 99999`
- положительное трёхзначное | `100 <= x <= 999`
- отрицательное трёхзначное | `-999 <= x <= -100`
:::

Можно использовать верхнюю границу без включения: `100 <= abs(x) < 1000`. Для целых чисел это то же самое, что `100 <= abs(x) <= 999`.

Ровно два четырёхзначных числа в тройке — количество из прошлой подтемы:

```python
k4 = (
    int(1000 <= abs(x) <= 9999)
    + int(1000 <= abs(y) <= 9999)
    + int(1000 <= abs(z) <= 9999)
)

if k4 == 2:
    ...
```

Переносы внутри круглых скобок позволяют записать длинное выражение на нескольких строках.

Можно определять количество цифр через текст: `len(str(abs(x)))` — здесь {{str|`str`}} превращает значение в строку, а `len` считает символы. Но `len(str(x))` для отрицательного числа посчитает и знак минус:

```python
print(str(-123), len(str(-123)), len(str(abs(-123))))
```

```output
-123 4 3
```

Проверка диапазона обычно проще для чтения и проверки.

---

**Цифру в любом разряде дают те же два действия: отбросить младшие цифры и взять остаток.**

Встречаются условия «две последние цифры записи одинаковы», «последняя цифра одного элемента совпадает с предпоследней цифрой другого», «старшие разряды чисел совпадают». Для модуля числа `m = abs(x)`:

- `m % 10` — последняя цифра;
- `m // 10` — число без последней цифры, а значит `m // 10 % 10` — предпоследняя цифра. Например, 347 // 10 = 34, а 34 % 10 = 4;
- первая цифра — первый символ записи модуля: `str(m)[0]`, это {{slice|индекс строки}}.

```python
x = -347
m = abs(x)
print(m % 10, m // 10 % 10, str(m)[0])
```

```output
7 4 3
```

Условие «две последние цифры одинаковы» требует, чтобы этих цифр было хотя бы две — та же тонкость, что с окончанием `07`:

```python
for x in [-455, 1050, 7]:
    m = abs(x)
    print(x, m >= 10 and m % 10 == m // 10 % 10)
```

```output
-455 True
1050 False
7 False
```

Первую цифру иногда удобнее проверить границами: положительное трёхзначное число, начинающееся с цифры 5, — это `500 <= x <= 599`.

---

**Знак числа нужно проверять с учётом нуля.**

Положительное — `x > 0`, отрицательное — `x < 0`, неотрицательное — `x >= 0`, неположительное — `x <= 0`. **Ноль не является ни положительным, ни отрицательным числом.**

Ровно одно отрицательное число в паре — количество: `int(x < 0) + int(y < 0) == 1` или `(x < 0) != (y < 0)`. Пара (−8, 0) подходит: отрицательное число в ней ровно одно. А проверка `x * y < 0` для этой пары не выполнена:

```python
x = -8
y = 0
print(int(x < 0) + int(y < 0) == 1, x * y < 0)
```

```output
True False
```

Она означает другое:

> Одно число строго положительное, другое строго отрицательное.

Поэтому:

- «ровно одно отрицательное» — проверяем количество отрицательных;
- «числа разных знаков» в смысле положительного и отрицательного — можно использовать `x * y < 0`.

Для тройки все числа одного знака: `(x > 0 and y > 0 and z > 0) or (x < 0 and y < 0 and z < 0)`. Или через количество положительных и отрицательных.

**Проверять только знак произведения трёх чисел нельзя**: −2, −3, 5 имеют положительное произведение, но не одинаковые знаки.

```python
x = -2
y = -3
z = 5
positive_count = int(x > 0) + int(y > 0) + int(z > 0)
negative_count = int(x < 0) + int(y < 0) + int(z < 0)
same_sign = positive_count == 3 or negative_count == 3
print(same_sign, x * y * z > 0)
```

```output
False True
```

---

**Итого.**

- Последние цифры отрицательного числа — остатки его модуля: `abs(x) % 10`, `abs(x) % 100`; `-17 % 10` равно 3.
- Условие на остаток от деления проверяется без модуля: «остаток от деления на 5 равен 2» — `x % 5 == 2`.
- Предпоследняя цифра — `abs(x) // 10 % 10`, первая — `str(abs(x))[0]`; для двух последних цифр у числа должно быть хотя бы две цифры.
- Количество цифр — числовыми границами модуля: `100 <= abs(x) <= 999`.
- Ноль не положительный и не отрицательный: «ровно одно отрицательное» — это количество, а не `x * y < 0`.
