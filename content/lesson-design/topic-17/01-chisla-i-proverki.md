**Задание 17 удобно осваивать через одну общую идею: мы перебираем нужные элементы последовательности, проверяем условия и собираем из подходящих случаев ответ.** Сложность обычно заключается в том, чтобы правильно понять, какие элементы рассматриваются и что именно нужно проверить.

В каждой задаче файл с числами превращается в список, а слова условия — в проверки делимости, сумм и произведений. С 2022 года все 15 задач реальных экзаменов — про соседние пары и тройки с порогом, посчитанным по всей последовательности; к этому мы придём постепенно.

Главный пример подтемы — последовательность 8, −12, 5, 20, −3, 14: каждый ответ на ней можно проверить вручную. Отдельные правила — про повторы, делимость суммы, квадраты — показаны на парах маленьких чисел. Начнём с основ, а затем постепенно соберём из них решение.

---

**Последовательность — это числа, расположенные в определённом порядке.**

Например, в последовательности `8, -12, 5, 20, -3, 14` шесть элементов.

Слово «элемент» означает число **на определённом месте**. Порядок существенен: последовательности `8, -12, 5` и `5, 8, -12` содержат одинаковые числа, но соседство у них разное.

Одинаковые значения могут встречаться несколько раз: в `7, 7, 12` первые две семёрки — два разных элемента, потому что находятся на разных местах.

Отсюда сразу два важных правила:

- нельзя удалять повторяющиеся значения, если этого не требует условие;
- нельзя переставлять числа, если задача связана с их расположением.

---

**Количество элементов и величина элементов — разные характеристики.**

В последовательности `10000, -5000, 300` три элемента. Число `10000` — значение первого элемента, а не длина последовательности.

Если в условии сказано «числа по модулю не превышают 100 000», это ограничивает их значения. Из этого не следует, что в файле ровно 100 000 чисел.

---

**В Python последовательность удобно хранить в списке.**

Наша последовательность в программе — {{list|список}}:

```python
a = [8, -12, 5, 20, -3, 14]
```

Обратиться к отдельному элементу можно по его {{listindex|индексу}} — номеру позиции, который в Python начинается с нуля. Поэтому обычный номер элемента на единицу больше индекса:

<figure class="plate-figure">
%%seq_strip([8, -12, 5, 20, -3, 14])%%
<figcaption>Первый элемент 8 — это a[0], второй −12 — a[1]. У шести элементов индексы от 0 до 5: последний элемент 14 — это a[5], то есть a[n − 1].</figcaption>
</figure>

Количество элементов возвращает {{len|`len`}}:

```python
a = [8, -12, 5, 20, -3, 14]
n = len(a)
print(n, a[0], a[1], a[n - 1])
```

```output
6 8 -12 14
```

Допустимые неотрицательные индексы: 0, 1, 2, …, n − 1.

**Последний индекс равен `n - 1`, а не `n`.**

Для списка из шести элементов обращение `a[6]` приведёт к ошибке: седьмого элемента нет.

**Сначала файл нужно превратить в список чисел.**

В текстовом файле числа записаны символами. Запись `"-12"` в тексте и число `-12`, с которым можно выполнять вычисления, — не одно и то же.

Файл нашей последовательности [17.txt](topic-17/files/17.txt) хранит по числу в строке:

```17.txt
8
-12
5
20
-3
14
```

Файл открывается {{file|`with open`}}, его текст целиком читает `f.read()`, а {{split|`split`}} делит текст по пробелам, переводам строк и другим пробельным символам. Получаются строки — их ещё нужно превратить в числа {{num|`int`}}:

```python
with open("17.txt") as f:
    parts = f.read().split()
print(parts)
print([int(part) for part in parts])
```

```output
['8', '-12', '5', '20', '-3', '14']
[8, -12, 5, 20, -3, 14]
```

Обе операции удобно записать одной строкой — {{comp|списковым включением}}:

```python
with open("17.txt") as f:
    a = [int(part) for part in f.read().split()]
```

Внутри квадратных скобок записано:

> Для каждой части текста получить `int(part)` и собрать результаты в список.

Для задания 17 такой способ чтения удобен: он работает и при одном числе в строке, и при нескольких числах, разделённых пробелами.

---

**Не удаляй первую строку автоматически.**

В некоторых задачах первая строка содержит количество последующих чисел. В других — это уже первый элемент последовательности. Решение определяется описанием файла.

Если условие прямо говорит, что первое число — количество элементов, после чтения можно отделить его:

```python
n = a[0]
a = a[1:]
```

Запись `a[1:]` — это {{slice|срез}}: «все элементы начиная с индекса `1` до конца».

Если количества в начале файла нет, эти две строки удалят настоящее число и испортят ответ.

Также проверь имя и расположение файла. Относительное имя `"17.txt"` ищется в рабочей папке запуска программы. При необходимости можно указать полный путь: `open("C:/EGE/17.txt")`.

**Условие задачи переводится в проверки, каждая из которых даёт ответ «да» или «нет».**

Проверка `x > 10` отвечает на вопрос, больше ли `x` десяти: результат — `True` (условие выполнено) или `False` (не выполнено). Знаки {{eq|сравнения}} в Python: `==` (равно), `!=` (не равно), `>`, `<`, `>=`, `<=`.

Не путай `x = 10` и `x == 10`: первое **присваивает** значение, второе **проверяет** равенство.

Слова из условия нужно переводить **буквально**. Выбери формулировку, чтобы увидеть проверку:

:::pick Формулировка в условии и проверка в Python
- *больше 100 | `x > 100`
- не меньше 100 | `x >= 100` | «не меньше» включает само 100
- меньше 100 | `x < 100`
- не больше 100 | `x <= 100` | «не больше» и «не превышает» включают 100
- от 100 до 999 включительно | `100 <= x <= 999` | то же, что `100 <= x and x <= 999`
:::

Последняя запись означает одновременное выполнение двух сравнений, соединённых {{andor|`and`}}. Чтобы выполнить действие только при истинном условии, используют {{if|`if`}}.

**Остаток от деления — основной инструмент для проверки делимости и цифр.**

Вспомним деление с остатком: 23 = 5 · 4 + 3. Это означает, что при делении `23` на `5` целая часть частного равна `4`, а остаток равен `3`. В Python для неотрицательных целых чисел {{intdiv|`//` даёт целую часть частного, `%` — остаток}}, а обычное деление записывается через `/`:

```python
print(23 // 5, 23 % 5, 23 / 5)
```

```output
4 3 4.6
```

**Число делится на `d` без остатка тогда и только тогда, когда остаток равен нулю.**

Поэтому `x % d == 0` означает «`x` кратно `d`». Здесь предполагается, что `d` не равно нулю. Отсюда все проверки делимости:

:::pick Условие и проверка в Python
- *число кратно 3 | `x % 3 == 0`
- число не кратно 3 | `x % 3 != 0`
- число чётное | `x % 2 == 0`
- число нечётное | `x % 2 != 0`
- остаток от деления на 7 равен 4 | `x % 7 == 4`
- остатки двух чисел при делении на 5 одинаковы | `x % 5 == y % 5`
- остатки различаются | `x % 5 != y % 5`
:::

Для отрицательных чисел проверка делимости тоже работает, и ноль ей не мешает:

```python
print(-12 % 3 == 0, 0 % 3 == 0)
```

```output
True True
```

**Ноль кратен любому ненулевому целому числу.** Поэтому условие «кратно 3» само по себе не исключает ноль. Если нужны положительные кратные трём числа: `x > 0 and x % 3 == 0`.

Так проверки и собирают ответ: **перебираем элементы, проверяем условие и считаем подходящие**. Посчитаем в нашей последовательности числа, кратные трём, и отдельно положительные кратные трём. Количество — это {{augassign|счётчик `+= 1`}}, который растёт на каждом подходящем элементе:

```python
with open("17.txt") as f:
    a = [int(part) for part in f.read().split()]

multiples = 0
positive = 0
for x in a:
    if x % 3 == 0:
        multiples += 1
    if x > 0 and x % 3 == 0:
        positive += 1
print(multiples, positive)
```

```output
2 0
```

Трём кратны −12 и −3, но оба отрицательные, поэтому во втором количестве ноль. Цикл {{for|`for`}} по очереди берёт каждый элемент списка.

**Условия на сумму или произведение нужно проверять для самой суммы или произведения.**

Например, `(x + y) % 7 == 0` означает, что сумма кратна семи. Это **не** то же самое, что требовать делимости каждого числа на семь. Для чисел `2` и `5`: 2 + 5 = 7, хотя ни `2`, ни `5` на семь не делятся.

Аналогично `(x * y) % 10 == 0` проверяет делимость произведения на десять. Числа `2` и `5` дают произведение `10`. Поэтому заменять эту проверку на `x % 10 == 0 or y % 10 == 0` нельзя:

```python
x = 2
y = 5
print((x + y) % 7 == 0, x % 7 == 0 and y % 7 == 0)
print((x * y) % 10 == 0, x % 10 == 0 or y % 10 == 0)
```

```output
True False
True False
```

Другие выражения, которые часто встречаются в условиях:

:::pick Что требуется и выражение
- *сумма пары | `x + y`
- произведение | `x * y`
- разность | `x - y`
- абсолютная разность | `abs(x - y)`
- квадрат числа | `x ** 2`
- сумма квадратов | `x ** 2 + y ** 2`
- квадрат суммы | `(x + y) ** 2`
:::

{{absval|`abs`}} возвращает **модуль**, то есть абсолютную величину числа. Например, |3 − 8| = 5:

```python
print(abs(-12), abs(12), abs(0), abs(3 - 8))
```

```output
12 12 0 5
```

Модуль разности позволяет измерить, насколько числа отличаются, независимо от того, какое записано первым.

**Сумма квадратов и квадрат суммы — разные выражения.**

Для `3` и `4`: 3² + 4² = 9 + 16 = 25, а (3 + 4)² = 7² = 49.

```python
print(3 ** 2 + 4 ** 2, (3 + 4) ** 2)
```

```output
25 49
```

В Python степень обозначается `**`. Символ `^` для возведения в степень не подходит.

---

**Итого.**

- Элемент — это число на своём месте: повторы и порядок сохраняются, количество элементов и их величина — разные вещи.
- Индексы списка идут от 0 до `n - 1`; файл превращается в список одной строкой `[int(part) for part in f.read().split()]`, первое число отделяется, только если так сказано в условии.
- Формулировки переводятся буквально: «не меньше» — `>=`, «кратно» — `x % d == 0`, и ноль кратен любому числу.
- Условие на сумму или произведение проверяется для самой суммы или произведения; сумма квадратов и квадрат суммы различаются.
