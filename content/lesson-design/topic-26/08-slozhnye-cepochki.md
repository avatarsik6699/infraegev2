**Дополнительный урок — для продвинутых.** Он для тех, кто хочет закрыть все возможные случаи задания 26: наименьшее число блоков из вложенных коробок, чередование цветов и материалов в «матрёшке» и лучший набор по убыванию элементов встречаются в подборках, но на реальных экзаменах таких задач не было. Задачи основных подтем решаются без него.

**Усложнённые цепочки иногда сводятся к нескольким жадным проходам или к окну, но это требует нового доказательства.** Обоснование «выбор оставляет больше возможностей» из подтемы о цепочках работает, только если на одной и той же позиции цепочки все условия одинаковы.

Основа урока — коробки подтемы о цепочках со сторонами 12, 18, 21, 27, 34, 40, 45; для блоков к ним добавлены 14 и 22. Окно по отсортированному списку знакомо по подтеме 7.

---

**Если цвета коробок должны чередоваться, а зазор постоянный, достаточно двух жадных проходов — по цвету внешней коробки.**

Пусть коробки двух цветов, 0 и 1, вкладываются друг в друга с разницей сторон хотя бы 5, а цвета соседних коробок обязаны различаться. Если известно, какого цвета внешняя коробка, цвета всех следующих определены: 0, 1, 0, 1, … или 1, 0, 1, 0, … На каждой глубине нужна коробка известного цвета, и снова **выгодно брать самую большую из подходящих**: она оставляет больше места внутри.

Поэтому выполняем два прохода снаружи внутрь — для каждого цвета внешней коробки — и берём лучший:

```python
boxes = [(40, 0), (37, 1), (33, 1), (31, 0), (26, 0),
         (24, 1), (20, 0), (18, 1), (12, 1)]
gap = 5
best = (0, 0)
for first in (0, 1):
    need, count, last = first, 0, None
    for size, color in sorted(boxes, reverse=True):
        if color != need:
            continue
        if last is None or last - size >= gap:
            count += 1
            last = size
            need = 1 - need
    best = max(best, (count, last))
print(*best)
```

```output
4 18
```

Снаружи коробка цвета 0 даёт цепочку 40, 33, 26, 18; снаружи коробка цвета 1 — только три коробки. Кортеж `(count, last)` сравнивает сначала длину, затем самую маленькую коробку — оба критерия задачи.

**Если зазор растёт с номером коробки, цепочку строят изнутри наружу — тоже двумя проходами.**

Пусть правило имеет вид:

> Между k-й и (k + 1)-й коробкой нужен зазор хотя бы C + k, материалы должны различаться.

Нумерация идёт изнутри наружу, а второй критерий — наименьшая внешняя коробка. Если известно, из какого материала сделана первая коробка, материалы всех следующих определены. Можно выполнить два прохода — цепочка начинается с материала 0 и с материала 1 — и внутри каждого прохода брать минимальную подходящую внешнюю коробку:

```python
boxes = [(10, 0), (11, 1), (13, 1), (14, 0), (17, 0),
         (18, 1), (22, 1), (23, 0), (27, 0), (28, 1),
         (33, 1)]
base_gap = 2
boxes.sort()
best_count = 0
best_outer = None
for first_type in (0, 1):
    expected_type = first_type
    count = 0
    last_size = None
    for size, material in boxes:
        if material != expected_type:
            continue
        gap = base_gap + count
        if last_size is None or size - last_size >= gap:
            count += 1
            last_size = size
            expected_type = 1 - expected_type
    if count > best_count or (
        count == best_count and last_size is not None
        and (best_outer is None or last_size < best_outer)
    ):
        best_count = count
        best_outer = last_size
print(best_count, best_outer)
```

```output
5 33
```

Здесь `base_gap` соответствует C. Почему перед добавлением новой коробки используется `count`? Потому что уже выбрано `count` коробок: последняя из них имеет номер `count`, значит, следующий зазор должен быть не меньше C + count. Цепочка из материала 1 — 11, 14, 18, 23, 33: зазоры 3, 4, 5 и 10, а коробка 28 не подошла, потому что 28 − 23 = 5 < 6.

Почему жадность работает при фиксированном первом материале? На одной и той же позиции цепочки нужный материал одинаков, требуемая прибавка к следующей коробке одинакова, а меньшая текущая коробка оставляет не меньше возможностей продолжения.

**Но если бы материал влиял на другую характеристику**, например на суммарную стоимость или ограниченный запас переходов, одного такого состояния могло бы не хватить. Утверждение проверено полным перебором всех цепочек на тысячах маленьких случайных наборов.

**Наименьшее число блоков равно наибольшему числу коробок, размеры которых отличаются меньше чем на зазор.**

Пусть коробки нужно убрать на склад: группа вложенных друг в друга коробок — **блок** — занимает одну ячейку, одиночная коробка — тоже. Сколько нужно ячеек? Возьмём коробки 12, 14, 18, 21, 22, 27, 34, 40, 45 и зазор 6.

Коробки 18, 21 и 22 попарно отличаются меньше чем на 6 — ни одну из них нельзя вложить в другую. Значит, **они лежат в трёх разных блоках**, и меньше трёх блоков не бывает. Это оценка снизу, и её дают любые коробки, размеры которых умещаются в промежуток короче зазора. Наибольшее число таких коробок находит окно из подтемы 7: участок отсортированного списка, где `a[right] - a[left] < gap`.

<figure class="plate-figure">

<figcaption>Коробки по возрастанию раскладываются в блоки: каждая ложится на блок, верхняя коробка которого меньше хотя бы на 6. Получилось три блока — столько же, сколько коробок 18, 21, 22 с разницей меньше 6.</figcaption>
</figure>

Жадная раскладка этой оценки достигает: идём по коробкам по возрастанию и кладём каждую на любой блок, верх которого меньше её хотя бы на зазор; если такого нет, начинаем новый блок.

```python
sizes = [12, 14, 18, 21, 22, 27, 34, 40, 45]
gap = 6
sizes.sort()
blocks = []
for size in sizes:
    placed = False
    for block in blocks:
        if size - block[-1] >= gap:
            block.append(size)
            placed = True
            break
    if not placed:
        blocks.append([size])
left = widest = 0
for right in range(len(sizes)):
    while sizes[right] - sizes[left] >= gap:
        left += 1
    widest = max(widest, right - left + 1)
print(len(blocks), widest)
```

```output
3 3
```

Флаг `placed` отмечает, нашёлся ли подходящий блок. Для ответа достаточно окна: раскладка нужна, только чтобы увидеть сами блоки. Наибольшее число коробок в одном блоке — это длина самой длинной цепочки из подтемы о цепочках.

<details class="proof" markdown="1">
<summary>Почему жадных блоков ровно столько, сколько коробок в самом широком окне</summary>

Пусть раскладка начала новый блок для коробки s. Значит, верх каждого уже начатого блока больше s − gap, а поскольку коробки идут по возрастанию, он не больше s. Верхние коробки всех блоков вместе с s умещаются в промежуток (s − gap, s] — короче зазора, и они различны как коробки. Их столько, сколько стало блоков. Значит, число блоков не больше наибольшего числа коробок с разницей меньше зазора, а меньше его быть не может — по оценке выше.

</details>

**С чередованием цветов наименьшее число блоков тоже находят жадно: каждую коробку кладут на подходящий блок другого цвета с самым большим верхом.**

Если в блоке цвета вложенных коробок должны чередоваться, верх блока нужен другого цвета. Из подходящих блоков выбирают тот, у которого верхняя коробка больше: блоки с маленьким верхом пригодятся следующим, более мелким по зазору коробкам.

```python
boxes = [(5, 0), (6, 1), (10, 0), (12, 0), (13, 1),
         (17, 1), (18, 0)]
gap = 5
tops = {0: [], 1: []}
blocks = 0
for size, color in sorted(boxes):
    other = tops[1 - color]
    fitting = [t for t in other if t <= size - gap]
    if fitting:
        other.remove(max(fitting))
    else:
        blocks += 1
    tops[color].append(size)
print(blocks)
```

```output
3
```

`tops[c]` — верхние коробки блоков, верх которых цвета c. Коробка 10 цвета 0 не может лечь на 5 того же цвета и начинает новый блок, а коробка 12 цвета 0 ложится на 6 цвета 1: 12 − 6 = 6 ≥ 5. Доказательство правильности здесь длиннее, чем подходит уроку; утверждение проверено полным перебором на тысячах маленьких наборов (наименьшее число блоков через наибольшее паросочетание).

**Лучший набор по убыванию элементов строят заменами сверху вниз.**

Иногда второй критерий при максимальном количестве сложнее «наибольшего отдельного файла»: среди наборов максимального размера нужен тот, где самый большой элемент наибольший, при равенстве — второй по величине наибольший и так далее. Это повторение приёма из подтемы 2 для каждого места набора.

Возьмём вместимость 62 и файлы 8, 12, 15, 19, 22, 34. Четыре самых маленьких занимают 54 — свободно 8, пятый не помещается. Сначала улучшаем самый большой элемент набора: вместо 19 можно взять любой файл не больше 19 + 8 = 27 — берём 22, свободно 5. Затем второй: вместо 15 — любой файл не больше 20 среди файлов между 15 и 22 — это 19, свободно 1. Третий, 12, заменить нечем.

```python
sizes = sorted([8, 12, 15, 19, 22, 34])
capacity = 62
used = k = 0
for x in sizes:
    if used + x > capacity:
        break
    used += x
    k += 1
chosen = list(range(k))
free = capacity - used
upper = len(sizes)
for j in range(k - 1, -1, -1):
    best = chosen[j]
    for i in range(chosen[j] + 1, upper):
        if sizes[i] - sizes[chosen[j]] <= free:
            best = i
    free -= sizes[best] - sizes[chosen[j]]
    chosen[j] = best
    upper = best
print(*[sizes[i] for i in chosen])
```

```output
8 12 19 22
```

`chosen` хранит индексы выбранных файлов, `upper` не даёт взять файл, уже занятый местом выше. Почему замены идут сверху вниз и каждый раз берут наибольший возможный файл? Самый большой элемент важнее всех остальных, а остальные пока самые маленькие — они оставляют ему наибольшее место; затем то же рассуждение повторяется для второго места при закреплённом первом.

---

**Итого.**

- Чередование при постоянном зазоре — два жадных прохода по цвету внешней коробки.
- Зазор, растущий с номером, — два прохода изнутри наружу по материалу первой коробки; `count` перед добавлением — номер последней выбранной коробки.
- Наименьшее число блоков — наибольшее число коробок в окне короче зазора; жадная раскладка его достигает.
- С чередованием цветов — жадно, на подходящий блок другого цвета с наибольшим верхом.
- Лучший набор по убыванию элементов — замены сверху вниз приёмом «наибольший, что помещается».
