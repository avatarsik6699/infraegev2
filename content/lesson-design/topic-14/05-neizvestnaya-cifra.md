**Неизвестная цифра принимает лишь несколько значений, поэтому её перебирают, каждый раз раскладывая запись по степеням основания.** Это частый вид задания: одна цифра x стоит в нескольких числах, сумма должна делиться на заданное число, а в ответ идёт частное.

Пройдём одну задачу от начала до конца: сумма 2Ax5₁₆ + 1xB3₁₆ должна делиться на 15. Потом посмотрим, что меняется, когда основания разные.

---

**В задачах с неизвестными цифрами сначала нужно определить, что именно обозначает буква.** Рассмотрим запись 2x3₇. Здесь x занимает место **одной цифры**. Это не умножение 2 · x · 3. По позиционной записи 2x3₇ = 2 · 7² + x · 7 + 3. Если x = 4, получится 243₇.

Если одна буква встречается несколько раз, её значение одинаково во всех этих местах. Например, 1xx2₇ = 1 · 7³ + x · 7² + x · 7 + 2. Нельзя в одном вхождении поставить `3`, а в другом `5`.

---

**Допустимые значения переменной определяются всеми условиями одновременно.** Выбери условие и посмотри, какие значения у x:

:::pick Условие и допустимые значения x
- *x — цифра пятеричной системы | 0, …, 4
- x — цифра шестнадцатеричной системы | 0, …, 15
- x — именно десятичная цифра | 0, …, 9
- x встречается в основаниях 8 и 13 | 0, …, 7 | цифра должна быть допустима в обоих
- x — первая цифра числа, которое должно оставаться многозначным | ноль исключается
:::

Особенно внимательно читай фразу «неизвестная цифра из алфавита десятичной системы счисления». Она ограничивает x значениями от 0 до 9, даже если числа записаны, например, в основаниях 15 и 18. Бывает и наоборот: числа записаны в системе с основанием 22, а x — «цифра из алфавита 15-ричной системы», тогда x от 0 до 14 (так было на основной волне ЕГЭ-2023). Для 2Ax5₁₆ + 1xB3₁₆ диапазон простой: x ∈ {0, 1, …, 15}.

---

**Запись с неизвестной цифрой раскладывают по степеням основания, и сумма становится выражением от x.** Раскрываем записи:

2Ax5₁₆ = 2 · 16³ + 10 · 16² + x · 16 + 5,

1xB3₁₆ = 16³ + x · 16² + 11 · 16 + 3.

После сложения S = 15032 + 272x. Что означает «делится на 15» или «кратно 15»? Это значит, что существует целое число k, для которого S = 15k. При делении остаток равен нулю: `S % 15 == 0`.

---

**Перебор цифр по возрастанию с остановкой на первой подходящей находит наименьшую цифру.** `range(16)` последовательно даёт 0, 1, 2, …, 15 — правая граница не включается. {{break|`break`}} завершает ближайший цикл.

```python
for x in range(16):
    a = 2*16**3 + 10*16**2 + x*16 + 5
    b = 16**3 + x*16**2 + 11*16 + 3

    total = a + b

    if total % 15 == 0:
        print(x, total, total // 15)
        break
```

```output
14 18840 1256
```

Почему здесь можно остановиться на первом подходящем значении? Потому что требуется минимальный x, мы проверяем x по возрастанию, и все меньшие значения к этому моменту уже проверены. Получаем x = 14, S = 18840, S / 15 = 1256. **Ответ: 1256.** Числовому значению 14 соответствует шестнадцатеричная цифра `E`.

Если нужен **наибольший** x, перебирают по убыванию, `range(15, -1, -1)`, и тоже останавливаются на первом подходящем — или перебирают по возрастанию и запоминают последнее подходящее, как в подтеме 4.

---

**Длинную запись удобнее считать функцией, которая приписывает цифры по одной.** В задачах экзамена числа с x бывают из семи-восьми цифр и по три слагаемых, а разложение по степеням вручную длинное и легко ошибиться в показателе. Мы уже знаем из подтемы 1: приписать справа цифру d — значит заменить текущее значение на Nq + d. Поэтому запись можно прочитать слева направо, начав с нуля: так же в теме 8 по слову находили его номер. Нажми «Запуск» и посмотри, как 2304₅ превращается в 329:

```python run value.py
def value(ds, q):
    v = 0
    for d in ds:
        v = v * q + d
    return v


print(value([2, 3, 0, 4], 5))
```

```output
329
```

Цифры передаются списком значений, поэтому буквы не нужны: `A` — это 10, `B` — 11, а на место x встаёт сама переменная цикла. Предполагается, что значения цифр допустимы, 0 ≤ d < q. Та же задача:

```python
for x in range(16):
    a = value([2, 10, x, 5], 16)
    b = value([1, x, 11, 3], 16)
    if (a + b) % 15 == 0:
        print((a + b) // 15)
        break
```

```output
1256
```

**Основания больше 36 не требуют нового метода.** Например, дана запись 1x2₅₀, где x — одна цифра со значением от 0 до 49. Её значение 1 · 50² + x · 50 + 2; при x = 37 получаем 2500 + 1850 + 2 = 4352, и `value([1, 37, 2], 50)` даёт то же. Не нужно придумывать отдельный печатный знак для цифры 37: можно работать с её числовым значением. Такой способ работает с любым целым основанием q ≥ 2, а строковый `int(s, q)` — только до 36.

---

**Строковый перебор тоже работает, но перебирать нужно символы алфавита, а не `str` от числа.** Можно перебирать символы строки `'0123456789ABCDEF'`, склеивать из них запись и читать её {{base|`int(…, 16)`}}: при `x = 'E'` выражение `'2A' + x + '5'` даёт строку `2AE5`.

<details class="proof" markdown="1">
<summary>Строковый вариант перебора целиком</summary>

```python
alphabet = '0123456789ABCDEF'

for x in alphabet:
    a = int('2A' + x + '5', 16)
    b = int('1' + x + 'B3', 16)

    total = a + b

    if total % 15 == 0:
        print(x, total // 15)
        break
```

```output
E 1256
```

Здесь переменная `x` поочерёдно содержит **символы**, а `+` между {{str|строками}} соединяет их.

</details>

**Нельзя бездумно подставлять десятичную запись значения цифры в строку.** Если числовое x равно 10, то `'1' + str(x) + '2'` даст `1102` — это четыре цифры. А запись с одной цифрой значения десять должна быть `1A2`. Поэтому при числовом переборе используй разложение по степеням или `value`, а при строковом — подходящие символы алфавита. Если нужно числовое значение найденного символа, например `'E'`, его даёт `int(x, 16)`.

---

**В ответ записывают ровно ту величину, о которой спрашивают.** Можно правильно найти x, но дать неверный ответ, если требовалось частное. В подборках встречается и частное от деления на **другое** число: сумма делится на 16, а в ответ — частное от деления на 8. Для нашей суммы S = 18840 выбери, что спросили:

:::pick Что спрашивают и что записать
- *частное от деления на 15 | 1256 | `total // 15`
- частное от деления на 5 | 3768 | делимость проверяем на 15, делим на 5
- значение выражения | 18840 | `total`
- цифру x | 14 | в шестнадцатеричной записи — `E`
:::

Если в выражении есть вычитание, его записывают как есть: `a + b - c`. Если сказано «ненулевая цифра», перебор начинают с единицы: `range(1, q)`.

---

**В разных основаниях одна и та же цифра имеет одинаковое значение, но разный вес разряда.** Разберём 3x2₈ + 2x5₁₃: нужно найти минимальный x, при котором сумма кратна 17, и вывести частное. Цифра встречается в обоих основаниях, значит, x ∈ {0, 1, …, 7}. Раскрываем: 3x2₈ = 3 · 8² + 8x + 2 = 194 + 8x, 2x5₁₃ = 2 · 13² + 13x + 5 = 343 + 13x. Поэтому S = 537 + 21x.

В первом числе цифра x умножается на 8, во втором — на 13. Значение цифры одинаковое, но места имеют разные веса.

---

**Ответ можно найти и до программы: часть суммы, кратную делителю, отбрасывают.** Если A = mk + r, то добавление или удаление части mk не меняет остаток от деления на m. Например, 537 = 17 · 31 + 10, поэтому при проверке остатка по модулю 17 число 537 можно заменить на 10. Выражение «по модулю 17» здесь означает: нас интересует остаток при делении на 17.

Для нашей суммы 537 + 21x = 17(31 + x) + (10 + 4x). Первая часть делится на 17. Поэтому нужно, чтобы делилась вторая, 10 + 4x.

При x от 0 до 7 она находится между 10 и 38. Возможные кратные 17: 17 и 34. Уравнение 10 + 4x = 17 не даёт целой цифры, а 10 + 4x = 34 даёт x = 6. Программа подтверждает:

```python
for x in range(8):
    a = value([3, x, 2], 8)
    b = value([2, x, 5], 13)

    total = a + b

    if total % 17 == 0:
        print(x, total // 17)
        break
```

```output
6 39
```

Получаем x = 6, S = 663, 663 / 17 = 39. **Ответ: 39.**

---

**Итого.**

- Буква в записи — одна цифра; одна и та же буква везде одинакова.
- Диапазон цифры — пересечение всех условий: оснований, «десятичного алфавита», запрета нуля.
- Запись с x считают по степеням или функцией `value(ds, q)`: она работает при любом основании, `int(s, q)` — до 36.
- Наименьший x — первый при переборе по возрастанию с `break`, наибольший — первый при переборе по убыванию.
- В строку подставляют символ алфавита, а не `str(x)`; в ответ — ровно то, что спросили.
