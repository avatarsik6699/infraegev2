## Правило уровней

- **Основной уровень** — цифры значения выражения программой (точные большие степени, % и // в цикле) с ручной проверкой по блокам степеней, свойства цифр, параметр x в выражении, значение записи с неизвестной цифрой, одна неизвестная цифра в одном или разных основаниях, две неизвестные цифры с явным выбором лучшего значения, основания больше 36.
- **Дополнительный уровень** — неизвестное основание (равенство с буквами-цифрами, кратность q − 1), наименьшая добавка до кратного и параметр x без верхней границы, когда ответ около 10⁷ и начало перебора нужно вывести рассуждением. Таких задач 13 из 111; на экзаменах они не встречались.

## Как проверена разметка

Все 111 задач решены программой (перебор цифр, параметра или основания), ответы совпали с ответами подборок. Подсчёт цифр в записи значения выражения занимает доли секунды даже для степеней около 6000: Python считает целые числа точно, цифр в записи — несколько тысяч. Задачи с параметром x (13) перебирают до 8410 значений x за доли секунды или секунды, две задачи без верхней границы (89197, 89233) находят ответ циклом `while` за миллисекунды.

## Где кончается перебор параметра

В 73840 и 73869 верхней границы x нет, а ответ около 2,9 · 10⁷: перебор с единицы занимает около 45 секунд. Обоснованной верхней границы, которая ускорила бы перебор, нет — ответ сам лежит далеко. Зато есть нижняя граница из блоков записи: пока x не больше младшего блока L выражения, старшие нули не исчезают и условие выполниться не может; перебор с L + 1 находит ответ сразу (это L + 1). Такое рассуждение — приём дополнительного уровня (решение архитектора 2026-10-12).

Ручной подсчёт по блокам степеней (qᵐ − qⁿ — это m − n цифр q − 1 и n нулей) приёмом не считается: все задачи основного уровня решаются программой, а блоки объясняют ответ и проверяют его. Признак делимости на q − 1 (сумма цифр) тоже не нужен программе: он дан как ручной способ в дополнительной подтеме, где задача 68247 решается им в одну строку.

Основание больше 36 отмечено там, где `int(s, q)` не работает (7 задач). Неизвестная цифра в таких задачах перебирается так же, а значение записи считается по цифрам-числам.
