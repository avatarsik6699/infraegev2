**При двух неизвестных цифрах нужно проверить все допустимые пары и отдельно учесть, что именно минимизируется.** Это одна из самых важных тонкостей задания: первая подходящая пара почти никогда не даёт наименьшее значение.

Будем искать наименьшее значение выражения 1xy₅ + 2yx₇, которое делится на 5, и выводить частное. Функцию `value` из подтемы 5 считаем определённой выше в программе.

---

**Для двух переменных диапазоны определяются отдельно.** Например, в выражении 1x2₈ + 2yA₁₆ получаем 0 ≤ x ≤ 7 и 0 ≤ y ≤ 15. Нельзя автоматически ограничивать обе переменные меньшим основанием: y в восьмеричном числе не встречается.

И ещё: разные буквы не обязаны обозначать разные цифры. Значения x = y допустимы, если условие явно их не запрещает.

В выражении 1xy₅ + 2yx₇ обе цифры встречаются в пятеричной записи, поэтому x, y ∈ {0, 1, 2, 3, 4}.

---

**Раскладываем обе записи, и сумма становится выражением от двух цифр.** 1xy₅ = 25 + 5x + y, 2yx₇ = 98 + 7y + x, сумма S = 123 + 6x + 8y. Всего 5 · 5 = 25 пар; посмотрим на все сразу:

Минимальная сумма 135 получается при x = 2, y = 0. Ответ: 135 / 5 = **27**.

---

**Первую подходящую пару брать нельзя: порядок перебора пар не гарантирует возрастание значения.** Если перебирать сначала x, а внутри каждого x — значения y, первой подходящей будет x = 0, y = 4. Она даёт 155, хотя существует 135. Уменьшение одной цифры может сопровождаться увеличением другой: в сумме 123 + 6x + 8y цифра y весит больше, чем x.

Ещё одна особенность: {{break|`break`}} завершает только ближайший цикл. Если поставить его внутри цикла по y, цикл по x продолжится.

---

**Наименьшее значение находят явным сравнением всех подходящих сумм.** Пары перебирают {{nested|вложенными циклами}}: для каждого фиксированного x внутренний цикл проверяет все значения y. Сравнение с лучшим — тот же приём, что в подтеме 4: `best` хранит наименьшую подходящую сумму, {{none|`None`}} означает, что подходящая сумма ещё не найдена.

```python
best = None

for x in range(5):
    for y in range(5):
        a = value([1, x, y], 5)
        b = value([2, y, x], 7)

        total = a + b

        if total % 5 == 0:
            if best is None or total < best:
                best = total

if best is not None:
    print(best, best // 5)
```

```output
135 27
```

Условие `best is None or total < best` означает: либо это первая подходящая сумма, либо новая сумма меньше сохранённой. При поиске минимума среди подходящих значений обычно проще проверить все пары и сравнить результаты.

---

**Иногда спрашивают не о значении выражения, а о самой паре.** В подборках встречаются вопросы «при каких x и y число кратно 36, а запись yx — наибольшая» или «запись yx — полный квадрат». Тогда для каждой подходящей пары считают ту величину, о которой спросили, и выбирают лучшую уже по ней. Например, среди пар, при которых 1xy₅ + 2yx₇ кратно 5, найдём ту, где пятеричная запись yx наибольшая:

```python
best = None

for x in range(5):
    for y in range(5):
        total = value([1, x, y], 5) + value([2, y, x], 7)
        pair = value([y, x], 5)
        if total % 5 == 0:
            if best is None or pair > best:
                best = pair

print(best)
```

```output
20
```

Это пара x = 0, y = 4: запись 40₅ = 20. Сумма у этой пары не наименьшая — у разных вопросов разные лучшие пары. Если спрашивают, является ли запись yx **полным квадратом**, проверяют целый корень: `isqrt(v) ** 2 == v`, где {{import|`isqrt` из модуля `math`}} — целая часть квадратного корня. Если основание больше 36, программа не меняется: `value` работает с числовыми значениями цифр.

---

**Итого.**

- Диапазон каждой буквы определяют отдельно — по основаниям, где она встречается.
- Все пары перебирают вложенными циклами; `break` выходит только из внутреннего.
- Первая подходящая пара не обязательно лучшая: лучшую выбирают явным сравнением с `best`.
- Сравнивают ту величину, о которой спрашивают: значение выражения, запись yx или её свойство.
