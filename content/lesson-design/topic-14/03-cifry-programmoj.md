**Программа считает цифры любого выражения одним способом: берёт последнюю цифру остатком и отбрасывает её целочисленным делением, пока число не кончится.** Так решается любая задача на подсчёт цифр, в том числе с основанием до 36 и вопросом о свойстве цифр. Ручной разбор из подтемы 2 становится проверкой.

Посчитаем нули в пятеричной записи 329 = 2304₅, затем проверим программой подсчёт подтемы 2 для 5¹² + 5⁷ − 5³.

---

**Большие целые степени Python вычисляет точно, если не выходить из целых чисел.** Возведение в степень записывается {{intdiv|`**`}}: `2 ** 10` — это 2¹⁰. Знак `^` в Python выполняет другую операцию и для возведения в степень не подходит.

Целые числа Python поддерживают произвольную точность; практические ограничения связаны с доступными ресурсами ([документация Python](https://docs.python.org/3/library/stdtypes.html)). Для выражений задания 14 это позволяет работать с точным целым результатом, даже если в нём тысячи цифр.

Для таких вычислений сохраняй целочисленные операции. Обычное деление `/` создаёт результат типа `float`, то есть {{floaterr|число с ограниченной точностью}}. Поэтому `n // q` нельзя бездумно заменять на `int(n / q)`: для большого числа точность теряется уже при `/`.

```python
n = 4**50 + 2**30 - 15
print(len(str(n)))
print(n // 7 == int(n / 7))
```

```output
31
False
```

В десятичной записи этого числа 31 цифра, и `int(n / 7)` уже отличается от точного `n // 7`.

**Программа подсчёта повторяет одно действие: проверить последнюю цифру и удалить её.** Посчитаем нули в записи 329₁₀ по основанию 5. Нажми «Запуск» и пройди программу по шагам: видно, как `n` теряет цифру за цифрой, а `count` растёт только на нуле.

```python run count_digit.py
number = 329
q = 5
target = 0

n = number
count = 0

while n > 0:
    digit = n % q
    if digit == target:
        count = count + 1
    n = n // q

print(count)
```

```output
1
```

`n` — рабочая копия числа: из неё удаляются цифры, а `number` остаётся исходным. После четырёх проходов `n` становится нулём, и условие {{while|`n > 0`}} ложно.

**Почему программа гарантированно учитывает все цифры?** На каждом шаге она проверяет одну крайнюю правую цифру, удаляет ровно эту цифру и переходит к следующей. Ни одна цифра не пропускается и не обрабатывается дважды. Порядок извлечения обратный, но для количества это не имеет значения.

Для большого примера нужно заменить только исходные данные: `number = 5**12 + 5**7 - 5**3`, `target = 4`. Остальной код останется прежним, и получится 4 — столько же четвёрок насчитали блоками в подтеме 2.

**Отдельный случай — исходное число ноль.** При `number = 0` цикл не выполнится ни разу. Однако запись числа `0` содержит одну цифру `0`. Поэтому приведённый вариант предназначен для положительного числа. Если ноль возможен, нужно обработать его отдельно или воспользоваться функцией из следующего шага.

**Если нужны сами цифры, удобно собрать их в список значений.** Например, {{list|список}} `[2, 3, 0, 4]` может представлять цифры числа 2304₅. Каждый элемент — числовое значение отдельной цифры. Такой подход работает и тогда, когда значение цифры больше девяти. В теме 5 функция `to_base` собирала запись строкой из `str(digit)` — это годится только для оснований до 10, а список значений годится для любого.

Чтобы не повторять алгоритм, оформим его в {{def|функцию}}: передадим число `n` и основание `q`, а получим список цифр. Запусти программу по шагам и посмотри, как список растёт справа налево и в конце переворачивается:

```python run digits.py
def digits(n, q):
    if n == 0:
        return [0]

    result = []

    while n > 0:
        result.append(n % q)
        n = n // q

    result.reverse()
    return result


print(digits(329, 5))
```

```output
[2, 3, 0, 4]
```

Функция рассчитана на n ≥ 0, q ≥ 2. `result.append(...)` добавляет одну цифру в конец списка, а `result.reverse()` меняет порядок элементов на обратный. Переворот нужен потому, что остатки извлекаются справа налево, а список мы хотим получить в обычном порядке.

**Список цифр отвечает на любой вопрос о записи: сколько данных цифр, сколько всего, какова сумма.** Выбери вопрос и посмотри код и результат для `[2, 3, 0, 4]`:

:::pick Вопрос о записи 2304₅ и код
- *Количество нулей | `ds.count(0)` → 1
- Количество троек | `ds.count(3)` → 1
- Количество цифр всего | `len(ds)` → 4
- Сумма значений цифр | `sum(ds)` → 9
- Наибольшая цифра | `max(ds)` → 4
- Наименьшая цифра | `min(ds)` → 0
:::

{{listcount|`count`}} считает элементы, равные указанному значению, {{len|`len`}} возвращает длину списка, {{agg|`sum`, `max` и `min`}} — сумму и крайние значения. Проверим подсчёт подтемы 2:

```python
number = 5**12 + 5**7 - 5**3
ds = digits(number, 5)
print(ds.count(4), ds.count(0), len(ds), sum(ds))
```

```output
4 8 13 17
```

Четыре четвёрки, восемь нулей, 13 цифр — как насчитали блоками. **Количество цифр и сумма цифр — разные характеристики**: для записи `2304` количество цифр равно 4, а сумма цифр 2 + 3 + 0 + 4 = 9.

---

**Цифры со свойством считают проверкой каждой цифры: чётные, больше 9, не больше заданного.** Конструкция {{for|`for d in ds:`}} поочерёдно берёт каждый элемент списка. В задачах спрашивают о разном, но каждый вопрос — проверка или подсчёт по тому же списку. Выбери вопрос:

:::pick Вопрос о цифрах и как его проверить
- *Сколько цифр с чётным значением | в цикле `if d % 2 == 0: count = count + 1`
- Сколько цифр больше 9 | в цикле `if d > 9: count = count + 1`
- Сумма цифр не больше 17 | в цикле `if d <= 17: total = total + d`
- Сколько различных цифр | `len(set(ds))`
- Какая цифра встречается чаще всего | `max(range(q), key=ds.count)`
:::

Проверим три вопроса на пятеричной записи 5¹² + 5⁷ − 5³:

```python
ds = digits(5**12 + 5**7 - 5**3, 5)
count = 0
for d in ds:
    if d % 2 == 0:
        count = count + 1
print(count)
print(len(set(ds)), max(range(5), key=ds.count))
```

```output
12
3 0
```

Чётных цифр 12: восемь нулей и четыре четвёрки — **ноль тоже чётный**, потому что делится на два без остатка. {{set|`set(ds)`}} оставляет различные цифры: их три, 0, 1 и 4. `max(range(5), key=ds.count)` перебирает возможные цифры и выбирает ту, что встречается чаще всего, — 0; запись {{sortkey|`key=`}} говорит `max` сравнивать цифры по их количеству.

Цифры больше 9 бывают только при основании больше 10. Запишем то же число в системе с основанием 25:

```python
big = digits(5**12 + 5**7 - 5**3, 25)
print(big)
count = 0
for d in big:
    if d > 9:
        count = count + 1
print(count)
```

```output
[1, 0, 0, 4, 24, 20, 0]
2
```

Цифры 24 и 20 — это одна цифра каждая: список хранит их значения, и букв для них придумывать не нужно.

**Готовые `bin`, `oct` и `hex` годятся только для оснований 2, 8 и 16, а их строка начинается служебным префиксом.** {{base|`bin(22)`}} возвращает `'0b10110'`; начальные `0b`, `0o`, `0x` — служебные обозначения основания, а `bin(22)[2:]` их отбрасывает. Это знакомо по теме 5. Подсчёт единиц из подтемы 2 — одной строкой:

```python
number = 4**50 + 2**30 - 15
print(bin(number)[2:].count('1'))
print(bin(8), bin(8).count('0'), bin(8)[2:].count('0'))
```

```output
28
0b1000 4 3
```

Здесь `'1'` в кавычках, потому что мы считаем символы строки; для списка значений цифр пишут `ds.count(1)`, без кавычек. **При подсчёте нулей особенно важно убрать служебное начало**: в полной строке `0b1000` четыре символа `0`, а в двоичной записи числа — три.

`int(строка, основание)` делает обратное — читает готовую запись: `int('2304', 5)` даёт 329. Это не перевод десятичной записи в основание q. Для оснований вроде 3, 5, 7 и всех больше 16 удобнее функция `digits`. А `str(number)` даёт **десятичную** запись — её цифры к заданию отношения не имеют.

---

**Итого.**

- Огромные степени — целые числа Python, точные; `/` даёт `float` и теряет цифры.
- Цикл `while n > 0` с `n % q` и `n // q` проходит все цифры записи в основании q ровно по разу.
- `digits(n, q)` возвращает список значений цифр для любого основания; дальше — `count`, `len`, `sum`, `max`, `set`.
- Цифры со свойством считают циклом по списку; ноль — чётная цифра.
- `bin(n)[2:]` без `0b`; `'1'` — символ строки, `1` — значение в списке.
