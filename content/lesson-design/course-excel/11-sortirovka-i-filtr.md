**Сортировка меняет порядок записей, фильтр только прячет строки, а обычные функции считают и спрятанное.** Урок опирается на записи и поля из урока 1, на функции из урока 6 и на подсчёт по условию из урока 9: здесь видно, чем отбор формулой надёжнее отбора глазами.

Пример урока — покупки по городам: отсортируем их, отберём Москву и сравним суммы.

---

**Сортируют всю таблицу целиком: строка — запись, и её поля переезжают вместе.** Сортировка меняет порядок записей. Например, можно расположить товары по возрастанию цены, а покупателей — по убыванию балла. Выделяй всю связанную таблицу вместе с заголовками, затем выбирай столбец сортировки.

Если отсортировать только столбец цен, оставив названия на месте, данные перемешаются: цена перестанет относиться к прежнему товару. Это не косметическая ошибка, а изменение смысла таблицы.

```sheet Сортировка select=B2 edit=none
|   | A        | B     | C | D        | E     | F | G        | H
| 1 | Исходно  |       |   | Вся таблица по цене |  |  | Только столбец цен |
| 2 | Тетрадь  | 40    |   | Карандаш | 15    |   | Тетрадь  | 15
| 3 | Ручка    | 20    |   | Ручка    | 20    |   | Ручка    | 20
| 4 | Папка    | 120   |   | Тетрадь  | 40    |   | Папка    | 40
| 5 | Карандаш | 15    |   | Папка    | 120   |   | Карандаш | 120
```

В средней таблице каждая цена осталась при своём товаре. В правой отсортирован только столбец цен: тетрадь «подешевела» до 15, а карандаш стал стоить 120.

При сортировке по нескольким признакам важен порядок уровней. «Сначала город, затем балл по убыванию» означает: сначала сгруппировать города, внутри каждого города упорядочить баллы. Обратный порядок уровней даст иной результат.

```sheet Уровни select=D2 edit=none
|   | A       | B    | C | D       | E    | F | G       | H
| 1 | Исходно |      |   | Город, затем балл ↓ |  |  | Балл ↓, затем город |
| 2 | Москва  | 72   |   | Казань  | 85   |   | Омск    | 90
| 3 | Казань  | 85   |   | Казань  | 64   |   | Казань  | 85
| 4 | Москва  | 60   |   | Москва  | 72   |   | Москва  | 72
| 5 | Казань  | 64   |   | Москва  | 60   |   | Казань  | 64
| 6 | Омск    | 90   |   | Омск    | 90   |   | Москва  | 60
```

В средней таблице города идут группами, а баллы упорядочены только внутри своего города: 85 и 64 у Казани, 72 и 60 у Москвы. В правой главный порядок — баллы, и города перемешаны; город решал бы только при равных баллах.

Сортировка записей сверху вниз не равна сортировке чисел внутри каждой строки. В задании 9 обычно удобнее найти минимум, максимум и нужные порядковые элементы формулами, чем пытаться отдельно сортировать тысячи строк.

---

**Фильтр временно скрывает неподходящие строки, данные остаются в книге.** Фильтр временно скрывает строки, не соответствующие выбранным условиям. Данные остаются в книге. Чтобы включить фильтр, выдели таблицу с заголовками и выбери «Данные → Фильтр». В заголовках появятся элементы выбора.

Условия в разных столбцах обычно применяются совместно: город Москва И балл не меньше 60. Несколько отмеченных значений внутри одного столбца означают выбор любого из них: Москва `ИЛИ` Казань. Всегда проверяй значки фильтра, если часть строк неожиданно исчезла.

Перед новой независимой задачей сбрось предыдущие фильтры. Иначе новое условие может добавиться к старому, и ты незаметно посчитаешь более узкую выборку.

---

**`СУММ` складывает и скрытые фильтром строки; сумму видимых считает `ПРОМЕЖУТОЧНЫЕ.ИТОГИ`.** Обычная `=СУММ(D2:D100)` суммирует диапазон независимо от того, какие его строки сейчас скрыты фильтром. `СУММЕСЛИ` также проверяет свои критерии, а не состояние видимости. Поэтому нельзя отфильтровать таблицу, ввести обычную сумму всего столбца и автоматически считать её суммой отобранных записей.

Для суммы видимых строк предназначена функция:

```excel
=ПРОМЕЖУТОЧНЫЕ.ИТОГИ(109;D2:D100)
```

На листе ниже включён фильтр «город — Москва»: строки 3 и 5 скрыты, номера строк идут с пропусками, как в Excel.

```sheet Фильтр select=D8
|   | A   | B       | C | D
| 1 | ID  | Город   |   | Сумма
| 2 | 1   | Москва  |   | 100
| 3 | 2   | Казань  |   | 200
| 4 | 3   | Москва  |   | 150
| 5 | 4   | Омск    |   | 300
| 6 | 5   | Москва  |   | 50
| 8 |     | СУММ               |   | =СУММ(D2:D6) ⇒ 800
| 9 |     | видимые строки      |   | =ПРОМЕЖУТОЧНЫЕ.ИТОГИ(109;D2:D6) ⇒ 300
| 10 |    | Москва по условию   |   | =СУММЕСЛИ(B2:B6;"Москва";D2:D6) ⇒ 300
| 11 |    | видимых записей     |   | =ПРОМЕЖУТОЧНЫЕ.ИТОГИ(103;A2:A6) ⇒ 3
filter 3 5
```

Видимая сумма и `СУММЕСЛИ` совпали — но по разным причинам: первая зависит от того, какой фильтр включён сейчас, вторая записывает условие в саму формулу. Если сбросить фильтр, `D9` станет 800, а `D10` останется 300.

Первый аргумент выбирает операцию и режим работы со скрытыми строками. 109 означает сумму с пропуском отфильтрованных и вручную скрытых строк. 9 тоже считает сумму без отфильтрованных строк, но учитывает строки, скрытые вручную. Режим относится к строкам; скрытие столбца не исключает его значения аналогичным образом.

```sheet Скрытые select=D8 edit=none
|   | A   | B       | C | D
| 1 | ID  | Город   |   | Сумма
| 2 | 1   | Москва  |   | 100
| 3 | 2   | Казань  |   | 200
| 4 | 3   | Москва  |   | 150
| 5 | 4   | Омск    |   | 300
| 6 | 5   | Москва  |   | 50
| 8 |     | код 9   |   | =ПРОМЕЖУТОЧНЫЕ.ИТОГИ(9;D2:D6) ⇒ 600
| 9 |     | код 109 |   | =ПРОМЕЖУТОЧНЫЕ.ИТОГИ(109;D2:D6) ⇒ 300
filter 3
hide 5
```

Здесь строка 3 скрыта фильтром, а строка 5 — вручную. Код 9 пропускает только отфильтрованную строку: 800 − 200 = 600; код 109 — обе: 800 − 200 − 300 = 300.

Для количества видимых числовых ячеек используется код 102, для видимых непустых — 103. Если нужно количество записей, выбери столбец с обязательно заполненным кодом записи. Такой код часто обозначают ID — идентификатор. Счётчик непустых значений случайного столбца с пропусками может дать меньше записей, чем на самом деле.

---

**Строка состояния — быстрая проверка, итоговая формула — воспроизводимый ответ.** Внизу окна Excel для выделенного диапазона могут показываться сумма, среднее и количество. Это удобно для быстрой проверки. Но различай количество всех непустых ячеек и количество чисел, а также проверяй, какой диапазон реально выделен. Итоговая формула в отдельной ячейке лучше сохраняет воспроизводимый результат.

---

**Итого.**

- Сортируют всю таблицу с заголовками: поля записи переезжают вместе.
- Порядок уровней сортировки важен: сначала группа, внутри неё — порядок.
- Фильтр прячет строки; условия разных столбцов — И, значения одного столбца — `ИЛИ`.
- `СУММ` и `СУММЕСЛИ` не видят фильтра; `ПРОМЕЖУТОЧНЫЕ.ИТОГИ(109;…)` считает только видимое, 9 — учитывает скрытое вручную.
- Ответ записывают формулой, строка состояния — только для проверки.

**Чтобы проверить понимание, реши задачи сначала рассуждением, а затем в Excel.**

1. В отфильтрованной таблице суммы находятся в `D2:D100`. Как сложить только видимые строки, исключив также вручную скрытые?

2. В таблице 6 строк с суммами 10, 20, 30, 40, 50, 60. Фильтр скрыл строки с суммами 20 и 50, вручную скрыта строка с 60. Что вернут `СУММ`, `ПРОМЕЖУТОЧНЫЕ.ИТОГИ` с кодом 9 и с кодом 109?

3. Как посчитать число видимых записей, если в столбце «Комментарий» есть пустые ячейки, а в столбце ID — нет?

4. Чем отличается сортировка «город, затем балл» от «балл, затем город»?

5. Таблицу отфильтровали по Москве и забыли сбросить фильтр. Затем включили фильтр «балл ≥ 80». Какие строки видны?

6. Почему ответ задачи надёжнее записать формулой `СУММЕСЛИ`, чем отфильтровать таблицу и посмотреть строку состояния?

7. Можно ли отсортировать числа внутри каждой строки, чтобы найти максимум строки? Что для этого удобнее?

**Ответы для проверки:**

1. `=ПРОМЕЖУТОЧНЫЕ.ИТОГИ(109;D2:D100)`. Обычная `СУММ` не учитывает отбор видимых строк.
2. 210, 140 и 80.
3. `=ПРОМЕЖУТОЧНЫЕ.ИТОГИ(103;…)` по столбцу ID: он заполнен в каждой записи.
4. В первом случае строки сгруппированы по городам, баллы упорядочены внутри города; во втором — по баллу, город важен только при равных баллах.
5. Только московские строки с баллом не меньше 80: условия разных столбцов действуют вместе.
6. Формула сохраняет условие и пересчитывается; строка состояния зависит от текущего выделения и фильтра.
7. Сортировать строки по отдельности неудобно и опасно для данных; максимум строки даёт `=МАКС(A2:F2)`, k-е по величине — `НАИБОЛЬШИЙ`.
