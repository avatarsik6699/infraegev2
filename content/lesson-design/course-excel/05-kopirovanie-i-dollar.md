**При копировании формулы её адреса сдвигаются вместе с ней, а знак $ запрещает сдвигаться той части адреса, перед которой стоит.** Урок продолжает урок 4: там формулу стоимости набирали в каждой строке, здесь одна формула заполнит весь столбец, и станет видно, когда сдвиг нужен, а когда мешает.

Пример урока — таблица покупок и общая скидка в ячейке `H2`.

---

**Ссылка без $ относительна: она указывает не на «ячейку `B2`», а на «ячейку на столько-то левее и выше».** Если в `D2` записано `=B2*C2`, то для следующей строки нужно `=B3*C3`. Меняется номер строки, а смысл остаётся тем же: «цена этой строки умножить на количество этой строки». Excel умеет автоматически изменять адреса при копировании.

Ссылка `B2` без знаков $ называется относительной. Это значит, что при копировании формулы её адрес сдвигается на то же число строк и столбцов, что и сама формула. При переносе копии на одну строку вниз `B2` превращается в `B3`. При копировании на два столбца вправо — в `D2`.

Такое поведение удобно: одна формула описывает одинаковое действие для тысячи записей. Копирование не вставляет тысячу одинаковых адресов, а сохраняет расположение нужных данных относительно результата.

```sheet База select=D4
|   | A        | B     | C          | D
| 1 | Товар    | Цена  | Количество | Стоимость
| 2 | Тетрадь  | 40    | 5          | =B2*C2 ⇒ 200
| 3 | Ручка    | 20    | 3          | ⇒ 60
| 4 | Папка    | 120   | 2          | ⇒ 240
| 5 | Карандаш | 15    | 4          | ⇒ 60
fill D2:D5
```

Формула набрана один раз — в `D2`. Выбери `D3`, `D4`, `D5`: в каждой стоит её копия со своими адресами, и рамки показывают, что копия берёт цену и количество своей строки.

---

**Столбец заполняют маркером, командой заполнения или выделением; конец заполнения проверяют.** Выдели `D2`. В правом нижнем углу рамки есть маленький квадрат — маркер заполнения. Перетащи его вниз до `D5`. Другой способ: после ввода `D2` выдели `D2:D5` и используй команду заполнения вниз, в Excel для Windows — [[Ctrl+D]].

Двойной щелчок по маркеру часто заполняет столбец вдоль соседней области данных, но при разрывах может остановиться раньше. Для экзаменационного файла надёжно знать последнюю строку и проверить её формулу.

Копирование вправо работает аналогично. В Windows команда [[Ctrl+R]] заполняет выделенный диапазон вправо по его левой ячейке. Перед заполнением полезно предсказать, какой станет формула на новом месте.

---

**Ссылку на общую для всех строк ячейку закрепляют знаком $.** Представь, что общий процент скидки записан в `H2`, а стоимость покупки — в `D2`. Формула `=D2*(1-H2)` правильно вычисляет первую строку. Но после копирования вниз станет `=D3*(1-H3)`. Скидка сдвинулась к `H3`, хотя она по-прежнему находится в `H2`.

```sheet Скидка select=E3
|   | A        | B    | C          | D            | E                 | F | G        | H
| 1 | Товар    | Цена | Количество | Стоимость    | После скидки      |   | Параметр | Значение
| 2 | Тетрадь  | 40   | 5          | =B2*C2 ⇒ 200 | =D2*(1-H2) ⇒ 180  |   | Скидка   | 10%
| 3 | Ручка    | 20   | 3          |              | ⇒ 60              |   |          |
| 4 | Папка    | 120  | 2          |              | ⇒ 240             |   |          |
fill D2:E4
fmt H2 %
```

Выбери `E3`: рамка на `H3` — пустой ячейке, поэтому скидки у ручки нет. Нужно зафиксировать адрес скидки:

```excel
E2: =D2*(1-$H$2)
```

```sheet Скидка select=E3
|   | A        | B    | C          | D            | E                   | F | G        | H
| 1 | Товар    | Цена | Количество | Стоимость    | После скидки        |   | Параметр | Значение
| 2 | Тетрадь  | 40   | 5          | =B2*C2 ⇒ 200 | =D2*(1-$H$2) ⇒ 180  |   | Скидка   | 10%
| 3 | Ручка    | 20   | 3          |              | ⇒ 54                |   |          |
| 4 | Папка    | 120  | 2          |              | ⇒ 216               |   |          |
| 5 | Карандаш | 15   | 4          |              | ⇒ 54                |   |          |
| 7 | Итого    |      |            |              | =E2+E3+E4+E5 ⇒ 504  |   |          |
fill D2:E5
fmt H2 %
```

При копировании вниз `D2` превратится в `D3`, а `$H$2` останется `$H$2`. Знак $ перед буквой фиксирует столбец; перед номером — строку. Он влияет на изменение адреса при копировании, а не «запирает» значение. Если поменять саму `H2`, все зависимые расчёты обновятся: поставь в `H2` 20% — все четыре цены пересчитаются.

---

**У ссылки четыре вида: закреплено всё, ничего, только столбец или только строка.** Незакреплённая часть адреса получает сдвиг копии, закреплённая остаётся:

<figure class="plate-figure">
%%ref_moves("A2", 3, 2)%%
<figcaption>Копия на 3 строки вниз и 2 столбца вправо: A2 → C5, $A$2 не меняется, $A2 → $A5, A$2 → C$2.</figcaption>
</figure>

Полностью закреплённая ссылка называется абсолютной. Ссылка с одной закреплённой частью называется смешанной. Названия описывают поведение адреса; заучивать их без примеров не нужно.

При копировании на два столбца вправо и три строки вниз `A2` станет `C5`, `$A2` станет `$A5`, `A$2` станет `C$2`, `$A$2` не изменится. Универсальное правило: незакреплённая часть получает соответствующее смещение, закреплённая сохраняется.

Проверь правило сам: поменяй формулу или ячейку, куда её копируем.

%%fill_try("=$A2*B$1", "B2", "D4")%%

---

**Смешанные ссылки нужны, когда формула должна брать число из своей строки по одному направлению и из своего столбца — по другому.** Пусть в `A2:A6` записаны числа 1–5, а в `B1:F1` — числа 1–5. Требуется таблица умножения. В `B2` нужна формула:

```excel
B2: =$A2*B$1
```

```sheet Умножение select=D4 edit=none
|   | A | B          | C | D | E | F
| 1 |   | 1          | 2 | 3 | 4 | 5
| 2 | 1 | =$A2*B$1 ⇒ 1 |   |   |   |
| 3 | 2 |            |   |   |   |
| 4 | 3 |            |   | ⇒ 9 |   |
| 5 | 4 |            |   |   |   |
| 6 | 5 |            |   |   |   | ⇒ 25
fill B2:F2
fill B2:F6
```

`$A2` берёт число слева: при движении вправо столбец A должен сохраниться, при движении вниз номер строки должен измениться. `B$1` берёт число сверху: при движении вниз строка 1 должна сохраниться, при движении вправо столбец должен измениться. Поэтому оба знака $ стоят в разных местах по разным причинам. Выбери `D4`: рамки стоят на `A4` и `D1`.

---

**Для каждой ссылки задают два вопроса: должен ли меняться столбец при копировании вправо и строка — при копировании вниз.** Фиксируй только те части, которые по смыслу должны сохраняться.

Закреплять можно обе границы диапазона. Запись `$A2:$F2` обозначает участок строки в столбцах `A:F`. При копировании вправо столбцы не меняются, а при копировании вниз номера строк увеличиваются. Так одна формула обрабатывает одинаковые участки разных строк. Позже мы применим эту ссылку для подсчёта повторений.

В Excel для Windows при редактировании ссылки [[F4]] циклически переключает её виды. Но проверяй конечную запись глазами. Клавиша не знает, что именно тебе нужно закрепить.

<details class="proof" markdown="1">
<summary>Тонкости: копирование, перемещение и вставка строк</summary>

Копирование и вырезание — разные операции. Правило смещения прежде всего относится к копированию и заполнению. При перемещении ячеек, вставке или удалении строк Excel может перестраивать ссылки по своим правилам. После таких действий проверяй формулы заново.

</details>

---

**Итого.**

- Относительная ссылка при копировании сдвигается на столько же строк и столбцов, что и формула.
- $ перед буквой закрепляет столбец, перед номером — строку; `$H$2` не сдвигается вовсе.
- Общий для всех строк параметр берут абсолютной ссылкой: `=D2*(1-$H$2)`.
- Таблица «строка × столбец» — смешанные ссылки: `=$A2*B$1`.
- Перед заполнением предскажи формулу на новом месте, после — проверь последнюю строку.

---

**Чтобы проверить понимание, реши задачи сначала рассуждением, а затем в Excel.**

1. В `D2` записано `=B2*C2`. Какой станет формула после копирования в `D5`? А после копирования в `F2`?

2. Формулу `=$B2*C$1+$H$2` скопировали из `D2` в `F5`. Запиши новую формулу и объясни каждое изменение.

3. Формулу `=A1*$B$1` из `C1` скопировали в `C3` и в `E1`. Какими стали формулы?

4. Ссылку `A$2` копируют на два столбца вправо и на три строки вниз. Во что она превратится? А ссылка `$A2`?

5. Скидка в `H2` равна 15%, стоимости в `D2:D5` — 200, 60, 240 и 60. В `E2` записано `=D2*(1-$H$2)` и скопировано до `E5`. Найди значения `E2:E5` и их сумму.

6. В `E2` по ошибке записали `=D2*(1-H2)` и скопировали вниз. Почему для второй строки получилась полная стоимость без скидки?

7. В таблице умножения из урока что будет записано в `E5` и чему равно значение?

8. Построй таблицу сложения: числа 1–4 в `A2:A5` и в `B1:E1`, в `B2` — одна формула, скопированная на весь прямоугольник `B2:E5`. Какая формула стоит в `B2` и что получится в `E5`?

**Ответы для проверки:**

1. В `D5` получится `=B5*C5`, в `F2` — `=D2*E2`. Сдвиг формулы переносится на обе относительные ссылки. Второй вариант сам по себе может не соответствовать смыслу покупки — автоматическое копирование не оценивает смысл данных.
2. `=$B5*E$1+$H$2`. Копия сместилась на два столбца вправо и три строки вниз. В `$B2` меняется только строка; в `C$1` — только столбец; последняя ссылка полностью закреплена.
3. В `C3` — `=A3*$B$1`, в `E1` — `=C1*$B$1`.
4. `C$2` и `$A5`.
5. 170, 51, 204 и 51; сумма 476.
6. После копирования во второй строке стоит `=D3*(1-H3)`: `H3` пуста, пустота в вычислении равна нулю, и множитель стал 1.
7. `=$A5*E$1`, значение 4 × 4 = 16.
8. `=$A2+B$1`; в `E5` — `=$A5+E$1`, значение 8.
