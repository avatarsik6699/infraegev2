**Если слов слишком много, считают не сами слова, а количество способов их продолжить или заполнить.** Все инструменты уже есть: правило умножения из подтемы 1, выбор мест из подтемы 2, промежутки из подтемы 3, выбор набора цифр из подтемы 4 и счёт слов раньше данного из подтемы 5.

Начнём со слов из букв `А`, `Б`, `В`, `Г`, в которых нет двух `А` подряд; функции и проверки основных подтем считаем знакомыми.

---

**Для слов длины 20 перебор уже не успевает: вариантов больше триллиона.** Пятибуквенных слов из `АБВГ` всего 4⁵ = 1024, и перебор с проверкой `'АА' not in word` даёт ответ мгновенно. Но если длина слова 20, вариантов 4²⁰ = 1 099 511 627 776 — больше триллиона. Даже миллион слов в секунду — это почти две недели работы.

`product` выдаёт варианты по одному, но не уменьшает их количество. Значит, нужен способ, в котором **число шагов не растёт вместе с числом слов**.

---

**Чтобы понять, можно ли дописать букву, не нужно знать всё слово.** Для запрета `АА` достаточно знать, заканчивается ли слово на `А`. Разделим допустимые слова текущей длины на две группы: a — заканчиваются на `А`, b — заканчиваются на другую букву.

При дописывании новой буквы:

1. Новые слова на `А` получаются только из прежней группы b: a_новое = b.
2. Новые слова на другую букву получаются из любой прежней группы, и вариантов последней буквы три: b_новое = 3 · (a + b).

Для длины 1 a = 1, b = 3. Листай схему по шагам: каждая длина получается из предыдущей по этим двум правилам.

%%cmb_states_stepper("АБВГ", "А", 5)%%

Для длины 5 получаем 171 + 648 = 819 — столько же даёт перебор всех 1024 слов. Программа хранит только два количества:

```python
end_a = 1
end_other = 3

for length in range(2, 6):
    new_a = end_other
    new_other = 3 * (end_a + end_other)

    end_a = new_a
    end_other = new_other

print(end_a + end_other)
```

```output
819
```

Такой подход относится к **динамическому программированию**: результаты для меньших частей задачи используются для получения результатов для больших. Здесь мы храним не все слова, а только два количества, достаточных для продолжения подсчёта. Для длины 20 меняется одно число в `range`:

```python
end_a = 1
end_other = 3
for length in range(2, 21):
    new_a = end_other
    new_other = 3 * (end_a + end_other)
    end_a = new_a
    end_other = new_other

print(end_a + end_other)
```

```output
393620574951
```

Девятнадцать шагов вместо триллиона слов. Для сложных ограничений может понадобиться помнить больше — например, число использованных `А` или несколько последних букв. Но принцип остаётся тем же.

**Если важны только типы цифр, перебирают схемы типов, а не сами цифры.** Посчитаем двенадцатизначные восьмеричные числа, в записи которых ровно четыре нечётные цифры и никакие две нечётные не стоят рядом. Чисел всего 7 · 8¹¹ ≈ 6 · 10¹⁰ — перебор не успеет.

Условие говорит только о том, где стоят нечётные цифры. Поэтому сначала выбираем **схему типов**: на каждом месте «ч» (чётная) или «н» (нечётная) — как схемы чередования в подтеме 3. Схем всего 2¹² = 4096. Для подходящей схемы количество чисел даёт правило умножения: нечётная цифра — 4 варианта (1, 3, 5, 7), чётная — 4 варианта (0, 2, 4, 6), но на первом месте чётная не может быть нулём — 3 варианта.

```python
from itertools import product

def by_types(length, odd_count):
    total = 0
    for types in product('чн', repeat=length):
        scheme = ''.join(types)
        if scheme.count('н') != odd_count:
            continue
        if 'нн' in scheme:
            continue
        ways = 1
        for i, kind in enumerate(scheme):
            if kind == 'н':
                ways *= 4
            elif i == 0:
                ways *= 3
            else:
                ways *= 4
        total += ways
    return total

brute = 0
for d in product(range(8), repeat=5):
    odd = [x % 2 for x in d]
    if d[0] != 0 and sum(odd) == 2:
        if all(odd[i] + odd[i + 1] < 2 for i in range(4)):
            brute += 1

print(by_types(5, 2), brute)
print(by_types(12, 4))
```

```output
5376 5376
1820327936
```

Сначала способ проверен на пятизначных числах, где перебор ещё возможен: оба подсчёта дали 5376. Затем та же функция за доли секунды считает двенадцатизначные. {{def|Функция}} `by_types` повторяет рассуждение: схема типов — где стоят нечётные, умножение — чем заполнить каждое место. В проверочном переборе {{comp|список}} `odd` хранит остаток каждой цифры от деления на 2, а `all(...)` проверяет, что ни в одной соседней паре нет двух нечётных.

Типов может быть и больше двух. Если условие говорит «ровно два нуля и не более четырёх цифр-букв» для 15-ричных чисел, типы — ноль (1 цифра), цифра-буква A–E (5 цифр) и остальные ненулевые (9 цифр); схем 3ⁿ, вес схемы — произведение этих количеств.

---

**Строгий порядок цифр любой длины считают выбором наборов.** Сколько натуральных чисел имеют девятеричную запись не менее чем из двух цифр, причём каждая следующая цифра строго меньше предыдущей? Длина может быть до девяти цифр, и перебор всех записей такой длины — это 9⁹ ≈ 3,9 · 10⁸ вариантов только для самой длинной.

Как в подтеме 4, каждый набор различных цифр даёт ровно одно число — цифры по убыванию. Первая цифра при этом — наибольшая из набора, а в наборе из двух и более различных цифр она не ноль. Значит, нужно сложить по длинам количество наборов: C₉² + C₉³ + … + C₉⁹. Наборы перебирает {{permutations|`combinations`}}:

```python
from itertools import combinations

total = 0
for k in range(2, 10):
    total += len(list(combinations(range(9), k)))

print(total, 2 ** 9 - 1 - 9)
```

```output
502 502
```

Второе число — проверка: всех подмножеств девяти цифр 2⁹, из них не подходят пустое и девять одноэлементных.

**Числа до границы считают разряд за разрядом — как номер слова.** Сколько четырёхзначных шестеричных чисел с различными цифрами не превышают 3204₆? Будем считать подходящие числа, которые идут раньше границы, так же, как в подтеме 5 считали слова раньше данного. Только слагаемые теперь — числа без повторов, а не любые слова.

1. Первая цифра меньше 3 и не ноль — 1 или 2. Остальные три места — различные цифры из пяти оставшихся: 2 · 5 · 4 · 3 = 120.
2. Первая цифра 3, вторая меньше 2 и не 3 — 0 или 1. Остальные два места — из четырёх оставшихся цифр: 2 · 4 · 3 = 24.
3. Начало 32, третья цифра меньше 0 — таких нет.
4. Начало 320, четвёртая цифра меньше 4 и не из 3, 2, 0 — только 1: одно число 3201₆.
5. Сама граница 3204₆ тоже подходит: её цифры различны.

Всего 120 + 24 + 0 + 1 + 1 = 146. Функция повторяет эти шаги для любой границы; `perm(a, b)` из модуля `math` — это a · (a − 1) · … , ровно b множителей:

```python
from itertools import permutations
from math import perm

def count_upto(bound, q):
    total = 0
    used = set()
    for i, d in enumerate(bound):
        rest = len(bound) - i - 1
        for x in range(d):
            if x in used or (i == 0 and x == 0):
                continue
            total += perm(q - len(used) - 1, rest)
        if d in used:
            return total
        used.add(d)
    return total + 1

brute = 0
for p in permutations(range(6), 4):
    if p[0] != 0 and p <= (3, 2, 0, 4):
        brute += 1

print(count_upto([3, 2, 0, 4], 6), brute)
```

```output
146 146
```

Перебор для проверки сравнивает кортежи цифр: они сравниваются как слова, по первому различному элементу, поэтому `p <= (3, 2, 0, 4)` значит «запись не больше границы». Если в самой границе цифры повторяются, все подходящие числа уже посчитаны раньше: функция завершается без прибавления единицы. Для восьмизначных 15-ричных чисел перебор перестановок занял бы минуты, а функция делает восемь шагов.

---

**Итого.**

- Сначала оцени число вариантов: от миллиардов перебор не успевает.
- Подсчёт по состояниям: храни количества слов по тому, что нужно знать для продолжения, — например, на какую букву слово заканчивается.
- Схема типов: перебирай типы мест (чётная, нечётная, ноль, цифра-буква), а заполнение считай умножением.
- Строгий порядок цифр — наборы `combinations`, сумма по длинам.
- Числа до границы — разряд за разрядом, как номер слова; проверяй способ перебором на маленьком случае.
