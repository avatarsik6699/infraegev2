**Ограничение на соседние буквы проверяют по всем парам соседних позиций, а считают умножением с промежутками или блоками.** Соседство встречается в 37 задачах из 133: одинаковые буквы не рядом, гласные не рядом, гласные и согласные чередуются, запрещено сочетание, «рядом с данной цифрой нет нечётных». Из 25 задач 2025–2026 годов таких 11.

Почти всё время будем считать слова из букв `А`, `Б`, `В`, `Г`, а для гласных — снова из `АОБВГ`. Счётчик подходящих слов и проверки `word.count(...)` и `in` из подтем 1 и 2 считаем знакомыми.

---

**Соседними называются символы на позициях 1 и 2, 2 и 3, …, n − 1 и n.** В слове длины n имеется n − 1 соседних пар. Первая и последняя буквы обычного слова соседними не считаются: для этого в условии должно быть сказано, что последовательность замкнута в кольцо.

Запреты «нет двух одинаковых букв подряд», «нет двух `А` подряд», «нет двух гласных подряд» и «`А` и `Б` не стоят рядом» — **четыре разных ограничения**. Выбери запрет, чтобы увидеть, нарушает ли его слово `АООБ`:

:::pick Запрет и слово АООБ
- *одинаковые подряд | нарушает: `О` и `О` стоят рядом
- две А подряд | не нарушает: `А` в слове одна
- две гласные подряд | нарушает: рядом `А` и `О`, `О` и `О`
- А и Б рядом | не нарушает: между `А` и `Б` две буквы
:::

---

**Проверку соседних символов можно написать буквально по определению.** Пусть запрещены любые две гласные подряд. Нажми «Запуск» и пройди программу по шагам:

```python run neighbours.py
word = 'БАОВГ'
good = True
for i in range(len(word) - 1):
    if word[i] in 'АО' and word[i + 1] in 'АО':
        good = False
        break
print(good)
```

```output
False
```

Переменная `good` хранит, подходит ли слово: сначала считаем, что подходит, а если нашли запрещённую пару, меняем значение на `False`. Такую переменную часто называют **флагом**: она хранит ответ «да или нет» о некотором свойстве. {{break|`break`}} прекращает цикл — одной запрещённой пары достаточно.

Почему {{for|`range(len(word) - 1)`}}? Если длина слова 5, нужно проверить пары индексов (0, 1), (1, 2), (2, 3), (3, 4). Левый индекс принимает значения 0, 1, 2, 3 — именно их даёт `range(4)`. Если пройти до индекса 4 включительно, обращение к `word[5]` выйдет за границы строки.

**Флаг нужно заново устанавливать в `True` для каждого нового слова**, иначе одна неудачная пара «испортит» все следующие слова.

---

**Если запрещены любые одинаковые соседние буквы, количество легко получить умножением.** Пусть алфавит содержит m букв, слово имеет длину n ≥ 1, повторения на несоседних местах разрешены. На первую позицию можно поставить любую букву — m вариантов. На каждую следующую — любую, кроме предыдущей: m − 1. Поэтому слов **m · (m − 1)ⁿ⁻¹**. Для пятибуквенных слов из `АБВГ` это 4 · 3⁴ = 324.

Это **не** запрет повторений вообще: слово `АБАБА` разрешено, буква `А` повторяется, но не стоит рядом с другой `А`. При полном запрете повторений пятибуквенных слов из четырёх букв не было бы вовсе.

Перебор с флагом подтверждает подсчёт:

```python
from itertools import product

count = 0
for letters in product('АБВГ', repeat=5):
    word = ''.join(letters)
    good = True
    for i in range(len(word) - 1):
        if word[i] == word[i + 1]:
            good = False
            break
    if good:
        count += 1

print(count)
```

```output
324
```

**Если ровно k одинаковых букв не должны стоять рядом, удобно использовать промежутки.** Пусть в шестибуквенном слове из `АБВГ` должны быть ровно две `А`, причём не рядом. Сначала составим последовательность из четырёх остальных букв; каждая выбирается из `БВГ`, вариантов 3⁴ = 81. Вокруг четырёх букв есть пять промежутков: перед первой, между соседними и после последней.

<figure class="plate-figure">
%%cmb_gaps("БВГБ", (1, 4), "А")%%
<figcaption>Четыре буквы без А и пять промежутков вокруг них. Две А в разных промежутках никогда не окажутся рядом: между ними стоит хотя бы одна буква. Выбрать два промежутка из пяти можно C₅² = 10 способами.</figcaption>
</figure>

Остаётся выбрать два промежутка из пяти для двух `А`: C₅² = 10. Получаем **C₅² · 3⁴ = 10 · 81 = 810**.

Почему каждое слово учитывается ровно один раз? Из готового слова можно удалить все `А`. Получатся однозначно определённые остальные буквы и однозначно определённые промежутки, куда были вставлены `А`.

<details class="proof" markdown="1">
<summary>Общая формула для k букв, которые не стоят рядом</summary>

Остальных букв n − k, промежутков вокруг них n − k + 1. Для данных букв выбираем k разных промежутков, остальные места заполняем любой из m − 1 других букв:

C₍ₙ₋ₖ₊₁₎ᵏ · (m − 1)ⁿ⁻ᵏ.

Если промежутков меньше, чем данных букв, то есть k > n − k + 1, вариантов нет. Например, невозможно расположить четыре `А` и две другие буквы так, чтобы никакие две `А` не соседствовали.

</details>

---

**Фрагмент `'АА' in word` — это две буквы подряд, а не две буквы где угодно.** Поэтому «две `А` не рядом» проверяется так: ровно две `А` и нет фрагмента `АА`.

```python
from itertools import product

count = 0
for letters in product('АБВГ', repeat=6):
    word = ''.join(letters)
    if word.count('А') == 2 and 'АА' not in word:
        count += 1

print(count)
print('АБ' in 'АВБ', 'АБ' in 'ВАБ')
```

```output
810
False True
```

Выражение `'АБ' in word` проверяет **непрерывный фрагмент** `АБ`: в `АВБ` обе буквы есть, но не подряд. Если `А` и `Б` не должны соседствовать ни в каком порядке, нужно запретить **оба направления**: `'АБ' not in word and 'БА' not in word`.

Так же проверяют условие «рядом с буквой `Б` нет буквы `А`». Посчитаем пятибуквенные слова из `АБВГ` с ровно одной `Б`, рядом с которой нет `А`.

Если `Б` стоит с краю, у неё один сосед — `В` или `Г`, а остальные три места заполняются из `А`, `В`, `Г`: 2 · 2 · 3³ = 108. Если `Б` на одном из трёх средних мест, оба соседа из `В`, `Г`, ещё два места — из трёх букв: 3 · 2² · 3² = 108. Всего 216. Программа проверяет оба запрещённых фрагмента:

```python
from itertools import product

count = 0
for letters in product('АБВГ', repeat=5):
    word = ''.join(letters)
    if (
        word.count('Б') == 1
        and 'АБ' not in word
        and 'БА' not in word
    ):
        count += 1

print(count)
```

```output
216
```

Если запрещённых соседей несколько, например любые гласные рядом с `Б`, удобнее проверить все соседние пары циклом, как в программе с флагом.

---

**Тот же способ промежутков работает для гласных, если любые две гласные запрещено ставить рядом.** Вернёмся к шестибуквенным словам из `АОБВГ` с ровно двумя гласными: в подтеме 2 их получилось 4860. Чтобы гласные не соседствовали, выбираем четыре согласные — 3⁴, два промежутка из пяти — C₅², сами гласные — 2². Получаем C₅² · 2² · 3⁴ = 10 · 4 · 81 = 3240.

А если эти две гласные должны стоять рядом? Двухбуквенный фрагмент может начинаться с позиции 1, 2, 3, 4 или 5 — 5 вариантов. Сами гласные выбираются 2² способами, согласные — 3⁴: 5 · 2² · 3⁴ = 1620.

Проверка: 3240 + 1620 = 4860. Для ровно двух гласных других случаев нет: они **либо соседствуют, либо нет**. Перебор с флагом считает обе группы:

```python
from itertools import product

apart = 0
together = 0
for letters in product('АОБВГ', repeat=6):
    word = ''.join(letters)
    if word.count('А') + word.count('О') != 2:
        continue
    good = True
    for i in range(len(word) - 1):
        if word[i] in 'АО' and word[i + 1] in 'АО':
            good = False
            break
    if good:
        apart += 1
    else:
        together += 1

print(apart, together)
```

```output
3240 1620
```

{{continue|`continue`}} сразу переходит к следующему слову, если гласных не две.

**Несколько соседних букв иногда можно считать одним блоком.** Нужно переставить четыре различные буквы `АБВГ` так, чтобы `А` и `Б` находились рядом. Объединим их в один блок. Тогда расставляются три объекта — блок, `В` и `Г` — 3! = 6 способами. Внутри блока возможны два порядка, `АБ` и `БА`, поэтому всего 3! · 2 = 12. Если требуется именно последовательность `АБ`, внутренний порядок уже задан: 3! = 6.

Но с повторяющимися буквами этот способ нужно применять **осторожно**. Посчитаем трёхбуквенные слова из `АБ`, содержащие `АА`. Если выбрать начало фрагмента `АА` двумя способами и оставшуюся букву двумя способами, получится 4. Однако подходят только три слова:

```python
from itertools import product

for letters in product('АБ', repeat=3):
    word = ''.join(letters)
    if 'АА' in word:
        print(word)
```

```output
ААА
ААБ
БАА
```

Слово `ААА` посчиталось бы дважды: фрагмент `АА` есть и на позициях 1–2, и на позициях 2–3. **Количество появлений фрагмента и количество слов, содержащих фрагмент, — разные величины.**

---

**Если гласные и согласные чередуются, сначала удобно выбрать схему типов букв.** В пятибуквенном слове возможны две схемы: «гласная — согласная — гласная — согласная — гласная» или «согласная — гласная — согласная — гласная — согласная». При двух гласных и трёх согласных, с разрешёнными повторениями:

2³ · 3² + 3³ · 2² = 72 + 108 = 180.

Если дополнительно запрещены повторения букв, степени применять нельзя: при каждом использовании буквы запас уменьшается. **Сначала определяй схему расположения типов, затем считай способы её заполнения.**

В программе «соседи разного типа» — это сравнение двух проверок: `word[i] in 'АО'` и `word[i + 1] in 'АО'` дают `True` или `False`, и если результаты равны, рядом стоят буквы одного типа.

```python
from itertools import product

count = 0
for letters in product('АОБВГ', repeat=5):
    word = ''.join(letters)
    good = True
    for i in range(len(word) - 1):
        if (word[i] in 'АО') == (word[i + 1] in 'АО'):
            good = False
            break
    if good:
        count += 1

print(count)
```

```output
180
```

**Если требуется количество появлений фрагмента, учитывай возможные наложения.** В строке `АААА` фрагмент `АА` начинается на трёх позициях: 1–2, 2–3 и 3–4. Но строковый метод `count` считает только неперекрывающиеся появления:

<figure class="plate-figure">
%%overlap("АААА", "АА")%%
<figcaption>Фрагмент АА в строке АААА начинается с индексов 0, 1 и 2. Метод count находит вхождения с 0 и с 2, а вхождение с 1 пропускает: оно перекрывается с уже найденным.</figcaption>
</figure>

Чтобы учесть все начала фрагмента, проверяют каждый {{slice|срез}} нужной длины:

```python
word = 'АААА'
fragment = 'АА'
occurrences = 0
for i in range(len(word) - len(fragment) + 1):
    if word[i:i + len(fragment)] == fragment:
        occurrences += 1

print(word.count(fragment), occurrences)
```

```output
2 3
```

Срез `word[a:b]` берёт символы с индекса `a` до индекса `b`, не включая `b`. Если длина слова n, а фрагмента k, то возможны n − k + 1 начальных позиций фрагмента. Для проверки простого наличия фрагмента достаточно `in`: вопрос о наложениях там не возникает.

---

**Итого.**

- Соседних пар n − 1; разные запреты соседства — разные задачи.
- Одинаковые не рядом: m · (m − 1)ⁿ⁻¹; данные буквы не рядом — промежутки; буквы рядом — блок, но без двойного счёта.
- Чередование типов — сначала схема типов, потом заполнение.
- В программе: флаг и цикл по `range(len(word) - 1)`, фрагмент `'АБ' in word` в обоих направлениях, наложения — проверкой каждого среза.
