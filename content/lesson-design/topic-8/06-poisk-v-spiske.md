**В нумерованном списке номер слова и количество подходящих слов — разные величины: номер даёт полный список, а условие только отбирает слова из него.** Так устроен главный вид задания 2023–2026 годов: «под каким номером последнее слово, которое не начинается с данной буквы и содержит ровно две другие», «сколько слов с нечётными номерами…». Это 17 задач из 133, среди них основная волна ЕГЭ-2026, и 10 из 25 задач 2025–2026 годов.

Почти всё время будем искать в списке четырёхбуквенных слов из `АБВ` слова с ровно одной буквой `А`. Номер слова и перевод из подтемы 5 считаем знакомыми.

---

**Первое подходящее слово имеет минимальный номер, последнее — максимальный.** В лексикографическом порядке более ранняя позиция важнее всех последующих. Поэтому при поиске первого слова хочется ставить слева минимальные буквы, а при поиске последнего — максимальные. Но **каждый выбор должен оставлять возможность выполнить все условия**.

Первое слово с ровно одной `А` — `АБББ`: на первое место ставим минимальную `А`, а дальше `А` уже нельзя, и остаются `Б`. Его номер — 0111₃ + 1 = 13 + 1 = 14. Последнее — `ВВВА`: максимальную `В` ставим на первые три места, но последнее место оставляем обязательной `А`. Номер — 2220₃ + 1 = 78 + 1 = 79.

При дополнительных запретах соседства или условиях на номер такая логика требует проверки. Если трудно доказать, что выбор допустим, проще выполнить **упорядоченный перебор**.

---

**Номер в полном списке и количество найденных слов хранят раздельно.** Номер увеличивается для каждого слова, счётчик — только для подходящего:

```python
from itertools import product

count = 0
for number, letters in enumerate(
    product('АБВ', repeat=4),
    start=1
):
    word = ''.join(letters)
    if word.count('А') == 1:
        count += 1

print(number, count)
```

```output
81 32
```

После цикла `number` равен 81 — это номер последнего слова всего списка, а подходящих слов 32: место `А` — 4 способа, остальные три буквы из `БВ` — 2³. **Если задача просит номер последнего подходящего слова, ответом будет не `count`.**

---

**Первое подходящее слово находят с остановкой, последнее — запоминая каждый новый подходящий вариант.** Посмотрим на поиск последнего по шагам на маленьком списке двухбуквенных слов из `АБ` — `АА`, `АБ`, `БА`, `ББ`:

```python run last.py
from itertools import product

last_number = None
for number, letters in enumerate(
        product('АБ', repeat=2), start=1):
    word = ''.join(letters)
    if word.count('А') == 1:
        last_number = number

print(last_number)
```

```output
3
```

{{none|`None`}} обозначает, что подходящее слово ещё не найдено. При каждом подходящем слове предыдущий ответ заменяется новым, поэтому после цикла остаётся последний. Для первого слова цикл останавливают {{break|`break`}}: перебор упорядочен, поэтому первый найденный вариант имеет минимальный номер.

```python
from itertools import product

for number, letters in enumerate(
    product('АБВ', repeat=4),
    start=1
):
    word = ''.join(letters)
    if word.count('А') == 1:
        print(number, word)
        break

last_number = None
last_word = None
for number, letters in enumerate(
    product('АБВ', repeat=4),
    start=1
):
    word = ''.join(letters)
    if word.count('А') == 1:
        last_number = number
        last_word = word

print(last_number, last_word)
```

```output
14 АБББ
79 ВВВА
```

Программа подтвердила рассуждение: 14 и 79.

**Прямая связь номера с системой счисления работает только для полного списка.** Условия могут означать два разных действия:

1. Все слова пронумеровали, затем ищут подходящие среди них.
2. Сначала оставили только подходящие слова, затем пронумеровали получившийся список.

В первом случае номера берутся из полного списка, во втором — из сокращённого. **После удаления слов и перенумерации формулу «значение в системе счисления плюс один» напрямую применять нельзя**: между оставшимися словами исчезли промежутки. То же касается списков слов без повторений: в полном списке с повторениями есть дополнительные слова, которые меняют номера.

Если список сначала отбирают, а потом нумеруют, роль нового номера играет **счётчик внутри `if`**:

```python
from itertools import product

count = 0
for number, letters in enumerate(
    product('АБВ', repeat=4),
    start=1
):
    word = ''.join(letters)
    if word.count('А') == 1:
        count += 1
        if word == 'БВАВ':
            print(number, count)
```

```output
48 18
```

В полном списке слово `БВАВ` стоит под номером 48, а среди слов с одной `А` — под номером 18.

**Чётность номера иногда позволяет сразу определить ограничения на последнюю букву.** Пусть алфавит содержит четыре буквы: А → 0, Б → 1, В → 2, Г → 3. Номер слова R = 1 + d₁ · 4ⁿ⁻¹ + … + dₙ. Все слагаемые со степенями 4 чётные, поэтому чётность номера определяется выражением 1 + dₙ:

- чётный номер — последняя цифра кода нечётная;
- нечётный номер — последняя цифра кода чётная.

Значит, **чётный номер имеют слова, заканчивающиеся на `Б` или `Г`**. При этом `А` имеет код 0, а не 1: отсчёт букв с нуля и отсчёт номеров слов с единицы нельзя смешивать.

Для алфавита нечётной мощности правило только по последней букве уже не работает: как и с числами в подтеме 4, решает сумма цифр. В программе об этом думать не нужно — условие на номер проверяют прямо: «чётный номер» — `number % 2 == 0`, «номер кратен 3» — `number % 3 == 0`.

---

**Несколько ограничений и условие на номер проверяют в одном цикле, храня номер и счётчик раздельно.**

> Все пятибуквенные слова из `АБВГ` записаны по алфавиту и пронумерованы с 1. Нужно найти количество слов, которые не начинаются с `А`, содержат ровно две `А`, не содержат `ББ` и имеют чётный номер. Также найдём номер последнего такого слова.

```python
from itertools import product

count = 0
last_number = None
last_word = None

for number, letters in enumerate(
    product('АБВГ', repeat=5),
    start=1
):
    word = ''.join(letters)

    if (
        word[0] != 'А'
        and word.count('А') == 2
        and 'ББ' not in word
        and number % 2 == 0
    ):
        count += 1
        last_number = number
        last_word = word

print(count)
print(last_number, last_word)
```

```output
49
964 ГГААГ
```

Каждая фраза условия — отдельная строка проверки, а номер и счётчик хранятся раздельно. Последнее подходящее слово — `ГГААГ`, его код 33003₄, номер 3 · 4⁴ + 3 · 4³ + 0 · 4² + 0 · 4 + 3 + 1 = 964.

<details class="proof" markdown="1">
<summary>Проверка количества рассуждением: 49 слов</summary>

Алфавит имеет мощность 4, поэтому чётный номер означает окончание на `Б` или `Г`. Следовательно, первая буква не `А`, последняя тоже не `А`, и две `А` находятся среди позиций 2, 3, 4. Есть три случая.

- **`А` на позициях 2 и 3**, слово вида x А А y z. Для x есть 3 варианта, для y — 3, для z — 2, но сочетание y = Б, z = Б запрещено: 3 · (3 · 2 − 1) = 15.
- **`А` на позициях 2 и 4**, слово вида x А y А z. Все остальные буквы разделены буквами `А`, поэтому `ББ` не появится: 3 · 3 · 2 = 18.
- **`А` на позициях 3 и 4**, слово вида x y А А z. Для x, y есть 3 · 3 вариантов, кроме пары `ББ`; для z — 2: (3 · 3 − 1) · 2 = 16.

Всего 15 + 18 + 16 = 49. Здесь видно, как математическое рассуждение и программа проверяют друг друга.

</details>

---

**При поиске номеров в полном списке нельзя сокращать сам список.** Полезные способы сократить работу перебора:

- если повторения запрещены, использовать `permutations`;
- если буква нигде не разрешена и номера не нужны, убрать её из алфавита при подсчёте;
- если требуется только номер известного слова, вычислить его напрямую;
- если требуется слово по номеру, выполнить перевод в систему счисления;
- не выводить каждое слово, если нужен только итог, и не сохранять все слова, если достаточно счётчика.

Однако **при поиске номеров в исходном полном списке нельзя просто удалить запрещённую букву из алфавита**: это изменит список и его нумерацию. В таком случае исходные слова нумеруются до проверки ограничения.

---

**Итого.**

- Номер в полном списке (`enumerate(..., start=1)`) и счётчик подходящих (`count`) — разные переменные.
- Первое подходящее — `break` на первом найденном, последнее — запоминать каждое найденное.
- Полный список и перенумерованный после отбора — разные списки; новый номер — счётчик внутри `if`.
- Чётность номера при четырёх буквах — по последней букве; в программе — `number % 2`.
- Алфавит при поиске номеров не сокращают.
