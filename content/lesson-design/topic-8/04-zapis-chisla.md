**Запись числа можно рассматривать как слово из цифр, но у числа есть ограничение на первую позицию.** Так устроены 34 задачи из 133: числа в системах с основанием от 4 до 16, у которых цифры различны, чередуется чётность или рядом с данной цифрой нет нечётных. Из 25 задач 2025–2026 годов таких 15.

Почти всё время будем считать четырёхзначные числа в шестеричной системе. Как устроена запись числа в системе с основанием q, разобрано в теме 5; здесь важно одно: цифры такой записи — значения 0, 1, …, q − 1.

---

**Код может начинаться с нуля, а запись числа — нет.** В системе счисления с основанием q используются цифры со значениями 0, 1, 2, …, q − 1: в двоичной — `0` и `1`, в пятеричной — от `0` до `4`, в восьмеричной — от `0` до `7`. Пятисимвольный код может начинаться с нуля, например `00127`. Но обычная запись пятизначного числа с нуля не начинается: начальные нули не увеличивают число разрядов.

Поэтому количество положительных n-значных чисел в системе с основанием q равно **(q − 1) · qⁿ⁻¹**: на первую позицию доступны q − 1 ненулевых цифр, на остальные — все q. Четырёхзначных шестеричных чисел 5 · 6³ = 1080.

Формулировка решает всё. Выбери её, чтобы увидеть, разрешён ли начальный ноль:

:::pick Формулировка и начальный ноль
- *код длины 3 | обычно разрешён: `007` — код
- трёхзначное число | запрещён: первая цифра не 0
- запись дополнена нулями до длины 3 | снова разрешён: `007`
:::

Для одноразрядных чисел отдельно учитывай, входит ли в рассматриваемый диапазон сам ноль.

**Числовые последовательности удобнее перебирать как числа-цифры, а не как строки.** {{product|`product(range(6), repeat=4)`}} выдаёт наборы из четырёх целых чисел от 0 до 5 — цифры шестеричной записи:

```python
from itertools import product

count = 0
for digits in product(range(6), repeat=4):
    if digits[0] != 0:
        count += 1

print(count)
```

```output
1080
```

`digits[0] != 0` проверяет начальный ноль, `sum(digits)` складывает значения цифр, `digits[0] < digits[1]` сравнивает их численно. Это особенно удобно для оснований больше 10, где значения цифр нельзя обозначить одним обычным десятичным символом.

Если цифры записаны символами, помни: `'2' + '3'` даёт строку `'23'`, а `int('2') + int('3')` — число 5. {{base|`int`}} преобразует строковую запись в целое число, а основание при необходимости указывают вторым аргументом:

```python
print('2' + '3', int('2') + int('3'))
print(int('1032', 6), int('D', 16), int('A0', 16))
```

```output
23 5
236 13 160
```

Здесь 1032₆ = 1 · 6³ + 0 · 6² + 3 · 6 + 2 = 236. В системах с основанием больше 10 цифры со значениями 10, 11, … записывают буквами: в шестнадцатеричной `A` = 10, …, `D` = 13, `F` = 15. **В переборе такие цифры — просто числа**: «цифра больше 12» — это `d > 12`, «цифра D» — значение 13.

---

**Если цифры числа не повторяются, начальный ноль всё равно учитывается отдельно.** Четырёхзначные шестеричные числа без повторений:

- первая цифра — одна из `1`, `2`, `3`, `4`, `5`: 5 вариантов;
- вторая — любая из пяти оставшихся цифр, включая возможный ноль: 5;
- третья — 4, четвёртая — 3.

Получаем 5 · 5 · 4 · 3 = 300. Первый и второй множители совпали, но **по разным причинам**: сначала исключили ноль, затем — уже использованную цифру.

```python
from itertools import permutations

count = 0
for digits in permutations(range(6), 4):
    if digits[0] != 0:
        count += 1

print(count)
```

```output
300
```

**Строгое возрастание или убывание цифр позволяет заменить расстановку выбором.** Пусть нужно составить четырёхзначные шестеричные числа со строго убывающими цифрами, например 5320₆. Строгое убывание означает d₁ > d₂ > d₃ > d₄: все цифры различны. Как только мы выбрали четыре цифры, их порядок уже определён — от большей к меньшей.

<figure class="plate-figure">
%%cmb_one_order((5, 3, 2, 0))%%
<figcaption>Цифры 5, 3, 2, 0 можно расставить 4! = 24 способами, но строго убывают они только в одном — 5320. Поэтому каждый выбранный набор из четырёх цифр даёт ровно одно число.</figcaption>
</figure>

Поэтому таких чисел столько же, сколько наборов из четырёх цифр: C₆⁴ = 15. Ноль выбирать можно: он окажется последним, а первая цифра строго убывающей записи будет ненулевой.

Для строго возрастающих цифр ситуация другая. Если выбрать ноль, он окажется первым, и число перестанет быть четырёхзначным. Значит, четыре цифры выбираем только из `1`–`5`: C₅⁴ = 5.

```python
from itertools import product

down = 0
up = 0
for d in product(range(6), repeat=4):
    if d[0] != 0 and d[0] > d[1] > d[2] > d[3]:
        down += 1
    if d[0] != 0 and d[0] < d[1] < d[2] < d[3]:
        up += 1

print(down, up)
```

```output
15 5
```

Важно различать d₁ < d₂ < d₃ и d₁ ≤ d₂ ≤ d₃. **Во втором случае равные цифры разрешены**: это другое ограничение и другой подсчёт, в программе — `<=` вместо `<`.

**Чётность цифры и чётность всего числа нужно различать.** Чётные цифры имеют значения 0, 2, 4, 6, …; **ноль — чётная цифра**. Если условие говорит о соседних чётных цифрах, проверяются именно значения отдельных цифр, в программе — `d % 2`.

А если требуется чётность всего числа, есть дополнительная тонкость:

- в системе с чётным основанием чётность числа определяется последней цифрой;
- в системе с нечётным основанием — чётностью суммы цифр.

Почему? В записи d₁ · q² + d₂ · q + d₃ при чётном q первые два слагаемых чётные, всё решает d₃. При нечётном q все степени основания нечётные, поэтому каждое слагаемое имеет ту же чётность, что и соответствующая цифра. Например, 12₃ = 1 · 3 + 2 = 5: **последняя цифра чётная, но само число нечётное**.

---

**Условие «рядом с цифрой 5 нет нечётных» проверяют по соседям этой цифры.** Сначала проверим одно число 2501₆. Позицию цифры даёт `d.index(5)`, а соседи — позиции `i - 1` и `i + 1`, если они есть в записи. Нажми «Запуск» и пройди проверку по шагам:

```python run neighbours5.py
d = (2, 5, 0, 1)
i = d.index(5)
good = True
for j in (i - 1, i + 1):
    if 0 <= j < 4 and d[j] % 2 == 1:
        good = False
print(good)
```

```output
True
```

Соседи пятёрки — 2 и 0, оба чётные, а единица стоит не рядом с ней. Проверка `0 <= j < 4` отбрасывает несуществующих соседей: у цифры на краю сосед один. Теперь посчитаем все четырёхзначные шестеричные числа, в которых ровно одна цифра 5 и рядом с ней стоят только чётные цифры:

```python
from itertools import product

count = 0
for d in product(range(6), repeat=4):
    if d[0] == 0 or d.count(5) != 1:
        continue
    i = d.index(5)
    good = True
    for j in (i - 1, i + 1):
        if 0 <= j < 4 and d[j] % 2 == 1:
            good = False
    if good:
        count += 1

print(count)
```

```output
201
```

<details class="proof" markdown="1">
<summary>Проверка рассуждением: 201 по месту цифры 5</summary>

Чётные цифры — 0, 2, 4, ненулевые цифры кроме 5 — 1, 2, 3, 4.

- 5 на первом месте: второе — чётное (3 варианта), третье и четвёртое — любые, кроме 5: 3 · 5 · 5 = 75.
- 5 на втором месте: первое — чётное и не ноль (2), третье — чётное (3), четвёртое — любое, кроме 5 (5): 2 · 3 · 5 = 30.
- 5 на третьем месте: первое — ненулевое, кроме 5 (4), второе и четвёртое — чётные: 4 · 3 · 3 = 36.
- 5 на четвёртом месте: первое — 4 варианта, второе — любое, кроме 5 (5), третье — чётное (3): 4 · 5 · 3 = 60.

Всего 75 + 30 + 36 + 60 = 201.

</details>

**Числа с различными цифрами и чередованием чётности считают по двум схемам типов.** Разберём полностью задачу:

> Сколько существует четырёхзначных чисел в шестеричной системе, у которых все цифры различны и чётные цифры чередуются с нечётными?

Цифры 0, 1, 2, 3, 4, 5; чётные — 0, 2, 4, нечётные — 1, 3, 5. Возможны две схемы.

Для схемы «чётная, нечётная, чётная, нечётная»: первая чётная не может быть нулём — 2 варианта; первая нечётная — 3; вторая чётная отличается от первой — 2; вторая нечётная отличается от предыдущей нечётной — 2. Получаем 2 · 3 · 2 · 2 = 24.

Для схемы «нечётная, чётная, нечётная, чётная»: первая нечётная — 3; первая чётная, включая ноль, — 3; следующая нечётная — 2; следующая чётная — 2. Получаем 3 · 3 · 2 · 2 = 36. Всего 24 + 36 = 60.

```python
from itertools import permutations

count = 0
for digits in permutations(range(6), 4):
    if digits[0] != 0:
        good = True
        for i in range(3):
            if digits[i] % 2 == digits[i + 1] % 2:
                good = False
                break
        if good:
            count += 1

print(count)
```

```output
60
```

Одинаковые остатки при делении на 2 означают одинаковую чётность. В программе каждое условие задачи отвечает за отдельную часть: `permutations` обеспечивает отсутствие повторений, проверка первой цифры исключает начальный ноль, цикл проверяет все соседние пары.

**Если длина числа не задана, считают по каждой длине и складывают.** Сколько натуральных чисел имеют шестеричную запись, в которой все цифры различны? Различных цифр шесть, поэтому **запись не длиннее шести цифр**. Для каждой длины работает правило умножения: одна цифра — 5 чисел, две — 5 · 5 = 25, три — 5 · 5 · 4 = 100 и так далее. Числа разной длины не пересекаются, поэтому результаты складываются — это правило сложения из подтемы 1:

```python
from itertools import permutations

total = 0
for length in range(1, 7):
    n = len([p for p in permutations(range(6), length)
             if p[0] != 0])
    print(length, n)
    total += n

print(total)
```

```output
1 5
2 25
3 100
4 300
5 600
6 600
1630
```

Внутри цикла {{comp|списковое включение}} собирает подходящие перестановки одной длины, а `len` считает их. Длина 4 дала уже знакомые 300.

---

**Итого.**

- Положительных n-значных чисел с основанием q: (q − 1) · qⁿ⁻¹; код, в отличие от числа, может начинаться с нуля.
- Цифры перебирают числами: `product(range(q), repeat=n)` и `permutations(range(q), n)` с проверкой `d[0] != 0`; цифры больше 9 — тоже просто числа.
- Строгое убывание или возрастание — выбор набора цифр вместо расстановки: Cₙᵏ наборов; при возрастании ноль не выбирают.
- Чётность цифры — `d % 2`; чётность числа при нечётном основании — по сумме цифр.
- Длина не задана — сумма по всем возможным длинам.
