**Полный список слов одинаковой длины, записанный по алфавиту, устроен как счётчик в системе счисления: номер слова — это значение его записи плюс один.** На этом держатся 45 задач из 133: «какое слово стоит под данным номером», «под каким номером данное слово», «под каким номером первое слово на данную букву». Такие задачи были на экзаменах с 2014 по 2023 год и в трёх демоверсиях.

Почти всё время будем нумеровать четырёхбуквенные слова из букв `А`, `Б`, `В`. Перевод числа в другую систему делением на основание разобран в теме 5; здесь он понадобится, чтобы по номеру найти слово.

---

**Слова одинаковой длины сравнивают слева направо до первой различающейся буквы.** Пусть А < Б < В. Тогда АВБ < БАА, потому что уже первая буква `А` меньше `Б`. У слов `БАВ` и `БВА` первые буквы совпадают, поэтому сравниваем вторые: А < В, значит, БАВ < БВА.

Такой порядок называется **лексикографическим**. В задачах его обычно называют алфавитным. Если условие задаёт специальный порядок символов, используем именно его.

---

**Полный список слов одинаковой длины меняется как счётчик.** Заменим буквы цифрами: А → 0, Б → 1, В → 2. Тогда трёхбуквенные слова из `АБВ` идут в том же порядке, что и числа 000, 001, 002, 010, … в троичной системе:

<figure class="plate-figure">
%%cmb_counter("АБВ", 3)%%
<figcaption>Начало и конец списка трёхбуквенных слов из АБВ. Справа меняется последняя буква; когда она доходит до В, следующей становится А, а предпоследняя увеличивается — как в троичной записи 002 → 010. Значение записи на единицу меньше номера.</figcaption>
</figure>

Так работает и обычный десятичный счёт: 008, 009, 010, 011. Только здесь символов три, поэтому основание системы равно 3. **Если в алфавите m букв, для нумерации полного списка используется система с основанием m.**

---

**К числовому значению нужно прибавлять единицу.** Первому слову `ААА` соответствует 000₃ = 0, но его номер в списке — 1. Второму слову соответствует число 1, третьему — 2. Поэтому:

**номер слова = числовое значение + 1**, и обратно, **числовое значение = номер слова − 1**.

Прибавление или вычитание единицы зависит от начала нумерации. Здесь и далее список начинается с 1, как обычно бывает в таких задачах.

---

**Номер слова — это количество слов, стоящих раньше него, плюс один.** Возьмём слово `БАВБ` из четырёхбуквенного списка и посчитаем, сколько слов стоит раньше него.

- На первой позиции вместо `Б` можно поставить одну меньшую букву — `А`; после неё допустимы любые три буквы: 1 · 3³ = 27 слов.
- Фиксируем первую `Б`. Вторая буква — `А`, меньше неё ничего нет: 0 · 3² = 0.
- Фиксируем начало `БА`. На третьем месте `В`, меньше неё две буквы — `А` и `Б`, и после каждой можно поставить любую последнюю букву: 2 · 3 = 6.
- Фиксируем `БАВ`. Последняя буква — `Б`, меньше неё одна буква: 1.

Всего перед словом 27 + 0 + 6 + 1 = 34 слова, следовательно, **номер 34 + 1 = 35**. Именно поэтому слово кодируется цифрами: БАВБ ↔ 1021₃, и множители 1, 0, 2, 1 — это цифры записи.

<figure class="plate-figure">
%%place_value("1021", 3)%%
<figcaption>БАВБ как запись 1021₃: веса разрядов 27, 9, 3, 1. Каждое слагаемое — сколько слов стоит раньше из-за одной позиции: 27 + 0 + 6 + 1 = 34, номер 35.</figcaption>
</figure>

Для слова длины n, чьи буквы заменены цифрами d₁, …, dₙ, номер равен

**R = 1 + d₁ · mⁿ⁻¹ + d₂ · mⁿ⁻² + … + dₙ · m⁰.**

Последний вес m⁰ = 1: после последней буквы нет позиций, которые можно свободно заполнить, есть один вариант продолжения — ничего не дописывать.

---

**Номер известного слова программа вычисляет без перебора.** Нажми «Запуск» и пройди программу по шагам:

```python run rank.py
alphabet = 'АБВ'
word = 'БАВБ'
base = len(alphabet)
value = 0
for letter in word:
    digit = alphabet.index(letter)
    value = value * base + digit

print(value + 1)
```

```output
35
```

`alphabet.index(letter)` находит позицию буквы в алфавите, считая с нуля: для `А` — 0, для `Б` — 1, для `В` — 2. Это и есть цифра буквы.

Главная строка `value = value * base + digit` работает так же, как дописывание цифры справа в десятичной записи: 37 → 374 = 37 · 10 + 4. В троичной системе используется умножение на 3. Для цифр 1, 0, 2, 1 значение растёт так: 0 · 3 + 1 = 1, 1 · 3 + 0 = 3, 3 · 3 + 2 = 11, 11 · 3 + 1 = 34. После прибавления единицы получаем номер 35.

---

**Чтобы найти слово по номеру, нужно выполнить обратное преобразование.** Найдём 50-е четырёхбуквенное слово из `АБВ`. Сначала вычтем единицу: 50 − 1 = 49. Теперь переведём 49 в троичную систему последовательным делением:

%%convert_stepper(49, 3)%%

Остатки, прочитанные снизу вверх, дают 49 = 1211₃. Первый остаток — последняя цифра, потому что любое число можно представить как 3 · остальная часть + последняя цифра; после удаления этой цифры действие повторяется с остальной частью.

Заменяем цифры буквами: 1 → Б, 2 → В. Получаем **`БВББ`**. Проверка: 1 · 27 + 2 · 9 + 1 · 3 + 1 = 49, и 49 + 1 = 50.

---

**При восстановлении слова начальные нули терять нельзя.** Найдём пятое четырёхбуквенное слово из `АБВ`: 5 − 1 = 4, а 4 = 11₃. Но слово должно иметь длину 4, поэтому запись дополняем слева: 0011₃. После замены получаем `ААББ`.

Здесь **начальные нули обозначают первые буквы алфавита** и являются частью слова. Это отличается от подсчёта n-значных чисел в подтеме 4, где начальный ноль запрещён.

Программа повторяет деление ровно столько раз, сколько букв в слове, — поэтому нули не теряются:

```python run word_by_number.py
alphabet = 'АБВ'
length = 4
number = 50
base = len(alphabet)
value = number - 1
word = ''
for i in range(length):
    digit = value % base
    word = alphabet[digit] + word
    value = value // base

print(word)
```

```output
БВББ
```

{{intdiv|`% base`}} получает последнюю цифру записи, `// base` удаляет её, а найденная буква добавляется **слева**, потому что цифры получаются справа налево. Это тот же цикл, что в функции `to_base` из темы 5, только с фиксированным числом шагов: когда `value` станет нулём, будут добавляться первые буквы алфавита. Предполагается, что номер допустим: 1 ≤ `number` ≤ `base` ** `length`.

---

**Общее начало слова позволяет считать целые блоки списка.** Пусть все четырёхбуквенные слова из `АБВ` записаны по порядку. Сначала идут слова на `А`, их 3³ = 27, затем слова на `Б` — ещё 27, затем на `В` — ещё 27. Поэтому первый номер слова на `Б` равен 27 + 1 = 28, последний — 27 + 27 = 54.

Если фиксировать первые две буквы, например `БА`, свободными остаются две позиции: 3² = 9 слов. Такое фиксированное начало называется **префиксом**. Префикс `БА` соответствует записи 10₃ = 3, перед ним три блока по девять слов: 3 · 9 = 27. Значит, слова на `БА` занимают номера 28, …, 36.

<figcaption>81 слово делится на три блока по 27 по первой букве, блок на Б — на три блока по 9 по второй. Слова с началом БА занимают номера 28–36.</figcaption>

В общем случае, если длина слова n, длина заданного начала k, а его числовое значение p, то блок начинается с номера **p · mⁿ⁻ᵏ + 1** и заканчивается номером **(p + 1) · mⁿ⁻ᵏ**.

---

**Количество слов между двумя номерами зависит от включения границ.** Если известны номера L и R, причём L ≤ R, выбери, какие границы входят:

:::pick Какие номера считаем и сколько их
- *от L до R включительно | R − L + 1
- строго между L и R (L < R) | R − L − 1
- одна граница включена | R − L
:::

Например, номера от 10 до 15 включительно — это 10, 11, 12, 13, 14, 15, их шесть: 15 − 10 + 1 = 6. Если внутри интервала нужно ещё проверять ограничения на слова, одной разности номеров недостаточно.

---

**Порядок алфавита записывай сам: `product` идёт в порядке входной строки.** В условии буквы часто перечислены не по алфавиту, например «из букв М, У, Х, А». Тогда алфавит — `'АМУХ'`, и буква `А` получает цифру 0. **`product` не исправляет порядок автоматически**: `product('ВАБ', repeat=3)` начнёт с `ВВВ`, а не с `ААА`.

Для задач на номера безопаснее явно записать алфавит в нужном порядке. Не стоит без проверки полагаться на автоматическую сортировку русских букв: компьютерный порядок символов не во всех случаях совпадает с привычным алфавитом, например при наличии `Ё`. Если условие задаёт обратный алфавитный порядок, алфавит записывают задом наперёд: `'ВБА'`.

С правильным алфавитом номер можно найти и полным перебором. {{enumerate|`enumerate`}} добавляет к каждому перебираемому элементу его номер, а `start=1` начинает отсчёт с единицы:

```python
from itertools import product

for number, letters in enumerate(
    product('АБВ', repeat=4),
    start=1
):
    word = ''.join(letters)
    if word == 'БАВБ' or number == 50:
        print(number, word)
```

```output
35 БАВБ
50 БВББ
```

Перебор подтвердил оба ответа, найденных переводом.

---

**Если в списке слова разной длины, сначала идут все короткие.** Иногда список составлен так: сначала по алфавиту все однобуквенные коды, затем все двухбуквенные, затем трёхбуквенные. Для кодов из `АБВ` длины от 1 до 3 перед словом `БАВ` стоят 3 однобуквенных кода, 9 двухбуквенных и 11 трёхбуквенных: БАВ ↔ 102₃ = 11. Номер равен 3 + 9 + 11 + 1 = 24.

Это сочетание правила сложения из подтемы 1 и номера внутри блока одной длины. Перебор проходит длины по очереди и ведёт общий номер сам:

```python
from itertools import product

number = 0
for length in range(1, 4):
    for letters in product('АБВ', repeat=length):
        number += 1
        if ''.join(letters) == 'БАВ':
            print(number)
```

```output
24
```

---

**Итого.**

- Полный список слов из m букв по алфавиту — счётчик с основанием m: буква → цифра, номер = значение + 1.
- Номер слова — количество слов раньше него плюс один; программа — `value = value * base + digit`.
- Слово по номеру — перевести номер − 1 в систему с основанием m, сохранив ведущие нули.
- Префикс длины k с значением p занимает номера от p · mⁿ⁻ᵏ + 1 до (p + 1) · mⁿ⁻ᵏ.
- Алфавит записывают по порядку сами; перебор с `enumerate(..., start=1)` проверяет ответ.
