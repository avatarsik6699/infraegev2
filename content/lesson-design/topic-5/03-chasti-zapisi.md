**Замена цифр отличается от дописывания: старый фрагмент сначала исчезает.** Почти треть задач подборок (22 из 69) берёт часть записи по её месту: копирует последние цифры, заменяет два левых разряда, удаляет цифру, переворачивает запись. Ещё три задачи меняют каждую цифру на противоположную. Всё это делается одними и теми же инструментами — номерами символов и срезами.

Будем разбирать двоичную запись `101110` — это 46. Для инверсии возьмём число 22 = 10110₂.

---

**При замене удаляется старый фрагмент и вставляется новый.** Пусть дана запись `101110`. Если первые две цифры заменить на `110`, получится `110` + `1110` = `1101110`. Мы:

1. убрали первые два символа `10`;
2. сохранили остаток `1110`;
3. поставили перед ним новый блок `110`.

Длина выросла на один символ: удалили два, вставили три.

Если последние две цифры заменить на `00`, получится `1011` + `00` = `101100`.

При замене последних k цифр на другой блок **той же длины**, имеющий значение A:

**R = ⌊N / qᵏ⌋ · qᵏ + A.**

Смысл формулы: удалить старый хвост, сдвинуть оставшуюся часть, поставить новый хвост. Для 46 и хвоста `00`: 46 // 4 = 11, 11 · 4 + 0 = 44 = 101100₂.

Для произвольной замены первых цифр обычно проще работать непосредственно с записью.

---

**Индексы и срезы позволяют брать нужные части записи.** Каждый символ строки имеет номер — **индекс**. В Python нумерация начинается с нуля: первая цифра записи `s = '101110'` — это `s[0]`, вторая — `s[1]`. Отрицательные индексы считают с конца: `s[-1]` — последний символ, `s[-2]` — предпоследний.

Чтобы получить несколько символов, используют {{slice|срез}} `s[a:b]`. Он берёт символы с индексами от `a` включительно до `b` **не включительно**. Например, `s[1:4]` берёт индексы 1, 2, 3 и даёт `'011'`.

<figure class="plate-figure">
%%slice("101110", 1, 4)%%
<figcaption>Срез s[1:4] записи 101110: границы стоят перед индексами 1 и 4, внутрь попадают символы 1, 2 и 3 — получается '011'.</figcaption>
</figure>

Если граница не указана, срез идёт от начала или до конца строки. Выберите срез, чтобы увидеть, что он берёт:

:::pick Срез и что он берёт из s = '101110'
- *s[:2] | `'10'` | первые два символа
- s[-2:] | `'10'` | последние два
- s[2:] | `'1110'` | всё, кроме первых двух
- s[:-2] | `'1011'` | всё, кроме последних двух
- s[::-1] | `'011101'` | строка в обратном порядке
- s[::2] | `'111'` | первая, третья, пятая позиции слева
- s[1::2] | `'010'` | вторая, четвёртая, шестая позиции слева
:::

В срезе можно указать третий параметр — **шаг**, то есть расстояние между выбираемыми индексами: `s[::2]` берёт индексы 0, 2, 4, … Срез `s[::-1]` использует шаг `-1`, поэтому проходит по строке с конца к началу.

**Если позиции в условии считают справа, нельзя без проверки применять срезы для позиций слева.** «Вторая справа цифра» — это `s[-2]`, а не `s[1]`.

---

**Из срезов и соединения строк собирается большинство преобразований задания.** Пусть `s` — текущая запись. Каждую команду условия можно перевести одной строкой:

:::pick Команда из условия и её перевод на Python
- *скопировать последние две цифры в конец | `s = s + s[-2:]`
- скопировать первые две цифры в конец | `s = s + s[:2]`
- удалить первые две цифры | `s = s[2:]`
- удалить последние две цифры | `s = s[:-2]`
- первые две цифры заменить на 110 | `s = '110' + s[2:]`
- последние две цифры заменить на 01 | `s = s[:-2] + '01'`
- перевернуть запись | `s = s[::-1]`
- перенести первую цифру в конец | `s = s[1:] + s[0]`
- перенести последнюю цифру в начало | `s = s[-1] + s[:-1]`
:::

В строке `s = s + s[-2:]` обе части справа вычисляются по старому значению `s`. После этого результат присваивается переменной.

Если после нескольких изменений нужно обратиться именно к исходной записи, сохрани её: `original = s`. Теперь `original` содержит исходный текст, а `s` можно дальше изменять. Сравни два алгоритма:

```python
n = 46
original = bin(n)[2:]
s = original + '1'
s = s + original[-2:]
print(s)

s = bin(n)[2:]
s = s + '1'
s = s + s[-2:]
print(s)
```

```output
101110110
101110101
```

В первом варианте последние две цифры взяты из исходной записи (`10`), во втором — уже из изменённой (`01`). Это два разных алгоритма, и условие всегда говорит, какой из них нужен.

---

**Перевернуть запись и инвертировать её — разные действия.** **Перевернуть запись** — прочитать её справа налево. **Инвертировать двоичную запись** — заменить каждый `0` на `1`, а каждый `1` на `0`. Например, для `1100` переворот даёт `0011`, и инверсия тоже даёт `0011`. На этом числе результаты случайно совпали. На другом уже нет: для `10110` переворот даёт `01101`, а инверсия — `01001`.

Поэтому ориентироваться нужно на смысл команды, а не на один пример.

---

**Для понимания инверсии полезно рассмотреть число, состоящее из одних единиц.** Возьмём пятизначную двоичную запись `10110`. После замены каждого `0` на `1` и каждого `1` на `0` получится `01001`. Если сложить значения исходной и изменённой записей, в каждом разряде получится единица:

<figure class="plate-figure">
%%invert("10110", 2)%%
<figcaption>В каждом столбце одна единица и один ноль, поэтому сумма — пять единиц, 11111₂ = 31. Значит, инверсия 22 равна 31 − 22 = 9.</figcaption>
</figure>

А число из пяти единиц равно 11111₂ = 2⁵ − 1 = 31. Поэтому N + M = 2ᴸ − 1, где L — длина записи, а M — результат инверсии. Отсюда:

**M = 2ᴸ − 1 − N.**

Для нашего примера N = 22, L = 5, M = 31 − 22 = 9. И действительно, 01001₂ = 9.

**Фиксированная длина имеет значение.** Число 5 можно записать как `101`. Инверсия этих трёх цифр — `010`, результат равен 2. Если условие требует сначала представить 5 восемью двоичными цифрами, `00000101`, то инверсия — `11111010`, и результат 255 − 5 = 250.

Поэтому нельзя автоматически представлять каждое число восемью разрядами. Такая длина должна быть задана условием.

Аналогичный принцип работает в троичной системе при замене 0 ↔ 2, 1 → 1. Каждая исходная цифра d заменяется на 2 − d. Сумма двух записей состоит из двоек: N + M = 222…2₃ = 3ᴸ − 1. Следовательно, **M = 3ᴸ − 1 − N.**

В общем случае, если в системе с основанием q каждую цифру d заменяют на q − 1 − d, то **M = qᴸ − 1 − N.** Эта формула не относится к любой произвольной замене цифр. Она работает именно для указанного правила.

---

**Одновременную замену символов нужно выполнять так, чтобы новые символы не заменялись повторно.** Пусть нужно поменять местами нули и единицы. Кажется, что можно написать `s.replace('0', '1').replace('1', '0')`. Но это ошибка.

Метод {{strmeth|`replace`}} создаёт строку с указанными заменами. В цепочке второй вызов работает с результатом первого. Для строки `'10'` получится `10 → 11 → 00`, а правильная инверсия — `10 → 01`.

```python
s = '10110'
print(s.replace('0', '1').replace('1', '0'))
```

```output
00000
```

После первой замены в строке одни единицы, и вторая замена превращает их все в нули.

Надёжный способ — читать исходную строку и собирать новую: на каждом шаге анализируется символ **исходной** строки, поэтому уже заменённые символы больше не трогаются. Запусти программу по шагам и следи, как растёт `new_s`:

```python run invert.py
s = '10110'
new_s = ''
for digit in s:
    if digit == '0':
        new_s = new_s + '1'
    else:
        new_s = new_s + '0'
print(new_s)
```

```output
01001
```

Для троичной записи 22 = 211₃ то же делает одна строка в цикле: новая цифра — `2 - int(digit)`.

```python
t = '211'
new_t = ''
for digit in t:
    new_t = new_t + str(2 - int(digit))
print(new_t, int(new_t, 3))
```

```output
011 4
```

Формула даёт то же: 3³ − 1 − 22 = 4.

---

**Ведущие нули можно игнорировать при получении числа, но не всегда при дальнейших действиях со строкой.** Python корректно прочитает `int('0011', 2)` и получит 3. Поэтому перед окончательным переводом специально удалять ведущие нули обычно не нужно.

Но рассмотрим два последовательных шага: получить строку `0011`, затем дописать слева `1`. Если сохранить строку, `0011 → 10011`, то результат равен 19. Если самовольно убрать нули между шагами, `0011 → 11 → 111`, то результат равен 7. Алгоритмы получились разными.

> Удаляй ведущие нули в тот момент, когда этого требует условие, либо при окончательном переходе от записи к числу, если промежуточных действий больше нет.

Также помни: строка `'0'` — корректная запись нуля, а пустая строка `''` — не запись числа, и `int('', 2)` вызовет ошибку. Если операция удаляет все символы, нужно проверить, допускает ли условие такой случай и как он трактуется.

---

**Итого.**

- Замена — это удаление старого фрагмента и вставка нового; длина записи может измениться.
- `s[a:b]` берёт индексы от a до b − 1, отрицательные индексы считают с конца; каждая команда условия — одна строка из срезов и `+`.
- Если шаг использует исходную запись, её сохраняют в отдельной переменной.
- Инверсия L-значной двоичной записи даёт 2ᴸ − 1 − N; длину задаёт условие.
- Замену «туда и обратно» собирают по исходной строке, а не цепочкой `replace`; ведущие нули убирают только тогда, когда этого требует условие.
