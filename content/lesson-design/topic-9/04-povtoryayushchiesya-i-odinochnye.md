**Главный тип задания — сравнить группы повторяющихся и неповторяющихся чисел в строке, подходящей по структуре повторов.** Так устроены 32 задачи из 74: все 11 задач основных волн 2023, 2024 и 2026 годов с повторами и демоверсии 2023–2025 годов.

Здесь мы решим целиком одну учебную задачу на шести строках учебной таблицы — сначала таблицей со вспомогательными столбцами, затем программой. Полоса частот и `Counter` — из прошлой подтемы, сравнение средних без деления — из подтемы о суммах и средних.

**Сумму группы в таблице складывает `СУММЕСЛИ` по полосе частот.** Функция {{xl-countif|`СУММЕСЛИ`}} проверяет условие в одном диапазоне и складывает соответствующие значения из другого. Вернёмся к строке 2, 2, 5, 5, 5, 9: исходные числа — в `A1:F1`, их частоты — в `G1:L1`. Сумма неповторяющихся чисел:

```excel
=СУММЕСЛИ(G1:L1;1;A1:F1)
```

Три аргумента означают: просмотреть частоты в `G1:L1`, выбрать позиции, где частота равна 1, сложить соответствующие исходные числа из `A1:F1`. Соответствие идёт по положению: `G1` соответствует `A1`, `H1` — `B1`, `I1` — `C1` и так далее. Сумма всех повторяющихся чисел с учётом каждого появления — `=СУММЕСЛИ(G1:L1;">1";A1:F1)`. Для нашей строки сумма неповторяющихся равна 9, сумма повторяющихся — 19.

Количество неповторяющихся элементов даёт `=СЧЁТЕСЛИ(G1:L1;1)`, количество элементов повторяющихся значений — `=СЧЁТЕСЛИ(G1:L1;">1")`. Следовательно, среднее повторяющихся:

```excel
=СУММЕСЛИ(G1:L1;">1";A1:F1)/СЧЁТЕСЛИ(G1:L1;">1")
```

Но эта формула имеет смысл только при наличии повторяющихся чисел. Иначе знаменатель будет равен нулю, и ячейка покажет {{xl-check|ошибку}} `#ДЕЛ/0!`.

**Средние двух групп сравнивают произведениями сумм и количеств.** Для сравнения двух средних зачастую удобнее:

1. отдельно найти суммы;
2. отдельно найти количества;
3. проверить непустоту обеих групп;
4. сравнить произведения: S₁ · k₂ и S₂ · k₁.

Для строки 2, 2, 5, 5, 5, 9 одиночное число одно (сумма 9), повторяющихся пять (сумма 19): 9 · 5 = 45 > 19 · 1 = 19, значит, среднее одиночных больше. По полосе частот это сравнение — `=СУММЕСЛИ(G1:L1;1;A1:F1)*СЧЁТЕСЛИ(G1:L1;">1")>СУММЕСЛИ(G1:L1;">1";A1:F1)*СЧЁТЕСЛИ(G1:L1;1)`.

**Не дели сумму всех повторяющихся чисел на 2 автоматически.** Это допустимо для получения суммы различных повторяющихся значений, только если каждое из них встречается ровно дважды. Например, 4, 4, 7, 7 даёт (4 + 4 + 7 + 7) / 2 = 4 + 7 = 11. Но для 4, 4, 7, 7, 7 деление общей суммы 29 на 2 уже не удалит повторы правильно: различных повторяющихся значений по-прежнему два, и их сумма 11, а не 14,5.

**Целое решение соединяет структуру повторов и сравнение групп.** Возьмём учебную задачу:

> В каждой строке шесть чисел. Нужно посчитать строки, в которых имеется одна пара одинаковых чисел, четыре остальных значения одиночные, а среднее одиночных чисел строго больше суммы двух чисел пары.

Начнём с одной строки: 2, 2, 5, 7, 9, 11. Структура повторений 2 + 1 + 1 + 1 + 1. Среднее одиночных чисел (5 + 7 + 9 + 11) / 4 = 32 / 4 = 8. Сумма двух чисел пары 2 + 2 = 4. Сравнение 8 > 4 выполнено — строка подходит.

В подходящей по структуре строке одиночных чисел ровно четыре. Поэтому, если сумма одиночных O, а сумма пары P, условие O / 4 > P равносильно O > 4P. Число 4 в сравнении не взято произвольно: оно следует из условия — при одной паре в строке из шести элементов остаётся ровно четыре одиночных числа.

**Вспомогательные столбцы хранят промежуточные результаты и показывают причину каждого ответа.** Вспомогательный столбец — обычный столбец, в котором хранится промежуточный результат:

| Диапазон или столбец | Что хранится |
|---|---|
| A:F | Исходные шесть чисел |
| G:L | Частота значения каждой исходной ячейки |
| M | Сумма неповторяющихся чисел |
| N | Сумма повторяющихся чисел |
| O | Итоговая отметка 1 или 0 |

В `G1` — полоса частот, её копируют вправо до `L1`; в `M1` и `N1` — суммы групп:

```excel
G1: =СЧЁТЕСЛИ($A1:$F1;A1)
M1: =СУММЕСЛИ(G1:L1;1;A1:F1)
N1: =СУММЕСЛИ(G1:L1;">1";A1:F1)
```

В `O1` — отметка строки:

```excel
=ЕСЛИ(И(СЧЁТЕСЛИ(G1:L1;2)=2;СЧЁТЕСЛИ(G1:L1;1)=4;M1>4*N1);1;0)
```

Она соединяет три проверки: две ячейки с частотой 2, четыре ячейки с частотой 1 и сравнение O > 4P. После проверки первой строки формулы копируют вниз до конца данных и складывают отметки:

**В Python неповторяющиеся и повторяющиеся элементы собирают в два списка.** Пустой список — `[]`, а `.append(x)` {{list|добавляет элемент}} в его конец. Пройди по шагам, куда попадает каждый элемент строки 2, 2, 5, 5, 5, 9:

```python run groups.py
a = [2, 2, 5, 5, 5, 9]
single = []
repeated = []
for x in a:
    if a.count(x) == 1:
        single.append(x)
    else:
        repeated.append(x)
print(single, repeated)
```

```output
[9] [2, 2, 5, 5, 5]
```

Слово `else` означает «иначе»: этот блок выполняется, если условие в `if` оказалось ложным. Почему здесь в `else` находятся именно повторяющиеся числа? Мы перебираем элементы, которые уже есть в `a`, поэтому их частота не может быть нулевой. Если она не равна 1, она больше 1. Повторения во втором списке сохраняются: мы посещаем каждую исходную позицию и добавляем её значение.

Теперь доступны суммы `sum(single)`, `sum(repeated)` и количества `len(single)`, `len(repeated)`. Средние `sum(single) / len(single)` можно вычислять только для непустых списков. Без деления сравнение средних записывается так:

```python
a = [2, 2, 5, 5, 5, 9]
single = [x for x in a if a.count(x) == 1]
repeated = [x for x in a if a.count(x) > 1]
if len(single) > 0 and len(repeated) > 0:
    condition = (
        sum(single) * len(repeated)
        > sum(repeated) * len(single)
    )
    print(condition)
```

```output
True
```

Здесь те же два списка построены короче — {{comp|включением с условием}}: «возьми из `a` те элементы `x`, для которых частота равна 1». Это не новый способ решения задачи, а сокращённая запись уже разобранного перебора. Скобки позволяют удобно перенести одно выражение на несколько строк. Программа подтвердила сравнение из таблицы: 45 > 19.

**Полная программа повторяет вспомогательные столбцы.** Для учебной задачи на файле [9.txt](topic-9/files/9.txt):

```python
answer = 0

with open("9.txt") as f:
    for line in f:
        a = [int(part) for part in line.split()]

        frequencies = [a.count(x) for x in a]

        single = [x for x in a if a.count(x) == 1]
        repeated = [x for x in a if a.count(x) > 1]

        correct_repetitions = (
            frequencies.count(2) == 2
            and frequencies.count(1) == 4
        )

        correct_comparison = (
            sum(single) > 4 * sum(repeated)
        )

        if correct_repetitions and correct_comparison:
            answer += 1

print(answer)
```

```output
2
```

Разберём, что принципиально:

- `answer = 0` находится **до** цикла по строкам, чтобы общий ответ не обнулялся;
- `a`, `frequencies`, `single`, `repeated` строятся заново **для каждой строки**;
- структура повторений и числовое сравнение проверяются отдельно — как столбцы `G:L` и `M:N` таблицы;
- `answer` увеличивается один раз после полной проверки строки, а `print(answer)` выводит итог по всему файлу.

**Различные повторяющиеся значения даёт перебор `Counter`.** Вернёмся к строке 4, 4, 4, 7, 7, 2, 9 и её {{counter|`Counter`}}. С сохранением всех появлений повторяющиеся числа собирает `[x for x in a if counts[x] > 1]`. Если перебирать сам `counts`, перебираются его ключи, то есть каждое различное значение один раз:

```python
from collections import Counter

a = [4, 4, 4, 7, 7, 2, 9]
counts = Counter(a)
repeated = [x for x in a if counts[x] > 1]
distinct_repeated = [x for x in counts if counts[x] > 1]
print(repeated, distinct_repeated)
print(sum(repeated), sum(distinct_repeated))
print(max(repeated), max(distinct_repeated))
```

```output
[4, 4, 4, 7, 7] [4, 7]
26 11
7 7
```

Для поиска максимума повторяющихся значений кратность не влияет, а для суммы и среднего она может влиять существенно: 26 против 11.

---

**Сначала проверяют структуру, и только потом — максимумы и минимумы групп.** Например, проверим строку, в которой требуется структура 3 + 2 + 1 + 1 и чтобы максимальное повторяющееся значение было меньше максимального одиночного:

```python
from collections import Counter

a = [4, 4, 4, 7, 7, 2, 9]
answer = 0
counts = Counter(a)
if sorted(counts.values()) == [1, 1, 2, 3]:
    repeated = [x for x in a if counts[x] > 1]
    single = [x for x in a if counts[x] == 1]
    if max(repeated) < max(single):
        answer += 1
print(answer)
```

```output
1
```

Порядок действий здесь важен. Сначала проверяется структура, которая гарантирует существование обеих групп. Только потом вычисляются их максимумы: у пустого списка максимума или минимума нет, и `max([])` остановит программу ошибкой.

---

**Итого.**

- В таблице суммы групп даёт `СУММЕСЛИ` по полосе частот, количества — `СЧЁТЕСЛИ` по ней же; в программе — списки `single` и `repeated`.
- Средние групп сравнивают произведениями сумм и количеств; при известной структуре количество групп — число из условия (одна пара из шести — четыре одиночных).
- Сумма повторяющихся «с учётом повторений» и сумма различных повторяющихся значений — разные величины; сумму повторов не делят на 2 автоматически.
- Решение целиком: полоса частот → суммы групп → отметка строки → сумма отметок; в программе те же шаги внутри цикла по строкам.
- Сначала структура, потом максимумы и средние групп: структура гарантирует, что группы не пусты.
