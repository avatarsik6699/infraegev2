**Геометрические задачи также сводятся к числовым проверкам строки, но формулы нужно понимать.** Почти всё решает сортированная копия строки: после неё видно, какая сторона наибольшая.

Разберём тройки 4, 6, 10 и 4, 5, 7. Сортированная копия и «сумма остальных» S − M — из подтемы о суммах и средних.

---

**Три положительных числа — стороны обычного треугольника, если сумма двух меньших больше наибольшего.** Рассмотрим три положительных числа и расположим их так: a ≤ b ≤ c. Чтобы они могли быть сторонами обычного, невырожденного треугольника, каждая сторона должна быть меньше суммы двух других. Но проверять достаточно a + b > c.

<figure class="plate-figure">
%%tb_triangle([[4, 6, 10], [4, 5, 7]])%%
<figcaption>Две меньшие стороны a и b, отложенные вдоль наибольшей c: 4 + 6 ровно достают до 10 — треугольник вырожден; 4 + 5 = 9 больше 7 — треугольник есть.</figcaption>
</figure>

Почему остальные неравенства выполняются автоматически? Поскольку c ≥ b и a > 0, выполнено a + c > b. Поскольку c ≥ a и b > 0, выполнено b + c > a. Проблема возможна только с самой длинной стороной. В Python:

```python
for a in [[4, 6, 10], [7, 4, 5]]:
    b = sorted(a)
    print(b, b[0] + b[1] > b[2])
```

```output
[4, 6, 10] False
[4, 5, 7] True
```

---

**Без сортировки ту же проверку даёт сравнение суммы с удвоенным максимумом.** Используем общую сумму S и максимум M: сумма двух меньших сторон равна S − M, и условие S − M > M после переноса становится S > 2M. Поэтому `sum(a) > 2 * max(a)` проверяет существование треугольника для трёх положительных чисел. В электронной таблице:

```excel
=ЕСЛИ(СУММ(A1:C1)>2*МАКС(A1:C1);1;0)
```

Это та же «сумма остальных», что в основных задачах: условие «наибольшее из четырёх чисел меньше суммы трёх других» записывается M < S − M так же, без всякой геометрии.

Граница важна. Выбери соотношение, чтобы увидеть, что получается:

:::pick Соотношение сторон a ≤ b ≤ c и что получается
- *a + b > c | обычный треугольник
- a + b = c | вырожденный случай: стороны укладываются на прямую
- a + b < c | треугольник не получается даже в вырожденном смысле
:::

Например, 4 + 6 = 10. Поэтому 4, 6, 10 не образуют обычный треугольник. Если спрашивают «не могут быть сторонами треугольника, в том числе вырожденного», требуется именно a + b < c, а не ≤.

---

**Тип треугольника по углам определяется сравнением квадратов сторон.** После сортировки a ≤ b ≤ c наибольший угол лежит напротив наибольшей стороны c. Если треугольник существует, выбери соотношение квадратов:

:::pick Соотношение квадратов и вид треугольника
- *a² + b² > c² | остроугольный
- a² + b² = c² | прямоугольный — это теорема Пифагора
- a² + b² < c² | тупоугольный
:::

Достаточно рассматривать наибольший угол: если он острый, остальные тоже острые; если он прямой или тупой, этим определяется вид треугольника. Например, для 4, 5, 7 треугольник существует (4 + 5 > 7), но 4² + 5² = 41 < 49 = 7². Значит, он тупоугольный.

<details class="proof" markdown="1">
<summary>Почему знак сравнения квадратов определяет вид треугольника</summary>

Теорема косинусов связывает сторону c с противолежащим углом γ:

c² = a² + b² − 2ab · cos γ.

Косинус острого угла положителен, прямого — равен нулю, тупого — отрицателен. Поэтому квадрат стороны получается соответственно меньше, равен или больше суммы двух других квадратов.

</details>

---

**Для тупоугольного треугольника проверка существования обязательна.**

```python
answer = 0
for a in [[7, 4, 5], [1, 2, 10]]:
    b = sorted(a)
    triangle = b[0] + b[1] > b[2]
    obtuse = (
        b[0] ** 2 + b[1] ** 2 < b[2] ** 2
    )
    print(b, triangle, obtuse)
    if triangle and obtuse:
        answer += 1
print(answer)
```

```output
[4, 5, 7] True True
[1, 2, 10] False True
1
```

Без проверки существования числа 1, 2, 10 прошли бы сравнение квадратов, хотя треугольник из них не существует. Для положительных сторон остроугольное сравнение само влечёт существование треугольника: из c² < a² + b² < (a + b)² следует c < a + b. Но проверять существование отдельно тоже можно: это делает рассуждение явным.

**Когда из четырёх чисел нужно выбрать три, иногда перебор заменяется выбором крайних значений.** Пусть a ≤ b ≤ c ≤ d. Нужно выяснить, можно ли выбрать тройку, которая не образует даже вырожденного треугольника. Чтобы получить такое нарушение, хочется сделать наибольшую сторону как можно больше, а сумму двух остальных — как можно меньше. Самая подходящая для этого тройка — a, b, d.

Поэтому существование нужной тройки равносильно a + b < d. Если даже сумма двух минимальных не меньше максимального, то для любой другой тройки сумма двух меньших будет не меньше, а наибольшее число — не больше. Нарушение не появится.

```python
a = [3, 5, 9, 4]
b = sorted(a)
condition = b[0] + b[1] < b[-1]
print(b, condition)
```

```output
[3, 4, 5, 9] True
```

Здесь отсортированный список назван `b`; его длина равна четырём. Тройка 3, 4, 9 не образует треугольника: 3 + 4 = 7 < 9.

**Задача о прямоугольном параллелепипеде сводится к площадям прямоугольников.** Пусть три размера a ≤ b ≤ c. Три грани, сходящиеся в одной вершине, имеют площади ab, ac и bc. Наибольшая площадь — bc, потому что все размеры положительны.

Если требуется, чтобы одна площадь была больше суммы двух других, достаточно проверить bc > ab + ac, или bc > a(b + c). В Python:

```python
for a in [[2, 3, 4], [4, 1, 3]]:
    b = sorted(a)
    condition = (
        b[1] * b[2]
        > b[0] * b[1] + b[0] * b[2]
    )
    print(b, condition)
```

```output
[2, 3, 4] False
[1, 3, 4] True
```

Для 2, 3, 4 площади 6, 8, 12, и 12 < 6 + 8. Для 1, 3, 4 площади 3, 4, 12, и 12 > 7. Важно не путать размеры a, b, c с площадями ab, ac, bc. Условие относится именно к площадям.

---

**Итого.**

- Существование треугольника — одна проверка после сортировки: a + b > c, или без сортировки S > 2M; равенство — вырожденный случай.
- Вид — по квадратам: a² + b² больше, равно или меньше c²; для тупоугольного сначала проверяют существование.
- Из четырёх чисел «худшая» тройка — два наименьших и наибольшее: a + b < d.
- Параллелепипед: наибольшая грань bc сравнивается с ab + ac.
