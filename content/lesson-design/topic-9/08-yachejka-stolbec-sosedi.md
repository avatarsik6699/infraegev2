**Когда условие зависит не только от своей строки, решение идёт в два уровня: сначала отмечают подходящие ячейки, затем по отметкам — строки.** В программе для этого таблицу читают целиком и проходят дважды.

Разберём маленькую таблицу из четырёх строк по три числа и квадрат 3 × 3 для соседей. Полоса частот и `Counter` — из подтемы о повторах, признак строки — из первой подтемы.

---

**В задачах на совпадения особенно важно определить область поиска.** Фраза «встречается пять раз» неполна без уточнения: в текущей строке, в текущем столбце, во всей таблице, в других ячейках, в других строках.

Предположим, исходные данные находятся в `A1:F5000`. Для значения `A1` выбери, где считаем:

:::pick Где считаем и формула
- *в текущей строке | `=СЧЁТЕСЛИ($A1:$F1;A1)`
- в текущем столбце | `=СЧЁТЕСЛИ(A$1:A$5000;A1)`
- во всей исходной таблице | `=СЧЁТЕСЛИ($A$1:$F$5000;A1)`
:::

Почему ссылки отличаются? В диапазоне строки фиксируются столбцы, но меняется номер строки. В диапазоне столбца фиксируются верхняя и нижняя строки, а буква столбца при копировании вправо меняется. Для всей таблицы фиксируются все границы — это знак `$` из {{xl-ref|урока о ссылках}}.

---

**Любой такой подсчёт включает проверяемую ячейку**, потому что она находится в диапазоне и содержит искомое значение. Если нужно количество появлений в других ячейках того же столбца, вычитают единицу:

```excel
=СЧЁТЕСЛИ(A$1:A$5000;A1)-1
```

Если нужно количество появлений в других строках всей таблицы, следует исключить **все** появления из текущей строки:

```excel
=СЧЁТЕСЛИ($A$1:$F$5000;A1)-СЧЁТЕСЛИ($A1:$F1;A1)
```

Например, во всей таблице число встречается 17 раз, в текущей строке — 3 раза. В остальных строках оно встречается 17 − 3 = 14 раз. **Вычитание единицы дало бы неправильный результат 16.** Если отдельно установлено, что число в текущей строке единственное, вычитание частоты строки действительно превращается в вычитание 1.

---

**Количество появлений и количество строк, содержащих значение, тоже могут различаться.** Допустим, число 5 встречается в первой строке три раза, во второй — два раза, в третьей — ни разу. Тогда появлений числа 5 — пять, а строк, содержащих число 5, — две.

Поэтому формулировка «встречается 20 раз в других строках» обычно относится к появлениям, а формулировка «встречается в 20 различных строках» требует считать сами строки. Это тот же принцип, с которого мы начали тему: прежде чем считать, нужно определить объект подсчёта.

---

**Проверка «особой» ячейки и проверка строки выполняются на разных уровнях.** Возьмём учебное определение: ячейка подходит, если её значение встречается в своей строке один раз и встречается в других ячейках своего столбца ещё хотя бы один раз. Для `A1` таблицы из четырёх строк отметка ячейки в `D1`:

```excel
=ЕСЛИ(И(СЧЁТЕСЛИ($A1:$C1;A1)=1;СЧЁТЕСЛИ(A$1:A$4;A1)-1>=1);1;0)
```

Эту формулу размещают в `D1` и копируют вправо до `F1`, а затем вниз. Теперь `D:F` содержат отметки отдельных ячеек. Строка с хотя бы одной подходящей ячейкой получает отметку `=ЕСЛИ(СУММ(D1:F1)>=1;1;0)`, и только после этого суммируются отметки строк:

```sheet Ячейки select=D1 edit=A1:C4
|   | A | B | C | D                                                              | E   | F   | G
| 1 | 2 | 3 | 2 | =ЕСЛИ(И(СЧЁТЕСЛИ($A1:$C1;A1)=1;СЧЁТЕСЛИ(A$1:A$4;A1)-1>=1);1;0) ⇒ 0 | ⇒ 0 | ⇒ 0 | =ЕСЛИ(СУММ(D1:F1)>=1;1;0) ⇒ 0
| 2 | 4 | 2 | 5 |                                                                | ⇒ 1 |     | ⇒ 1
| 3 | 2 | 6 | 7 | ⇒ 1                                                            |     |     | ⇒ 1
| 4 | 8 | 2 | 2 |                                                                |     |     | ⇒ 0
| 5 |   |   |   |                                                                |     |     | =СУММ(G1:G4) ⇒ 2
fill D1:F1
fill D1:F4
fill G1:G4
```

Подходят вторая строка (двойка единственна в строке, и в столбце B есть ещё одна двойка) и третья (двойка в столбце A). Тройка первой строки единственна в строке, но больше в своём столбце не встречается. **Если сразу сложить все отметки ячеек по всей таблице, получится количество подходящих ячеек, а не строк.** Если строка должна содержать ровно одну подходящую ячейку, отметка строки — `=ЕСЛИ(СУММ(D1:F1)=1;1;0)`.

---

**Когда условие зависит от всего столбца или всей таблицы, в Python удобно сначала прочитать все данные.** Таблицу можно представить как список строк, где каждая строка сама является списком. При чтении файла его собирают так:

```python
table = []
with open("9.txt") as f:
    for line in f:
        a = [int(part) for part in line.split()]
        table.append(a)
print(len(table), table[0])
```

```output
6 [2, 2, 5, 7, 9, 11]
```

Для нашей маленькой таблицы `table[0]` — первая строка `[2, 3, 2]`, а `table[0][1]` — элемент с индексом 1 в первой строке, то есть число 3. Теперь можно сделать два прохода:

1. Посчитать частоты по столбцам.
2. Проверить ячейки и строки по уже известным частотам.

```python
from collections import Counter

table = [
    [2, 3, 2],
    [4, 2, 5],
    [2, 6, 7],
    [8, 2, 2],
]
width = len(table[0])

column_counts = []
for j in range(width):
    column_counts.append(Counter())

for a in table:
    for j in range(width):
        column_counts[j][a[j]] += 1

answer = 0
for a in table:
    row_counts = Counter(a)
    good_cells = 0
    for j in range(width):
        x = a[j]
        if (
            row_counts[x] == 1
            and column_counts[j][x] - 1 >= 1
        ):
            good_cells += 1
    if good_cells >= 1:
        answer += 1

print(answer)
```

```output
2
```

Разберём строку `column_counts[j][a[j]] += 1`: `j` — индекс столбца, `a[j]` — число текущей строки в этом столбце, `column_counts[j]` — {{counter|счётчик}} соответствующего столбца, а `+= 1` добавляет одно появление числа. У `Counter` частота ещё не встречавшегося значения считается нулевой, поэтому её можно сразу увеличивать. Перебор строк и столбцов — это {{nested|вложенные циклы}}.

Почему два прохода удобны? При чтении первой строки мы ещё не знаем, сколько раз её значения встретятся ниже. Сначала собираем информацию, затем применяем условие.

Если нужны частоты по всей таблице, `all_counts.update(a)` добавляет в общий счётчик все появления элементов строки, и количество появлений `x` вне текущей строки — `all_counts[x] - a.count(x)`. Если же нужно количество строк, содержащих значение, каждое значение надо учитывать в строке только один раз — через множество:

```python
from collections import Counter

table = [[2, 3, 2], [4, 2, 5], [2, 6, 7], [8, 2, 2]]
all_counts = Counter()
row_presence = Counter()
for a in table:
    all_counts.update(a)
    for x in set(a):
        row_presence[x] += 1
print(all_counts[2], row_presence[2])
print(all_counts[2] - table[0].count(2))
```

```output
6 4
4
```

Двойка встречается 6 раз в 4 строках; вне первой строки — 6 − 2 = 4 раза.

**У ячейки в углу три соседа, на краю — пять, внутри — восемь.** Если соседними считаются ячейки с общей стороной или углом, у внутренней ячейки восемь соседей. Например, в квадрате

|  |  |  |
|---:|---:|---:|
| 2 | 2 | 7 |
| 4 | **5** | 9 |
| 6 | 1 | 8 |

у центральной пятёрки соседи 2, 2, 7, 4, 9, 6, 1, 8. Сама центральная ячейка в число соседей не входит. В обычной прямоугольной таблице размером хотя бы 2 × 2:

**Перебор соседей меняет индексы строки и столбца на −1, 0 и 1 и проверяет границы таблицы.** Пусть текущая ячейка имеет индексы `r` и `c`. Чтобы перейти к соседу, индекс строки может измениться на −1, 0 или 1, и индекс столбца — тоже. Комбинация изменений 0, 0 оставляет нас в текущей ячейке, поэтому её исключаем — {{continue|`continue`}} пропускает оставшуюся часть текущего шага ближайшего цикла. Проверим для каждой ячейки квадрата, есть ли у неё больший сосед ({{def|функция}} `has_larger`):

```python
table = [[2, 2, 7], [4, 5, 9], [6, 1, 8]]

def has_larger(r, c):
    x = table[r][c]
    found = False
    for dr in [-1, 0, 1]:
        for dc in [-1, 0, 1]:
            if dr == 0 and dc == 0:
                continue
            nr = r + dr
            nc = c + dc
            if (
                0 <= nr < len(table)
                and 0 <= nc < len(table[0])
            ):
                if table[nr][nc] > x:
                    found = True
    return found

for r in range(len(table)):
    print([int(has_larger(r, c)) for c in range(3)])
```

```output
[1, 1, 1]
[1, 1, 0]
[0, 1, 1]
```

Здесь `dr`, `dc` — изменения индексов, `nr`, `nc` — индексы предполагаемого соседа; проверки границ исключают позиции за пределами таблицы. Большего соседа нет у девятки и у шестёрки в левом нижнем углу.

**Проверять границы необходимо.** В частности, индекс `-1` в Python не означает «ячейки нет»: он обращается к последнему элементу. Без проверки шестёрка в левом нижнем углу «увидела» бы соседей с правого края — 9 и 8 — и ошибочно получила бы большего соседа.

Дальше этот фрагмент соединяется с остальными условиями:

1. Проверить, что значение единственное в своей строке.
2. Проверить наличие нужного соседа.
3. Увеличить количество подходящих ячеек строки.
4. Проверить требование к строке.
5. Увеличить общий ответ один раз.

В электронной таблице для внутренней ячейки `B2` существование большего соседа можно проверить формулой `=МАКС(A1:C3)>B2`. Хотя диапазон содержит саму `B2`, здесь это не мешает: `B2` не может быть строго больше самой себя. Если максимум больше `B2`, он находится в другой ячейке. Аналогично для меньшего соседа — `=МИН(A1:C3)<B2`. На границах диапазоны нужно ограничить исходными данными: например, нельзя захватить справа вспомогательные столбцы и считать их соседями исходной таблицы.

---

**Итого.**

- Сначала определяют область подсчёта: строка, столбец, таблица, другие ячейки, другие строки; `$` в ссылке закрепляет её границы.
- Подсчёт включает саму ячейку: «в других ячейках столбца» — минус 1, «в других строках» — минус частота строки.
- Появления и строки, содержащие значение, — разные величины; строки считают через множество значений строки.
- Отметки ячеек, затем отметки строк; в программе — таблица целиком и два прохода: счётчики столбцов, затем проверка.
- Соседи — изменения индексов на −1, 0, 1 без (0, 0) и с проверкой границ.

2. Число 7 встречается в первой строке дважды, во второй — трижды, в третьей ни разу, в четвёртой — один раз. Сколько у него появлений и в скольких строках оно встречается?

8. `600`: перебор соседей с проверкой границ, вершина — без большего соседа и единственная в строке.
