**Чётность, кратность и «особые» числа проверяются одним инструментом — точной проверкой отдельного числа строки.** Чётность и кратность нужны в 8 задачах из 74, целая часть среднего и квадраты или кубы натуральных чисел — ещё в 2; все они, кроме двух, — задачи 2025–2026 годов.

Чётные и нечётные группы разберём на строке 1, 3, 5, 20, 30, а особые числа — на строке из семи чисел 2, 8, 4, 9, 11, 13, 12. Группы чисел и сравнение со средним без деления — из прошлых подтем.

---

**Чётность и делимость проверяются через остаток от деления.** При делении 17 на 5 получаем 17 = 5 · 3 + 2; здесь 2 — остаток. В Python остаток обозначается {{intdiv|`%`}}: число делится на 5 без остатка, если `x % 5 == 0`. Чётное число делится на 2 без остатка — `x % 2 == 0`, нечётное — `x % 2 != 0`:

```python
print(17 % 5, 17 // 5)
print(-7 % 2, 0 % 2, 20 % 2)
```

```output
2 3
1 0 0
```

Эти проверки работают и для отрицательных целых чисел: −7 нечётное, остаток 1. **Ноль является чётным:** `0 % 2 == 0`.

Если нужно проверить, что максимум не кратен минимуму, — `max(a) % min(a) != 0`. При натуральных числах минимум положителен. Если допускается ноль, деление на минимум требует отдельного рассмотрения: делить на ноль нельзя.

---

**Количество и сумма чётных чисел — независимые условия.** Группы чётных и нечётных элементов собирают включениями с условием, после чего можно независимо сравнивать количества и суммы:

```python
a = [1, 3, 5, 20, 30]
even = [x for x in a if x % 2 == 0]
odd = [x for x in a if x % 2 != 0]
print(even, odd)
print(len(odd) > len(even), sum(odd) < sum(even))
```

```output
[20, 30] [1, 3, 5]
True True
```

**Первое условие не определяет второе.** Нечётных больше (3 > 2), но их сумма меньше: 1 + 3 + 5 = 9 < 50 = 20 + 30.

В электронной таблице остаток вычисляет {{xl-mod|`ОСТАТ`}}: для целого числа `=ОСТАТ(A1;2)` даёт 0 или 1. В отдельной задаче на чётность можно разместить эти остатки полосой в `G1:L1` — как полосу частот. Тогда количество чётных элементов и их сумма:

```excel
G1: =ОСТАТ(A1;2)
=СЧЁТЕСЛИ(G1:L1;0)
=СУММЕСЛИ(G1:L1;0;A1:F1)
```

---

**Если число сравнивается со средним строки, знаменатель тоже можно убрать.** Пусть в строке n чисел с суммой S. Условие x > S / n равносильно n · x > S, поскольку n > 0. Для строки 1, 3, 5, 20, 30 имеем n = 5, S = 59: выше среднего 11,8 числа, для которых 5x > 59, — это 20 и 30.

Обрати внимание на области действия условий. Если задача требует сравнить количества чётных и нечётных чисел **выше среднего** и сравнить суммы **всех** чётных и нечётных чисел строки, то для второй проверки нельзя использовать только числа выше среднего:

```python
a = [1, 3, 5, 20, 30]
n = len(a)
s = sum(a)
above_even = [x for x in a if n * x > s and x % 2 == 0]
above_odd = [x for x in a if n * x > s and x % 2 != 0]
condition1 = len(above_even) > len(above_odd)

even = [x for x in a if x % 2 == 0]
odd = [x for x in a if x % 2 != 0]
condition2 = sum(even) < sum(odd)
print(above_even, above_odd, condition1, condition2)
```

```output
[20, 30] [] True False
```

**Слова, ограничивающие группу чисел, относятся именно к той части условия, где они указаны.** Выше среднего здесь только чётные 20 и 30, а в суммы всех чётных и нечётных входят все пять чисел.

---

**Целую часть среднего натуральных чисел даёт целочисленное деление.** Для положительного числа целая часть получается отбрасыванием дробной части: целая часть 8,7 равна 8. Если в строке положительные целые числа, целую часть среднего можно вычислить {{intdiv|целочисленным делением}} `sum(a) // len(a)`: операция `//` выполняет деление с округлением вниз, и для положительного результата это и даёт нужную целую часть.

Строка 2, 8, 4, 9, 11, 13, 12 имеет сумму 59, а 59 : 7 = 8 + 3/7. Поэтому `59 // 7` равно 8, и проверка наличия такого числа в строке — {{in|`in`}}:

```python
a = [2, 8, 4, 9, 11, 13, 12]
mean_integer_part = sum(a) // len(a)
print(mean_integer_part, mean_integer_part in a)
```

```output
8 True
```

В электронной таблице целую часть даёт `ЦЕЛОЕ`, а наличие числа в строке — `СЧЁТЕСЛИ`:

```excel
=СЧЁТЕСЛИ(A1:G1;ЦЕЛОЕ(СРЗНАЧ(A1:G1)))>=1
```

Для отрицательных значений нужно быть внимательнее: округление вниз и отбрасывание дробной части различаются. Например, округление −2,7 вниз даёт −3, а отбрасывание дробной части — −2. В рассматриваемой проверке положительность чисел устраняет эту неоднозначность.

**Число является квадратом натурального числа, если оно равно k² для некоторого целого k ≥ 1.** Примеры: 1, 4, 9, 16, 25, …

Для точной проверки на Python можно использовать `isqrt` из стандартного модуля `math` ({{import|`from math import isqrt`}}). Эта функция для неотрицательного целого числа возвращает наибольшее целое k, для которого k² ≤ x: `isqrt(81)` и `isqrt(82)` оба равны 9. Поэтому достаточно возвести найденное число обратно в квадрат — `isqrt(x) ** 2 == x`. Для 81 равенство выполнится, для 82 — нет:

```python
from math import isqrt

print(isqrt(81), isqrt(82))
print(isqrt(81) ** 2 == 81, isqrt(82) ** 2 == 82)

a = [2, 8, 4, 9, 11, 13, 12]
has_square = False
for x in a:
    if x > 0 and isqrt(x) ** 2 == x:
        has_square = True
print(has_square)
```

```output
9 9
True False
True
```

В строке есть квадраты 4 и 9. Условие `x > 0` исключает отрицательные числа и ноль. Ноль является квадратом целого числа 0, но не квадратом натурального числа при принятом здесь определении натуральных чисел от 1. В Python при соединении через `and` правая часть не вычисляется, если левая уже ложна. Поэтому для отрицательного `x` функция `isqrt` здесь не вызывается.

**Для кубов удобно заранее построить точный набор возможных значений.** Кубы натуральных чисел: 1³ = 1, 2³ = 8, 3³ = 27, 4³ = 64, …

Если вся положительная таблица уже прочитана в список строк `table`, найдём её максимум и создадим {{set|множество}} кубов, не превышающих этот максимум. Пустое множество создаёт `set()`, `.add(...)` добавляет значение, а {{while|`while`}} повторяет действия, пока указанное условие верно:

```python
table = [
    [2, 8, 4, 9, 11, 13, 12],
    [27, 1, 5, 30, 14, 6, 20],
]
limit = 0
for a in table:
    limit = max(limit, max(a))

cubes = set()
k = 1
while k ** 3 <= limit:
    cubes.add(k ** 3)
    k += 1
print(limit, sorted(cubes))

for a in table:
    has_cube = False
    for x in a:
        if x in cubes:
            has_cube = True
    print(has_cube)
```

```output
30 [1, 8, 27]
True
True
```

Теперь принадлежность к кубам проверяется точно: `x in cubes`. Набор кубов строится один раз для всего файла, а не заново для каждой строки. Почему полезно обходиться без дробной степени? Вычисление кубического корня через вещественные числа может дать приближённый результат около целого. Построение значений `k ** 3` использует точные целочисленные вычисления.

В электронной таблице можно сделать аналогично: создать отдельный столбец 1³, 2³, 3³, … до нужной границы и проверять наличие исходного числа в нём через `СЧЁТЕСЛИ`. Так же можно проверять и квадраты.

---

**Итого.**

- Чётность и кратность — остаток: `x % 2 == 0`, `max(a) % min(a) != 0`, в таблице — полоса `ОСТАТ` и `СЧЁТЕСЛИ`/`СУММЕСЛИ` по ней; ноль чётный.
- Количество и сумма чётных — разные условия; слова «выше среднего» относятся только к своей части условия.
- Число выше среднего строки: n · x > S, без деления.
- Целая часть среднего натуральных чисел — `sum(a) // len(a)` или `ЦЕЛОЕ(СРЗНАЧ(…))`, наличие в строке — `in` или `СЧЁТЕСЛИ(…)>=1`.
- Квадрат натурального — `x > 0 and isqrt(x) ** 2 == x`, кубы — множество `k ** 3`, построенное один раз.
