**В любой задаче задания 2 порядок столбцов подходит, только если при нём все строки фрагмента одновременно восстанавливаются в разные наборы с нужным F.** Ошибки обычно возникают в смысле операций и в прочтении фрагмента, а не в переборе.

Всё главное из подтем собрано на одной схеме. Номер раздела ведёт на его подтему.

**Для новой задачи можно использовать один порядок рассуждений.**

1. **Перепиши формулу** со всеми скобками и направлениями стрелок, выпиши F каждой строки (подтема 2).
2. **Найди подходящие наборы** для F = 1 и F = 0 — по внешней операции, разбором по случаям или полной таблицей (подтема 2).
3. **Ищи сильные признаки:** постоянное значение, число нулей и единиц переменной среди наборов, цепочку стрелок (подтемы 3–4).
4. **Сопоставляй строки вместе:** одна шапка на все строки, строки различны, у каждой строки — свой список по её F (подтемы 3–4).
5. **Проверь ответ** подстановкой в исходную формулу; при сомнении — программой (подтема 5).
6. **Запиши буквы** в порядке столбцов слева направо.

**Частые ошибки удобно связывать с конкретной проверкой.** Выбери ошибку, чтобы увидеть, почему рассуждение неверно и как себя проверить:

:::pick Ошибка и что проверить
- *«или» — оба | Из A ∨ B = 1 делают A = B = 1: достаточно одной единицы | подставить A = 1, B = 0
- «и» — оба нули | Из A ∧ B = 0 делают A = B = 0: достаточно одного нуля | подставить A = 0, B = 1
- 0 → 0 ложно | Считают 0 → 0 ложным: нарушение стрелки только 1 → 0 | раскрыть ¬A ∨ B
- направление стрелки | Путают A → B с B → A: у стрелки есть направление | проверить набор 0,1
- 0 ≡ 0 ложно | Считают 0 ≡ 0 ложным: эквивалентность проверяет совпадение | сравнить два нуля
- пропуск — ноль | Принимают пропуск за 0: пропуск допускает оба значения | перечислить оба заполнения
- буквы в строках | Переставляют буквы отдельно в строках: подписи общие для столбцов | подписать столбцы один раз
- фрагмент — всё | Считают фрагмент полной выборкой: часть подходящих строк могла не попасть в условие | найти слово «все» и его точный смысл
- набор дважды | Используют один набор дважды: строки должны различаться | сравнить восстановленные входы
- строки по номеру | Сопоставляют строки по номеру: порядок вывода программы произволен для задачи | сравнивать цифры, а не позиции
- `x <= y == z` | Пишут `x <= y == z`: Python выполняет цепочку сравнений | явно поставить `(x <= y) == z`
- номера вместо букв | Выдают порядок номеров вместо букв: ответ читается слева направо по столбцам | подписать C1, C2, C3, C4
:::

Ещё одна ошибка менее заметна: рассуждать по «похожести» столбцов. Например, если две переменные иногда равны, это не значит, что они всегда должны иметь одинаковые значения. Используй только доказанное ограничение — во всех рассматриваемых наборах или в конкретной строке.

Полезная проверка законченного решения состоит из четырёх действий. Сохранены ли все известные цифры? Одинаковы ли подписи столбцов во всех строках? Даёт ли исходная формула требуемое F в каждой строке? Различны ли полностью восстановленные входные наборы? Если условие требует полноту, отдельно проверь и её.

**Ответы для проверки:**

1. xzy: F = 1 на наборах xyz 001, 100, 110. В C1 две единицы, а y и z равны 1 лишь в одном наборе каждая — C1 = x. В строке 3 x = 0 — это 001, единица в C2 — z: C2 = z, C3 = y.
2. wyxz: строка 1 — C3 раньше C2, строка 2 — C4 раньше C1, строка 3 — C2 раньше C4. Вдоль цепочки C3, C2, C4, C1 — это x, y, z, w, а в порядке столбцов — w, y, x, z.
3. xzwy: F = 0 на 0101, 0110, 1010, 1110 (xyzw). Нули в C1 стоят в двух строках, в C3 — тоже в двух; два нуля бывают только у x и w — значит, C1 и C3 — это x и w, а C2 и C4 — y и z. Если C2 = y, строки 1 и 2 обе восстанавливаются в 0110. Значит, C2 = z; в строке 3 z = 0 — набор 0101, где ноль у x: C1 = x, C3 = w, C4 = y.
4. zywx: F = 1 на 0100, 1000, 1010, 1110 (xyzw), во всех w = 0 — значит, w в C3, где единиц нет. Строкам 1 и 3 нужны два разных набора с нулём в C2 и единицей в C4; среди x, y, z так бывает только у y = 0, x = 1 (1000 и 1010). Значит, C2 = y, C4 = x, C1 = z; строка 2 — набор 1110.
5. zyx: F = 1 на 011, 100, 110, 111, F = 0 — на 000, 001, 010, 101 (xyz). Строка 2 с двумя нулями и F = 1 — только 100, значит, C3 = x, а C1 и C2 — y и z. В строке 1 x = 1 и F = 0 — это 101, где единица у z: C1 = z, C2 = y.

**Что дальше.** Если задачи этой страницы получаются, основные подтемы освоены. Дополнительный урок 6 — полный автоматический перебор и задачи с двумя функциями. Закреплять тему удобно по этапам:

Первый этап — восстановить таблицы операций по их смыслу. Особенно важно уметь словами объяснить, почему 0 → 0 = 1, почему 1 ∨ 1 = 1 и почему 0 ≡ 0 = 1. Если эти случаи понятны, самые частые ошибки уже предотвращены.

На втором этапе вычисляй составные формулы через промежуточные части. Не пытайся сразу считать длинную строку целиком. Проверяй себя на двух наборах, отличающихся одной переменной, и объясняй, почему результат изменился или остался прежним.

На третьем этапе решай обратную задачу: по F = 0 или F = 1 выводи ограничения. Каждый раз спрашивай себя, требуется ли совместное выполнение условий или достаточно одного из нескольких случаев. Выписывай все ветви, если возникло «или».

На четвёртом этапе переходи к фрагментам с неизвестными столбцами. Для каждой найденной подписи записывай причину: постоянное значение, невозможное число нулей, равенство переменных, запрет конкретного набора или неповторение строк. Причина должна оставаться проверяемой без догадки «похоже, это x».

Затем используй Python как независимую проверку. Сначала сравни напечатанные подходящие наборы со своим ручным списком, затем проверь порядок столбцов. Если результаты расходятся, найди первую конкретную строку, где ручное вычисление и код дают разные F, и пересчитай её по частям.

После каждого решённого задания полезно ответить на два вопроса: «Какое условие определило самый первый столбец?» и «Почему другой оставшийся порядок не подходит?». Именно эти ответы превращают выполненное упражнение в переносимый способ рассуждения.
