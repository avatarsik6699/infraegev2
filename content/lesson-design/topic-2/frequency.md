Источник: подборки «Решу ЕГЭ» по заданию 2 — «Строки с пропущенными значениями» (тема 352). Подборки скачаны 2026-10-16. Условия не копируются: ниже только номера, источники и наши описания.

Файл сгенерирован скриптом `frequency_report.py` из размеченной таблицы `tasks.py`. Год задач без пометки источника оценён по номеру задачи между датированными задачами, поэтому это приблизительная оценка.

- Задачи 2025–2026 годов (по оценке): 22, из них 22 основного уровня.

## Какие приёмы нужны

Одна задача обычно требует нескольких приёмов, поэтому сумма больше числа задач.

| Приём | Задач | Доля | Из них 2025–2026 |
|---|---:|---:|---:|
| Двузначные операции, скобки и вычисление/отбор подходящих наборов | 78 | 100% | 22 из 22 |
| Общий порядок столбцов и совместный выбор подходящих различных строк | 78 | 100% | 22 из 22 |
| Две функции: совместная проверка известных значений обоих выходов | 3 | 4% | 0 из 22 |

**Снимок подборки, не статистика всего экзамена.** Общий метод один: вычислить допустимые входы и согласовать все строки с одной перестановкой переменных. Разные F в строках, известная часть шапки и пятая переменная меняют входные данные, а не создают новый алгоритм. Оценочные годы по ID не используются как доказательство экзаменационного тренда.

## Правило уровней

- **Основной уровень** — двузначная логика и общий метод сопоставления строк с собственным F, известными клетками и общей перестановкой столбцов. Проверяется совместный выбор различных входных наборов; отбор по одному F разрешён только при действительно одинаковых F. Этот минимальный набор методов покрывает 75 из 78 задач (96,2 %). Удаление любого из двух классов оставляет задачи без необходимой части решения.
- **Дополнительный уровень** — 3 из 78: три фрагмента с двумя логическими функциями. Полный автоматический решатель, скрытые выходные клетки и редкие знаки сохраняются как углубление исходника, но не объявляются обязательным способом решить обычные задачи.

## Варианты данных и пределы атрибуции

Прочитаны все 78 ID темы 352, все клетки основных таблиц и поясняющие таблицы-примеры. 59796 и 69880 содержат формулы в SVG: прочитаны визуально, включая границы отрицания и вложенность стрелок. В raw HTML прочитаны пустые td/th; пустая клетка не заменяется нулём.

Варианты обычного метода: **12** фрагментов одной функции со смешанными F; **2** с известной подписью одного входного столбца (84664, 84696); **1** с пятью входами и четырьмя строками (63018: 32 входных набора, 120 перестановок); **1** явно перечисляет все нулевые входы (15618). Это пересекающиеся описания входа, а не дополнительные приёмы и не основания скрытно отсеять часть корпуса ради ровных 80 %. В 55589 и 61348 результаты одной из двух функций тоже различаются по строкам, но они входят в отдельную группу двухфункциональных задач.

78 ID не означают 78 независимых типов. У 18071 и 55798 совпадают формула, входные шаблоны и F, отличается обрамляющий текст; оба ID сохранены в знаменателе. У ряда других задач похожие формулы различаются отрицанием, переименованием или таблицей: это проверено по каждой задаче.

Последние два года проверены по первичным примерам: в [методических рекомендациях ФИПИ-2026](https://doc.fipi.ru/ege/analiticheskie-i-metodicheskie-materialy/2026/inf_mr_2026.pdf), с. 10–11, пример 3 показывает обычный фрагмент, пример 4 прямо назван заданием 2025 г. В примере 4 все F равны 0: его составная формула не является доказательством смешанных F. У 92179 есть метка реальной волны ЕГЭ-2026: цепочка импликаций и три различные единичные строки. Все эти типы покрыты основным методом; закрытые варианты не аттестуются.

92544 совпадает с текущим №2 проекта демоверсии ФИПИ-2027, печатная с. 6: формула, известные клетки и требование различных строк. Его год 2026* в таблице — оценка по ID каталога, не дата реального экзамена. [Проект ФИПИ-2027](https://doc.fipi.ru/ege/demoversii-specifikacii-kodifikatory/2027/inf_11_2027.zip).

Автоматический перебор не является частотным требованием: обычные задачи решаются и ручным сопоставлением после понимания формулы. Неповторение полных строк, общая шапка и собственное F каждой строки остаются обязательными при любом способе.
