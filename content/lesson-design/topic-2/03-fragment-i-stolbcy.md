**Фрагмент таблицы — несколько её строк с пропусками, и подписи столбцов подходят, только если все строки можно одновременно восстановить разными наборами с нужным F.** Общий порядок столбцов и согласование строк нужны во всех 78 задачах подборок.

Главный пример подтемы — та же функция F = (x ∨ y) ∧ (x → z) и фрагмент из трёх различных строк с F = 1, по которому восстановим порядок столбцов. Операции, подходящие наборы и разбор по случаям из подтем 1–2 считаем известными.

---

**Фрагмент — несколько строк полной таблицы в любом порядке; пропуск скрывает 0 или 1.**

В следующих таблицах символ \* будет обозначать пустую клетку условия. Это обозначение для удобства чтения, а не умножение и не третье логическое значение.

Каждый пропуск допускает 0 или 1, пока другие условия не исключат один из вариантов. Разные звёздочки не обязаны заполняться одинаково. Например, строка 0, \*, 1 совместима с 0, 0, 1 и с 0, 1, 1.

Строки фрагмента могут быть расположены в любом порядке. Если программа напечатала подходящие наборы в порядке 000, 001, 010, это ничего не говорит о порядке строк в задании. Сопоставлять первую напечатанную строку с первой строкой условия без проверки нельзя.

Фраза «все строки различны» относится к полностью восстановленным наборам. Две строки вида \*, \*, 0 внешне одинаковы, но могут после заполнения стать 1, 0, 0 и 1, 1, 0. Они допустимы. А разные на вид шаблоны могут вынужденно восстановиться в один и тот же набор; тогда использовать их вместе нельзя.

Слово «фрагмент» само по себе не обещает, что перечислены все строки с данным F. Например, если F = 1 на четырёх наборах, в условии могут показать только три. Недостающая строка остаётся правильной строкой полной таблицы, но не обязана появляться во фрагменте.

Если явно сказано «приведены все наборы, при которых F = 0», это дополнительное условие полноты. Тогда нельзя оставить подходящий нулевой набор неиспользованным. При этом порядок показанных строк всё равно может быть произвольным.

Это различие особенно важно при подсчёте нулей и единиц. Если среди всех подходящих строк переменная x равна 0 только один раз, то столбец с двумя известными нулями в разных строках не может быть x. Но если x равна 1 в трёх из четырёх подходящих строк, фрагмент из двух строк не обязан содержать именно какое-то заранее заданное число единиц.

Условие о различных строках позволяет рассуждать о числе доступных наборов. Если при некотором порядке столбцов первая и вторая строки могут восстановиться только в один и тот же единственный набор, этот порядок не подходит. Проверки «для каждой строки найдётся хоть один вариант» недостаточно: варианты должны выбираться одновременно и без повторений.

---

**Ручное решение идёт по одному порядку: наборы формулы → сильные признаки → совместный выбор строк → проверка.**

1. Перепиши формулу, сохранив все скобки, отрицания и направления стрелок. Посчитай различные переменные. Отдельно запиши значения F в каждой показанной строке.

2. Пронумеруй неизвестные столбцы: C1, C2, C3 и при необходимости C4. Эти обозначения означают позиции, а не новые переменные формулы.

3. Найди внешнюю операцию. Если F = 0 и снаружи ИЛИ, потребуй нулей у всех частей. Если F = 1 и снаружи И, потребуй единиц у всех частей. Если внешняя операция другая, используй её таблицу.

4. Получи подходящие наборы в фиксированном порядке переменных. Можно вывести их по случаям или построить полную таблицу. Для четырёх переменных полный перебор содержит всего 16 наборов.

5. Ищи наиболее сильные признаки. Переменная может быть постоянной во всех подходящих наборах. Две переменные могут всегда совпадать или различаться. Набор с единственной единицей может однозначно определить её столбец. Используй только признаки, которые действительно следуют из формулы.

6. Сопоставляй сразу несколько строк. Учитывай уже известные цифры, общую для всех строк перестановку столбцов и неповторение. Если есть несколько возможностей, выпиши их явно и исключай противоречивые.

7. После нахождения порядка восстанови хотя бы один допустимый вариант всех строк. Подставь каждую строку обратно в исходную формулу, проверь F и различие наборов. Проверка исходной формулы защищает от ошибки при преобразованиях.

8. Запиши буквы в порядке столбцов слева направо. Не переставляй их обратно в привычный порядок x, y, z, w.

Метод универсален по логике проверки. Короткий ручной ход зависит от конкретной формулы. Если удобного признака не видно, полный перебор всех наборов и порядков столбцов остаётся конечным и надёжным способом.

---

**Подписи столбцов выбирают так, чтобы все строки одновременно получили разные подходящие наборы.**

Рассмотрим наш учебный пример. Формула F = (x ∨ y) ∧ (x → z). Даны три различные строки с F = 1. Нужно установить порядок переменных.

| Строка | C1 | C2 | C3 | F |
| --- | --- | --- | --- | --- |
| 1 | \* | \* | 0 | 1 |
| 2 | \* | \* | 0 | 1 |
| 3 | 0 | 1 | 1 | 1 |

Мы уже вывели все подходящие наборы в порядке xyz: 010, 011, 101, 111. Сопоставим, сколько раз каждая переменная равна 0 среди этих четырёх различных наборов.

| Переменная | Наборы, где она равна 0 | Количество |
| --- | --- | --- |
| x | 010 и 011 | 2 |
| y | 101 | 1 |
| z | 010 | 1 |

В C3 стоят два известных нуля в двух разных строках. Значит, переменная этого столбца должна быть равна 0 как минимум в двух различных подходящих наборах. Только x имеет такое свойство. Получаем C3 = x.

Почему нельзя выбрать y? Тогда обе первые строки были бы вынуждены стать набором 101 в порядке xyz: другого подходящего набора с y = 0 нет. Строки повторились бы. По той же причине нельзя выбрать z: для z = 0 есть только 010.

<figcaption>Если C3 = y, у первых двух строк остаётся один и тот же единственный набор 1 1 0 в порядке столбцов x, z, y — строки совпали бы, порядок не подходит.</figcaption>
</figure>

Теперь третья строка сообщает x = 1. В нашей формуле при x = 1 первая часть истинна, а стрелка x → z требует z = 1. Среди оставшихся столбцов третьей строки C1 равен 0, C2 равен 1. Поэтому C2 = z, а C1 = y.

Ответ: yzx. Проверим восстановление. В первых двух строках x = 0, поэтому для F = 1 требуется y = 1, а z может быть 0 или 1. Чтобы строки различались, значения z в них должны быть разными.

| Строка | y | z | x | F |
| --- | --- | --- | --- | --- |
| 1 | 1 | 0 | 0 | 1 |
| 2 | 1 | 1 | 0 | 1 |
| 3 | 0 | 1 | 1 | 1 |

Можно поменять значения z в первых двух строках местами. Получится другое заполнение пропусков с тем же порядком столбцов. Это нормальная ситуация: вопрос задачи относится к порядку переменных, а не обязательно к единственному заполнению всех клеток.

<figcaption>При порядке y, z, x первым двум строкам подходят два разных набора, 1 0 0 и 1 1 0, а третьей — 0 1 1: все строки можно восстановить различными.</figcaption>
</figure>

Также обрати внимание: набор 111 из полной таблицы здесь не использован. Это допустимо, потому что условие говорит о трёх строках фрагмента, а не обо всех четырёх строках с F = 1.

---

**Наборов значений 2ⁿ, а порядков столбцов n!: это разные объекты перебора.**

Перестановка — расположение одних и тех же различных элементов в разном порядке. Например, для x, y, z есть шесть порядков: xyz, xzy, yxz, yzx, zxy, zyx. Для первого места есть три выбора, для второго — два оставшихся, для третьего — один. Получается 3 · 2 · 1 = 6.

Для четырёх переменных порядков 4 · 3 · 2 · 1 = 24. Такое произведение сокращённо обозначают 4! и называют факториалом четырёх. Не путай: 2⁴ = 16 — число наборов значений, а 4! = 24 — число порядков названий столбцов. Это разные объекты перебора.

Если несколько порядков удовлетворяют всем выписанным условиям, нельзя выбирать первый наугад. Сначала нужно проверить копирование таблицы и формулы, значения F, неповторение и слова «все наборы». Возможно, какая-то информация потеряна.

Но иногда данные действительно не различают две переменные. Например, F = x ∧ y симметрична относительно x и y: обмен этих букв не меняет результата ни в одной строке. Если нет дополнительных сведений о подписях, по значениям одной этой функции невозможно отличить x от y.

Отсюда полезный диагностический принцип: полная таблица помогает проверить формулу, но не обещает, что любая придуманная задача про неизвестные подписи имеет единственный ответ. В корректно составленном упражнении на единственный порядок должно быть достаточно различающей информации.

Не следует путать несколько порядков столбцов и несколько заполнений пропусков. В разборе с ответом yzx было два заполнения первых строк, но один порядок букв. Для ответа этого достаточно.

---

**Итого.**

- Пропуск — 0 или 1, разные пропуски заполняются независимо; порядок строк фрагмента произволен.
- Фрагмент не обязан содержать все наборы с данным F, если не сказано «все наборы».
- Подпись столбца одна для всех строк; строки после восстановления различны.
- Сильные признаки: сколько раз переменная равна 0 или 1 среди подходящих наборов, постоянные значения, единственный набор строки.
- Для одного порядка может быть несколько заполнений — ответ от этого не меняется; 2ⁿ наборов и n! порядков — разные числа.

---

**Чтобы проверить понимание, реши задачи сначала рассуждением, а затем при необходимости программой.**

1. Рассматривается F = x → y. Дан фрагмент из одной строки: C1 = 0, C2 = 1, F = 0. Определи подписи столбцов. Почему ответ не xy?
2. У функции F = (x ∨ y) ∧ (x → z) показаны все строки с F = 1. В неизвестном столбце ровно две единицы. Какая это переменная? Почему тот же подсчёт нельзя без изменений применить к произвольному фрагменту из трёх строк?
3. Формула F = (a ∨ b) ∧ (a → c). Найди порядок столбцов.

   | Строка | C1 | C2 | C3 | F |
   | --- | --- | --- | --- | --- |
   | 1 | \* | 0 | \* | 1 |
   | 2 | \* | 0 | \* | 1 |
   | 3 | 1 | 1 | 0 | 1 |
4. Для некоторого порядка столбцов у первой строки есть ровно один допустимый полный набор 101, у второй тоже только 101, у третьей только 011. Каждая строка отдельно согласуется с формулой. Допустим ли порядок для фрагмента из трёх различных строк?
5. Известно, что C1 = y, C2 = w, C3 = x, C4 = z. Запиши ответ. Затем для строки столбцов 1, 0, 1, 0 выпиши значения в порядке x, y, z, w. Почему это два разных порядка записи?
6. Формула F = x ≡ y. Может ли фрагмент её таблицы без дополнительных сведений о подписях однозначно различить x и y? Объясни ответ, даже если известны все клетки.

7. Логическая функция F задаётся выражением (x ∨ y) → (z ≡ x). Дан частично заполненный фрагмент, содержащий неповторяющиеся строки таблицы истинности функции F. Определите, какому столбцу соответствует каждая из переменных x, y, z. В ответе напишите буквы в том порядке, в котором идут соответствующие им столбцы.

   | C1 | C2 | C3 | F |
   |---|---|---|---|
   | \* | 1 | 0 | 0 |
   | 0 | \* | 1 | 0 |
   | \* | 1 | 1 | 0 |

8. Логическая функция F задаётся выражением ¬(x ∧ z) ∧ (y → x). Дан частично заполненный фрагмент, содержащий неповторяющиеся строки таблицы истинности функции F. Определите, какому столбцу соответствует каждая из переменных x, y, z. В ответе напишите буквы в том порядке, в котором идут соответствующие им столбцы.

   | C1 | C2 | C3 | F |
   |---|---|---|---|
   | 1 | 0 | \* | 1 |
   | \* | 1 | 0 | 1 |
   | 1 | \* | 0 | 1 |

**Ответы для проверки:**

1. Стрелка ложна только при x = 1, y = 0. В первом столбце 0, значит, там y. Во втором 1, значит, там x. Ответ yx. При подписях xy строка означала бы x = 0, y = 1 и давала бы F = 1, что противоречит условию.
2. Все единичные наборы xyz: 010, 011, 101, 111. У x две единицы, у y три, у z три. Следовательно, столбец с двумя единицами — x. В произвольном фрагменте один набор может быть опущен, и число единиц для y или z тоже может стать равным двум. Полнота здесь была существенна.
3. Ответ cab. Подходящие наборы в порядке abc: 010, 011, 101, 111. Только a равна 0 в двух различных подходящих наборах, поэтому C2 = a. В третьей строке a = 1, значит, c = 1. Из оставшихся столбцов C1 равен 1, C3 равен 0: C1 = c, C3 = b. Первые две строки восстанавливаются как 001 и 101 в порядке cab, в любом из двух порядков.
4. Порядок недопустим. Первую и вторую строки пришлось бы восстановить одинаково. Возможность подобрать строку по отдельности не гарантирует возможности подобрать разные строки для всего фрагмента.
5. Ответ ywxz. Данная строка сообщает y = 1, w = 0, x = 1, z = 0. В порядке xyzw получаем 1100. Строка ответа описывает подписи над столбцами, а набор 1100 — значения переменных в выбранном привычном порядке.
6. Не может. Обмен x и y не меняет значение x ≡ y при любом наборе. Если один порядок подходит, обменённый тоже подойдёт. Нужна дополнительная информация, нарушающая эту неразличимость, или другой вопрос задачи.
7. zyx: F = 0 при x ∨ y = 1 и z ≠ x — наборы xyz 011, 100, 110. В C3 две единицы, а z = 1 только в одном наборе, поэтому C3 — x или y. Если C3 = y, строки 2 и 3 обе восстанавливаются в 110. Значит, C3 = x; в строке 3 x = 1 и C2 = 1, а при x = 1 нужно z = 0 — поэтому C2 = y, C1 = z.
8. xzy: F = 1 на наборах xyz 000, 001, 100, 110. В C1 две единицы, а y и z равны 1 лишь в одном наборе каждая — C1 = x. Если C2 = y и C3 = z, строке 1 подходит только 100, строке 2 — только 110, а строке 3 нужен третий набор с x = 1, z = 0 — его нет. Значит, C2 = z, C3 = y.
