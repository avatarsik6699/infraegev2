**В обратном вопросе фигура известна с точностью до одного числа, а ответ — само это число: наименьшая сторона, лучшее положение второй фигуры или сколько раз Черепаха побывала в точке.** Такие вопросы встречаются в 5 задачах подборок из 54, среди задач 2025–2026 годов их нет. Основные задачи и итоговая страница эту подтему не требуют.

Главный пример — снова прямоугольник: одна его сторона равна неизвестному натуральному A. Подсчёт точек по формулам подтемы 3 остаётся тем же; новое — неизвестное стоит не в ответе, а в условии.

---

**Сначала записывают число точек как функцию параметра, потом решают неравенство из вопроса.** Алгоритм:

```text
Повтори 2 [
    Вперёд A
    Направо 90
    Вперёд 6
    Направо 90
]
```

Из (0; 0) вверх он рисует прямоугольник шириной 6 и высотой A. По формуле подтемы 3 строго внутри

N(A) = (6 − 1)(A − 1) = 5(A − 1).

Вопрос: при каком наименьшем натуральном A внутри **не менее** 40 точек?

5(A − 1) ≥ 40, A − 1 ≥ 8, A ≥ 9.

Проверяем соседей: N(8) = 35 — мало, N(9) = 40 — уже достаточно. Ответ 9.

<figcaption>При A = 9: пять столбцов по 8 точек, ровно 40 — первое A, при котором порог «не менее 40» выполнен.</figcaption>

---

**Строгий и нестрогий порог дают разные ответы.** Если спрашивают «**больше** 40», то

5(A − 1) > 40, A − 1 > 8, A ≥ 10.

При A = 9 точек ровно 40 — это не больше 40. Ответ 10.

Поэтому неравенство переписывают из условия дословно: «не менее» — ≥, «больше» — >, «не более» — ≤. И всегда проверяют найденное A и предыдущее: первое должно подходить, второе — нет. Так ловится ошибка на единицу.

Наименьшее A можно найти и перебором: для каждого A посчитать точки, остановиться на первом подходящем.

```python
for A in range(1, 20):
    count = 0
    for x in range(0, 7):
        for y in range(0, A + 1):
            if 0 < x < 6 and 0 < y < A:
                count += 1
    if count >= 40:
        print(A, count)
        break
```

```output
9 40
```

{{break|`break`}} останавливает внешний цикл на первом подходящем A — оно и есть наименьшее, потому что A перебираются по возрастанию.

**Если положение второй фигуры можно выбрать, наибольшее пересечение оценивают сверху по каждой оси отдельно.** Первая фигура — прямоугольник 0 ≤ x ≤ 8, 0 ≤ y ≤ 6. Вторая — квадрат 4 × 4, его левый нижний угол (p; q) можно поставить в любую целую точку. Сколько наибольшее число целых точек в пересечении, включая границу?

Пересечение лежит внутри квадрата, поэтому точек в нём не больше, чем в квадрате: (4 + 1)(4 + 1) = 25. Это достижимо: квадрат помещается в прямоугольник целиком, например при (p; q) = (0; 0). Ответ 25.

Сколько таких положений? Квадрат целиком внутри, когда 0 ≤ p и p + 4 ≤ 8, то есть p = 0 … 4, и 0 ≤ q и q + 4 ≤ 6, то есть q = 0 … 2. Всего 5 · 3 = 15 положений.

---

**Когда вторая фигура не помещается, общая часть по каждой оси не длиннее меньшей из двух сторон.** Пусть теперь вторая фигура — квадрат 7 × 7. По высоте он больше прямоугольника: общая часть по y не длиннее 6. По ширине общая часть не длиннее 7. Значит, в пересечении не больше (7 + 1)(6 + 1) = 56 точек.

Оценка достигается: при (p; q) = (1; −1) квадрат занимает 1 ≤ x ≤ 8, −1 ≤ y ≤ 6, а пересечение — 1 ≤ x ≤ 8, 0 ≤ y ≤ 6.

<figure class="plate-figure">
%%tt_rects(((0, 8, 0, 6), (1, 8, -1, 6)), 'both')%%
<figcaption>Квадрат 7 × 7 (пунктир) при (p; q) = (1; −1): по ширине общая часть 7, по высоте 6 — больше быть не может.</figcaption>
</figure>

Перебор всех положений подтверждает оценку. Границы общей части — те же максимумы и минимумы, что в подтеме 4:

```python
best = 0
for p in range(-8, 9):
    for q in range(-8, 9):
        left, right = max(0, p), min(8, p + 7)
        low, high = max(0, q), min(6, q + 7)
        if left <= right and low <= high:
            n = (right - left + 1) * (high - low + 1)
            best = max(best, n)
print(best)
```

```output
56
```

**Посещение — это момент, когда Черепаха оказывается в точке, а не сама точка.** Повтор, который проходит часть контура второй раз, не добавляет точек на линии, но добавляет посещений. Поэтому в таком вопросе Черепаху ведут по единичным шагам и для каждой целой точки ведут счётчик.

Алгоритм «Повтори 6 [Вперёд 2 Направо 90]» из (0; 0) вверх. Четыре повторения обходят квадрат 2 × 2, ещё два — его левую и верхнюю стороны второй раз. По единичным шагам Черепаха проходит точки

(0; 0) → (0; 1) → (0; 2) → (1; 2) → (2; 2) → (2; 1) → (2; 0) → (1; 0) → (0; 0) → (0; 1) → (0; 2) → (1; 2) → (2; 2).

%%tt_draw('Повтори 6 [ Вперёд 2 Направо 90 ]', grid=(-1, 3, -1, 3), show='edge', label_end=True, height=300)%%
<figcaption>На линиях 8 различных точек; левая и верхняя стороны пройдены дважды, Черепаха остановилась в (2; 2).</figcaption>
</figure>

Различных точек на линиях 8. Дважды Черепаха была в (0; 0), (0; 1), (0; 2), (1; 2), (2; 2) — это 5 точек, если начальное положение считается посещением. Если не считается, (0; 0) посещена один раз — при возврате, — и ответ 4. Что считать посещением, говорит условие; без этого задачу решить нельзя.

---

**Счётчик посещений программой: шаг на единицу и словарь «точка → сколько раз».** Направление хранят как пару (dx; dy); поворот направо на 90° превращает (dx; dy) в (dy; −dx): вверх (0; 1) → вправо (1; 0) → вниз (0; −1) → влево (−1; 0).

```python
from collections import Counter

x, y = 0, 0
dx, dy = 0, 1
seen = Counter([(x, y)])
for _ in range(6):
    for _ in range(2):
        x, y = x + dx, y + dy
        seen[(x, y)] += 1
    dx, dy = dy, -dx
print(len(seen), sum(1 for v in seen.values() if v >= 2))
```

```output
8 5
```

{{counter|`Counter`}} начинает со счётчика 1 у начальной точки — это решение «начальное положение — посещение». Чтобы его не считать, создают пустой `Counter()`. Такой счётчик годится только для поворотов на 90° и целых шагов: на наклонной стороне Черепаха проходит через целые точки не на каждом шаге.

---

**Итого.**

- Параметр: число точек записывают формулой от A и решают неравенство условия дословно; проверяют найденное A и предыдущее.
- «Не менее» и «больше» отличаются на одно значение параметра.
- Наибольшее пересечение при свободном положении: по каждой оси общая часть не длиннее меньшей стороны; оценку подтверждают положением, где она достигается.
- Посещения — моменты, а не точки: ведут Черепаху по единичным шагам и считают, сколько раз она была в каждой точке; начальное положение считают, только если так сказано.

1. Черепахе был дан для исполнения алгоритм «Повтори 2 [Вперёд A Направо 90 Вперёд 4 Направо 90]», голова в начале направлена вверх. При каком наименьшем натуральном A внутри области, ограниченной линией, будет не менее 30 точек с целочисленными координатами? Точки на линии не учитывать.
2. Для того же алгоритма: при каком наименьшем натуральном A область вместе с линией содержит больше 60 точек с целочисленными координатами?
3. Черепахе был дан для исполнения алгоритм «Повтори 2 [Вперёд A Направо 90 Вперёд A Направо 90]». При каком наименьшем натуральном A строго внутри будет больше 100 точек с целочисленными координатами?
4. Первая фигура — прямоугольник 0 ≤ x ≤ 10, 0 ≤ y ≤ 4. Вторую фигуру, квадрат 6 × 6 со сторонами вдоль осей, можно поставить в любую целую точку. Какое наибольшее число точек с целочисленными координатами может оказаться в пересечении, включая границу?
5. Сколькими способами можно поставить квадрат 3 × 3 со сторонами вдоль осей и целыми вершинами так, чтобы он целиком лежал в прямоугольнике 0 ≤ x ≤ 10, 0 ≤ y ≤ 4?
6. Черепаха из (0; 0) вверх выполнила «Повтори 5 [Вперёд 3 Направо 90]». Начальное положение считается посещением. Сколько целочисленных точек она посетила не менее двух раз?
7. В задаче 6 начальное положение посещением не считается. Сколько теперь точек посещено не менее двух раз и сколько всего различных точек на линиях?

**Ответы для проверки:**

1. 11: 3(A − 1) ≥ 30, A − 1 ≥ 10; при A = 10 только 27.
2. 12: 5(A + 1) > 60, A + 1 > 12; при A = 11 ровно 60 — не больше.
3. 12: (A − 1)² > 100, A − 1 ≥ 11; при A = 11 ровно 100.
4. 35: по ширине общая часть не длиннее 6 (7 точек), по высоте не длиннее 4 (5 точек); 7 · 5 достигается, например, при (0; −1).
5. 16: p = 0 … 7 и q = 0 … 1, 8 · 2.
6. 4: (0; 0), (0; 1), (0; 2), (0; 3) — первые 12 шагов обходят квадрат 3 × 3, следующие 3 повторяют левую сторону.
7. 3 точки — (0; 1), (0; 2), (0; 3); различных точек на линиях 12.
