**Незнакомое условие в формуле — «треугольник существует», MAX, делитель параметра — сначала переводят в знакомые неравенства или делимость по его определению, а потом решают как обычно: ищут ложный случай.** Такие условия встречаются в 4 задачах подборок из 90; основные задачи и итоговая страница эту подтему не требуют.

Главный пример — треугольник со сторонами x, 4 и 7: его существование даёт 3 < x < 11. Затем MAX двух чисел, условия, где опасный набор зависит от самого A, и связанные делимости.

---

**Новый предикат читают по определению: «треугольник со сторонами a, b, c существует» — это три строгих неравенства.**

Треугольник со сторонами a, b, c существует тогда и только тогда, когда каждая сторона меньше суммы двух других:

a < b + c, b < a + c, c < a + b.

Для сторон x, 4 и 7: x < 11, 4 < x + 7 — верно для любого натурального x, 7 < x + 4 — то есть x > 3. Вместе: 3 < x < 11, для натуральных x — от 4 до 10.

Неравенства строгие: при x = 3 стороны 3, 4, 7 «складываются» в отрезок (3 + 4 = 7), треугольника нет. Именно поэтому граница 3 не входит.

---

**После перевода предикат становится обычной частью формулы: ищут, когда формула ложна.**

Найдём наименьшее натуральное A, при котором для всех натуральных x истинно

T(x, 4, 7) → (x < A),

где T(x, 4, 7) — «треугольник со сторонами x, 4, 7 существует». Формула ложна, если треугольник существует, а x ≥ A. Значит, все x от 4 до 10 должны быть меньше A: A > 10, наименьшее A = 11.

Достаточность: при A = 11 каждый x, для которого треугольник существует, не больше 10 < 11; для остальных x левая часть ложна.

---

**MAX(a, b) — большее из двух чисел; его разбирают по случаям: какое из чисел больше.**

MAX(x, 5) равно 5, если x ≤ 5, и равно x, если x ≥ 5. Как функция от x она сначала постоянна, а потом растёт.

Найдём наименьшее целое A, при котором для всех натуральных x истинно

(MAX(x, 8) < A) ∨ (x > 20).

Опасны x ≤ 20 — там вторая часть ложна, и нужна первая. Наибольшее значение MAX(x, 8) при x ≤ 20 — это 20 (при x = 20). Нужно 20 < A, наименьшее A = 21.

Если бы опасными были только x ≤ 7, MAX(x, 8) на них равнялся бы 8, и ответ был бы 9: случай «x меньше второго числа» даёт постоянное значение.

---

**Если опасный набор зависит от самого A, его нельзя выписать один раз: для каждого A он свой, и проверяют каждый кандидат.**

Найдём наибольшее натуральное A ≤ 50, при котором для всех натуральных x истинно

(x ∈ [A; A + 5]) → ¬ДЕЛ(x, 7).

Отрезок [A; A + 5] — шесть подряд идущих чисел; формула требует, чтобы среди них не было кратного 7. Из семи подряд идущих остатков от деления на 7 шесть чисел пропускают ровно один — остаток 0, если начинаются с остатка 1. Значит, A должно давать при делении на 7 остаток 1: A = 1, 8, 15, …, 50. Наибольшее A ≤ 50 — 50 (50 = 7 · 7 + 1: числа 50 … 55).

Опасный набор здесь — кратные 7 внутри [A; A + 5] — меняется вместе с A. Для A = 49 он равен {49}, для A = 50 — пуст.

---

**В связанных делимостях параметр может сам решать, есть ли опасные числа вообще.**

Найдём наибольшее натуральное A ≤ 100, при котором для всех натуральных x истинно

(ДЕЛ(A, x) ∧ ДЕЛ(x, 2)) → ДЕЛ(60, x).

Опасны чётные делители A, не делящие 60. Если A чётное, то само A — его чётный делитель, поэтому A ∣ 60, и наибольшее такое A — 60. Но если A нечётное, чётных делителей у него нет вовсе: опасный набор пуст, и формула истинна при любом x. Наибольшее нечётное A ≤ 100 — 99.

Ответ: 99, а не 60. Ошибка — считать, что опасный набор всегда непуст: для нечётного A левая часть никогда не выполняется.

---

**Итого.**

- Новый предикат переводят по определению: треугольник — три строгих неравенства, MAX — два случая.
- Дальше — обычный ложный случай, опасный набор, граница и достаточность.
- MAX(x, c) постоянна при x ≤ c и растёт при x ≥ c — наибольшее значение ищут на опасной области.
- Если опасный набор зависит от A, проверяют каждый кандидат или находят условие на A (остаток, чётность).
- Опасный набор может быть пустым — тогда формула истинна при любом x.

---

**Чтобы проверить понимание, сначала переведи новое условие в неравенства или делимость.**

1. При каких натуральных x существует треугольник со сторонами x, 5 и 9? Найди наименьшее натуральное A, при котором T(x, 5, 9) → (x < A) истинно для всех натуральных x.
2. Найди наибольшее целое A, при котором ¬T(x, 3, 8) ∨ (x > A) истинно для всех натуральных x.
3. Найди наименьшее целое A, при котором (MAX(x, 12) < A) ∨ (x ≥ 30) истинно для всех натуральных x.
4. Найди наименьшее целое A, при котором (MAX(x, y) ≤ 6) → (x + y < A) истинно для всех натуральных x, y.
5. Найди наибольшее натуральное A ≤ 200, при котором для всех натуральных x истинно (ДЕЛ(A, x) ∧ ДЕЛ(x, 3)) → ДЕЛ(90, x).
6. Отрезок [A; A + 4] не должен содержать кратных 6. Найди наибольшее натуральное A ≤ 40 и количество подходящих натуральных A ≤ 40.

**Ответы для проверки:**

1. x = 5 … 13; A = 14.
2. 5: треугольник существует при x = 6 … 10, нужно x > A для них.
3. 30: опасны x ≤ 29, наибольшее MAX(x, 12) = 29.
4. 13: опасны x, y ≤ 6, наибольшее x + y = 12.
5. 200: у 200 нет делителей, кратных 3, — опасный набор пуст.
6. 37 и 7: A при делении на 6 даёт остаток 1 — 1, 7, …, 37.
