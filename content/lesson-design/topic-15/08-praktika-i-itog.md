**Параметр должен устранять каждый допустимый контрпример: сначала находят, когда формула может стать ложной, потом — что должно быть у A, чтобы этот случай не наступил, и доказывают, что этого достаточно.** Ошибки чаще всего не в арифметике, а в прочтении: область переменных, строгий знак, порядок аргументов ДЕЛ, связность одного отрезка.

Всё главное из подтем собрано на одной схеме. Номер раздела ведёт на его подтему.

**Для новой формулы можно использовать один порядок рассуждений.**

1. **Область.** Какие значения принимают переменные и параметр? Натуральные, неотрицательные целые, вещественные? (Подтема 1.)
2. **Ложный случай.** Когда формула ложна? Для ИЛИ — все части ложны, для импликации — левая истинна, правая ложна. (Подтема 1.)
3. **Модель.** Что описывают условия без A: отрезки, биты, область на плоскости, кратные или делители? (Подтемы 2–5.)
4. **Необходимость.** Какой опасный случай заставляет A быть не меньше или не больше какого-то числа? Найди свидетеля.
5. **Достаточность.** Почему при найденном A контрпримера нет вообще?
6. **Ответ и соседнее значение.** Нужный минимум, максимум или количество; соседнее A должно нарушаться.
7. **Проверка.** Если нужна программа — только на доказанно достаточном наборе. (Подтема 6.)

Полезная запись одного решения:

1. «Переменные такие-то, параметр такой-то».
2. «Формула ложна, когда одновременно ...».
3. «Значит, параметр обязан ...».
4. «Это достаточно, потому что для любого опасного случая ...».
5. «Нужный минимум/максимум/количество равен ...».
6. «Соседний неверный параметр нарушается на ...».

Последняя строка не заменяет общее доказательство, но помогает обнаружить ошибки на границе.

**Модель и конечную проверку выбирают по виду условий.**

| Тип задачи | Какие объекты исследовать | Что обосновывает конечную проверку |
|---|---|---|
| Побитовая конъюнкция | Единичные разряды и их сочетания | Все участвующие маски помещаются в k битах: 0 ≤ x<2^k |
| Отрезки | Области между концами и сами концы | Постоянство всех условий принадлежности внутри областей |
| Координатная плоскость | Опасные пары (x,y) | Доказанные границы опасной области или аналитическая оценка |
| Делимость | Кратные или делители | Период НОК фиксированных делителей либо конечный опасный набор |

Один общий принцип связывает все разделы: параметр должен устранять каждый допустимый контрпример. Как именно это выглядит - обязательные биты, покрытый отрезок, числовая граница или делимость - определяется смыслом условий внутри формулы.

**Частые ошибки меняют ответ на единицу или на целую область.** Выбери ошибку, чтобы увидеть, что идёт не так:

:::pick Ошибка и почему она меняет ответ
- *один удачный x | Проверить один удачный x вместо всех: Для A=3 формула (x ≤ 5) → (x ≤ A) истинна при x=1, но ложна при x=4. Нужен поиск нарушений, а не поиск подтверждений.
- разные A | Каждый раз менять A: Параметр выбирается один раз. Нужно одно значение для всех x или всех пар (x,y).
- ложная предпосылка | Считать, что ложная предпосылка делает стрелку ложной: Импликация ложна только при 1 слева и 0 справа. Если слева 0, результат 1.
- потерянное равенство | При отрицании терять равенство: Отрицание x<10 есть x ≥ 10. Значение 10 должно попасть в одну из двух взаимно противоположных областей.
- строгая граница | Перепутать строгую и нестрогую границу: Для целого A требования A>36 и A ≥ 36 дают минимумы 37 и 36.
- ноль | Не учесть ноль: Если условие говорит «неотрицательные целые», начинай проверку с 0. Это особенно важно для формул с самостоятельным требованием x&A ≠ 0: при x=0 оно невозможно для любого A.
- ∧ и & | Перепутать логическое И и побитовое И: p ∧ q соединяет два утверждения; x&M строит число. Только сравнение результата с 0 или другим числом превращает его в утверждение.
- биты по примеру | Определить биты только по одному примеру: Одноразрядные числа часто дают необходимые условия. Формула может нарушаться только при сочетании битов. Всегда отдельно доказывай достаточность.
- отрезок и целые | Подменить отрезок списком целых точек: Длина [5;10] равна 5, не 6. Проверка только целых x не покрывает вещественный промежуток.
- сложенные длины | Сложить длины раздельных областей: Один отрезок либо выбирается внутри одной разрешённой части, либо обязан включить промежуток между обязательными частями. Это два разных вида ограничений.
- ≡ при 0 и 0 | Забыть, что эквивалентность истинна при 0 и 0: Вне обоих отрезков p ≡ q тоже истинно.
- аргументы ДЕЛ | Поменять аргументы ДЕЛ: ДЕЛ(x,60) говорит о кратных 60, ДЕЛ(60,x) - о делителях 60.
- перебор как доказательство | Считать результаты конечного перебора автоматическим доказательством: Для масок нужна достаточная длина двоичной записи, для делимости - период или конечный опасный набор, для отрезков - все области и границы, для неравенств - доказанная опасная область.
- предел программы | Принять предел программы за максимум: Если поиск остановился на 999, убедись, что 1000 и большие значения исключены математически. Иначе максимум мог не существовать в выбранном диапазоне или вообще.
- направление A | Считать помощь параметра всегда однонаправленной: Фраза «чем больше A, тем лучше» верна только после анализа знаков и структуры. Если A одновременно стоит в условиях x<A и y>A, допустимые значения могут образовать ограниченный диапазон.
:::

**Задачи основных подтем в формате экзамена.** Подсказка в скобках называет подтему, приём которой нужен.

1. Для какого наименьшего целого числа A формула (x ≤ 12) → (x · x < A) тождественно истинна, то есть принимает значение 1 при любом натуральном значении переменной x? (Подтема 1.)
2. На числовой прямой даны два отрезка: P = [15; 40] и Q = [21; 63]. Укажите наименьшую возможную длину такого отрезка A, что формула (x ∈ P) → (((x ∈ Q) ∧ ¬(x ∈ A)) → ¬(x ∈ P)) истинна при любом значении переменной x. (Подтема 2.)
3. Обозначим через m & n поразрядную конъюнкцию неотрицательных целых чисел m и n. Для какого наименьшего неотрицательного целого числа A формула (x & 29 ≠ 0) → ((x & 17 = 0) → (x & A ≠ 0)) тождественно истинна при любом неотрицательном целом x? (Подтема 3.)
4. Укажите наибольшее целое значение A, при котором выражение (2x + y ≠ 70) ∨ (x < y) ∨ (A < x) истинно для любых натуральных x и y. (Подтема 4.)
5. Обозначим через ДЕЛ(n, m) утверждение «натуральное число n делится без остатка на натуральное число m». Для какого наименьшего натурального числа A формула (x ∈ [20; 50]) → (ДЕЛ(x, 4) ∨ (x < A)) тождественно истинна при любом натуральном x? (Подтема 5.)

**Ответы для проверки:**

1. 145: опасны x = 1 … 12, наибольший квадрат 144, нужно 144 < A.
2. 19: обязательна общая часть [21; 40].
3. 12: у 29 веса 16, 8, 4, 1, у 17 — 16 и 1; обязательны 8 и 4.
4. 23: опасны пары с 2x + y = 70 и x ≥ y, у них x от 24 до 34; нужно A < 24.
5. 51: опасны некратные 4 числа отрезка, последнее — 50.

**Что дальше.** Если задачи этой страницы получаются, основные подтемы освоены. Дополнительный урок 7 — новые предикаты (треугольник, MAX), опасный набор, зависящий от A, и связанные делимости. Для первых двух-трёх задач каждого типа полностью расписывай ложный случай и оба доказательства. Если ответ не совпал, не меняй диапазон наугад: найди конкретную точку или число, которое нарушает твой кандидат, и объясни, какое условие было пропущено.
