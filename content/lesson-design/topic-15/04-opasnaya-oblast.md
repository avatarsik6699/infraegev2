**Для формул с двумя переменными ищут опасную область — точки, где формула держится только на части с A, — и наибольшее или наименьшее значение выражения на ней; A должно его превзойти.** Такие задачи — 37 из 90 подборок; в задаче ЕГЭ-2026 параметр стоит множителем при x.

Главный пример — область 2x + 3y < 30 на натуральной решётке и наибольшее x + 2y на ней. Затем — сумма, произведение, две независимые импликации с квадратами и параметр-коэффициент.

---

**Пара (x; y) — точка; на натуральных числах это решётка с положительными координатами.**

Пара (x,y) задаёт точку координатной плоскости: x - горизонтальная координата, y - вертикальная. Условие x+y<12 описывает все точки, лежащие по одну сторону от прямой x+y=12.

Если переменные вещественные, область непрерывная. Если целые, допустимы только точки с целыми координатами. Их называют решётчатыми точками. Если переменные натуральные, рассматривается только положительная часть этой решётки; оси при соглашении 1,2,… не входят.

Нередко рисунок не нужен. Главное - выделить область, где логическая часть без параметра не спасает формулу, и найти на ней самый опасный случай.

---

**В формуле (g ≥ C) ∨ (h < A) опасна только область g < C, и A должно превзойти наибольшее h на ней.**

Пусть требуется

(g(x,y) ≥ C) ∨ (h(x,y)<A)

для всех допустимых пар. Там, где g ≥ C, первая часть уже истинна. Опасная область - g<C. Только на ней требуется h<A.

Если на этой области h имеет наибольшее значение H, необходимо и достаточно A>H. Для целого A и целого H минимум равен H+1. Если в формуле было бы h ≤ A, условие стало бы A ≥ H, и минимум был бы H.

Почему нельзя максимизировать h на всей области переменных? Большие x,y могут давать сколь угодно большие h, но одновременно делать истинной первую часть. Такие точки не создают ограничений для параметра.

---

**Опасная область задаётся всеми ложными частями сразу: наибольшее значение ищут с учётом каждой из них.**

Найди наименьшее целое A, при котором для всех натуральных x,y истинно

(x+y ≥ 12) ∨ ((x<y) ∨ (y<A)).

Чтобы формула стала ложной, должны одновременно выполняться

x+y<12, x ≥ y, y ≥ A.

Поэтому нужно исключить последнюю часть на области первых двух. Из x ≥ y следует x+y ≥ 2y. Вместе с x+y<12 получаем 2y<12, то есть y<6. Поскольку y целое, y ≤ 5.

Граница достижима: x=y=5 даёт сумму 10, и обе первые части исходного ИЛИ ложны. Поэтому нужно 5<A. Минимальное целое A=6.

Проверка достаточности: если первые две части ложны, обязательно y ≤ 5<6, поэтому третья истинна. Если хотя бы одна из первых двух истинна, формула уже истинна. Проверка минимальности: при A=5 пара (5,5) даёт три ложных части; при любом ещё меньшем A эта же пара тоже нарушает формулу.

Обрати внимание: число 11 является наибольшей возможной целой суммой меньше 12, но максимальное y не равно 11. Дополнительное ограничение x ≥ y уменьшает допустимый диапазон y.

---

**Наибольшее значение выражения на опасной области доказывают неравенством и подтверждают точкой, где оно достигается.**

Для всех натуральных x,y должно выполняться

(2x+3y ≥ 30) ∨ (x+2y<A).

Ищем максимум x+2y на опасной области 2x+3y<30. Так как координаты целые, 2x+3y ≤ 29. Обозначим эту сумму s. Из 3y=s-2x получаем

x+2y=x+(2(s-2x))/3=(2s-x)/3.

Здесь s ≤ 29, а x ≥ 1, следовательно,

x+2y ≤ (58-1)/3=19.

Верхняя граница достигается при x=1,y=9: 2+27=29, а 1+18=19. Для строгого условия x+2y<A необходимо A>19. Минимальный целый параметр равен 20.

Почему выбор «самых больших x и y по отдельности» неверен? Эти координаты связаны одним ограничением. Максимальное отдельно возможное x=13 достигается при маленьком y, а максимальное y=9 - при маленьком x. Пара (13,9) не принадлежит опасной области.

Если вручную трудно найти максимум, можно перебрать только одну координату. Из опасной области и x ≥ 1 следует y ≤ 9. Для каждого y=1,…,9 находят самый большой допустимый x. Это короткая конечная таблица вместо произвольного поиска тысяч пар.

---

**Две независимые части И дают два ограничения на A — нижнее по самому большому безопасному числу и верхнее по самому маленькому опасному.**

Найди наибольшее целое A, при котором для всех неотрицательных целых x,y истинно

((x ≤ 7) → (x² ≤ A)) ∧ ((y² ≤ A) → (y ≤ 7)).

Обе части И должны выполняться. Первая касается только x, вторая только y. Поэтому их можно исследовать отдельно и затем пересечь ограничения на A.

Первая часть требует, чтобы квадраты всех x=0,1,…,7 не превосходили A. Самый большой квадрат - 49. Получаем A ≥ 49. При x>7 левая часть стрелки ложна, эти числа не добавляют требований.

Во второй части опасны y>7: для них правая часть ложна. Нужно, чтобы предпосылка тоже была ложной, то есть y²>A. Наименьшее разрешённое y>7 равно 8, наименьший опасный квадрат - 64. Получаем A<64.

Все подходящие целые параметры:

49 ≤ A ≤ 63.

Максимум 63, минимум 49, количество 63-49+1=15.

Для A=63 первая часть выполняется, потому что x² ≤ 49 при 0 ≤ x ≤ 7. Во второй части из y² ≤ 63 и целочисленности y следует y ≤ 7. Значение 64 уже нарушает вторую часть при y=8.

Почему нижняя граница находится по самому большому безопасному числу 7, а верхняя по самому маленькому опасному 8? Первая стрелка требует включить весь безопасный набор квадратов. Вторая запрещает включить хотя бы один опасный квадрат. Чтобы запретить их все, достаточно не дойти до самого маленького.

---

**Строгий знак сдвигает целую границу на единицу; количество целых A от L до R — R − L + 1.**

Рассмотрим

((x<7) → (x²<A)) ∧ ((y² ≤ A) → (y ≤ 7))

для всех неотрицательных целых x,y. В первой части теперь самый большой допустимый x=6, квадрат 36, и неравенство строгое: A>36. Во второй части всё ещё A<64. Значит, целые A от 37 до 63 включительно; количество 63-37+1=27.

Для подсчёта целых чисел в замкнутом диапазоне L ≤ A ≤ R используют R-L+1, если L ≤ R. Сначала приведи строгие границы к целым концам, потом считай. Если A может быть вещественным, между двумя разными границами обычно бесконечно много значений.

---

**Увеличение A может и мешать формуле: направление влияния параметра выводят из формулы.**

Для всех натуральных x,y требуется

(xy<30) ∨ (x ≥ A) ∨ (y ≥ A),

где A натуральное. Найдём наибольшее A.

Если последние две части ложны, то x<A и y<A. При целых координатах это x,y ≤ A-1. Для таких чисел наибольшее произведение равно (A-1)², оно достигается при x=y=A-1, если A ≥ 2.

Чтобы первая часть обязательно спасала формулу, требуется (A-1)²<30. При A=6 получаем 25, условие выполняется. При A=7 получаем 36, и пара (6,6) нарушает формулу. Для ещё больших A та же пара остаётся контрпримером. Максимум равен 6. При A=1 формула автоматически истинна, потому что любое натуральное x ≥ 1.

Здесь увеличение A усложняет выполнение формулы: всё больше точек делают ложными условия x ≥ A,y ≥ A. В предыдущих примерах увеличение A в части h<A помогало. Направление влияния параметра выводится из конкретной формулы.

---

**Порядок решения: область, ложный случай, опасная область, экстремум со свидетелем, строгость, проверка соседнего A.**

1. Выпиши область x,y и область A.
2. Определи, когда формула ложна. Для ИЛИ отрицай все части и соедини их И; для импликации оставь левую часть и отрицай правую.
3. Отдели ограничения на переменные от ограничения с параметром.
4. Исследуй только опасную область. Выясни, ограничена ли она.
5. Найди на ней наибольшее или наименьшее значение нужного выражения.
6. Докажи границу неравенством и покажи допустимую пару, где она достигается, если говоришь о максимуме или минимуме.
7. Учти строгий знак и целочисленность параметра.
8. Проверь найденное A и соседнее значение, которое должно не подходить.

---

**Если параметр стоит множителем при неограниченной переменной, сначала выясняют знак: при x ≥ 1 и A > 0 произведение A·x не меньше A.**

Найдём наименьшее целое A, при котором для всех натуральных x, y истинно

(y ≥ 7) ∨ (A·x > y + 20).

Опасная область — где первая часть ложна: y ≤ 6. Здесь x никак не ограничен — на опасной области может стоять x = 1 и x = 1000. Поэтому решают не перебором x, а рассуждением о знаке.

Если A ≤ 0, то A·x ≤ 0 при любом натуральном x, а y + 20 ≥ 21: при (1; 1) формула ложна. Значит, A > 0. Тогда A·x растёт вместе с x, и самый трудный случай — наименьший x = 1 и наибольшее опасное y = 6: нужно A > 26.

При A = 27 для любого опасного случая A·x ≥ 27 > 26 ≥ y + 20 — формула истинна. При A = 26 пара (1; 6) даёт 26 > 26 — ложь. Ответ: 27.

Свидетель провала соседнего значения найден в самой опасной точке: маленький x, большой y. Перебор «x до 100» здесь не доказательство: x неограничен, а вывод держится на знаке A.

---

**Итого.**

- Опасная область — где ложны все части без A; ограничения на A берутся только с неё.
- Наибольшее значение выражения доказывают неравенством и подтверждают точкой; отдельные максимумы x и y брать нельзя.
- Две независимые импликации: нижняя граница по самому большому безопасному, верхняя — по самому маленькому опасному.
- Строгий знак: A > H на целых — A ≥ H + 1; количество целых от L до R — R − L + 1.
- Параметр-множитель при неограниченном x: сначала знак, потом самый трудный случай; перебор x не доказательство.

---

**Чтобы проверить понимание, сначала опиши опасную область.**

1. Найди наименьшее целое A, при котором (x<5) → (x² ≤ A) истинно для всех неотрицательных целых x.
2. Найди минимальное целое A для всех натуральных x,y:

(x+y ≥ 18) ∨ (x<y) ∨ (y<A).
3. Найди минимальное целое A для всех натуральных x,y:

(3x+2y ≥ 24) ∨ (x+y<A).
4. Для всех неотрицательных целых x,y должно выполняться

((x ≤ 5) → (x² ≤ A)) ∧ ((y² ≤ A) → (y ≤ 5)).

Найди все целые A, наибольшее из них и их количество.
5. Измени первую часть предыдущей формулы на (x<5) → (x²<A). Как изменятся допустимые целые A и их количество?
6. Найди наименьшее целое A, при котором (y ≥ 10) ∨ (A·x ≥ 2y + 5) истинно для всех натуральных x, y.
7. Найди наибольшее натуральное A, при котором (xy < 40) ∨ (x ≥ A) ∨ (y ≥ A) истинно для всех натуральных x, y.
8. Укажите наименьшее целое значение A, при котором выражение (3x + y ≥ 33) ∨ (x + y < A) истинно для любых натуральных значений x и y.

**Ответы для проверки:**

1. 16.
2. 9.
3. 12.
4. A = 25, 26, …, 35; максимум 35; количество 11.
5. A = 17, 18, …, 35; количество 19.
6. 23: при A ≤ 0 формула ложна; иначе самый трудный случай x = 1, y = 9.
7. 7: (A − 1)² < 40 при A = 7, а при A = 8 пара (7; 7) даёт 49.
8. 31: на опасной области 3x + y ≤ 32 наибольшее x + y = 30 при x = 1, y = 29.

<summary>Разбор задач 1–5 подробно</summary>

**1.** **Ответ: 16.** Предпосылка истинна при x=0,1,2,3,4. Самый большой квадрат 16. Требуется A ≥ 16, этого достаточно; при меньшем A контрпример x=4.

**2.** **Ответ: 9.** Опасная область: x+y<18, x ≥ y. Отсюда 2y<18, целое y ≤ 8. Граница достижима при (8,8). Нужно A>8, минимальное целое 9.

**3.** **Ответ: 12.** В опасной области s=3x+2y ≤ 23, а x ≥ 1. Тогда 2(x+y)=s-x ≤ 22, значит x+y ≤ 11. Равенство достижимо при (1,10): 3+20=23. Поэтому A>11, минимум 12.

**4.** **Ответ: A=25,26,…,35; максимум 35; количество 11.** Первая часть требует A ≥ 5²=25. Вторая запрещает квадрат первого y>5, то есть A<6²=36. Диапазон содержит 35-25+1=11 целых чисел.

**5.** **Ответ: A=17,18,…,35; количество 19.** Теперь в первой части самый большой x=4, квадрат 16, причём нужно 16<A. Вторая часть не изменилась. Получаем 17 ≤ A ≤ 35, количество 35-17+1=19.
