**Если вопрос — наименьшая или наибольшая сумма при ограничениях на количества или простота суммы, сначала выражают сумму через количества исходных цифр, а потом ищут лучший допустимый состав и строку, которая его даёт.** Такие вопросы встречаются в 3 задачах из 22. Основные задачи и итоговая страница эту подтему не требуют.

Главный пример — однократный проход, который заменяет 3 → 7, 6 → 8, 9 → 3. Как читать такую таблицу, известно из подтемы 2; новое — ограничения на количества и простота.

---

**Однократная замена превращает вопрос о строке в вопрос о трёх количествах.**

Головка стартует в ближайшей пустой ячейке справа, в `q0`; вход — непустая строка из цифр 3, 6, 9:

| Состояние | `λ` | `3` | `6` | `9` |
| --- | --- | --- | --- | --- |
| `q0` | `λ, L, q1` | — | — | — |
| `q1` | `λ, S, q1` | `7, L, q1` | `8, L, q1` | `3, L, q1` |

Пусть во входе a троек, b шестёрок и c девяток. Тогда длина N = a + b + c, а сумма цифр результата

S = 7a + 8b + 3c.

Порядок цифр на сумму и длину не влияет — достаточно перебрать количества a, b, c, а не строки.

---

**Наименьшая сумма при нижней границе — это граница плюс самый дешёвый способ её выполнить; затем нужен пример.**

Пусть во входе встречается каждая из трёх цифр, а нечётных цифр (3 и 9) не меньше пяти. Найдём наименьшее S + N.

S + N = 8a + 9b + 4c. Каждая цифра есть хотя бы раз: a ≥ 1, b ≥ 1, c ≥ 1. Нечётных не меньше пяти: a + c ≥ 5. Шестёрки увеличивают сумму и ничего не дают для условия о нечётных — берём b = 1. Среди нечётных девятка дешевле тройки (4 < 8) — берём a = 1 и c = 4.

S + N = 8 + 9 + 16 = 33. Пример: `369999` → `783333`, сумма 27, длина 6, 27 + 6 = 33.

Меньше быть не может: каждая из пяти нечётных цифр добавляет к S + N не меньше 4, хотя бы одна из них — тройка (8), и шестёрка добавляет 9: 8 + 4 · 4 + 9 = 33.

---

**Наибольшая сумма при ограничении длины — заполнить длину самыми дорогими цифрами, оставив ровно столько, сколько требует условие.**

Пусть длина не больше 10, а нечётных цифр во входе не меньше четырёх. Найдём наибольшее S + N.

Самая дорогая цифра — шестёрка (9 к S + N), но она чётная. Значит, ровно четыре места отдаём нечётным, причём выгоднее тройка (8), чем девятка (4): a = 4. Остальные шесть мест — шестёрки: b = 6.

S + N = 8 · 4 + 9 · 6 = 32 + 54 = 86. Пример: `3333666666` → `7777888888`, сумма 76, длина 10.

---

**Простое число — целое больше 1 с двумя делителями; 0 и 1 не простые, а проверять делители достаточно до √x.**

Простое число — целое число больше 1, у которого только два положительных делителя: 1 и оно само. Поэтому 0 и 1 не являются простыми. Чтобы проверить число `x`, достаточно искать делитель от 2, пока `d · d ≤ x`. Если составное число равно произведению двух множителей, хотя бы один из них не больше квадратного корня: иначе их произведение было бы больше `x`.

```python
def is_prime(x):
    if x < 2:
        return False
    d = 2
    while d * d <= x:
        if x % d == 0:
            return False
        d += 1
    return True
```

{{def|`def`}} создаёт функцию, `return` возвращает результат и завершает вызов. `x % d == 0` означает, что `x` делится на `d` без остатка.

---

**Когда условие требует простую сумму, простоту проверяют для каждой допустимой суммы; угадывать по нескольким запускам нельзя.**

Найдём наименьшую длину входа, в котором есть все три цифры, количество шестёрок чётное, а сумма результата — простое число.

При N = 3 каждая цифра по одной — шестёрок одна, нечётно. При N = 4 шестёрок две, тройка и девятка по одной: S = 7 + 16 + 3 = 26 — составное. При N = 5 шестёрок две, а тройки и девятки — 2 и 1 или 1 и 2: S = 33 = 3 · 11 или S = 29 — простое. Ответ: N = 5, например `36699` → `78833`.

Тот же поиск программой — перебор количеств, а не строк:

```python
for n in range(3, 20):
    found = []
    for a in range(1, n):
        for b in range(1, n - a):
            c = n - a - b
            s = 7 * a + 8 * b + 3 * c
            if b % 2 == 0 and is_prime(s):
                found.append((a, b, c, s))
    if found:
        print(n, found)
        break
```

```output
5 [(1, 2, 2, 29)]
```

Внутренний диапазон `range(1, n - a)` оставляет хотя бы одну девятку: c = n − a − b ≥ 1.

---

**Итого.**

- Однократная замена: длина и сумма результата — линейные выражения от количеств исходных цифр; порядок не важен.
- Минимум при нижней границе: выполнить её самыми дешёвыми цифрами, остальное — по минимуму; максимум при ограничении длины — заполнить самыми дорогими.
- Каждую границу подтверждают строкой, на которой она достигается.
- Простое число больше 1; 0 и 1 не простые; делители проверяют до √x.
- Простоту проверяют для каждой допустимой суммы — рассуждением или перебором количеств.
