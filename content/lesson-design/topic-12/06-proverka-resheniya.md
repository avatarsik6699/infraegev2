**Задание решается рассуждением по таблице; программа-исполнитель нужна, чтобы проверить уже понятный ответ: выполнить ту же таблицу на нескольких словах и сравнить с выводом из подтем 1–5.** Это проверка для всех 19 основных задач, нового типа она не добавляет. Писать универсальную программу на экзамене необязательно: ручной разбор короче.

Главный пример — снова таблица вычитания единицы и слово `10100`: программа должна повторить ручную трассу подтемы 1 — `10011`, головка на 2, четыре такта.

---

**Один такт в программе — те же три действия, что вручную: выбрать команду по паре, записать, сдвинуться.** Самая короткая программа для нашей таблицы — на слове `1010`, чтобы шагов было немного:

```python run tm.py
rules = {
    ('q0', 'λ'): ('λ', 'L', 'q1'),
    ('q1', '0'): ('1', 'L', 'q1'),
    ('q1', '1'): ('0', 'S', 'q1'),
}
tape = {0: '1', 1: '0', 2: '1', 3: '0'}
pos, state = 4, 'q0'
while True:
    write, move, state = rules[(state, tape.get(pos, 'λ'))]
    tape[pos] = write
    if move == 'S':
        break
    pos += -1 if move == 'L' else 1
print(tape[0] + tape[1] + tape[2] + tape[3])
```

```output
1001
```

Пройди её по шагам: каждый проход {{while|цикла `while`}} — один такт, `state` и `pos` меняются так же, как в таблице подтемы 1: вход, ноль хвоста стал единицей, единица — нулём с остановкой.

---

**Ленту удобно хранить словарём «координата → символ»: так работают и отрицательные координаты, и пустые ячейки.**

Обычный список подходит, если заранее известно, сколько свободных ячеек нужно слева и справа. Но в Python индекс `-1` у списка означает последний элемент, а не новую клетку слева. Поэтому прямой запуск с отрицательными координатами легко даёт ошибку.

{{dict|Словарь}} позволяет хранить пары «координата — символ». Например, `{0: '1', 1: '0'}` означает единицу в клетке 0 и ноль в клетке 1. Если координата не записана в словаре, считаем ячейку пустой.

Команда {{dictget|`tape.get(pos, 'λ')`}} читает символ по координате `pos`; если такой координаты нет, возвращает `λ`. Команда `tape[pos] = symbol` записывает символ в эту клетку. Отрицательные координаты работают так же, как положительные.

Правила тоже удобно хранить в словаре. Его ключом будет пара `(state, symbol)`, а значением тройка `(что_записать, движение, новое_состояние)` — {{tuple|кортеж}}.

---

**Универсальная функция выполняет любую таблицу и сообщает об ошибке, а не молча останавливается, если команды нет.**

```python
def run_tm(word, rules, start_pos, start_state='q0',
           max_steps=100000):
    tape = {}
    for i, symbol in enumerate(word):
        tape[i] = symbol

    pos = start_pos
    state = start_state
    steps = 0

    while steps < max_steps:
        symbol = tape.get(pos, 'λ')
        key = (state, symbol)
        if key not in rules:
            raise RuntimeError('Нет команды для ' + str(key))

        write, move, next_state = rules[key]
        tape[pos] = write
        state = next_state
        steps += 1

        if move == 'S':
            return tape, pos, state, steps
        elif move == 'L':
            pos -= 1
        elif move == 'R':
            pos += 1
        else:
            raise RuntimeError('Неизвестное движение')

    raise RuntimeError('Достигнут предел числа шагов')
```

{{enumerate|`enumerate(word)`}} выдаёт по порядку номер символа и сам символ. Поэтому первые четыре строки функции записывают слово в клетки от 0 до `len(word) - 1`.

Каждый проход `while` выполняет ровно один такт. Сначала читаются прежний символ и прежнее состояние и выбирается команда. Затем выполняется запись. При `S` функция возвращает результат уже после записи.

`raise RuntimeError(...)` сообщает об ошибке и прекращает запуск с пояснением. Отсутствующее правило не считается штатной остановкой. Ограничение `max_steps` защищает от слишком долгого запуска; его достижение не означает, что найден ответ или доказан цикл.

```python
rules = {
    ('q0', 'λ'): ('λ', 'L', 'q1'),
    ('q1', 'λ'): ('λ', 'S', 'q1'),
    ('q1', '0'): ('1', 'L', 'q1'),
    ('q1', '1'): ('0', 'S', 'q1'),
}

word = '10100'
tape, pos, state, steps = run_tm(
    word, rules, start_pos=len(word)
)

result = ''
for i in range(len(word)):
    result += tape.get(i, 'λ')

print(result)
print(pos, state, steps)
```

```output
10011
2 q1 4
```

Тот же итог, та же координата 2 и те же четыре такта, что в ручной трассе.

**Если машина дописывает цифры за краями слова, читают весь изменённый фрагмент ленты, а не прежние позиции.**

Здесь можно было читать только прежние пять позиций, потому что именно эта машина не добавляет цифры за их границами. Для машины, которая дописывает цифры, нужно прочитать весь изменённый фрагмент ленты. Возьмём приписывание единицы слева из подтемы 3:

```python
left_rules = {
    ('q0', 'λ'): ('λ', 'L', 'q1'),
    ('q1', '0'): ('0', 'L', 'q1'),
    ('q1', '1'): ('1', 'L', 'q1'),
    ('q1', 'λ'): ('1', 'L', 'q2'),
    ('q2', 'λ'): ('λ', 'S', 'q2'),
}
tape, pos, state, steps = run_tm('10101', left_rules, 5)

left = min(tape)
right = max(tape)
fragment = ''
for i in range(left, right + 1):
    fragment += tape.get(i, 'λ')
print(fragment.strip('λ'), steps)
```

```output
110101 8
```

`min(tape)` и `max(tape)` дают минимальную и максимальную записанную координату. {{strip|`strip('λ')`}} убирает пустые символы только с двух краёв. Если внутри есть `λ`, его нельзя автоматически удалить: это отдельная клетка между данными. Для условий, где нужен один сплошной двоичный блок, сначала убедись, что результат действительно имеет такой вид.

**Гипотезу проверяют на краевых словах: каждое слово проверяет свою часть рассуждения.**

Сопоставь короткий запуск с ручной таблицей, затем проверь характерные случаи. Для машины вычитания это, например, `1`, `0`, `000`, `10101`, `10100`, `1000`. Такие варианты проверяют остановку на единице, остановку на пустой ячейке, нулевой хвост разной длины и сохранение начальных нулей.

```python
for word in ['1', '0', '000', '10101', '10100', '1000']:
    tape, pos, state, steps = run_tm(word, rules, len(word))
    result = ''
    for i in range(len(word)):
        result += tape.get(i, 'λ')
    print(word, result, steps)
```

```output
1 0 2
0 1 3
000 111 5
10101 10100 2
10100 10011 4
1000 0111 5
```

Каждая строка согласуется с подтемой 4: хвост из t нулей даёт t + 2 такта, строка из L нулей — L + 2.

**Формулу проверяют перебором многих чисел: программа сравнивает свой результат с выводом из разрядов.**

Для перевода между числом и словом служат {{base|`bin` и `int(…, 2)`}}:

```python
print(bin(37))
print(bin(37)[2:])
print(int('1001011', 2))
```

```output
0b100101
100101
75
```

`bin` строит двоичную запись с префиксом `0b`. Запись {{slice|`[2:]`}} берёт символы начиная с позиции 2 до конца, убирая префикс. `int(строка, 2)` читает строку как двоичную запись. Эти операции используют для перевода систем счисления, а не для хранения строки с заданными начальными нулями.

Проверим вывод подтемы 3 «единица слева даёт N + 2ᵏ» сразу на числах от 1 до 500:

```python
bad = 0
for n in range(1, 501):
    word = bin(n)[2:]
    tape, pos, state, steps = run_tm(
        word, left_rules, len(word)
    )
    fragment = ''
    for i in range(min(tape), max(tape) + 1):
        fragment += tape.get(i, 'λ')
    value = int(fragment.strip('λ'), 2)
    if value != n + 2 ** len(word) or steps != len(word) + 3:
        bad += 1
print('расхождений:', bad)
```

```output
расхождений: 0
```

Совпадение на 500 числах — проверка, а не доказательство: доказательство дают разряды. Но если бы формула была неверной, расхождение нашлось бы сразу.

---

**Цикл доказывает только повтор полной конфигурации; повтор одного состояния ничего не доказывает.**

Для машины Тьюринга повториться должны одновременно лента, положение и состояние. Повторение только состояния `q1` ничего не доказывает: оно нормально при проходе по длинной строке. Бесконечное движение по пустой ленте вправо может даже не повторять полную конфигурацию, потому что координата всё время меняется.

---

**Итого.**

- Программа повторяет такт: выбрать команду по `(state, symbol)`, записать, сдвинуться; `S` возвращает результат после записи.
- Лента — словарь «координата → символ», пустая ячейка — `tape.get(pos, 'λ')`; отрицательные координаты работают.
- Нет команды — ошибка, а не остановка; предел шагов — не ответ и не доказательство цикла.
- Результат читают по всему изменённому фрагменту, если машина пишет за краями слова.
- Программа проверяет вывод на краевых словах и переборе чисел; доказательство даёт рассуждение.
