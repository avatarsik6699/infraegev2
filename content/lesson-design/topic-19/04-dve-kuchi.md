**В игре с двумя кучами логика стратегии остаётся той же, но позиция теперь состоит из двух чисел.** Именно такие игры были на последних экзаменах. Функции подтемы 3 не меняются: меняются только `moves` и `finished`.

Учебная игра: можно добавить один камень или удвоить одну кучу, игра заканчивается при сумме не менее 20, начальная позиция — (3, S).

---

**Позицию из двух куч записывают парой чисел.** Если в первой куче a камней, а во второй b, записываем (a, b). Например, (3, 8). Если разрешается добавить один камень в одну выбранную кучу или удвоить одну выбранную кучу, есть четыре действия:

(a, b) → (a + 1, b), (a, b) → (2a, b), (a, b) → (a, b + 1), (a, b) → (a, 2b).

**Один ход изменяет одну выбранную кучу.** Если условие не разрешает иное, нельзя за один ход добавить по камню в обе кучи, удвоить обе кучи или сначала изменить первую, затем вторую.

Также неверно считать, что каждый игрок управляет «своей» кучей. **Если по условию каждый может выбрать любую, то и Петя, и Ваня на каждом своём ходе рассматривают все четыре действия.**

---

**В Python пара чисел записывается кортежем, и функции подтемы 3 работают с ним без изменений.** Запись `p = (3, 8)` — {{tuple|кортеж}}: одна запись, которая хранит два значения. Строка `a, b = p` извлекает из неё первое и второе числа: a = 3, b = 8. Правила игры:

```python
def moves(p):
    a, b = p

    return [
        (a + 1, b),
        (a * 2, b),
        (a, b + 1),
        (a, b * 2),
    ]


def finished(p):
    a, b = p
    return a + b >= 20
```

Функции `win1`, `lose1`, `win2`, `lose2`, `after_mistake` менять не нужно. **Они работают с позицией через `moves` и `finished` и не требуют, чтобы позиция была одним числом.**

---

**Позицию из двух куч проверяют так же, как одну кучу: все ходы соперника и хотя бы один свой.** При S = 8 начальная позиция (3, 8). Посмотрим на все первые ходы Пети:

| Ход Пети | Позиция перед Ваней | Победный ответ Вани |
|---|---|---|
| Добавить в первую кучу | (4, 8) | Удвоить вторую: (4, 16), сумма 20 |
| Удвоить первую | (6, 8) | Удвоить вторую: (6, 16), сумма 22 |
| Добавить во вторую | (3, 9) | Удвоить вторую: (3, 18), сумма 21 |
| Удвоить вторую | (3, 16) | Добавить в первую: (4, 16), сумма 20 |

Все ответы Пети дают Ване немедленную победу. Поэтому (3, 8) — `L1`.

Проверим позиции `W2`. При S = 4: (3, 4) → (3, 8) — Петя удваивает вторую кучу и передаёт Ване `L1`. При S = 7: (3, 7) → (3, 8) — Петя добавляет один во вторую кучу. При S = 6: (3, 6) → (6, 6). Позиция (6, 6) тоже `L1`. Действительно, после прибавления единицы получится (7, 6) или (6, 7), откуда соперник удвоит семёрку и получит сумму 20; после удвоения получится (12, 6) или (6, 12), откуда соперник сможет сразу достичь нужной суммы.

---

**Позиция (3, 3) — пример `L2`, где все первые ходы Пети передают Ване `W2`.**

| Первый ход Пети приводит к | Ваня передаёт Пете |
|---|---|
| (4, 3) | (8, 3) |
| (6, 3) | (6, 6) |
| (3, 4) | (3, 8) |
| (3, 6) | (6, 6) |

В правом столбце находятся позиции `L1`. Поэтому после следующего хода Пети Ваня выиграет. Из всех четырёх позиций левого столбца Ваня не может выиграть немедленно. Здесь он гарантирует именно второй свой ход. **Наличие ветки с победой Вани первым ходом не требуется.**

---

**Вопрос о неудачном ходе Пети в двух кучах решается так же: два сильнейших хода подряд.** В нашей игре сильнее всего удвоение большей кучи. Из (3, S) два удвоения второй кучи дают 3 + 4S ≥ 20, то есть S ≥ 4,25, и наименьшее S = 5: (3, 5) → (3, 10) → (3, 20). Из (3, 4) так получается только 3 + 16 = 19. Программа ниже это проверит.

---

**Программа перебирает начальные позиции (3, S) теми же функциями.** Меняются только начальная позиция и диапазон. Почему S от 1 до 16? Начальная игра ещё не закончена: 3 + S < 20, значит, S < 17. Начальные позиции соберём в список пар, а ответом будет вторая куча S — `p[1]`:

```python
starts = [(3, s) for s in range(1, 17)]
print([p[1] for p in starts if lose1(p)])
print([p[1] for p in starts if win2(p)])
print([p[1] for p in starts if lose2(p)])
print(min(p[1] for p in starts if after_mistake(p)))
```

```output
[8]
[4, 6, 7]
[3]
5
```

Программа нашла те же группы, что и ручной разбор, и то же S = 5 для неудачного хода.

---

**Даже если победа зависит от суммы двух куч, одной суммы недостаточно для описания позиции.** Возьмём две позиции с одинаковой суммой 12: (6, 6) и (2, 10). Из (6, 6) после одного хода наибольшая сумма — 18, из (2, 10) — 22, то есть можно сразу выиграть. Причина: **удваивается одна куча, а не общая сумма.** После удвоения большей кучи новая сумма равна a + b + max(a, b), где max(a, b) — большее из двух чисел. Например, для (2, 10): 2 + 10 + 10 = 22.

На сетке всех позиций это видно сразу: позиции с одинаковой суммой лежат на одной диагонали, а группы у них разные.

**Сумма может определять окончание игры, но разрешённые продолжения могут зависеть от распределения камней между кучами.** Поэтому позицию хранят парой, а не суммой.

---

**Меняются только правила: другая проверка окончания или другие ходы — другие `moves` и `finished`.** Если в двух кучах конец определяется суммой, пишут `return a + b >= limit`. В задачах подборок встречаются и другие правила окончания, и это разные игры:

:::pick Когда игра заканчивается и что вернуть
- *Сумма не менее порога | `a + b >= limit` | чаще всего
- Хотя бы одна куча достигла порога | `a >= limit or b >= limit` | «количество камней в одной из куч»
- Обе кучи достигли порога | `a >= limit and b >= limit` | обе одновременно
- Произведение не менее порога | `a * b >= limit` | «произведение количеств камней»
:::

С ходами так же: их перечисляют в `moves` дословно по условию. «Добавить в одну из куч столько камней, сколько их в другой» — это `(a + b, b)` и `(a, a + b)`. «Увеличить первую кучу в два раза, а вторую — в три» — это `(2 * a, b)` и `(a, 3 * b)`, а не четыре одинаковых удвоения. «Добавить один камень в одну кучу и два в другую» — `(a + 1, b + 2)` и `(a + 2, b + 1)`: здесь один ход меняет обе кучи, потому что так сказано в условии.

---

**Итого.**

- Позиция из двух куч — кортеж `(a, b)`; ход меняет одну выбранную кучу, если условие не говорит иначе.
- `moves` перечисляет ходы дословно, `finished` — проверку окончания; проверки `win1`, `lose1`, `win2`, `lose2` не меняются.
- Одинаковая сумма не делает позиции равнозначными: важно, какую кучу можно удвоить.
- Диапазон S следует из того, что начальная игра ещё не закончена.
